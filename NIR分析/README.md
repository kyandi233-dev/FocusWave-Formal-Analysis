# NIR 分析

本模块以当前 `fullclass-final` 瞳孔输出为事实起点，不再使用已经淘汰的“320×160 分析层”表述。当前来源与 27 个场次级标识预检见 [1-当前生产管线与 27 场次来源预检](1-当前生产管线与27场次来源预检.md)，候选指标和亮度前置审计见 [1.1-瞳孔候选指标与亮度前置审计实现方案](1.1-瞳孔候选指标与亮度前置审计实现方案.md)，031 主几何紧凑验证见 [1.2-拓扑主几何紧凑验证说明](1.2-拓扑主几何紧凑验证说明.md)。031 的正式主几何已冻结为拓扑规则版本，其他几何只做紧凑方法对比。首先建立 031、032、033 与历史 YOLO 输出的逐场次权威来源表并统一字段结构；然后在当前/上一刺激亮度、对比度、刺激大小、时间进程、重复场次和质量覆盖等控制下，比较瞳孔原始水平、基线变化、被试内变化和动态特征。PIR 相关旧脚本保留，但只有在明确、验证过的虹膜几何来源存在时才可进入候选比较。

当前阶段仅放行 27 个场次级标识的工程来源预检，不将其解释为 27 名参与者或 44 场次正式完成；在来源唯一性、schema（字段结构）兼容、身份冻结、质量分轨和瞳孔-only 适配器通过前，不放行正式统计或跨模态融合。
