当前生产提取已完成44/44，全部44个场次均有可供下游读取的生产输出；这不等于44场次的瞳孔测量效度、质量控制或正式统计通过。此前27个场次级标识的来源预检，以及031、032、033和历史YOLO b8四个场次级标识的PR27瞳孔-only隔离式真实复跑，均保留为历史/工程证据，不再作为当前生产完成度口径。当前正式样本口径为44个session、38个当前队列匿名参与者分析组，其中6个双场重复组涉及12个session。NIR输出与来源manifest保持场次级；模型和交叉验证必须在后续联结数据区现有匿名映射后按38组分组，不能把session数写成参与者数，也不在Git文档中展开具体匿名组键。

当前身份联结依据为E2姓名主匹配，但不由姓名单字段单独决定身份；手机号/学号必须精确交叉核验，并由Q3匿名键独立复核。旧R2 corrected registry仅覆盖31/44，作为敏感性辅助。13个R2外场次属于当前队列单场分析组，不是完全未知。`subid`、`subject_id`和`experiment_id`是session键；`presence`只表示模态输出存在性，不是签到。未来约72场接入时必须全量重建映射，当前38组不是永久全球身份。
