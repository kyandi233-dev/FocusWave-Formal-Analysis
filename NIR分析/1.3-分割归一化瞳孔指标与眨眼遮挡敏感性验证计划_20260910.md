# 分割归一化瞳孔指标与眨眼/遮挡敏感性验证计划

> 日期：2026-09-10
> 状态：`candidate_validation_plan`；尚未冻结为正式 NIR 主指标
> 目标变量：`seg_pupil_fraction_within_pupil_iris`
> 现有正式主线：`pupil_geom_mean_diameter`（瞳孔几何平均直径）及当前 pupil-only（仅瞳孔）正式轨道保持不变

## 一、研究目的

本计划新增一个 segmentation-normalized pupil metric（分割归一化瞳孔指标），用于检验基于瞳孔和虹膜分割比例构造的相对指标，是否能在不依赖绝对像素尺度的情况下保留与注意状态和行为有关的信息，并评估其是否容易被眨眼、眼睑遮挡、偏眼/偏头造成的可见虹膜变化及分割边界错误污染。

本轮不把该指标称为传统 PIR（pupil-to-iris ratio，瞳孔-虹膜直径比），也不做平方根变换。传统 PIR 需要独立、经过验证的虹膜几何直径；当前 fullclass-final 中的 `hard_iris_fraction` 是分割类别比例，不能直接解释为虹膜直径。

## 二、候选指标定义与前置契约

候选指标定义为：

\[
seg\_pupil\_fraction\_within\_pupil\_iris
=
\frac{hard\_pupil\_fraction}
{hard\_pupil\_fraction+hard\_iris\_fraction}
\]

仅在以下前置条件得到 producer（生产器）代码核验后允许计算：

1. `hard_pupil_fraction` 与 `hard_iris_fraction` 来自同一帧、同一眼、同一 analysis domain（分析区域）和同一有效像素分母；
2. 两者是互斥或语义明确的分割类别比例，且不存在重复计数；
3. 分母 `hard_pupil_fraction + hard_iris_fraction` 有限且大于 0；
4. 原始字段缺失、来源缺失或质量失败时不做 0 填充或跨帧插补。

若 producer 核验发现两个 fraction（比例）的分母定义不同，则停止该公式实现，先修正语义契约，不用现有字段强行生成结果。

## 三、需要写的 test（测试）

这里的 test 分为两层：代码契约测试和数据敏感性验证。前者验证“算得对不对”，后者验证“这个指标是否真的适合作为心理学分析变量”。

### 3.1 代码契约测试

至少新增以下单元/回归测试：

| 测试 | 检查内容 | 通过标准 |
|---|---|---|
| 公式正确性 | 已知 pupil/iris fraction 输入能否得到预期比例 | 数值与手算一致 |
| 公共尺度不变性 | pupil 与 iris 同时乘相同常数 | 指标保持不变 |
| 类别边界转移敏感性 | 固定 pupil+iris 总量，把部分 iris 转为 pupil | 指标应发生相应变化，避免误以为边界错误会自动抵消 |
| 零/无效分母 | pupil+iris=0、NaN、Inf | 输出缺失/失败状态，不生成伪值 |
| 缺失传播 | pupil 或 iris 任一来源缺失 | 不插补为 0，不生成正式值 |
| 眼别/帧键一致性 | 左眼、右眼、帧时间键 | 不跨眼、不跨帧拼接 |
| 原正式字段不变 | 新派生指标加入后 | `pupil_geom_mean_diameter` 等原正式输出完全保持 |

### 3.2 数据敏感性验证

敏感性验证不先设“高于某阈值就删掉”的新门槛，而是先描述异常帧和窗口级指标之间的关系。主要检查：

1. 新指标的可计算率、分母分布和极端值分布；
2. 新指标与 `pupil_geom_mean_diameter` 的帧级/窗口级关系；
3. 新指标与现有 QC（质量控制）代理变量的关系，包括 pupil fit invalid（瞳孔拟合无效）、fragmentation（碎片化）、analysis valid pixel fraction（分析有效像素比例）、temporal anomaly（时序异常）等当前可用字段；
4. 左/右/双眼及 primary/strict（主/严格）轨道下结果是否一致；
5. 视觉刺激亮度、RMS contrast（均方根对比度）、刺激尺寸和可见面积是否仍与新指标存在明显关系。

## 四、眨眼与眼睑遮挡的专项验证

当前正式 NIR 管线没有经过验证的 blink detector（眨眼检测器），因此本轮不声称能够准确识别每一次眨眼。先利用现有质量字段和短时跳变特征做“眨眼/遮挡敏感性审计”，目的在于判断窗口内 variability（变异性）是否主要由少数异常帧驱动。

### 4.1 30 s 窗口内比较的变异指标

每个正式 probe-pre 30 s（探针前 30 秒）窗口至少同时计算：

| 指标 | 作用 |
|---|---|
| SD（标准差） | 与当前常用变异指标保持可比，但对极端帧敏感 |
| MAD（中位数绝对偏差） | 对少量极端跳变更稳健 |
| IQR（四分位距） | 描述中间 50% 波动，对异常值不敏感 |
| QC 标记帧比例 | 判断窗口是否含较多拟合/时序/有效像素异常 |
| 高分位瞬时变化幅度 | 识别少数突发跳变是否主导 SD；只作审计，不作心理学主指标 |

### 4.2 判断逻辑

若 SD、MAD、IQR 对 Q1/Q2 或行为的方向与主要结论一致，且效应不依赖高 QC 标记帧窗口，则支持真实瞳孔变异解释。若只有 SD 显示明显效应，而 MAD/IQR 不支持，同时 SD 与异常帧比例或瞬时跳变高度相关，则应优先解释为眨眼/遮挡/分割异常敏感性问题，不把 SD 直接解释为生理性瞳孔波动。

对于 `seg_pupil_fraction_within_pupil_iris`，还要特别检查眼睑遮挡导致可见 iris（虹膜）面积减少、而 pupil（瞳孔）面积相对保存时的比例上升。该现象不会被共同尺度归一化自动消除。

## 五、正式分析复用范围

在前置 producer 契约通过后，新指标尽量复用当前 NIR 的窗口和统计结构：

- 主窗口继续为 probe-pre 30 s；10 s/20 s 仅按当前正式规则作为敏感性窗口；
- 保留 level（水平）、variability（变异性）和 trend（趋势）三类紧凑特征思想，但每项是否进入监督学习仍需后续冻结；
- Q1、Q2、行为关系和视觉混杂分析沿用现有模型结构，不因新增指标而另起一套统计逻辑；
- 不改写原 pupil-only 主线，不删除原几何直径结果；新指标先作为 candidate/sensitivity（候选/敏感性）轨道。

## 七、放行条件

该指标只有在以下条件满足后，才可进入后续正式候选特征审查：

1. producer 代码确认 pupil/iris fraction 使用同一分析分母；
2. 代码契约测试全部通过；
3. 正式队列上不存在大规模不可计算或明显边界异常；
4. 结果不主要由 QC 异常窗口、眨眼/遮挡代理或单一 SD 异常敏感性驱动；
5. 与原几何指标相比，其增益、冗余和稳定性有可解释证据；
6. 不把该指标重新命名或解释成传统 PIR。
