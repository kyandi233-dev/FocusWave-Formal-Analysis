# 毫米波分析

本模块当前入口为 [1-当前管线与 44 场次输入审计](1-当前管线与44场次输入审计.md)、[1.1-单场次试跑与质量门验证](1.1-单场次试跑与质量门验证.md) 和 [1.2-后续样本合并与复现契约](1.2-后续样本合并与复现契约.md)。阶段 0 已核验当前队列为 44 个场次、38 个匿名分析组，其中 6 个双场重复组；毫米波可加载队列为 39 个场次、33 个匿名分析组，仍包含 6 个双场重复组。`sub-036`、`sub-038`、`sub-040`、`sub-041` 为 32 字节 `.bin` 加 0 字节 timestamps 的无效占位，`sub-047` 目录为空，不能静默纳入可加载数据。

本模块先完成当前 44 场次的 HR、RR/BR、质量覆盖和行为对齐审计，输出 schema 固定、可与后续约 72 场次直接纵向拼接的 merge-ready（可合并）行级表和 manifest。HR、RR、IBI/HRV 的“能计算”“通过工程 QC”“通过外部生理验证”“可进入报告”是不同状态。RGB motion gate 只生成附加标记和敏感性副本，不覆盖原始毫米波输出；当前未放行 44 场次批量生产或正式生理结论。
