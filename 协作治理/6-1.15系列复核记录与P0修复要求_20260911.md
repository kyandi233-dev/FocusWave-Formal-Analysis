1. **参与者级计分规则**：一个参与者有多个 probe，如何合成参与者得分未定义。可选方案至少包括 probe 概率平均、多数投票、加权平均，三者在类别不均衡下结论可能不同；

`reporting.py` 的校验覆盖行数一致、折审计条数一致、失败键一致，属归档完整性校验，不涉及计分与不确定性。

**期望行为**

**影响范围**

参与者级推断无法进行。以参与者为单位的效应量与区间估计缺乏定义，跨参与者的性能差异无法量化。

**验收条件**

1. 参与者级计分与加权规则在正式口径文档中显式冻结；
2. 不确定性方法选定并实现，输出含区间估计；
3. 增加测试：给定已知逐 probe 预测与参与者归属，参与者级得分与区间可复现。

## 7. NIR 生产端分母核验结论

《NIR问题.txt》要求先追溯 AMD/fullclass-final 生产代码，确认 `hard_pupil_fraction` 与 `hard_iris_fraction` 的像素分母。**核验已完成。**

### 7.1 已核验的代码位置

| 文件 | 作用 |
|---|---|
| `runtime/nir-formal/ritnet_fullclass_metrics.py` | 四类分割分数的实际计算处 |
| `runtime/nir-formal/ritnet_fullclass_contract.py` | 冻结的类别映射与版本号 |
| `runtime/nir-formal/run_pipeline.py` | 单被试运行入口 |
| `src/attention_pipeline/nir_pupil_only/adapter.py` | NIR 消费端适配器 |

### 7.2 分母结论

`ritnet_fullclass_metrics.py::_assemble_result` 中：

```python
total_pixels = analysis_w * analysis_h            # 默认 320 × 160 = 51200
background_fraction   = counts[CLASS_BACKGROUND] / total_pixels
sclera_fraction       = counts[CLASS_SCLERA]     / total_pixels
iris_fraction         = counts[CLASS_IRIS]       / total_pixels
pupil_fraction        = counts[CLASS_PUPIL]      / total_pixels
iris_outer_fraction   = (counts[CLASS_IRIS] + counts[CLASS_PUPIL]) / total_pixels
```

并在函数末尾断言四类像素数之和等于 `total_pixels`：

```python
if (background_pixels + sclera_pixels + iris_pixels + pupil_pixels) != total_pixels:
    raise AssertionError("RITnet class counts do not sum to the analysis frame size")
```

**判定：`pupil_fraction` 与 `iris_fraction` 来自同一帧、同一眼、同一 analysis domain、同一分母，四类互斥不重复计数。NIR 1.3 放行条件 1「producer 代码确认 pupil/iris fraction 使用同一分析分母」在字面上成立。**

### 7.3 两处文档未覆盖的缺陷

**缺陷 A — padding 未排除**

`analysis_valid_pixel_fraction` 与 `predicted_in_padding_fraction` 是**并行独立的 QC 字段**，从未参与分母构造。若 RITnet 输入做了 letterbox 填充，填充像素计入 `total_pixels`，会同时压低两个 fraction 的绝对值。

对 `seg_pupil_fraction_within_pupil_iris` 而言，分子分母同乘公共因子，**比值对 padding 近似不变**——但该近似依赖填充比例在 pupil 与 iris 上完全一致。在 `roi_clipped` / `touches_roi_edge` 为真的帧上，填充会不均匀地吃掉 iris 类像素，比值被系统性抬高。`normalization_valid` 保护的是几何归一化路径，**不保护 fraction 比值路径**。

**缺陷 B — 字段命名存在生产版本断裂**

- `hard_pupil_fraction` / `hard_iris_fraction` 属 **fullclass-final** 阶段命名；
- 当前 `ritnet_fullclass_contract.py` 声明 `EXTENSION_VERSION = "ritnet-fullclass-v1.2-fast-qc"`；
- `run_pipeline.py` 全文**不含** `hard_*` 任何字段，当前输出的是 `pupil_fraction` / `iris_fraction` / `iris_outer_fraction`；
- `nir_pupil_only/adapter.py` 将 `hard_pupil_fraction` / `hard_iris_fraction` / `soft_pupil_fraction` / `soft_iris_fraction` 与其他字段并列声明为透传字段。

**仓库中没有 `hard_*` → 当前字段的显式映射层。** 若直接按 NIR 1.3 文档的公式实现，消费端存在读到全空列的风险。

**另需明确语义**：生产端 `iris_fraction` 是**纯虹膜类比例**，`iris_outer_fraction` 才是虹膜+瞳孔。NIR 1.3 公式中的"虹膜"若指外虹膜环，应取 `iris_outer_fraction` 再减去 pupil，需写明。

### 7.4 放行条件评估

| 项 | 状态 | 需要的动作 |
|---|---|---|
| 同分母 | 成立 | 无 |
| padding 排除 | 未处理 | 明确是否排除；若不排除，给出 `roi_clipped` / `touches_roi_edge` 帧的排除或分层规则 |
| 字段名映射 | 缺失 | 在 NIR 1.3 中补 `hard_*` → 当前字段的映射表，并指明取自哪个 `EXTENSION_VERSION` |
| `iris_fraction` 语义 | 待明确 | 明确"虹膜"取 `iris_fraction` 还是 `iris_outer_fraction - pupil_fraction` |

### 8.5 双轨设计

**轨 1：原始 NIR 质量轨（主轨，保持不变）**

- 输入：全部 NIR 有效帧，不剔除眨眼；
- 主信号：`pupil_geom_mean_diameter`；
- 窗口：probe 前 30 s，严格 `[probe-30s, probe)`；
- 特征：level（mean/median）+ variability（sd / mad / iqr）+ trend（`robust_binned_slope_per_sec`）。

**轨 2：RGB 眨眼掩蔽敏感性轨（附加轨，仅敏感性）**

1. 两轨都保留、都输出，不得互替；

## 9. R_seg 方法学定位

`seg_pupil_fraction_within_pupil_iris` 的定位须写成明确表述，避免误读：

1. 它是 **segmentation-normalized relative indicator（分割归一化相对指标）**，**不是** PIR（pupil-to-iris ratio，瞳孔-虹膜直径比）；
2. **不做平方根变换**。平方根变换是传统 PIR 为把面积比拉回直径尺度而设；本指标没有独立验证过的虹膜几何直径，套用会制造一个无物理意义的量；
3. 它**不能**取代 `pupil_geom_mean_diameter` 成为 NIR 主信号，只能作为独立敏感性指标；
4. 它**不得并入 Task D 的 `feature_schemes`**。D 分支配置已明文禁止，与《NIR问题.txt》的边界要求一致；
5. 规模不变性（scale invariance）只在有限条件下成立：**分母共同尺度可约，但眼睑遮挡导致可见虹膜面积减少、瞳孔面积相对保留时，比值会被抬高，且该抬升不会被共同尺度归一化自动消除。** 这正是 NIR 1.3 §4 专项验证要检查的现象。
