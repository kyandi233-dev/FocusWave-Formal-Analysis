# 正式报告对话交付规则更新

日期：2026-08-29

自本记录起，正式报告章节仍按分步方式完成，但完整正文与完整章节参考文献目录只写入 `正式报告/章节草稿/`，不再在聊天窗口中重复输出。

每轮报告写作完成后，对话回复只需总结：

1. 修改或新增了哪些 GitHub 文件；
2. 本轮写了哪些内容、解决了哪些结构或证据问题；
3. 查阅和核对了哪些项目内资料与外部文献；
4. 采用了什么组织逻辑，以及为何这样组织；
5. 存在哪些证据边界、旧稿冲突或暂不能下结论的问题；
6. 哪些具体内容需要用户人工审阅、确认或决定。

除用户明确要求查看正文片段、对照版本或参考文献细节外，不在聊天中重复粘贴完整章节。该规则已同步写入 `正式报告/2-章节融合工作要求.md`。
