### 3.3 当前行为

### 3.4 期望行为

### 4.3 当前行为

D→B 的失败是条件性失败链，首道关卡不是 `analysis_group_token`。

D 按自己的合同输出 `PROBE_ID_COLUMNS = (participant_group_id, session_id, block_num, probe_index_global)`（`supervised_probe_table.py:21-26`）。其中 `probe_index_in_block`、`probe_event_id` 在输入存在时会被透传（同文件 `:200-210`，`if optional in probe.index`），并非绝不提供。

首道关卡：D 的键进入 B 的 `load_modality_table` 后，命中 `alignment.py:147-148`——`_PROBE_INDEX_ALIASES["nir"]` 要求 `probe_index_in_block`，而 D 的必需键是 `probe_index_global`，于是追加 `nir_missing_probe_index_column:probe_index_in_block` 并返回空表。

第二道关卡：若 D 侧补齐了 `probe_index_in_block` 但无 `block_num`／`block_id`，则命中 `:154-156` 的缺块列路径，同样返回空表。

第三道关卡：若两侧键齐备，该规范化路径可以返回数据。B 的归档适配器 `_probe_index_from_task_a`（`prediction_archive.py:52-60`）的优先级为 `probe_index_in_block` → `probe_order_in_block` → 正则 `\|probe\|(\d+)$` 解析 `probe_event_id`，即优先读块内序号，最后才解析 event_id。

第四道关卡：A 侧 `REQUIRED_PROBE_LOCATORS = (session_id, block_id, probe_event_id)`（`runner.py:23`），`probe_event_id` 为必需列，而 D 的 `PROBE_ID_COLUMNS` 不含它，这构成第二条独立断点。

关于 `analysis_group_token`：该列仅在 `_canonical_group`（`alignment.py:95-97`）中被读取，NIR 分支在第 142–145 行用它合成 `participant_group_id`。该列缺失不会先于键检查报错。外来复核 6.4 称 D 最小键直接进入 B 的规范化路径可能先报 `analysis_group_token` 缺失，该顺序不成立。

语义差异须单独注意：`probe_index_in_block`（块内序号）与 `probe_index_global`（全局序号）语义不同，仅改名无法对齐。

### 4.4 B 与 D 的耦合方式

两个任务分支不直接消费彼此的输出，而是通过一份中间文件解耦：

```python

_INPUT_PATHS["nir"] = "NIR/11_analysis_tables/probe_pupil_models/probe_pupil_model_table.csv"
```

B 读取的是 `probe_pupil_model_table.csv`，该文件由 D 侧流水线生成。因此键不一致同时存在于两侧：生产侧（D 写出的列名）与消费侧（B 声明的别名表）。修复须同时锁定这份中间文件的列 schema，仅改一侧仍会失败。当前 `tests/test_task_b_analysis_set_audit.py` 的全部数据由 `_tables()` 手工构造，从未经过这份中间文件的真实 schema，故键缺口不可被现有测试发现。

### 6.5 为什么不能简单地把参与者内概率平均

当前预测对象是每个 probe 的窗口状态，同一个人的 Q1 可随 probe 改变，参与者并非一个固定的人类标签。数学反例如下：真实标签 `y = [0, 1]`，两组预测

| 预测 | 组内平均概率 | 平均 log loss |
|---|---|---|
| `[0.01, 0.99]` | 0.50 | 0.01005 |
| `[0.99, 0.01]` | 0.50 | 4.60517 |

两组平均概率相同，性能相差两个数量级。把该人的概率平均或多数投票成一个类别，不能替代性能评价。

### 6.6 建议的主评价方案

以下为方法建议，待研究负责人确认，不得直接冻结。

1. 每个 held-out probe 先以其自身真实标签与预测概率计算误差；
2. 在每位参与者内平均误差：`L_i = mean_j loss(y_ij, p_ij)`；
3. 主汇总 `L = mean_i L_i`（参与者等权）；另给按 probe 数加权的汇总作为补充；
4. M0 与 M1 在同一成员集合上计算配对增量 `Δ_i = L_i(M0) − L_i(M1)`，再汇总；
5. 以参与者为簇重采样，直接采用 `science` 段已写定的 1000 次与种子 `20260830`；固定 OOF 预测下的 bootstrap 只描述该重采样下的不确定性，不含完整重训练变异；
6. AUROC 等非可加指标单独定义汇总；单类参与者的 AUROC 不可估计，不得静默记 0.5；
7. 训练权重、内层选择评分、外层报告权重分开冻结。改动训练权重或内层目标须完整重训；仅增加预定的最终汇总可消费已有折外预测。
