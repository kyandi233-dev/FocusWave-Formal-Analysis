# 行为分析

本模块保留试次级原始事实、探针窗口/周期/区块/场次二级指标以及注意水平候选定义。当前工程审计见 [1-现有管线与指标资产审计](1-现有管线与指标资产审计.md)，BB 小样例和多尺度冻结条件见 [1.1-多尺度行为指标试跑与冻结条件](1.1-多尺度行为指标试跑与冻结条件.md)。既有 12 项探针窗口特征只是可复用工程特征集，不等于完整行为指标体系。RT 水平、离散程度、变异系数和斜率可以在窗口、区块和场次尺度分别计算；d′、c 和 β 也不是固定属于某一尺度，但只在 Go/No-Go 机会数足够时估计。重复场次始终嵌套在参与者内处理。

当前状态为 BB 工程试跑，未启动 44 场次正式统计；旧 BBB 输出和图表仅作为方法溯源，不代表当前 BB 结果，也不进入正式报告结论。
