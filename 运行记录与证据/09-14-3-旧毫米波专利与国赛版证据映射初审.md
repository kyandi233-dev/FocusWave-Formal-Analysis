## 2. 当前国赛版必须作为专利改版依据的事实

### 2.1 正式系统与分析已经超出旧毫米波单案

当前 Formal 权威入口显示：正式 LOSO 监督学习、冻结特征登记、设备组合评价和概率诊断已经完成；行为、眼部、动作和心肺均进入共同事件/探针窗口体系。当前主要科学结论不能简化为“毫米波可直接测专注”。

Formal 结果中：
- 行为参照的 participant-macro AUROC 约 `0.7060`；
- 眼部约 `0.5683`；
- 仅传感联合约 `0.5560`；
- 动作约 `0.4569`；
- 心肺单独约 `0.4691`，区间包含 0.5；
- 行为基础上加入心肺的对数损失改善区间包含 0。

因此旧标题中“毫米波非接触专注状态测评系统”若被理解为“毫米波单独已经建立可部署专注测量能力”，会超过当前正式证据。更稳妥的发明主题应把毫米波部分聚焦于“测量可信性/异常判定/拒绝输出”，把国赛新增的多模态测评系统作为独立候选案继续查新。

### 2.2 当前毫米波 canonical 边界

`greenboo26/focuswave-multimodal-attention-analysis@main` 的历史账本已把 mmWave estimator improvement line 收口为：
- `MMWAVE_ESTIMATOR_IMPROVEMENT_V1 = NO_STABLE_IMPROVEMENT`；
- HR/BR = `HOLD / SUPPORTING_ONLY`；
- HRV = `BLOCKED`；
- 新的 C1/C2 改进候选因正式 cohort 从设计上没有 ECG 而 `PAUSED_PENDING_NEW_COLLECTION`。

这说明当前毫米波成果应区分：
1. 已实现且可追溯的 producer/质量与异常机制；
2. 已观察但未完成独立验证的生理准确性；
3. 不得扩张到“毫米波独立准确测专注”。

## 3. 旧案七项技术点的第一轮映射

### T1 分层可信性判定

**当前状态：`SUPPORTED_CONCEPTUALLY / NEED_LOCAL_CLAIM_AUDIT`。**

当前 canonical 毫米波链存在 confidence、time/frequency 分支、一致性与 anchor 决策，以及对估计器失败/偏差机制的系统审计；正式多模态层也明确区分 measurement/QC status、coverage、time-legality 和是否可进入模型。

因此“分层可信性判定”作为工程思想仍与当前系统一致。但旧权利要求具体分几层、各层输入与输出是什么、阈值是否来自历史诊断，必须读取 `01_权利要求书` 与 `02_说明书` 后才能判断是否可继续保留原措辞。

### T2 拒绝输出预定标识

**当前状态：`POTENTIALLY_STRONG / NEED_IMPLEMENTATION_EVIDENCE`。**

国赛版最值得保留的原则之一是：质量条件不满足时不能把不可估计状态伪装成有效数值。Formal 设备组合逻辑要求“没有取得资格的冻结特征”时配置不可用，而不是构造空模型或占位性能。

但“预定标识”是否在当前毫米波 producer 中实际编码、以什么字段/枚举表示、触发规则是什么，目前未从 canonical repo 命中对应实现。因此该点不能仅凭旧 AI 文稿宣称已实现，需对本地专利脚本和旧实现逐项核对。

### T3 保持缺失

**当前状态：`SUPPORTED_AS_FORMAL_SYSTEM_RULE / CLAIM_SCOPE_NEEDS_REWRITE`。**

当前国赛方法明确把模态 availability 与总体 cohort membership 分开；设备或来源缺失不应反向篡改总体队列，也不能把 missing 解释为 zero。该原则在 Ocular 等模块已经正式采用。

对毫米波旧案而言，“保持缺失”如果只是数据治理规则，单独专利性较弱；如果它与“可信性判定→拒绝输出→下游禁止消费→可用配置变化”形成技术链，则更值得作为组合限定，而非孤立创新点。

### T4 判据 P：通道间相位差帧间波动率

**当前状态：`NOT_VERIFIED_IN_CURRENT_CANONICAL`。**

当前 main 可确认存在 phase 相关处理、相位解缠、phase/QC 字段及多通道机制审计，但本轮代码检索没有找到“通道间相位差帧间波动率”作为当前正式冻结判据的直接实现或合同。

因此该点目前只能视为旧案候选技术事实。需要本地 37 文件中的公式、定义、实验数据和对应代码位置，才能判断它属于：
- 当前有效实现；
- 历史诊断特征；
- 专利撰写时抽象出的未落地规则。

在核清前，不应把它作为独立权利要求的关键限定。

### T5 单 bin 尖峰

**当前状态：`NOT_VERIFIED_IN_CURRENT_CANONICAL`。**

当前毫米波链确实围绕 range bin、目标选择、谱峰和 target selection 做过大量审计，但本轮没有找到名为“单 bin 尖峰”且已正式冻结的可信性判据。

旧案如果把“单 bin 尖峰”写成核心判据，需要确认：
- 它的数学定义；
- 与邻近 bin/多通道的比较方式；
- 是否直接进入 reject/keep 决策；
- 是否有真实正反样本支持。

未完成以上核对前标记为 `UNVERIFIED_LOCAL_ONLY_CANDIDATE`。

### T6 误差同号性

**当前状态：`HISTORICAL_DIAGNOSTIC_LIKELY / NOT_CURRENT_FORMAL_GATE`。**

当前历史账本存在对 HR 误差 bias、paired improve/worsen、不同算法分支误差方向的系统比较，但没有找到“误差同号性”作为当前正式运行所需的在线判据。

如果该判据需要 ECG/RSP 参考才能计算，则更应谨慎：正式 FocusWave cohort 从实验设计起就没有 ECG，只有少量校准数据。因此“误差同号性”可以作为校准/验证证据，但不能自然地写成部署时实时可信性判据，除非旧案定义的是不依赖外部金标准的内部同号性。

### T7 谐波折叠 / 锁半频

**当前状态：`STRONGLY_SUPPORTED_AS_TECHNICAL_PROBLEM + PARTIALLY_IMPLEMENTED_AS_EXISTING_MECHANISM`。**

这是七项里当前证据最清楚的一项。

既有校准记录明确观察到：任务段 HR 出现明显半频锁定，BR 也存在类似问题，且不能由简单体动或距离单元跳变解释；当时已经决定后续必须处理呼吸谐波和主频谐波判别。

当前 canonical producer/history 也确认存在 half/double fold 的 harmonic handling；但历史审计同时记录某些正式 probe 中 `time_harmonic_folded_30s=False`，说明“存在折叠机制”不等于“当前所有错误都已被该机制解决”。

因此专利中可以保留“检测/处理谐波折叠或半频锁定”这一技术问题和处理链，但不得写成“已彻底消除锁半频”或“已证明 HR/BR 准确”。

## 5. 对旧标题的当前判断

旧标题：`一种毫米波非接触专注状态测评系统及其可信性判定方法`。

当前不建议立即废弃，但建议进入 `TITLE_REVIEW_REQUIRED`：

- “可信性判定方法”与现有证据一致，且可能是旧案真正的技术核心；
- “毫米波非接触专注状态测评系统”过宽，容易被理解为毫米波自身已具备稳定专注测量能力，与当前 Formal 结果不完全相符；
- 更稳妥的改版方向可能是“毫米波生理状态估计/测量结果的可信性判定与拒绝输出方法”，再把“用于持续注意测评系统”放在用途或从属结构中；是否改名必须等 37 文件 claims-first 审计后决定。

## 6. 国赛版新增专利方向与旧案的关系

当前更适合新案而不是硬塞进旧案的技术链：

`事件锚定的严格前序窗口`
→ `多设备真实依赖`
→ `每项特征的 preprocessing/QC/time-legality/coverage`
→ `不可估计时保持缺失/拒绝进入配置`
→ `根据可用特征生成实际设备配置和对应预测`
→ `同时报告预测性能与覆盖/失效条件`。

该方向回答的是“系统如何只在测量与时间条件合法时形成可解释的多模态测评结果”，与旧案的“毫米波单通道内部可信性判定”层级不同，初步建议独立作为国赛版新案候选。
