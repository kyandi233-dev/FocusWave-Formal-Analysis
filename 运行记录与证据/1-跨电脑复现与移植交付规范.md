# 跨电脑复现与移植交付规范

## 一、目标

本项目的“可复现”不是复制当前电脑的绝对路径，而是使另一台电脑或新接手者在准备好同等输入后，能用同一版本的代码、参数、字段结构和质量门生成可核对的中间表、图表和报告结果。

## 二、交付包必需内容

| 类别 | 必需内容 | 约束 |
|---|---|---|
| 代码 | 每个模态唯一运行入口、通用分析入口、画图入口和报告表生成入口 | 不在报告目录复制第二份源码；在权威 Git 仓库保存 |
| 环境 | 锁定依赖文件、解释器版本、操作系统与硬件要求、导出的实际包版本 | 不根据环境文件夹名称猜解释器 |
| 路径 | 可提交的路径模板与本机私有路径配置 | 程序不写死 `D:`/`E:` 路径；私有配置不提交 |
| 输入 | 参与者—场次清单、重复参与者映射、各模态来源映射、输入文件校验值 | 原始数据不打包进 Git；使用匿名标识 |
| 字段结构 | 试次、探针、窗口、区块、场次和融合表的字段字典，主键、单位、缺失码、状态码和版本 | 列不一致时停止合并，不静默填补 |
| 配置 | 时间窗、质量门、候选指标、模型、分组交叉验证和图表清单 | 科学参数改变必须升版本，不能只改本机配置 |
| 运行记录 | 仓库与提交版本、参数摘要、开始/结束时间、输入/输出校验值、警告、失败与重试 | 每次运行不可覆盖前一次记录 |
| 测试 | 环境预检、小样例快速测试、字段结构测试、唯一键测试、时间对齐测试和重复参与者泄漏测试 | 快速测试通过后才能批量运行 |
| 小样例 | 去身份化的最小输入与预期输出摘要 | 不含原始人脸、身份表或大体积原始数据 |

## 三、新增被试和跨电脑的标准流程

1. 安装已验证的解释器和依赖，运行环境预检。
2. 在本机路径配置中声明原始数据、派生数据、模型和输出根目录。
3. 向参与者—场次清单追加新数据，不在程序中硬编码“44”或“72”。
4. 运行来源和时间轴审计，生成待处理清单。
5. 以小样例和一个新场次运行快速测试，确认列、单位、时间键和质量状态。
6. 按场次逐个运行，增量保存中间表和失败记录，支持从中断处续跑。
7. 把各模态“可合并表”按同版本字段结构追加，重新生成全样本冻结和参与者分组折。
8. 重新拟合模型和生成图表；不平均两批数据各自的 p 值或预测性能。

## 四、产物层级

1. 生产器原始输出：尽可能保留可追溯的观测和质量字段。
2. 标准化表：统一列名、单位、时间和身份键。
3. 分析就绪表：根据明确的质量规则生成，保留拒绝原因。
4. 可合并表：供后续被试与跨模态追加。
5. 聚合安全结果：报告表、图和不含敏感行级数据的摘要。

上述层级之间不覆盖，每层保存来源、输入版本和输出校验值。
