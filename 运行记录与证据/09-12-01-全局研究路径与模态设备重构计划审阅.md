## 审阅结论

重构方向合理且必要。科学模态按 Behavior / Ocular / Movement / Cardiopulmonary 组织，设备按 RGB / NIR / mmWave 记录；校正依赖不自动成为预测模态。具体特征、科学模态、设备包应分别回答变量信息、信息类别与现实硬件部署问题。

实时代码仍存在 required_devices -> modality_blocks、behavior 被列入设备、Behavior 特征被要求设备集合等于 behavior 的问题。Task B analysis_sets.py 还以 modality + feature 作为状态查找键，entrypoint.py 仍要求 modality_blocks 非空及候选间一致，所以不能只改两个数据类。

现有代码已经包含 required_features 与实际列并集校验、registry 严格布尔解析、not_estimable_feature_absent 报告处理。Issue #59 已关闭，直接 Python 入口已调用 required_outcomes 校验；PR #62 正文仍写 open gate，属于陈旧状态说明，不宜当成当前未修复结论。上述内容须保留并扩展回归，不能按旧总页重复实施。

## 全局研究路径

1. 身份、场次、试次、探针时间轴及设备可用性治理。以参与者组为独立推广单位，场次与探针是重复观测。
2. 测量审计与科学变量资格。先确认信号含义、同步、伪迹、真实观测支持及可估计性，再冻结表示。
3. RQ1：行为与 Q1/Q2 的多尺度分布、时间变化和一致/分离关系。行为不只是预测基线，Q1/Q2 不合成未经验证的真值。
4. RQ2：眼部、动作和通过验证的心肺变量与行为/Q1/Q2 的解释性关联，区分人内变化与人际差异，并控制与测量有关的混杂。
5. RQ3：未见参与者的 Q1 报告预测。首轮 probe 前 30 秒、Q1=1 对 Q1=2/3/4、L2 logistic regression、outer participant-disjoint LOSO、inner grouped CV、参与者等权训练/预处理/评价。
6. 用具体特征、模态整体、行为条件增量及后续删一模态说明条件预测价值；用设备包另行说明部署意义。
7. 合法 OOF 总体表现、比较差及区间、离散探针轨迹、可估分母与失败结构进入报告；Q2 和问卷保留解释作用，四分类及校准诊断后续实施。

解释性分析的人内/人际分解与零个体校准预测是不同任务。不能把测试参与者全场中心化后的变量回流到监督学习。探针轨迹不能直接称连续注意监测。

## 当前变量收口

- Behavior：五维目标 B 为 RT 水平、RT-CV、RT 趋势、raw Go omission、No-Go commission；RT 水平 mean/median 待 G0 决定。d-prime 留报告/敏感性，不与两种基础错误率同时进入主 B。
- Ocular：瞳孔水平、波动、线性趋势、二次曲率仍待 G1 表示及时间支持冻结；几何直径与 hard R_seg 默认作为替代测量表示。眨眼频率预冻结为 blink_event_rate_per_min，真实质量仍需确认。
- Movement：body_motion_energy_median 的可见运动水平为当前紧凑主变量；曝光和径向方向辅助量不进主预测集。不能把候选头动一律当成已冻结成员。
- Cardiopulmonary：HR/BR 及设备依赖等待独立验证和正式 producer 合同；不为凑齐四模态提前放行。

## 建议补充到实施验收的内容

1. 统一 feature_id / scientific_feature_id / predictor columns / scientific modality / source namespace；Task B 旧状态表如使用设备键，应经显式适配映射，不按设备整体重命名成模态。
2. Behavior 的 required_devices 可为空传感器集合，但必须另保留任务日志及时间依赖；空设备集合不代表不需要数据。
3. 明确 modality-level eligibility 与 standalone eligibility 不等价；同一科学维度多个替代表示不能因属于同一模态而自动全部进入模型。
4. M0-M7 保留原 Behavior reference B 时，需单独声明 includes_behavior_reference，避免把 B+RGB 误称纯 RGB 信息模型。设备资格白名单只能收窄真实依赖允许的范围。
5. 缺少科学资格的模态记录 pending/unavailable；如运行三模态模型，明确其实际成员和版本，不冒称四模态 Full。删一模态保留其他特征必要的校正来源。
6. 模态比较同样需要折内实际输入审计，区分整组缺失与部分特征缺失。成对比较使用共同样本和相同折，不复用别的 analysis_set 上训练的 B。
7. 不同成对比较的队列可能不同，不能把各自增量直接排成模态贡献榜。跨模态直接排序若有研究需要，应另定义该项比较需要的共同集合，而非恢复所有任务的全局交集。
8. Q1-blind 并不自动证明零泄漏。区分预声明测量规则与从数据学习的校正参数，并审计 RGB 开眼参考、头动校正、滤波和同步是否使用未来信息或测试参与者全场统计。训练型变换仍须折内估计。
9. 同步 1.16.4、1.16.6、1.16.7 和 PR #62 的旧术语/执行时点/状态说明；新定义已覆盖旧术语，但执行者仍有误读风险。

## 执行顺序与放行

代码语义重构可与 Behavior G0、NIR G0/G1、RGB 质量确认并行推进，不必等待全部具体表示冻结才开始写结构。最终真实 registry 和集成验收必须等待上游冻结。

汇合后依次完成最终 probe-key / NIR status 接线、纵向集成、2-3 场真实 schema/materialization smoke、参与者数量与类别支持足够的 mini-LOSO、正式 Q1 二分类。其他变量的正式关联结果可以独立进入报告，不必等待所有监督学习完成。
