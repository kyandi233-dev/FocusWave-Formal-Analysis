# 09-13-8 心肺正式纳入的状态传播与图件更正

> 性质：更正记录。心肺由"补充分析"转为"正式纳入"后，前一轮只更正了方法层与 §1.3／5.6.4，
> **下游的图件与若干正文表述仍停留在"补充"口径**。本记录登记本次把状态传播补齐的范围与证据。
> 边界：不新增任何科学结论，不改动任何数值；所有被更正处都是**标签、来源与限定语**。

## 1. 触发与发现

第五项（四分类多类布里尔分数与校准）收口后，逐图清点"心肺"的出现位置时发现：

1. **图 5-2（`fig5.6-1_modality_performance.png`）的位图内行标签印着"心肺（补充）"**，
   而心肺此时已是注册表 v3 的正式注册特征；该行的数据来源仍是**补充通道**
   （`SupervisedRunsV3_SupplementaryCardiopulmonaryM1` 的 `supplementary::cardiopulmonary_only`）。
2. `5.6` §5.6.1 的图注写"心肺一行属于补充分析"。
3. `5.7` §5.7.1 的表行写"心肺估计（补充）"、表注写"属于主结果后的补充分析"；
   §5.7.2 的表行写"从补充扩展组合中移除"、表注写"不是正式 11 指标组合"。
4. `5.5` §5.5.3 写"主结果完成后另有心肺二分类补充预测"。
5. `完整结果/6` §1.1 的主对照表三行写"（补充比较）"、AUROC 段写"补充比较中的心肺"；
   §9 资产清单写"M2、M4、M6、M7 尚不存在"与"Q1 四分类本轮未执行"。

## 2. 处置

### 2.1 数据来源改为正式通道

- `.harness\compute_matched_baseline.py` 的 `DEFAULT_TARGETS`：三条补充目标
  （`SupervisedRunsV3_SupplementaryCardiopulmonaryM1` 的
  `supplementary::cardiopulmonary_only` / `supplementary::behavior_plus_cardiopulmonary` /
  `supplementary::full_plus_cardiopulmonary`）替换为两条正式目标
  （`SupervisedRunsV4_Cardiopulmonary` 的 `AS.behavior_plus_cardiopulmonary` 下的
  `modality::cardiopulmonary` 与 `behavior_plus_modality::cardiopulmonary`）。
  「完整 + 心肺（补充）」一行删除，因为注册表 v3 后 `AS.full` 本身已含心肺，两者不再是两个模型。
- `.harness\build_supervised_result_figures.py`：
  - `load_diagnostics` 的补充通道路径改为 `SupervisedRunsV4_Cardiopulmonary\probability_diagnostics`；
  - `INFO_TYPE_ORDER` 与 `figure_5_6_1` 的第 5 行由「心肺（补充）」
    （`supplementary::cardiopulmonary_only`）改为「心肺」
    （`modality::cardiopulmonary` / `AS.behavior_plus_cardiopulmonary`）。

### 2.2 数值未变（这是本次最重要的事实）

重算后的 `matched_baseline.csv` 与旧表逐值对比：**两者共有的 8 行在对数损失、
同口径无信息基线、增益、探针数、参与者数上 0 处变化**；变的只是三条补充行被两条正式行替换。
即：**资格状态的改变没有改变任何一个数字**，与 §1.3 的结论一致。

### 2.3 图件重生成的范围

`build_supervised_result_figures.py` 会重生成 5 张图。重跑后
`git status` 只显示 **1 个变更文件**（`fig5.6-1_modality_performance.png`），
其余 4 张（`fig5.7-1`、`fig5.7-2`、`fig5.7-3`、`fig5.8-1`）**逐字节未变** ——
这同时证明本次改动的作用域被限制在预期范围内。
