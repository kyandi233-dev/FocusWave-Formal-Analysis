# formal_v3 行为结果组合图制作

## 背景

`D:\_AttentionData\_Formal\formal_v3\figures_publication` 已包含各行为指标的单幅正式图，但当前 `0827报告v1.docx` 中行为结果图位与图意不匹配，且错误事件轨迹缺少与 publication 图统一的英文版式。用户要求直接制作可用于第 5.2 节的组合图。

## 目标

在不覆盖既有单图、不重新读取原始试次数据、不重新拟合统计模型的前提下，使用 `formal_v3` 已完成的图片和正式汇总表生成三张组合图：任务进程、错误时序、思维探针。输出 PNG 和可编辑 SVG，并保留清晰的面板标识与外置图注接口。

## 计划步骤

1. 回读正式单图、figure manifest、`error_trajectory_summary.csv` 和相关模型表，冻结每个面板的来源与统计单位。
2. 直接组合已有 publication 单图；依据 `error_trajectory_summary.csv` 补绘英文错误事件轨迹面板。
3. 生成不含图内大标题的高分辨率 PNG 与 SVG，不覆盖已有文件。
4. 逐图检查面板顺序、字体、坐标、误差线、观察单位、图像清晰度与图注口径。
5. 在本记录中补充实际执行、最终决策、已完成/未完成及待确认事项。

## 风险

- B1/B2 单图中的细线代表 session，不代表相互独立的参与者；组合图图注必须保留这一边界。
- Q1 为名义四分类，不能用连线暗示顺序；Q2 为有序四级，可以使用趋势连线。
- 错误事件轨迹的相对试次 0 为错误事件本身，没有正确 Go RT，应显示为空位而非插值。
- `formal_v3` 使用 116 场、61 个参与者组；不能未经队列核验移植到当前 44 场、38 组口径的报告。
- 现有仓库工作树包含其他任务的未提交变化，本任务只新增本记录和数据区新图，不提交、不推送、不改动既有文件。

## 校验标准

- 三张组合图的 PNG 与 SVG 均存在且非空。
- PNG 保留足够分辨率，面板在报告单页宽度下仍可辨读。
- SVG 可正常解析，嵌入的图像和文字不依赖临时路径。
- 错误事件轨迹数值逐点与 `error_trajectory_summary.csv` 一致。
- 组合图不新增未经正式结果表支持的显著性标记或统计结论。
