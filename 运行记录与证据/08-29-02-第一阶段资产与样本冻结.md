# 第一阶段资产与样本冻结

## 计划

### 背景

本任务负责正式分析完整管线的第一阶段：核验资产位置、仓库版本、正式场次、重复参与者映射、数据来源和跨模态可用性。当前阶段只做只读审计和小型校验，不启动正式统计或大规模重跑。

### 目标

1. 以正式分析完整管线与报告证据库的总 README 为入口，确认当前任务边界和现有冻结规则。
2. 现场核验 `E:\正式实验`、`D:\_AttentionData`、相关机器包/派生表和各代码仓库的实际状态。
3. 冻结可审计的场次、唯一参与者、重复参与者、9504 排除位置、NIR 来源和跨模态可用性；冲突单独记录，不静默合并。
4. 新增资产导航三份说明，并将敏感行级数据留在权威数据位置，不复制到报告目录。

### 步骤

1. 读取总入口、资产导航、修订执行计划、指标候选方案和最近工作记录。
2. 记录各仓库路径、分支、提交版本、远端、工作树和未提交状态。
3. 只读盘点正式原始数据、派生输出、manifest、字段结构、重复映射候选和 9504 处理证据。
4. 用文件名、表头、主键和聚合计数建立样本与来源冻结；对身份/来源/时间轴冲突设置停止点。
5. 写入 `资产导航/1.1-D_AttentionData与正式场次来源地图.md`、`资产导航/1.2-仓库分支与运行入口.md`、`资产导航/1.3-重复参与者与样本冻结.md`。
6. 完成路径、链接、计数、主键和文档一致性校验，补全本记录的命令、输入、发现、风险、停止点和下一阶段放行条件。

### 风险

- 父工作树存在用户未提交修改、未跟踪目录和历史删除状态；不得将其误判为本任务产生，也不得清理。
- 目录名、旧报告和旧摘要可能携带历史数字；当前数字必须由现场文件和生成记录支持。
- 重复参与者映射可能涉及敏感身份关系；报告目录只保存匿名键、聚合计数、来源和精确链接，不复制原始映射行。
- `9504` 可能在原始目录、manifest、筛选配置或下游表中分别体现；必须记录实际执行位置，不能只写结果数字。

### 校验

- 仓库状态、分支、提交版本和工作树逐一记录。
- 原始目录与权威派生目录只读列举；检查文件数、表头、唯一键、重复键和来源字段。
- 样本计数在至少两个独立证据之间交叉核对；跨模态覆盖按匿名场次键聚合。
- 新文档的相对链接、敏感数据边界、停止点和放行条件可复核。
