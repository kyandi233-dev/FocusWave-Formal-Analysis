# 第一阶段资产与样本冻结

## 计划

### 背景

本任务负责正式分析完整管线的第一阶段：核验资产位置、仓库版本、正式场次、重复参与者映射、数据来源和跨模态可用性。当前阶段只做只读审计和小型校验，不启动正式统计或大规模重跑。

### 目标

1. 以正式分析完整管线与报告证据库的总 README 为入口，确认当前任务边界和现有冻结规则。
2. 现场核验 `E:\正式实验`、`D:\_AttentionData`、相关机器包/派生表和各代码仓库的实际状态。
3. 冻结可审计的场次、唯一参与者、重复参与者、9504 排除位置、NIR 来源和跨模态可用性；冲突单独记录，不静默合并。
4. 新增资产导航三份说明，并将敏感行级数据留在权威数据位置，不复制到报告目录。

### 步骤

1. 读取总入口、资产导航、修订执行计划、指标候选方案和最近工作记录。

4. 用文件名、表头、主键和聚合计数建立样本与来源冻结；对身份/来源/时间轴冲突设置停止点。
5. 写入 `资产导航/1.1-D_AttentionData与正式场次来源地图.md`、`资产导航/1.2-仓库分支与运行入口.md`、`资产导航/1.3-重复参与者与样本冻结.md`。
