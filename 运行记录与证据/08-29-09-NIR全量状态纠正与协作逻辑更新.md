## 一、背景和目标

本轮目标如下：

1. 根 README 和 NIR README 明确写出 NIR 生产提取 44/44 完成、全部 44 个场次可作为下游分析输入，同时明确这不等于瞳孔测量效度、质量控制或正式统计通过。
2. 在协作治理说明中补充网页 GPT、本地 Codex Luna、监督者和专门 Git 任务的实际职责链路、输入输出与禁止事项。
3. 保留数据区 `identity_status` 原始枚举和历史运行元数据，不改写 CSV；在 Git 文档中只保留 44 场、38 组、6 个双场组和 12 个 session 等聚合口径，不展开具体匿名组键。
4. 修正 E2/Q3/R2 的文字口径，新增本工作记录，供监督复核。

原计划是先核验正式证据库工作树、远端基线、现有身份文档和 NIR README，再核验 NIR 权威来源目录的完成状态；随后只做定向 Markdown 修改和匿名键脱敏，最后检查链接、编号、编码、敏感信息和 Git 差异。禁止提交、推送、合并、删除、重命名、修改数据区 CSV 或清理并发任务文件。
