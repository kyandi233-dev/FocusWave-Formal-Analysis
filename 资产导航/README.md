# 资产导航

本模块回答“什么东西在哪里、当前是什么状态、由谁生产、以后什么时候查”。路径映射将区分当前权威、工程生产、分析候选、历史证据、仅验证、未来工作和当前受阻；不会用一个“完成/未完成”覆盖所有层级。

- [1.1-D_AttentionData 与正式场次来源地图](1.1-D_AttentionData与正式场次来源地图.md)：阶段 0 资产、来源、44/38/6 和模态存在性证据。
- [1.2-仓库分支与运行入口](1.2-仓库分支与运行入口.md)：关联代码仓库、分支、解释器和生产入口的只读核验。
- [1.3-重复参与者与样本冻结](1.3-重复参与者与样本冻结.md)：匿名分析组、重复场次、身份边界和当前冻结/停止点。

当前阶段的 44/38/6 是当前队列匿名分析口径，不是跨队列永久身份；NIR 的 27 场次来源预检也不等同于 44 场次正式完成。后续同类导航文件使用 1.1、1.2、1.3 顺排，不从其他编号起步。
