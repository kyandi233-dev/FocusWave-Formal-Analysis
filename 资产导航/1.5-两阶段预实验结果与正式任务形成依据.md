# 两阶段预实验结果与正式任务形成依据

> 日期：2026-08-30  
> 用途：记录正式报告第 4 章“方案形成与两阶段预实验”的直接证据。本文保存预实验设计、关键结果、数据质量边界以及这些结果如何支持后续任务结构调整；不把预实验结果与最终 BB 正式样本合并推断。

## 2. 预实验阶段一：ABCCBA 条件探索

### 2.1 样本与结构

阶段一报告整合 8 个被试/记录，跨多个采集批次，采用六 Block 的 ABCCBA 顺序。该阶段主要目的不是建立最终效度结论，而是观察 A/B/C 条件是否形成稳定的行为难度梯度，同时评估时间进程、行为指标和早期思维探针设计。

报告中的 A/B/C 条件具有不同 No-Go 机会数：A=48、B=24、C=12。由于原始误按次数会机械受到 No-Go 次数影响，报告使用 `commission_rate` 等比例指标进行比较。

### 2.2 对正式方案最重要的发现

**第一，预设 A/B/C 难度梯度没有得到稳定支持。** 跨被试平均的 `commission_rate` 为 A=0.266、B=0.195、C=0.250；A 与 C 的归一化误按率几乎没有差异，报告给出的 A vs C 比较 `p=0.825`。进一步拆分前后半程后，条件排序发生变化，提示原先看似存在的条件差异与 Block 所处时间位置纠缠。阶段一因此不能支持把 A/B/C 作为最终正式实验中的单调认知负荷梯度。

**第二，时间进程比条件标签表现出更一致的变化。** 阶段一报告将前半程 Block 1–3 与后半程 Block 4–6 比较时，观察到后半程误按率、漏按率和 RT-CV 上升，d′下降，同时平均 RT 缩短。相同 B 条件的 B2 与 B5 比较中，6/8 被试在 B5 误按上升，6/8 d′下降，6/8 RT 变快；报告给出的配对 RT 比较为 `p=0.029`。这些结果属于 n=8 的形成性证据，但支持后续把重点从“条件梯度”转向“同一任务条件下的时间进程与个体内变化”。

**第三，阶段一的早期 probe 方案存在明显测量问题。** 报告记录了不同批次 probe 密度不一致、量表越界按键以及多名被试几乎固定使用同一选项等现象，因此该阶段 probe 不能作为稳定的个体内注意状态指标。阶段一关于 probe 与行为关系的相关结果只可视为探索性观察，不能直接移植到后续正式探针设计或最终效度结论。

### 2.3 阶段一的数据质量边界

阶段一报告本身包含若干需要限制解释的记录：`sub-sxq` 为自测且 RT 分布明显污染；不同批次 probe 协议存在差异；8 个记录跨多个采集批次，并非同一冻结程序下形成的统一正式队列。因此阶段一最适合支持**方案选择和问题发现**，不适合作为最终正式样本的统计结果。

## 3. 预实验阶段二：BBB 同条件时间进程验证

### 3.1 样本与结构

阶段二采用 3 个相同 B Block，每 Block 432 trial、48 个 No-Go、10 个思维探针，即每人 1296 个正式 trial、144 个 No-Go、30 个探针。报告最初提取 20 名被试，其中 `sub-015` 几乎无有效 Go 反应，主分析排除后为 19 名有效被试；`sub-9504` 作为试运行记录排除在主队列之外。

阶段二已经使用后来正式保留的双探针框架：Q1 为 4 类注意状态的名义变量，Q2 为 4 点警觉度有序变量。RT 在主分析中不按阈值机械删除，极端区间主要作为质量标记。

### 3.2 对正式方案最重要的发现

**第一，同一 B 条件下能够观察到稳定的时间相关变化。** 主队列中，Go 漏按率从 B1 的 0.029 上升到 B3 的 0.048，Friedman `p=0.003`，B3−B1 经 Holm 校正 `p=0.007`；RT-CV 从 0.369 上升到 0.485，Friedman `p=0.018`，B3−B1 Holm `p=0.021`。No-Go 误按率则没有显著 Block 主效应。该结果表明，统一 B 条件并不会消除行为动态，反而有利于把时间进程从条件差异中分离出来。

**第二，阶段二恢复了更接近经典 SART 的事件级行为证据。** No-Go 误按事件前 lag−1 和 lag−2 的正确 Go RT 分别比正确抑制事件前更快约 45 ms 和 24 ms，Holm 校正后均 `p<0.002`。这一结果支持后续保留 trial/事件尺度指标，而不只依赖 Block 总体均值。

**第三，行为指标具有明显的多维性和跨 Block 稳定性。** 阶段二报告中 d′ 与 RT-CV 在 subject×block 层面呈强负相关（Spearman `ρ=-0.89`）；B1 与 B3 的多项指标相关系数约为 0.55–0.92。误按、漏按、反应时及其变异性并不能被压缩成单一“专注分数”，后续正式分析需要保留不同指标的测量含义。

**第四，新探针结构的编码方式得到明确。** Q1 四分类中“完全专注”占 63.2%（360/570），Q2 警觉度 3–4 占 71.2%。Q1 应作为名义变量处理，不对类别编码直接求平均；Q2 可以作为有序变量分析。阶段二探针后行为的简单关联较弱，因此探针应作为任务内主观参照之一，而不是行为表现的替代物或绝对真值。

## 4. 从 ABCCBA 到 BBB，再到最终 BB 的方案形成逻辑

两阶段预实验共同支持了以下设计收敛过程：

1. **取消 A/B/C 难度梯度作为正式实验核心操纵。** 阶段一没有得到稳定的单调难度效应，且条件与 Block 位置发生混杂，因此正式验证不再把 A/B/C 条件差异作为主要研究因素。
2. **改为统一 B 条件，以突出个体内时间动态。** 阶段二 BBB 证明，在相同任务条件下仍能观察到漏按、RT-CV、事件前加速等时间相关变化，因此无需依靠不同条件制造注意差异。
3. **保留行为与思维探针的多尺度观测。** 阶段一暴露早期 probe 的协议与反应质量问题；阶段二采用固定的 Q1 四分类 + Q2 四级警觉结构，并同时保留 trial、Block、事件和探针尺度信息。
4. **最终正式任务进一步简化为 BB 两 Block。** 最终 `formaltest` 将 BBB 缩短为 BB，同时将探针由 30 个降为 20 个。正式报告可以表述为“在保留同条件前后时段比较的基础上，最终采用两个 B Block”，但目前没有独立证据支持把这一变化强行归因于某一个具体原因，例如“三 Block 过度疲劳”或“设备稳定性不足”。这些动机除非后续有明确记录，否则不在报告中补造。

## 5. 正式报告写作边界

- 两份 PDF 的结果属于**形成性预实验证据**，可用于说明正式任务为何从多条件设计收敛为统一 B 条件及双 Block 方案。
- 预实验的 p 值、相关和个案模式不应与最终 44 场/38 名参与者的正式统计结果合并，也不应写成最终样本已经复现的结果。
- 阶段一 n=8 且协议跨批次，包含明显 RT 污染、自测和 probe 协议差异；其统计结论必须降格为探索性。
- 阶段二主分析 n=19，虽然报告标题含“正式”，但其 BBB 三 Block 结构已经被最终 BB 取代，因此属于方案形成阶段证据。
- 方法章只保留足以解释设计选择的关键结果；完整预实验统计、图和个案细节留在本证据文件和原始 PDF，不把方法章节写成第二个结果章节。
