## 一、冻结对象和键的中文含义

| 字段/对象 | 中文含义 | 本阶段口径 |
|---|---|---|
| `subject_id` | 场次级匿名编号 | 现有数据中形如 `sub-031`；只能表示一个采集目录/场次，不能直接当独立统计参与者 |
| `experiment_id` | 实验记录编号 | 重复参与者 sessions 表的场次级联结字段 |
| `session_key` | 场次联结键 | 用于 NIR、行为和 RGB 的同场次联结；每场保持独立行 |
| `session` | 实验场次记录 | 一个 `subid` 对应一次采集/到场记录；同一参与者多次到场时保留多条 session |
| `group` | 匿名分析组 | 由 E2 姓名主匹配、手机号/学号精确交叉核验，并由 Q3 匿名键复核得到的当前队列分组单位；用于防止重复参与者泄漏 |
| `presence` | 模态存在性记录 | 记录某一 session 的 NIR/RGB 输出候选、存在性和歧义状态；不是 E2 的“签到”字段，也不是身份分组 |

| `identity_status` | 身份映射状态 | 数据区 CSV 保留原始机器枚举：`confirmed_repeat_group`、`provisional_registry_history`、`unresolved_registry_external_singleton`；不能把这些机器状态直接改写成跨队列永久身份结论 |
| `analysis_join_policy` | 分析联结策略 | `keep_session_row; do_not_merge_sessions`：保留场次行，不把重复场次合成一条时间序列 |
