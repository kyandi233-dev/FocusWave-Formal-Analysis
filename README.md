# 正式分析完整管线与报告证据库

本目录是本轮“资产核验—方法选择—管线实现—44 个场次分析—多模态融合—报告修订”的唯一工作入口。旧报告、旧输出和历史工作记录保持原样；不合适、未通过验证或暂时受阻的结果不会删除，而是保留在完整过程与证据台账并注明状态。

Codex 自动进入本仓库时先读取本文件，再按根目录 [AGENTS.md](AGENTS.md) 执行稳定入口顺序。协作角色、数据执行边界、科学/写作边界和 Git 门控统一见 [运行记录与证据/1.2-协作角色、任务分工与Git治理.md](运行记录与证据/1.2-协作角色、任务分工与Git治理.md)。

## 权威位置原则

- 可执行代码只在对应 Git 仓库维护，不在本目录复制第二份源码。
- 大体积原始数据和行级派生数据只在 `D:\_AttentionData` 或正式机器包目录维护，不提交 Git；本目录保存路径、字段结构、校验值、运行清单和报告可用的聚合结果。
- 本目录中的“正式报告”只存新版本，不覆盖原始 0827报告v1.docx。
- `docs/工作记录`、旧报告和旧分析目录均视为历史溯源证据，不删除、不改写。

## 文件编号

每个子目录都以 `README.md` 作为唯一入口。说明文档在各自子目录中独立从 `1-` 开始，同组后续文档使用 `1.1-`、`1.2-`、`1.3-` 顺排，不沿用其他目录的编号。工作记录例外，固定使用 `MM-DD-NN-标题.md`。

## 推荐阅读顺序

1. [资产导航](资产导航/README.md)：当前资产、权威路径、状态和何时使用。
2. [分析设计](分析设计/README.md)：修订执行计划、指标选择逻辑、决策门与停止点。
3. [行为分析](行为分析/README.md)：注意水平候选定义、行为指标和重复测量分析。
4. [NIR分析](NIR分析/README.md)：当前正式 pupil 产物、亮度/尺度等混淆控制和候选指标。
5. [毫米波分析](毫米波分析/README.md)：44-session HR/RR、QC 和后续合并包。
6. [RGB分析](RGB分析/README.md)：在 NIR 与毫米波之后冻结的眨眼、头动、姿态和 AU 层次。
7. [跨模态融合](跨模态融合/README.md)：统一键、重复被试安全的验证和增量/交互分析。
8. [正式报告](正式报告/README.md)：只收录通过报告准入标准的文字、表格、图和新报告版本。
9. [运行记录与证据](运行记录与证据/README.md)：命令、环境、输入输出校验值、失败、协作规则和当前受阻状态。
