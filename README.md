## 权威位置原则

- 可执行代码只在对应 Git 仓库维护，不在本目录复制第二份源码。
- 大体积原始数据和行级派生数据只在 `D:\_AttentionData` 或正式机器包目录维护，不提交 Git；本目录保存路径、字段结构、校验值、运行清单和报告可用的聚合结果。
- 本目录中的“正式报告”只存新版本，不覆盖原始 0827报告v1.docx。
- `docs/工作记录`、旧报告和旧分析目录均视为历史溯源证据，不删除、不改写。

## 文件编号

每个子目录都以 `README.md` 作为唯一入口。说明文档在各自子目录中独立使用 `1-标题`、`2-标题`、`3-标题` 接续；同主题或从属说明使用 `1.1-标题`、`1.1.1-标题`、`1.2-标题`。文件夹内部不继承父目录编号，不使用 `01`、`02`、`001` 或 `000` 补零；需要在当前层级置顶时使用 `_1-标题`、`_2-标题`。程序、配置、模型、数据和测试默认不编号。新工作记录使用 `MM-DD-N-标题.md`，同一天从 `1` 接续且不补零。既有补零文件作为历史证据保留，不追溯批量重命名。
