# 正式报告

本模块与完整过程分析严格分开。工程兴趣区、分割遮罩、失败例、诊断频谱、当前受阻结果和算法比较留在过程证据区；正式报告只使用能够回答研究问题、方法可解释、样本与重复结构正确、图表可复现且措辞与证据等级一致的内容。结果是否显著只是准入因素之一，不是唯一标准。源报告不在原位置改写；完成时在本目录生成带版本号的新文档并进行逐页渲染验收。

**正式正文以高信息密度的论文写法为目标，而不是以最短文本为目标。删除聊天式、辩解式、教学式或防御性语言时，只删除不适合论文的表达方式；其中承载的科学事实、方法、样本量、统计量、关键非显著结果及必要的时间过程必须以论文语言保留。**

## 强制前置阅读

**任何正式报告正文、章节草稿、结果表述、图题图注、讨论或结论的新增、改写和润色，开始前必须首先完整读取 [0-正式报告写作与统计结果呈现规范](0-正式报告写作与统计结果呈现规范.md)。不得仅依据聊天记忆、旧稿或通用统计知识直接撰写。**

涉及统计结果时，在读取上述写作规范后，还必须读取该结果对应的当前正式分析 runner、正式配置和实际结果表/运行证据，确认当前真正使用的分析方法、变量方向、样本单位和输出统计量。若仓库中同时存在历史实现和当前实现，以当前正式 runner 实际调用的代码和当前配置为准。无法从当前正式证据核实的数字、p 值、模型方向或样本量不得补造。

随后读取 [2-章节融合工作要求](2-章节融合工作要求.md) 和将要修改的当前章节全文，再进行写作。以上步骤为正式报告写作的固定前置流程。
