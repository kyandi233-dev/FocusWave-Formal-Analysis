# 2.1 持续注意的行为表现与主观体验

持续注意（sustained attention）是个体在较长时间内保持目标指向性加工，并对低频、偶发或不可预测事件维持反应准备的能力（Sarter et al., 2001）。这一能力并不是在整个任务过程中保持恒定不变。随着任务持续，个体可能出现反应节律变化、短暂任务脱离以及警觉水平下降；与此同时，注意也可能从当前任务转向与任务无关的内部思维，即心智游移（mind wandering）（Smallwood & Schooler, 2015）。因此，持续注意既包含相对稳定的个体差异，也包含同一个体随时间发生的状态波动。测评时若只使用整场平均成绩，容易掩盖这种时间动态。

持续性注意反应任务（Sustained Attention to Response Task, SART，持续性注意反应任务）为观察上述变化提供了标准化行为情境。经典 SART 要求参与者对高频 Go 刺激持续作出反应，并在低频 No-Go 刺激出现时抑制已经形成的优势反应（Robertson et al., 1997; Manly et al., 1999）。这种设计同时要求参与者维持任务规则、保持连续反应并监控少量需要抑制的事件。Seli 等（2012）比较视觉与听觉版本的 SART 后发现，两种模态下的错误率、反应时和反应时变异具有较强的跨模态相关，说明这些指标能够稳定反映持续注意表现中的个体差异，而不仅由某一种刺激通道决定。

SART 的行为结果需要分层解释。No-Go 试次中的错误按键通常称为 commission error（错误抑制），表示优势反应未被成功抑制；Go 试次未出现有效反应则构成 omission error（遗漏反应），表示应作出的持续反应没有发生。两类错误的任务要求和形成过程不同，因此不宜合并为单一“正确/错误”指标。commission error 更直接涉及对优势反应的监控与抑制，而 omission 还可能与反应迟缓、反应节律中断以及按键相对于相邻试次的时序错位有关。正式分析因而需要分别报告 Go 与 No-Go 的表现，并结合原始按键时序判断不同遗漏所对应的行为过程。

正确 Go 试次的反应时提供了另一个互补维度。平均或中位反应时描述总体反应速度，但相近的平均速度可能对应完全不同的稳定性，因此还需考察反应时标准差、四分位距、中位数绝对偏差以及变异系数等离散程度指标。反应时变异尤其适合描述注意控制在任务过程中的不稳定性。进一步地，SART 还可通过信号检测论（signal detection theory，信号检测论）将 Go 有效反应和 No-Go 错误反应共同纳入辨别力与反应偏向指标，从而避免只依赖单一错误率解释任务表现。由此，反应速度、反应稳定性、commission、omission、辨别力和反应偏向分别描述持续注意表现的不同侧面，而不应被压缩成单一综合正确率。

行为记录仍不能直接回答参与者当时“在想什么”或“有多清醒”。思维探针（thought probe，思维探针）通过在任务过程中间歇性询问探针出现前一刻或前一时间段的主观体验，为注意状态提供在线标定。心智游移研究通常利用这类方法区分任务专注与任务无关思维，并进一步考察元意识、内容和任务脱离程度（Smallwood & Schooler, 2015）。Wiemers 和 Redick（2019）在持续注意任务中比较不同探针条件后，没有发现探针本身系统性损害准确率、反应时或反应时变异，为思维探针作为任务内主观测量提供了非反应性证据。不过，探针仍依赖参与者的自我觉察和报告，只能覆盖若干离散时点，因此更适合作为对行为与连续生理信号的主观参照，而不是替代连续测量。

注意内容与警觉程度还需要区分。近期结合 SART、思维探针、瞳孔和心脏活动的研究将任务专注、心智游移和大脑空白分别记录，并同步询问警觉水平。Corcoran 等（2025）发现，心智游移和大脑空白均随任务时间增加，并伴随较低警觉程度和较小瞳孔；两种任务脱离状态又表现出不同的行为与生理模式，其中大脑空白与更明显的低唤醒和心率下降相联系。该结果说明“注意内容”和“警觉程度”虽然相关，却并非同一构念。因而，本研究将探针第一问作为注意内容的类别型主观指标，将第二问作为近期警觉程度的有序指标，并分别考察它们与反应速度、反应稳定性和错误形成之间的关系。

综合来看，SART 行为与思维探针提供了两个互补的测量层次：行为记录参与者实际“做得如何”，探针记录参与者能够报告的“当时处于何种主观状态”。前者具有连续的试次级时间信息，但同一行为结果可能具有不同形成机制；后者能够直接区分主观注意内容和警觉程度，却具有离散采样和自我报告限制。将两者共同作为任务内认知参照，能够为后续瞳孔、毫米波和可见行为信号提供更明确的效标基础，也使持续注意的分析从整场平均表现扩展到区块、时间窗口、错误前兆和探针前状态等多个时间尺度。
