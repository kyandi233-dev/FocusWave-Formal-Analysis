## 4.5 数据处理与统计分析

各模态以任务事件时间为共同参照，并保留原有时间分辨率。行为数据形成试次、错误事件、Block、Block 内时间段和探针前窗口等分析单位；NIR、毫米波和 RGB 连续记录完成质量评价与特征提取后，对应到相同任务事件和时间窗口。单模态分析考察任务时间变化及其与行为、思维探针的关系，多模态分析在共同探针前窗口上进行增量预测。

### 4.5.1 行为与思维探针

SART 行为指标包括反应速度、反应稳定性、Go 遗漏、No-Go 误按和信号辨别指标。Go 遗漏率以有效 Go 试次为分母，No-Go 误按率以有效 No-Go 试次为分母，两类错误分别分析。

正确 Go 试次的反应时（reaction time, RT）用于描述反应速度。低于 100 ms 的按键作为提前反应单独记录；有效正确 Go RT 同时计算均值和中位数。反应稳定性采用 RT 标准差、四分位距、中位数绝对偏差和反应时变异系数（RT-CV）描述：

RT-CV = SD(RT) / M(RT)。

RT-CV 在相应时间窗口至少包含 20 个有效正确 Go 反应时时计算。窗口内 RT 随时间的变化采用 Theil–Sen 稳健斜率估计，以成对观测斜率的中位数表示总体趋势（Theil, 1950; Sen, 1968）。

信号检测论指标以 Go 正确反应为命中、No-Go 误按为虚报。当分析单位至少包含 4 个 Go 和 2 个 No-Go 机会时，采用对数线性校正：

H = (N_hit + 0.5) / (N_Go + 1)，

FA = (N_commission + 0.5) / (N_No-Go + 1)。

在此基础上计算：

d′ = Z(H) − Z(FA)，

c = −[Z(H) + Z(FA)] / 2，

β = exp{[Z(FA)^2 − Z(H)^2] / 2}。

其中 d′表示 Go 与 No-Go 的辨别力，c 与 β 描述反应偏向。

Go 遗漏根据按键时序进一步分为真遗漏和预判遗漏。真遗漏指原始 Go 遗漏中未检测到刺激前按键或跨试次按键延续候选的记录；预判遗漏指伴随上述时序歧义的 Go 遗漏。总遗漏率、真遗漏率和预判遗漏率使用相同的有效 Go 试次作为分母，并满足：

总 Go 遗漏率 = 真遗漏率 + 预判遗漏率。

B1 与 B2 的区块比较先在每份实验记录内形成 B2−B1 配对差值；同一参与者存在多份实验记录时，先计算参与者内平均差，再以参与者为重抽样单位进行 20,000 次 bootstrap，报告平均差、bootstrap 标准误和 95% 百分位置信区间（Efron & Tibshirani, 1994）。Block 内时间过程将每个 Block 按顺序划分为 6 个连续时间段，采用以参与者为聚类单位的广义估计方程（generalized estimating equations, GEE）分析 Block、时间段及二者交互作用（Liang & Zeger, 1986）。错误事件分析以错误试次为锚点，提取事件前后相邻正确 Go 试次的中心化 RT 轨迹。

思维探针的正式主窗口为探针前 30 s，10 s 和 20 s 窗口用于敏感性分析；窗口截止于探针出现前，并排除探针锚定试次。Q1 注意内容为四类别名义结局，以“完全专注”为参照，采用预测变量标准化后的多项 Logistic 回归，并使用参与者聚类稳健协方差；Q2 警觉程度为四级有序结局，采用参与者聚类的有序 GEE。模型报告标准化预测变量每增加 1 SD 对应的回归系数、标准误和 95% 置信区间。

### 4.5.2 近红外瞳孔测量

近红外视频首先使用项目训练的 YOLO26n 检测器定位眼部区域（Redmon et al., 2016），再采用 RITnet 四分类语义分割模型识别背景、巩膜、虹膜和瞳孔（Chaudhary et al., 2020）。瞳孔几何通过拓扑约束确定主要眼球区域及与其相连的瞳孔成分，并对瞳孔成分进行椭圆拟合。正式分析主要采用瞳孔几何平均直径和硬分割瞳孔面积比例；瞳孔等效直径与几何平均直径由同一椭圆导出、数学等价，仅保留几何平均直径，椭圆长短轴、轮廓面积、椭圆面积与软分割瞳孔面积比例作为敏感性指标保留于附录。虹膜分割用于辅助空间定位和分割质量评价，不作为瞳孔大小的归一化参照；眼裂开合相关指标用于分割质量控制。网络训练、眼部区域重建和模型输入尺寸等实现参数列于附录 A。

瞳孔几何平均直径由拟合椭圆的两个完整轴长 d₁ 与 d₂ 计算：

D_geom = √(d₁ × d₂)。

拟合椭圆面积为：

A_ellipse = πd₁d₂ / 4。

硬分割瞳孔面积比例定义为：

P_hard = N_pupil / N_valid，

其中 N_pupil 为有效分析域内标记为 pupil 的 hard-label 像素数，N_valid 为仍由原始图像支持的有效分析域像素数。ROI 扩展产生的人工 padding 不计入 N_valid。

瞳孔数据质量根据眼部可见性、瞳孔分割与几何拟合稳定性、有效图像区域、分割不确定性以及连续帧的时间与几何连续性评价，左右眼分别保留测量结果。任务过程中的瞳孔变化以该次实验中较稳定的瞳孔水平作为个体内参照，即中心化瞳孔 = 瞳孔几何平均直径 − 该场次该眼的中位数基线；事件相关变化以事件发生前的短时瞳孔水平作为局部参照。任务开始前 3 min 静息阶段仅在眼部具有足够稳定的可用数据时用于探索性比较。连续瞳孔序列进一步汇总到试次、Block 和探针前窗口。

视觉协变量按照 9 类水果与 3 种尺寸形成的 27 种呈现条件计算数字相对亮度、RMS 对比度和刺激可见面积；试次级调整模型同时纳入当前与前一试次的视觉属性。亮度指标采用屏幕图像的数字相对量。

试次级正确 Go RT 采用线性混合效应模型，Go 遗漏和 No-Go 误按采用参与者聚类的二项 GEE，并比较未调整模型与纳入视觉属性及数据质量协变量的模型。探针前 30 s 中，Q1 采用多项 Logistic 回归，Q2 采用有序累积 Logit 模型；Block 层连续行为指标采用混合效应模型。主要连续瞳孔指标分解为参与者间平均水平和参与者内相对变化两个分量。

### 4.5.3 RGB 可见行为测量

RGB 视频指标包括整体运动、画面亮度变化、姿态方向候选和眨眼候选事件。整体运动采用相邻帧图像变化形成的运动能量（motion energy）描述，并单独计算画面平均灰度变化。基于人体姿态关键点模型（BlazePose；Bazarevsky et al., 2020）提取左右和上下方向的可见运动；前后方向综合深度方向姿态、肩宽变化和人体画面面积变化形成无量纲方向候选。

眼睑活动采用基于 MediaPipe 面部网格（Lugaresi et al., 2019）的眼睛纵横比（eye aspect ratio, EAR）描述（Soukupová & Čech, 2016），左右眼分别计算，并以各自可观测时段中的较高开放水平作为相对参照。双眼具有足够可用数据且变化基本一致时识别眨眼候选，候选闭眼阶段持续时间限定为 50～1000 ms；明显时间间隔、多脸歧义或主要面孔追踪切换构成事件边界。由此形成眨眼候选事件率、持续时间、事件间隔和有效帧比例等指标，眨眼结果均按算法候选事件报告。

RGB 特征按 Block 内时间进程和探针前 30 s 窗口汇总。Block×时间段变化采用参与者聚类 GEE；探针层 Q1 采用多项 Logistic 回归，Q2 采用有序 GEE；RGB 特征与近期行为指标及毫米波指标的窗口级关系采用参与者聚类 GEE。探针层连续特征同时保留参与者间平均水平和参与者内相对变化。运动能量与曝光变化分别分析，窗口有效帧比例作为质量指标。

### 4.5.4 毫米波心肺相关活动与身体微动

毫米波正式数据为距离域复数信号，由 2 发射×4 接收形成 8 个通道，每个通道包含 256 个距离单元，距离间隔按 0.037 m/距离单元解释。分析在人体所在距离范围内综合信号能量、相位变化和时间稳定性选择反射位置与通道，并提取、展开复数相位，形成胸壁方向的相对微动序列。

呼吸相关成分主要分析 0.10～0.50 Hz，心搏相关成分主要分析 0.8～2.0 Hz；心搏路径在带通滤波基础上结合变分模态分解（variational mode decomposition, VMD）形成补充窄带表示（Dragomiretskiy & Zosso, 2014）。呼吸频率和心率估计综合时域峰间隔、频域谱峰及两者一致性，同时记录运动代理、心率可用窗口比例、心率置信度、相位稳定性和时间戳覆盖比例等质量指标。滤波阶数、VMD 参数和内部候选窗口列于附录 A。

逐帧毫米波数据按采集时间与任务事件对应，连续分析窗口限制在单个 Block 内。正式效标分析使用探针前 30 s 窗口：Q1 采用多项 Logistic 回归，Q2 采用参与者聚类的有序 GEE，窗口行为结局采用参与者聚类 GEE；主要连续预测变量进行参与者间/参与者内分解。身体运动敏感性分析排除运动代理高于全样本第 90 百分位的窗口。

心率和呼吸估计使用同步 ECG 与呼吸带进行外部参考核验，评价探针前窗口尺度的误差以及呼吸谐波锁半频等失效模式。当前主要生理指标为心率和呼吸频率，IBI 与 HRV 仅在逐搏时序精度得到外部参考支持时解释。

### 4.5.5 跨模态对齐与多模态增量预测

行为、NIR、毫米波和 RGB 依据任务事件时间对齐。主分析单位为探针前 30 s 窗口，融合键由实验记录、Block 和 Block 内探针序号确定。Q1 与 Q2 标签来自正式行为与思维探针数据。结构性缺失保留为缺失值；缺失值插补、标准化、零方差或全缺失特征剔除以及参数选择均在训练数据内拟合。

多模态采用特征级早期融合。各模态独立完成信号处理和特征提取后，将同一探针前窗口的结构化特征拼接为模型输入，近期行为构成基准模型 M0。正式输入包括：

| 信息块 | 正式输入内容 |
|---|---|
| 近期行为 | 正确 Go RT 中位数、RT-CV、Go 遗漏相关指标、No-Go 误按率与 d′ |
| NIR | 瞳孔几何平均直径、硬分割瞳孔面积比例及其参与者内/参与者间分量 |
| 毫米波 | 心率、呼吸频率、运动代理、心率可用窗口比例、心率置信度、相位稳定性、时间戳覆盖比例 |
| RGB | 运动能量、曝光变化、左右/上下/前后方向候选、眨眼候选事件率、眨眼帧比例、窗口有效帧比例 |

八种比较组合为：M0 行为基准；M1 行为+NIR；M2 行为+毫米波；M3 行为+RGB；M4 行为+NIR+毫米波；M5 行为+NIR+RGB；M6 行为+毫米波+RGB；M7 行为+NIR+毫米波+RGB。各组合使用相同的参与者、探针观测、结局、外层划分和评价指标。

Q1 在融合中作为四分类名义结局；Q2 在单模态推断中按四级有序结局建模，在融合预测中按四分类结局建模。主要模型为 L2 规则化多项 Logistic 回归，正则化强度 C 在每个外层训练折内通过按参与者分组的五折交叉验证选择；Random Forest 作为非线性补充模型，使用固定超参数。外层验证采用留一参与者交叉验证（leave-one-subject-out cross-validation, LOSO），每次将一名参与者的全部实验记录和探针观测作为测试数据，其余参与者用于训练。

分类性能报告 one-vs-rest 宏平均 ROC-AUC、平衡准确率、宏平均 F1 和对数损失。M1–M7 与 M0 进行逐折配对比较，并以参与者/LOSO 折为重抽样单位进行 2,000 次 bootstrap，报告性能差异及 95% 百分位置信区间。NIR、毫米波和 RGB 的 3! = 6 种加入顺序用于计算平均边际贡献，作为描述性预测贡献指标。
