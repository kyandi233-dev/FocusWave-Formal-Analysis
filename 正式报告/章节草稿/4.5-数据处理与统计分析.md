## 4.5 数据处理与统计分析

数据处理围绕任务表现、主观状态和三类连续传感观测建立统一的分析框架。行为反应和思维探针用于刻画持续注意表现与即时主观状态；近红外视频用于测量瞳孔变化；毫米波用于提取胸部微动中的呼吸、心搏相关变化与身体运动；RGB 视频用于描述可见身体运动、姿态变化和眨眼候选事件。连续观测依据实验时间记录与任务事件对应，并在试次、错误事件、探针前窗口和 Block 内时间进程等尺度上形成分析变量。对随时间变化的连续指标，同时区分参与者之间的稳定差异与同一参与者内部的状态波动。

### 4.5.1 行为与思维探针

SART 行为指标分别描述反应执行、抑制控制、反应速度和反应稳定性。依据刺激类型和按键结果，每个试次分为 Go 正确反应、Go 遗漏、No-Go 正确抑制和 No-Go 误按。Go 遗漏率以 Go 试次总数为分母，No-Go 误按率以 No-Go 试次总数为分母，两类错误分别分析。

正确 Go 试次的反应时用于描述反应速度。低于 100 ms 的按键作为提前反应单独记录；有效正确 Go 反应以中位数表示典型反应速度，并同时保留均值。反应稳定性采用标准差、四分位距、中位数绝对偏差和反应时变异系数描述，其中变异系数为反应时标准差与均值之比，时间窗口至少包含 20 个有效正确 Go 反应时才计算该指标。窗口内采用 Theil–Sen 稳健斜率描述反应速度随时间的变化方向。

信号检测论指标用于综合描述反应辨别能力与反应倾向。Go 正确反应作为命中，No-Go 误按作为虚报；相应分析单位至少包含 4 个 Go 和 2 个 No-Go 机会时，采用对数线性校正估计辨别力 d′、反应标准 c 和 β。上述指标与反应速度、反应变异、Go 遗漏和 No-Go 误按分别保留，以避免把不同认知与反应过程压缩为单一正确率。

Go 遗漏进一步依据按键时序特征区分为无时序歧义遗漏和时序歧义遗漏。前者指按键记录中未出现预设异常时序特征的 Go 遗漏，后者指与刺激前按键、跨试次按键延续或迟发反应等时序特征相伴的 Go 遗漏。相应的无时序歧义遗漏率和时序歧义遗漏率使用相同的 Go 试次分母，两者之和等于 Go 遗漏率。该划分用于描述遗漏反应的时序异质性，不将其中任一亚类单独等同于注意状态。

错误形成过程采用错误前反应轨迹分析。以 No-Go 试次为事件锚点，提取其前 8 个正确 Go 试次的反应时和变化趋势，比较随后正确抑制与发生误按的两类事件。较慢的任务时间变化则在每个 Block 内按顺序划分为 6 个连续时间段，从而把错误发生前的局部变化与 Block 内较长时间尺度的表现变化区分开来。

思维探针主要对应探针出现前的近期行为状态。主要窗口为探针前 30 s，并以 10 s 和 20 s 窗口评价时间尺度敏感性；窗口截止于探针出现之前，不包含探针对应的当前试次。第一问的四类注意内容作为名义类别变量，第二问的四级警觉程度作为有序变量。各窗口汇总近期反应速度、反应稳定性、Go 遗漏、No-Go 误按及满足机会数要求时的信号检测论指标，用于检验主观状态与近期任务表现之间的关系。

### 4.5.2 近红外瞳孔测量

近红外视频首先使用项目训练的 YOLO26n 检测器定位眼部区域，再采用 RITnet 四分类语义分割模型识别背景、巩膜、虹膜和瞳孔。瞳孔几何通过拓扑约束确定主要眼球区域及与其相连的瞳孔成分，并仅对瞳孔成分进行椭圆拟合。由此获得瞳孔等效直径、几何平均直径、椭圆长短轴、轮廓面积和椭圆面积等直接几何指标，同时保留瞳孔像素比例作为补充描述。虹膜分割用于辅助空间定位和分割质量评价，不作为瞳孔大小的归一化参照。网络训练、眼部区域重建和模型输入尺寸等实现参数列于附录 A。

瞳孔观测质量综合眼部可见性、瞳孔分割与几何拟合稳定性、有效图像区域、分割不确定性以及连续帧的时间与几何连续性进行评价，左右眼分别保留测量与质量信息。任务过程中的瞳孔变化以每次实验中该眼稳定的典型瞳孔水平作为个体内参照；事件相关变化以事件发生前的短时瞳孔水平作为局部参照。任务开始前 3 min 静息阶段仅在眼部具有足够稳定可观测数据时用于探索性比较。

连续瞳孔序列在短时间窗内汇总中位数、离散程度、变化斜率和相邻变化幅度，并形成 Block 内任务进程、行为事件附近和探针前窗口的指标。为控制屏幕刺激引起的瞳孔光反射差异，按照实际呈现规则重建 9 类水果与 3 种尺寸形成的 27 种视觉条件，计算数字相对亮度、RMS 对比度和刺激可见面积。刺激后分析同时考虑当前及前一试次的视觉属性；刺激前窗口仅使用严格发生在此前的视觉信息。这里的亮度指标表示屏幕图像之间的数字相对差异，与光度计测得的物理照度属于不同测量量。

### 4.5.3 RGB 可见行为测量

RGB 视频分析聚焦于整体运动、画面亮度变化、姿态辅助信息和眨眼候选事件。整体运动采用相邻帧图像变化形成的运动能量（motion energy）描述，并单独计算画面平均灰度变化，以区分身体运动与曝光或整体亮度变化。姿态关键点用于描述左右和上下方向的可见运动；前后方向结合深度方向姿态、肩宽变化和人体在画面中的面积变化形成复合方向候选，仅用于辅助判断运动方向。

眼睑活动采用眼睛纵横比（eye aspect ratio, EAR）描述，左右眼分别计算并以各自可观测时段中的较高开放水平作为相对参照。双眼均具有足够可观测性且变化基本一致时形成眨眼候选事件，候选闭眼阶段的持续时间限定为 50～1000 ms。时间序列出现明显间隔、多脸导致主要面孔无法稳定确定或面部追踪发生切换时，眨眼事件在相应位置重新起算。由此形成眨眼候选次数、持续时间和间隔等指标；这些指标按算法定义的候选事件解释，其测量效度需要独立事件标注支持。

RGB 运动、姿态和眨眼候选按 Block 时间进程和探针前窗口汇总。整体运动用于描述外显体动，并作为毫米波运动敏感性分析的并行观测；姿态方向用于辅助解释运动来源，眨眼候选与运动指标分别分析。

### 4.5.4 毫米波心肺相关活动与身体微动

毫米波采集结果已经表示为距离域复数信号，由 2 发射×4 接收形成 8 个通道，每个通道包含 256 个距离单元，正式距离轴按 0.037 m/距离单元解释。分析在人体所在距离范围内综合信号能量、相位变化和时间稳定性确定用于微动分析的反射位置与通道，再提取并展开复数相位，以获得胸壁方向上的相对微动序列。

呼吸和心搏相关变化采用不同频段处理。呼吸相关成分主要分析 0.10～0.50 Hz，心搏相关成分主要分析 0.8～2.0 Hz；心搏相关分析在带通滤波基础上结合变分模态分解（variational mode decomposition, VMD）形成补充的窄带信号表示。呼吸频率和心率估计综合时域峰间隔、频域候选及其一致性，同时保留谱峰集中程度、相位连续性、运动幅度和反射位置稳定性等质量信息。呼吸、心搏相关变化和身体运动作为不同变量分别解释。滤波阶数、VMD 参数和内部候选窗口等实现细节列于附录 A。

逐帧毫米波数据按照采集过程中记录的实际时间与任务事件对应。连续分析窗口完全位于单个 Block 内，避开休息、坐姿调整和 Block 边界，并依据真实帧时间确定窗口内的数据范围。心肺相关估计在满足相应信号质量要求的窗口中汇总，再与 Block 时间进程、行为事件和探针前状态建立对应关系。

身体运动既是任务中的外显行为信息，也会影响微弱心肺相关信号的估计。毫米波分析因此同时保留未经 RGB 体动限制的结果、排除明显高体动时间段后的敏感性结果，以及将 RGB 连续运动量作为协变量的调整结果，以评价主要关系对身体运动的敏感程度。心率、呼吸频率和心搏相关连续特征构成当前主要生理分析指标；逐搏间期和心率变异性仅在逐搏识别及外部参考比较能够支持其生理解释时单独分析。

### 4.5.5 跨模态对齐与统计推断

任务事件时间为行为、NIR、毫米波和 RGB 提供共同参照。行为数据保留逐试次结果和探针作答，三类连续传感观测映射到相同的 Block、行为事件和探针前窗口。Block 比较描述较慢的任务时间变化，错误前窗口描述局部错误形成过程，探针前窗口连接近期行为、连续生理与可见行为变化以及即时主观状态。每项结果均报告与其分析单位相对应的参与者数、实验记录数和有效观测数。

重复测量统计以参与者作为上层相关单位，同一参与者的多次实验及同一次实验内的重复观测均在模型中体现。试次级 Go 遗漏和 No-Go 误按等二元结局采用广义线性混合效应模型，正确 Go 反应时以及 NIR、RGB 和毫米波连续指标采用线性混合效应模型；Block 内时间进程采用能够处理重复观测相关性的模型估计 Block、时间及其交互作用。第一问思维探针按四类别名义变量分析，第二问按四级有序变量分析。同一预设指标族中的多重比较采用 Holm 方法调整。

对随时间变化的连续特征，模型同时纳入参与者的平均水平和各时间窗相对于该平均水平的偏离，从而区分个体间稳定差异与个体内状态波动。瞳孔模型同时考虑视觉亮度、对比度和刺激大小等因素；毫米波模型考察身体运动的影响；RGB 模型将曝光变化与身体运动分开。各模态的观测质量通过质量指标和敏感性分析体现，以检验主要效应在不同测量条件下的稳定性。

多模态增量分析以探针前共同时间窗为基本单位，并在相同参与者、相同探针观测和相同外层测试划分上比较不同信息组合。以任务进程和近期行为构成基准模型，依次形成加入毫米波、NIR、RGB 的三个单模态组合、三个双模态组合以及完整三模态组合，共八种比较条件。

参与者独立验证采用留一参与者交叉验证（leave-one-subject-out cross-validation, LOSO）：每次将一名参与者的全部实验和探针观测作为测试数据，其余参与者用于模型训练；标准化、缺失值处理、特征筛选和参数选择均仅利用训练参与者完成。主要比较模型采用规则化逻辑回归，并以 Random Forest 作为预设的非线性稳健性分析。分类性能报告受试者工作特征曲线下面积、平衡准确率、宏平均 F1，以及 Brier 分数或对数损失，并比较相同测试参与者上的成对性能差异及其不确定性。

八种信息组合进一步用于估计各传感模态在不同已有信息条件下带来的性能增量，并比较两种模态共同加入时的联合增益，以评价信息之间的冗余和互补。三种传感模态的全部组合还用于计算不同加入顺序下的平均边际贡献，该指标只表示预测信息贡献，不作因果归因。次级预测分析包括小型多层感知机以及根据各模态观测质量调整权重的融合模型；复杂模型的解释以其在同一参与者独立验证框架下相对于简单特征级融合的稳定增量为依据。
