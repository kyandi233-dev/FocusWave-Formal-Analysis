## 4.5 数据处理与统计分析

数据分析围绕任务表现、主观状态以及三类连续传感观测展开。行为反应和思维探针用于描述持续注意表现与即时主观状态；近红外视频用于提取瞳孔变化，毫米波用于描述胸部微动中的呼吸、心搏相关候选成分与身体运动，RGB 视频用于描述可见身体运动、姿态变化和眨眼候选事件。各类连续观测依据实验时间记录与任务事件对齐，并按试次、错误事件、探针前窗口和 Block 内时间进程形成分析变量。对于连续指标，同时关注参与者之间的稳定差异和同一参与者随任务进程发生的相对变化。

### 4.5.1 行为与思维探针

SART 行为分析分别描述反应执行、抑制控制、反应速度和反应稳定性。依据刺激类型和按键结果，每个正式试次分为 Go 正确反应、Go 遗漏、No-Go 正确抑制和 No-Go 错误反应。Go 遗漏率以 Go 试次总数为分母，No-Go 误按率以 No-Go 试次总数为分母，两类错误分别分析。

正确 Go 试次的反应时用于描述反应速度。低于 100 ms 的按键作为提前反应单独记录；有效正确 Go 反应以中位数表示典型反应速度，并同时报告均值。反应稳定性采用标准差、四分位距、中位数绝对偏差和反应时变异系数描述，其中变异系数为反应时标准差与均值之比，时间窗口至少包含 20 个有效正确 Go 反应时才计算该指标。窗口内进一步采用 Theil–Sen 稳健斜率描述反应速度随时间的变化方向。

信号检测论指标用于综合描述反应辨别能力与反应倾向。Go 正确反应视为命中，No-Go 误按视为虚报；当相应分析单位至少包含 4 个 Go 和 2 个 No-Go 机会时，采用对数线性校正估计辨别力 d′、反应标准 c 和 β。反应速度、反应变异、Go 遗漏、No-Go 误按以及 d′、c 和 β 分别作为具有不同含义的行为指标。

Go 遗漏进一步依据按键时序特征分为无时序歧义遗漏和时序歧义遗漏。前者表示在现有按键记录中未观察到预设的异常时序特征，后者包括与刺激出现前按键、跨试次按键延续或迟发反应相一致的时序情况。相应的无时序歧义遗漏率和时序歧义遗漏率使用相同的 Go 试次分母，两者之和等于 Go 遗漏率。该划分用于区分不同的反应形成过程，其中无时序歧义遗漏只表示按键记录中未出现这些时序特征。

错误形成过程通过错误前反应轨迹分析。以 No-Go 试次为事件锚点，提取其前 8 个正确 Go 试次的反应时及变化趋势，比较随后正确抑制与发生误按的两类事件，考察错误出现前是否存在反应加速、波动增加或跨试次趋势改变。较慢的任务时间变化则在每个 Block 内按顺序划分为 6 个连续时间段，使局部错误前变化与较长时间尺度的任务进程分别估计。

思维探针主要考察探针出现前的近期行为状态。主窗口为探针前 30 s，并以 10 s 和 20 s 窗口进行时间尺度敏感性分析；所有窗口截止于探针出现之前，不包含探针所对应的当前试次。第一问的四类注意内容按名义类别分析，第二问的四级警觉程度按有序变量分析。各窗口汇总近期反应速度、反应稳定性、Go 遗漏、No-Go 误按和满足机会数要求时的信号检测论指标，用于检验主观状态与近期任务表现之间的关系。

### 4.5.2 近红外瞳孔测量

近红外视频的眼部定位使用项目训练的 YOLO26n 检测器。训练材料来自 47 段视频中按时间抽取并人工标注的 575 帧眼部图像，训练、验证和测试数据按参与者划分；模型训练 100 个轮次，检测输入尺寸为 640。正式处理利用既有眼部定位结果回到原始近红外视频，以眼部框为中心重建宽高比为 1.6 的固定眼部区域，并缩放至 640×400 后输入 RITnet 四分类语义分割模型，得到背景、巩膜、虹膜和瞳孔的像素级分割结果。

瞳孔几何采用拓扑约束的主成分定位方法。首先利用虹膜与瞳孔在分割结果中的空间连通关系确定主要眼球区域，再从中识别与该区域相连的瞳孔成分，并仅对瞳孔成分拟合椭圆。由此获得瞳孔等效直径、椭圆长短轴、几何平均直径、轮廓面积和椭圆面积等直接几何量，同时保留瞳孔像素比例作为补充描述。正式瞳孔分析采用直接瞳孔几何；虹膜分割用于辅助定位和分割质量评价。

瞳孔观测质量从眼部图像是否可见、瞳孔分割与几何拟合是否稳定、分割碎片化、边缘接触、有效图像区域、分割不确定性以及连续帧之间的时间间隔和几何突变等方面评价。左右眼分别保留测量和质量信息。每次实验以该眼在有效观测中的稳定典型水平描述相对于自身的瞳孔变化，从而减少不同参与者、不同日期和成像尺度造成的基础差异。

连续瞳孔序列按短时间窗汇总中位数、四分位距、中位数绝对偏差、变化斜率和相邻变化幅度，并形成 Block 内任务进程、行为事件附近和探针前窗口的指标。事件相关变化以事件发生前的短时瞳孔水平作为参照。任务开始前 3 min 静息阶段在眼部具有足够稳定可观测数据时用于探索性比较；主要任务分析以实验过程中的相对变化和事件前局部参照为基础。

为控制屏幕刺激引起的瞳孔光反射差异，按照实际呈现规则重建 9 类水果与 3 种尺寸形成的 27 种视觉条件。图像由 sRGB 转换到线性颜色空间后计算数字相对亮度和 RMS 对比度，并记录刺激可见面积及其相对于掩蔽画面的变化。刺激后分析可同时考虑当前与上一试次的视觉属性；刺激前窗口只使用严格发生在此前的刺激信息。上述亮度指标表示屏幕图像之间的数字相对差异，与光度计测得的物理照度属于不同测量量。

### 4.5.3 RGB 可见行为测量

RGB 正式分析集中于整体运动、画面亮度变化、必要的姿态确认以及眨眼候选事件。已有的面部关键点、身体姿态和逐帧图像变化序列分别用于构造眼睑、姿态和整体运动指标。

整体运动采用相邻帧图像变化形成的运动能量（motion energy）描述，同时单独计算画面平均灰度变化，用于识别由曝光或整体亮度变化引起的画面波动。两类变化分别分析。姿态信息主要利用头部、双肩及可见上半身关键点描述左右和上下方向的运动；前后方向结合深度方向的姿态变化、肩宽变化和人体在画面中的面积变化形成复合候选，用于辅助识别明显的前后移动，其数值仅代表图像中的方向性变化。

眼睑活动由左右眼关键点分别计算眼睛纵横比，并以每只眼在可观测时段中的较高开放水平作为相对参照。左右眼均具有足够可观测性且变化基本一致时形成眨眼候选事件。候选闭眼阶段依据相对开放程度识别，持续时间限定在 50～1000 ms；当时间序列出现明显间隔、画面中存在无法确定主要面孔的多脸情况，或面部追踪发生切换时，事件在该处重新起算。由此获得眨眼候选次数、持续时间和间隔等指标。在建立独立事件标注效度之前，这些指标均按算法定义的眨眼候选解释。

RGB 运动和眨眼候选按 Block 时间进程和探针前窗口汇总。整体运动用于描述外显体动，并在毫米波分析中检验明显体动对胸部微动估计的影响；姿态方向用于辅助解释运动来源，眨眼候选与运动指标分别分析。

### 4.5.4 毫米波心肺相关活动与身体微动

毫米波设备输出已经完成距离向变换，正式记录由 2T4R 共 8 通道、每通道 256 个距离单元的复数距离域信号构成。距离轴按 0.037 m/距离单元解释。分析在人体所在距离范围内结合信号能量、相位变化和时间稳定性寻找胸部相关反射候选，再从选定复数序列提取并展开相位，以描述胸壁的相对微动变化。

胸壁微动分别在呼吸和心搏相关频段进行分析。呼吸相关成分主要位于 0.10～0.50 Hz，心搏相关成分主要位于 0.8～2.0 Hz；时域峰间隔与频域峰值共同用于形成呼吸频率和心率候选估计，并同步描述谱峰集中程度、相位连续性、运动幅度和目标稳定性。由于呼吸谐波、反射位置变化和身体运动均可能影响心搏相关成分，心率候选、呼吸频率候选和身体运动分别作为不同变量解释。

逐帧毫米波数据使用采集过程中记录的时间与任务事件对齐。连续分析窗口完全位于单个 Block 内，并避开休息、坐姿调整和 Block 边界；实际帧时间用于确定每个窗口包含的数据。心肺相关候选估计在信号质量满足相应分析要求的窗口中汇总，并进一步与 Block 时间进程、行为事件和探针前状态对应。

身体运动既可能反映任务中的外显行为，也可能影响微弱心肺相关信号的估计。为评价这一影响，毫米波分析同时比较原始结果、排除明显高体动时间段后的敏感性结果，以及将 RGB 连续运动量纳入模型后的调整结果，从而判断主要关系对身体运动的敏感程度。

逐搏间期和心率变异性依赖稳定且经过外部参考验证的逐搏识别。当前核心分析使用心搏相关候选特征及其质量信息；IBI 和 HRV 在完成逐搏及外部参考验证后再进行独立生理解释。

### 4.5.5 跨模态对齐与统计推断

任务事件时间为各类数据提供共同参照。行为数据保留逐试次结果和探针作答，NIR、RGB 和毫米波连续观测按时间映射到相同的 Block、行为事件和探针前窗口。Block 比较用于描述较慢的任务时间变化，错误前窗口用于研究局部行为事件，探针前窗口用于连接近期行为和连续生理/行为观测与即时主观状态。每项结果均报告与该分析相对应的参与者数、实验记录数和有效观测数。

重复测量统计以参与者为上层相关单位。同一参与者多次实验及同一次实验内的重复观测均在模型中考虑。试次级 Go 遗漏和 No-Go 误按等二元结局采用广义线性混合效应模型，正确 Go 反应时以及 NIR、RGB 和毫米波连续指标采用线性混合效应模型；Block 内时间进程使用能够处理重复观测相关性的模型估计 Block、时间及其交互作用。第一问思维探针按四类别名义变量分析，第二问按四级有序变量分析。对于同一预设指标族的多重比较采用 Holm 方法调整。

对随时间变化的连续特征，分别估计参与者自身的平均水平以及每个时间窗相对于该平均水平的偏离，以区分个体间稳定差异和个体内状态波动。瞳孔模型进一步考虑视觉亮度、对比度和刺激大小等因素；毫米波模型同时考察身体运动的影响；RGB 的曝光变化与身体运动分别建模。各模态的质量指标用于描述观测质量，并通过敏感性分析检验主要关系在不同质量水平下是否稳定。

多模态增量分析以探针前共同时间窗为基本单位，并只在相同参与者和相同探针观测上比较不同模型。以任务进程和近期行为构成基准后，分别加入毫米波、NIR 和 RGB 特征，形成基准、三个单模态组合、三个双模态组合和完整三模态组合共八种模型。所有模型使用相同的外层测试参与者，以使性能差异能够对应于新增模态信息。

参与者独立验证采用留一参与者交叉验证：每次将一名参与者的全部实验和探针观测作为测试数据，其余参与者用于模型训练；标准化、缺失值处理、特征筛选和参数选择均仅利用训练参与者完成。主要采用规则化逻辑回归作为可解释的比较模型，并以 Random Forest 作为预设的非线性稳健性比较。分类性能主要报告受试者工作特征曲线下面积、平衡准确率、宏平均 F1 以及 Brier 分数或对数损失，并计算在相同测试参与者上的成对性能差异及其不确定性。

在八种模态组合的基础上，进一步计算每种传感模态相对于不同已有信息组合的性能增量，并比较两种模态共同加入时的联合增益，以区分主要重复的信息与能够相互补充的信息。由于仅包含毫米波、NIR 和 RGB 三种传感模态，八种组合还可用于计算每种模态在不同加入顺序下的平均边际贡献；该指标表示预测信息贡献，不作因果解释。

更复杂的多模态模型作为次级预测分析。在简单特征级融合形成稳定基准后，可进一步比较小型多层感知机以及根据各模态观测质量调整权重的融合模型。复杂模型只有在相同的参与者独立验证中稳定优于较简单模型时，才作为主要预测结果报告。多模态分析因此首先回答各模态是否提供独立、冗余或互补的信息，再评价复杂融合是否带来额外的泛化收益。
