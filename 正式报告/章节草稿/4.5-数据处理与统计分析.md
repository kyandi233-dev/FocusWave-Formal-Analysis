## 4.5 数据处理与统计分析

数据处理以任务事件时间为共同参照，在保留各模态原有时间分辨率的基础上，将行为、思维探针和连续传感记录整理为具有明确任务含义的分析单位。行为数据形成试次、错误事件、Block、Block 内时间段和探针前窗口等指标；近红外、毫米波和 RGB 连续记录则先进行各自的数据质量评价与特征提取，再对应到相同任务事件和时间窗口。单模态分析用于回答各类指标自身的任务时间变化及其与行为、思维探针之间的效标关系，多模态分析则在共同探针前窗口上检验传感信息相对于近期行为基准的增量预测价值。

### 4.5.1 行为与思维探针

SART 行为指标分别描述反应速度、反应稳定性、Go 反应执行、No-Go 抑制以及信号辨别能力。依据刺激类型和按键结果，每个试次分为 Go 正确反应、Go 遗漏、No-Go 正确抑制和 No-Go 误按。Go 遗漏率以有效 Go 试次总数为分母，No-Go 误按率以有效 No-Go 试次总数为分母，两类错误始终分别计算和分析。

正确 Go 试次的反应时（reaction time, RT）用于描述反应速度。低于 100 ms 的按键作为提前反应单独记录；有效正确 Go RT 同时计算均值和中位数。反应稳定性采用 RT 标准差、四分位距、中位数绝对偏差和反应时变异系数（RT-CV）描述，其中：

RT-CV = SD(RT) / M(RT)。

RT-CV 只有在相应时间窗口至少包含 20 个有效正确 Go 反应时才计算。窗口内反应速度随时间的变化方向采用 Theil–Sen 稳健斜率估计，即以成对观测斜率的中位数描述 RT 随时间的总体变化趋势（Theil, 1950; Sen, 1968）。

信号检测论指标用于综合描述辨别力和反应倾向。Go 正确反应作为命中，No-Go 误按作为虚报；当分析单位至少包含 4 个 Go 和 2 个 No-Go 机会时，采用对数线性校正：

H = (N_hit + 0.5) / (N_Go + 1)，

FA = (N_commission + 0.5) / (N_No-Go + 1)。

在此基础上计算：

d′ = Z(H) − Z(FA)，

c = −[Z(H) + Z(FA)] / 2，

β = exp{[Z(FA)^2 − Z(H)^2] / 2}。

其中 d′越高表示对 Go 与 No-Go 的辨别表现越好；c 与 β 描述反应标准或反应偏向。上述信号检测指标与 RT、RT 变异、Go 遗漏和 No-Go 误按分别保留，不以单一正确率替代。

Go 遗漏进一步根据按键时序划分为真遗漏和预判遗漏。真遗漏指原始 Go 遗漏中未检测到刺激前按键或跨试次按键延续候选的记录；预判遗漏指伴随上述异常按键时序特征的 Go 遗漏。两者使用相同的有效 Go 试次作为分母，并满足“总 Go 遗漏率 = 真遗漏率 + 预判遗漏率”。该分类描述遗漏记录的按键时序特征，不直接等同于特定心理状态。

行为分析使用多个互补时间尺度。B1 与 B2 的区块比较先在每个实验记录内形成 B2−B1 配对差值；同一参与者存在多个实验记录时，先计算其参与者内平均差，再以参与者为重抽样单位进行 20,000 次 bootstrap，报告平均差、bootstrap 标准误和 95% 百分位置信区间（Efron & Tibshirani, 1994）。较慢的 Block 内时间过程将每个 Block 按顺序划分为 6 个连续时间段，采用以参与者为聚类单位的广义估计方程（generalized estimating equations, GEE）分析 Block、时间段及二者交互作用（Liang & Zeger, 1986）。错误形成过程以错误事件为锚点，提取事件前后相邻正确 Go 试次的中心化 RT 轨迹；当前正式结果将该轨迹作为事件中心化描述，不赋予未由正式模型支持的逐位置显著性结论。

思维探针主要对应探针出现前的近期行为状态。正式主窗口为探针前 30 s，10 s 和 20 s 窗口用于时间尺度敏感性分析；窗口严格截止于探针出现之前，并排除探针锚定试次。Q1 注意内容为四类别名义结局，以“完全专注”为参照，采用行为预测变量标准化后的多项 Logistic 回归，并使用参与者聚类稳健协方差；Q2 警觉程度为四级有序结局，采用以参与者为聚类单位的有序 GEE。模型报告标准化预测变量每增加 1 SD 对应的回归系数、标准误和 95% 置信区间。

### 4.5.2 近红外瞳孔测量

近红外视频首先使用项目训练的 YOLO26n 检测器定位眼部区域（Redmon et al., 2016），再采用 RITnet 四分类语义分割模型识别背景、巩膜、虹膜和瞳孔（Chaudhary et al., 2020）。正式分析利用瞳孔类别及其拓扑关系确定主要瞳孔成分，并对其进行椭圆拟合。虹膜类别用于辅助空间定位和分割质量评价，不用于构造瞳孔—虹膜比例。网络训练规模、眼部区域重建和模型输入尺寸等实现参数列于附录 A。

近红外指标分为直接几何、分割比例和质量指标三层。正式主分析使用瞳孔几何平均直径与硬分割瞳孔面积比例两个主要指标；瞳孔等效直径、椭圆长短轴、轮廓面积、椭圆面积和软分割瞳孔面积比例作为敏感性指标保留。瞳孔几何平均直径用于概括拟合椭圆两个主轴所表示的瞳孔尺度，硬分割瞳孔面积比例用于描述分割层面的相对瞳孔占比。两项指标的程序化计算定义及其与其他几何字段的对应关系在正式冻结时以当前生产代码为准，并在附录 A 保留可复现定义。

瞳孔数据质量综合眼部可见性、瞳孔分割与几何拟合稳定性、有效图像区域、分割不确定性以及连续帧的时间与几何连续性评价，左右眼分别保留测量结果。连续瞳孔序列根据分析尺度形成试次、Block 和探针前窗口指标。为控制屏幕刺激引起的瞳孔光反射差异，按照实际呈现规则重建 9 类水果与 3 种尺寸形成的 27 种视觉条件，计算数字相对亮度、RMS 对比度和刺激可见面积；试次级调整模型同时考虑当前与前一试次的视觉属性。这里的亮度指标表示屏幕图像之间的数字相对差异，不等同于光度计测得的物理照度。

瞳孔效标分析同时关注参与者间平均水平与参与者内相对波动。试次级正确 Go RT 采用线性混合效应模型，Go 遗漏和 No-Go 误按采用按参与者聚类的二项 GEE，并比较未调整模型与纳入视觉属性及数据质量协变量后的模型。探针前 30 s 分析中，Q1 采用多项 Logistic 回归，Q2 采用有序累积 Logit 模型；Block 层连续行为指标采用混合效应模型。主要结果同时报告参与者间项与参与者内相对项，使稳定个体差异与同一参与者的短时变化在解释上保持分离。

### 4.5.3 RGB 可见行为测量

RGB 视频分析聚焦于整体运动、画面亮度变化、姿态方向候选和眨眼候选事件。整体运动采用相邻帧图像变化形成的运动能量（motion energy）描述，并单独计算画面平均灰度变化，以区分身体运动与曝光或整体亮度变化。基于人体姿态关键点模型（BlazePose；Bazarevsky et al., 2020）提取的姿态关键点用于形成左右和上下方向的可见运动；前后方向综合深度方向姿态、肩宽变化和人体画面面积变化形成无量纲方向候选，只解释为图像中的前后变化趋势，不视为真实物理位移。

眼睑活动采用基于面部网格（MediaPipe；Lugaresi et al., 2019）的眼睛纵横比（eye aspect ratio, EAR）描述（Soukupová & Čech, 2016），左右眼分别计算，并以各自可观测时段中的较高开放水平作为相对参照。双眼均具有足够可用数据且变化基本一致时识别眨眼候选事件，候选闭眼阶段持续时间限定为 50～1000 ms；明显时间间隔、多脸歧义或主要面孔追踪切换构成事件边界。由此形成眨眼候选事件率、持续时间、事件间隔和有效帧比例等指标。在独立事件标注效度建立之前，相关结果均按算法识别的眨眼候选解释。

RGB 特征按 Block 内时间进程和探针前 30 s 窗口汇总。Block×时间段变化采用参与者聚类 GEE；探针层 Q1 采用多项 Logistic 回归，Q2 采用有序 GEE；RGB 特征与近期行为指标及毫米波指标的窗口级对应采用参与者聚类 GEE。探针层进一步保留参与者间平均水平和参与者内相对变化的分解结果。运动能量与曝光变化始终分轨分析，窗口有效帧比例等质量指标用于描述测量条件，不与状态指标混为同一心理构念。

### 4.5.4 毫米波心肺相关活动与身体微动

毫米波正式保存的数据已经表示为距离域复数信号，由 2 发射×4 接收形成 8 个通道，每个通道包含 256 个距离单元，距离间隔按 0.037 m/距离单元解释。分析在人体所在距离范围内综合信号能量、相位变化和时间稳定性选择用于微动分析的反射位置与通道，再提取并展开复数相位，获得胸壁方向上的相对微动序列。

呼吸与心搏相关变化采用不同频段处理。呼吸相关成分主要分析 0.10～0.50 Hz，心搏相关成分主要分析 0.8～2.0 Hz；心搏路径在带通滤波基础上结合变分模态分解（variational mode decomposition, VMD）形成补充窄带表示（Dragomiretskiy & Zosso, 2014）。呼吸频率和心率估计综合时域峰间隔、频域谱峰及两者一致性，并同时记录运动代理、心率可用窗口比例、心率置信度、相位稳定性和时间戳覆盖比例等测量质量信息。呼吸频率、心率和身体运动分别解释，不把质量指标本身视为持续注意的生理指标。滤波阶数、VMD 参数和内部候选窗口列于附录 A。

逐帧毫米波数据按采集过程中保存的实际时间与任务事件对应，连续分析窗口完全位于单个 Block 内，不跨越休息、坐姿调整和 Block 边界。正式效标分析使用探针前 30 s 窗口：Q1 采用多项 Logistic 回归，Q2 采用参与者聚类的有序 GEE，窗口行为结局采用参与者聚类 GEE；同时对主要连续预测变量进行参与者间/参与者内分解。身体运动的稳健性通过排除运动代理高于全样本第 90 百分位的窗口进行敏感性分析。RGB 连续运动量的协变量调整尚未形成正式结果，因此不作为当前报告已完成的方法或结论依据。

毫米波心率和呼吸估计另使用同步 ECG 与呼吸带记录进行外部参考核验，以评价探针前窗口尺度上的误差量级以及呼吸谐波锁半频等已知失效模式。逐搏级心搏识别只有在外部参考能够支持事件时序精度时才可用于 IBI/HRV 解释；当前正式报告不将逐搏间期和 HRV 作为主要生理结果。

### 4.5.5 跨模态对齐与多模态增量预测

行为、NIR、毫米波和 RGB 依据同一任务事件时间建立对应。多模态主分析单位为探针前 30 s 窗口，融合键由实验记录、Block 和 Block 内探针序号共同确定。Q1 与 Q2 标签统一由正式行为/思维探针数据提供，其他模态中的标签仅用于一致性核对。结构性缺失不编码为 0；缺失值处理、标准化、零方差或全缺失特征剔除以及参数选择均只在训练数据内完成。

多模态采用特征级早期融合，即各模态先独立完成信号处理和结构化特征提取，再将同一探针前窗口中的特征拼接为统一模型输入。近期行为构成基准模型 M0；NIR、毫米波和 RGB 分别作为可增加的信息块。当前正式融合使用的特征块为：

| 信息块 | 正式输入内容 |
|---|---|
| 近期行为 | 正确 Go RT 中位数、RT-CV、Go 遗漏相关冻结字段、No-Go 误按率与 d′ |
| NIR | 瞳孔几何平均直径、硬分割瞳孔面积比例，并在训练折内形成参与者内/参与者间分量 |
| 毫米波 | 融合心率、呼吸频率、运动代理、心率可用窗口比例、心率置信度、相位稳定性、时间戳覆盖比例 |
| RGB | 运动能量、曝光变化、左右/上下/前后方向候选、眨眼候选事件率、眨眼帧比例、窗口有效帧比例 |

八种比较组合固定为：M0 行为基准；M1 行为+NIR；M2 行为+毫米波；M3 行为+RGB；M4 行为+NIR+毫米波；M5 行为+NIR+RGB；M6 行为+毫米波+RGB；M7 行为+NIR+毫米波+RGB。所有组合使用相同的结局、相同的外层参与者划分和相同的评价指标，使增量比较只反映新增信息块带来的性能变化。

Q1 在融合中作为四分类名义结局；Q2 虽在单模态推断中保留四级有序结构，但在融合主分析中为保持统一的规则化分类框架，同样按四分类结局建模。主要可解释模型为 L2 规则化多项 Logistic 回归，正则化强度 C 在每个外层训练折内部通过按参与者分组的五折交叉验证选择；Random Forest 作为预设非线性补充模型，使用固定超参数。外层验证采用留一参与者交叉验证（leave-one-subject-out cross-validation, LOSO），每次将一名参与者的全部实验记录和探针观测作为测试数据，其余参与者用于训练，从而保证训练集和测试集在参与者层面完全分离。

分类性能报告 one-vs-rest 宏平均 ROC-AUC、平衡准确率、宏平均 F1 和对数损失。M1–M7 均与 M0 在相同测试参与者上进行逐折配对比较，并以参与者/LOSO 折为重抽样单位进行 2,000 次 bootstrap，报告性能差异及 95% 百分位置信区间。进一步对 NIR、毫米波和 RGB 的 3! = 6 种加入顺序计算平均边际贡献，用于描述各模态在已有信息基础上的平均预测增量；该指标只解释预测信息，不作因果归因。
