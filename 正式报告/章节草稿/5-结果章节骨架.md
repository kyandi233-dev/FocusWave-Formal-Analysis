注：表中为场次级 *M*（*SD*），比例指标以百分数表示。总体列及 B1、B2 列均基于 116 个实验场次。

整体上，正确 Go RT 的场次均值为 318.93 ms（*SD* = 88.88），场次中位数的平均水平为 309.31 ms（*SD* = 116.06）。正确 Go RT 的标准差为 98.40 ms（*SD* = 63.63），RT-CV 为 0.3033（*SD* = 0.1371）。错误指标中，总 Go 遗漏率平均为 2.20%（*SD* = 5.08%），No-Go 误按率平均为 33.44%（*SD* = 18.02%）；信号检测辨别力 d′ 的场次均值为 2.93（*SD* = 1.01）。

从 B1、B2 的描述统计看，平均反应速度基本保持稳定：正确 Go RT 均值分别为 319.10 ms 和 319.14 ms，中位数分别为 309.38 ms 和 306.69 ms。相比之下，反应时离散程度在 B2 中较高，RT 标准差由 91.95 ms 增至 100.76 ms，RT-CV 由 0.2852 增至 0.3083。总 Go 遗漏率由 1.86% 增至 2.53%，No-Go 误按率由 34.25% 降至 32.63%，d′由 2.91 变为 2.88。

为检验上述区块差异，对 116 个实验场次的 B1 与 B2 指标进行场次内配对，并采用参与者聚类自助重采样估计 B2−B1 的平均差及 95% 置信区间。同一参与者具有多个实验场次时，先对其各场次差值进行参与者内平均，再以 61 名参与者为重抽样单位进行 20,000 次 bootstrap。结果显示，B2 的 RT-CV 高于 B1，Δ = 0.029，95% CI [0.007, 0.055]；正确 Go RT 的标准差亦增加，Δ = 8.9 ms，95% CI [1.4, 17.2]，两项置信区间均未包含 0。

正确 Go RT 的均值和中位数、总 Go 遗漏率、No-Go 误按率及 d′的 B2−B1 差值的 95% 置信区间均包含 0。因此，B1 与 B2 的整体比较主要表现为正确 Go 反应时变异增大，而平均反应速度、总体遗漏、No-Go 误按和辨别力未出现同样稳定的区块差异。

进一步采用参与者聚类的广义估计方程考察 Block 内的时间进程。每个 Block 划分为 6 个连续 cycle，模型检验 Block、cycle 及 Block × cycle 交互作用。以 RT-CV 为因变量时，B2 相对 B1 的区块项为 *B* = 0.0292，*SE* = 0.0138，95% CI [0.0022, 0.0562]；cycle 项为 *B* = 0.0078，*SE* = 0.0023，95% CI [0.0033, 0.0122]；Block × cycle 交互项为 *B* = 0.0001，*SE* = 0.0030，95% CI [−0.0057, 0.0060]。模型纳入 61 名参与者、116 个实验场次和 1,391 条有效 cycle 记录。RT-CV 随 cycle 推进而升高，且 B2 整体水平高于 B1；交互项置信区间包含 0，未显示两个 Block 的 cycle 变化斜率存在明确差异。

### 5.2.2 反应错误及其时序特征

根据按键时序，Go 遗漏分为无时序歧义遗漏和时序歧义遗漏，后者包括伴随刺激前按键或跨试次按键延续的遗漏记录；两类遗漏之和为总 Go 遗漏率。整体上，无时序歧义遗漏率为 1.57%（*SD* = 4.44%），时序歧义遗漏率为 0.62%（*SD* = 1.21%）。B1 中两类遗漏率分别为 1.39% 和 0.47%，B2 中分别为 1.76% 和 0.77%。

采用与 5.2.1 相同的参与者聚类自助重采样比较 B1 与 B2。总 Go 遗漏率的 B2−B1 差值的 95% 置信区间包含 0；无时序歧义 Go 遗漏率的 B2−B1 差值为 0.0018，95% CI [−0.0068, 0.0099]，同样未达到当前置信区间判据。时序歧义 Go 遗漏率在 B2 中增加，Δ = 0.0030，95% CI [0.0011, 0.0052]。No-Go 误按率由 B1 的 34.25% 降至 B2 的 32.63%，但其 B2−B1 差值的 95% 置信区间包含 0。

因此，总 Go 遗漏率在两个 Block 间未见稳定变化，但遗漏记录的时序构成发生了变化：B2 中时序歧义遗漏比例有所升高，而无时序歧义遗漏未出现明确区块差异。结合 RT-SD 和 RT-CV 的增加，任务后期较稳定的变化集中于反应时间分布和按键时序，而不是所有错误指标同步增加。

错误事件轨迹进一步考察错误发生附近的短时反应变化。正式运行共形成 39,710 条事件相对试次记录，其中包括 3,724 个 No-Go commission 事件，以及在不同相对位置上 1,944～1,957 个 Go omission 事件。反应时以参与者内正确 Go RT 为基线进行中心化，0 位置为错误事件本身，因此不定义正确 Go RT。

Go omission 发生前的正确 Go RT 相对基线呈逐步升高趋势：事件前第 3、2、1 个试次的平均偏移分别为 32.8 ms（*SEM* = 15.1）、48.8 ms（*SEM* = 12.3）和 76.6 ms（*SEM* = 19.2）。遗漏后的第 1 个正确 Go 试次平均偏移降至 −38.3 ms（*SEM* = 10.7），随后第 2、3 个试次分别为 6.7 ms（*SEM* = 7.1）和 10.3 ms（*SEM* = 7.6）。从均值轨迹看，Go omission 前出现较明显的反应延长，并在遗漏后的首个正确 Go 反应中出现短暂反向偏移。

No-Go commission 周围的 RT 偏移幅度较小。误按前第 3、2、1 个正确 Go 试次的平均偏移分别为 4.4 ms（*SEM* = 5.3）、8.6 ms（*SEM* = 5.0）和 9.7 ms（*SEM* = 5.0）；误按后第 1、2、3 个正确 Go 试次分别为 −6.1 ms（*SEM* = 9.1）、−18.3 ms（*SEM* = 7.1）和 −6.6 ms（*SEM* = 7.0）。与 Go omission 相比，No-Go commission 前后的平均 RT 轨迹整体更接近参与者自身基线。

### 5.2.3 思维探针与行为表现

116 个实验场次共获得 2,320 个思维探针记录，每个场次 20 个。主分析采用探针出现前 30 s 的行为窗口，并以参与者为聚类单位。Q1 四类别的探针数量分别为 1,594（68.7%）、467（20.1%）、95（4.1%）和 164（7.1%）；Q2 四个等级的探针数量分别为 39（1.7%）、334（14.4%）、1,054（45.4%）和 893（38.5%）。

**表 5-3 思维探针 Q1 与 Q2 的分布**

| 探针变量 | 类别/等级 | n | 比例 |
|---|---:|---:|---:|
| Q1 | 1 | 1,594 | 68.7% |
| Q1 | 2 | 467 | 20.1% |
| Q1 | 3 | 95 | 4.1% |
| Q1 | 4 | 164 | 7.1% |
| Q2 | 1 | 39 | 1.7% |
| Q2 | 2 | 334 | 14.4% |
| Q2 | 3 | 1,054 | 45.4% |
| Q2 | 4 | 893 | 38.5% |

Q1 采用多项 Logistic 回归，以 Q1 类别为因变量、标准化后的近期行为指标为预测变量，并以类别 1 为参照；协方差采用参与者聚类稳健估计。No-Go 误按率与 Q1 类别分布存在明确关联：No-Go 误按率每增加 1 个标准差，类别 2 相对于类别 1 的回归系数为 *B* = 0.598，95% CI [0.384, 0.812]；类别 3 相对于类别 1 为 *B* = 0.729，95% CI [0.481, 0.976]。

d′与 Q1 的关系方向相反。d′每增加 1 个标准差，类别 2 相对于类别 1 的回归系数为 *B* = −0.448，95% CI [−0.700, −0.196]；类别 3 相对于类别 1 为 *B* = −0.620，95% CI [−0.940, −0.300]。上述四个置信区间均未包含 0，表明类别 2 和类别 3 相对于参照类别的出现与较高的 No-Go 误按率及较低的 d′具有一致方向的关联。

类别 4 与类别 1 的比较未呈现同等稳定的模式。No-Go 误按率的标准化回归系数为 *B* = 0.127，95% CI [−0.314, 0.567]；d′的标准化回归系数为 *B* = −0.283，95% CI [−0.842, 0.275]，两项置信区间均包含 0。正确 Go RT、RT 变异及 Go 遗漏相关指标在当前 Q1 模型中也未出现与 No-Go 误按率和 d′同样明确的关联。

Q1 的 No-Go 误按率、d′、criterion c、β，以及总 Go 遗漏、无时序歧义遗漏和时序歧义遗漏模型均纳入 61 名参与者、116 个实验场次和 2,320 条探针记录。RT mean、RT median、RT-SD、MAD 和 IQR 模型分别纳入 2,318 条记录；RT-CV 模型纳入 61 名参与者、112 个场次和 1,814 条记录；RT slope 模型纳入 2,316 条记录。

Q2 采用有序广义估计方程，以四级警觉程度为有序因变量、标准化后的近期行为指标为预测变量，并以参与者为聚类单位。No-Go 误按率的标准化回归系数为 *B* = −0.299，*SE* = 0.050，95% CI [−0.397, −0.201]；d′为 *B* = 0.389，*SE* = 0.052，95% CI [0.287, 0.490]；无时序歧义 Go 遗漏率为 *B* = −0.404，*SE* = 0.082，95% CI [−0.564, −0.244]；RT-CV 为 *B* = −0.232，*SE* = 0.055，95% CI [−0.340, −0.123]。四项置信区间均未包含 0。

No-Go 误按率、d′和无时序歧义 Go 遗漏率的 Q2 模型均纳入 61 名参与者、116 个实验场次和 2,320 条探针记录；RT-CV 模型纳入 61 名参与者、112 个场次和 1,814 条记录。按当前 Q2 编码方向，较高的警觉等级与较低的 No-Go 误按率、较低的无时序歧义 Go 遗漏率和较低的 RT-CV 相关，同时与较高的 d′相关。

总体上，Q1 中较明确的行为关联主要集中于 No-Go 误按率和 d′；Q2 则同时与 No-Go 误按率、d′、无时序歧义 Go 遗漏率和 RT-CV 相关。两类探针从注意内容和警觉程度两个方面呈现了即时主观状态与探针前近期行为之间的对应关系。
