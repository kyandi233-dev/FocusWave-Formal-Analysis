任务时间效应首先比较同一实验记录内的 B1 与 B2。正式分析对每个场次计算 B2−B1 的指标差值；同一参与者具有多个实验记录时，先在参与者内汇总场次差值，再以参与者为重抽样单位进行 20,000 次自助重采样，估计平均差及 95% 置信区间。结果显示，B2 的 RT-CV 高于 B1，平均差为 Δ = 0.029，95% CI [0.007, 0.055]；正确 Go RT 的标准差亦增加，Δ = 8.9 ms，95% CI [1.4, 17.2]。两项置信区间均未包含 0，表明任务后期正确反应的时变波动增大。

相比之下，正确 Go RT 的均值和中位数、总 Go 遗漏率、No-Go 误按率及 d′的 B2−B1 差值的 95% 置信区间均包含 0。当前结果因此未显示平均反应速度、总体 Go 遗漏、No-Go 抑制表现或辨别力在两个 Block 间发生同方向的稳定变化，而反应时离散程度的增加更为明确。

除 B1/B2 配对比较外，正式管线还以 Block × cycle 的广义估计方程检验区块内任务进程。模型以参与者为聚类单位，对各行为指标估计 Block、cycle 及其交互项的参数、标准误和 95% 置信区间。该部分在最终正文中仅报告与主要任务时间效应直接相关且经正式结果表核实的参数。

### 5.2.2 反应错误及其时序特征

Go 遗漏和 No-Go 误按对应不同的试次要求，正式分析分别计算两类错误。No-Go 误按表示在 No-Go 试次中发生按键；Go 遗漏表示在 Go 试次中未记录到有效反应。根据遗漏试次附近的按键时序，总 Go 遗漏进一步分为无时序歧义遗漏和时序歧义遗漏。前者未伴随刺激前按键或跨试次按键延续，后者存在上述至少一种时序现象；两类遗漏使用相同的 Go 试次分母，其比例之和等于总 Go 遗漏率。

B1 与 B2 的比较继续采用参与者聚类自助重采样。总 Go 遗漏率的 B2−B1 置信区间包含 0；时序歧义 Go 遗漏率在 B2 中增加，Δ = 0.0030，95% CI [0.0011, 0.0052]。无时序歧义遗漏率的完整 B1、B2 水平及其差值将在表 5-2 和正式 B1/B2 结果表核对后同时报告。No-Go 误按率未显示明确的 B1−B2 区块差异。

该结果表明，程序记录的总 Go 遗漏在两个 Block 间没有稳定增加，但其中伴随刺激前按键或跨试次按键延续的时序歧义遗漏在任务后期有所增加。结合同时出现的 RT-SD 和 RT-CV 增大，当前区块比较主要表现为反应时间分布和按键时序稳定性的变化。

正式分析同时构建了错误事件轨迹，以 Go omission 和 No-Go commission 为事件中心，提取错误事件前后的正确 Go 反应时，并先按参与者的正确 Go RT 基线进行中心化。当前正式运行共生成 39,710 条错误事件轨迹记录。该分析用于比较随后发生错误与未发生错误的事件附近是否存在一致的 RT 时序差异，其具体相对试次效应和置信区间需依据 `error_trajectory_summary` 正式结果表核实后写入正文。

### 5.2.3 思维探针与行为表现

当前 116 个行为场次共获得 2,320 个正式思维探针记录，主分析采用每次探针前 30 s 的行为窗口。探针级分析保留重复测量结构，并以参与者为聚类单位。Q1 表示四类注意内容，作为名义分类变量分析；Q2 表示四级警觉程度，作为有序变量分析。

Q1 采用多项 Logistic 回归。模型以 Q1 类别作为因变量、标准化后的行为指标作为预测变量，以类别 1 为参照，并使用参与者聚类稳健协方差。No-Go 误按率每增加 1 个标准差，Q1 类别 2 相对于类别 1 的回归系数为 *B* = 0.598，95% CI [0.384, 0.812]；类别 3 相对于类别 1 的回归系数为 *B* = 0.729，95% CI [0.481, 0.976]。两项置信区间均未包含 0。

d′与 Q1 的关系方向相反。d′每增加 1 个标准差，类别 2 相对于类别 1 的回归系数为 *B* = −0.448，95% CI [−0.700, −0.196]；类别 3 相对于类别 1 为 *B* = −0.620，95% CI [−0.940, −0.300]。类别 4 相对于类别 1 的 No-Go 误按率系数为 *B* = 0.127，95% CI [−0.314, 0.567]，d′系数为 *B* = −0.283，95% CI [−0.842, 0.275]，两项置信区间均包含 0。正确 Go RT、RT 变异及 Go 遗漏相关指标在当前 Q1 模型中未出现同样明确的关联模式。

Q2 采用有序广义估计方程，以四级警觉程度作为有序因变量、标准化后的行为指标作为预测变量，并以参与者为聚类单位。当前已核验的正式结果显示，No-Go 误按率、d′、无时序歧义 Go 遗漏率和 RT-CV 均与 Q2 等级存在关联；对应标准化回归系数分别约为 *B* = −0.299、0.389、−0.404 和 −0.232。该部分正式正文在回填前不使用近似系数作为最终统计量，最终需从 `q2_ordinal_gee_models.csv` 逐项写入 *B*、*SE* 和 95% CI。

从已核验的方向看，较高的 Q2 警觉等级对应较低的 No-Go 误按率、较低的无时序歧义 Go 遗漏率和较低的 RT-CV，同时对应较高的 d′。Q1 与 Q2 的结果分别呈现注意内容类别和警觉程度与近期行为表现之间的关系。
