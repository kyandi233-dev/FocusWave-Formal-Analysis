# 3 研究目标与研究问题

综上，现有研究已经证明持续注意可以通过行为表现、主观体验以及多类生理和外显行为指标加以描述，毫米波也具备连续获取人体微动和部分生命体征信息的技术基础。然而，现有证据仍存在三个相互关联的不足。其一，既有毫米波研究主要集中于生命体征提取或动作识别，其特征与标准化持续注意指标之间的效标关系仍缺乏系统检验。其二，持续注意具有明显的个体内波动，而已有研究常以整体标签或简单分类处理状态，较少同时区分稳定的个体差异与同一个体随时间发生的变化。其三，不同模态具有各自的非特异性和测量误差，跨模态关系还会受到时间对齐、缺失模式和质量差异影响，因此多模态的互补价值需要在统一任务、共同时间单位和一致统计框架下加以验证。

基于上述问题，本研究旨在构建一套面向持续注意动态变化的多模态测评框架。该框架以游戏化持续性注意反应任务（SART）提供统一任务情境，以行为表现和思维探针分别表征可观察的任务表现与可报告的主观状态，并同步获得近红外眼部、毫米波雷达和 RGB 视频信息。研究重点在于检验不同连续观测与持续注意表现之间的效标关系，并区分个体间差异、个体内波动和任务时间进程。在此基础上，进一步比较各模态在共同样本与共同时间单位下能够提供的独立信息与互补信息，从而评价毫米波及多模态连续测量在持续注意测评中的适用范围。

## 3.1 研究问题

围绕上述目标，研究提出三个相互衔接的问题。

1. 游戏化 SART 中的反应速度、反应稳定性、Go 遗漏、No-Go 错误按键以及辨别力等行为指标，如何共同描述持续注意表现，并与思维探针记录的注意内容和警觉程度相联系？这些关系在试次、探针前窗口、区块和场次等不同时间尺度上是否具有一致性？

2. 在考虑任务时间进程、参与者差异以及各模态特有影响因素后，近红外瞳孔动态、毫米波心肺相关微动与身体运动、RGB 头部和眼睑等可见行为特征，分别与行为表现和思维探针呈现怎样的对应关系？这些关系主要体现为稳定的个体间差异，还是同一个体相对于自身平均水平的动态变化？

3. 在相同样本范围、相同时间单位和相同认知效标下，不同传感模态是否能够提供稳定而非冗余的互补信息？将多种连续观测联合使用时，其对持续注意表现或主观状态的解释与预测是否优于单一传感模态，并能否在按参与者划分的验证中保持稳定？

## 3.2 研究假设与分析预期

基于前述持续注意、思维探针和多模态测量文献，本研究对行为与主观状态之间的关系提出方向性预期：相较于任务专注和较高警觉状态，任务脱离或较低警觉状态预计伴随更不稳定的反应表现，表现为反应时变异增大、反应迟缓或辨别表现下降。由于 Go 遗漏与 No-Go 错误按键具有不同的任务含义，两类错误分别检验，不预设其必然沿同一方向变化。

对于连续生理和外显行为信号，现有研究显示瞳孔、心率、呼吸和身体运动与注意状态之间的关系会受到视觉输入、任务时间、运动、个体特征和状态类型调节，因此不对每一项传感特征预设统一的升高或降低方向。相应的检验重点是：在控制相关影响因素后，至少部分近红外、毫米波或 RGB 特征能够解释同一个体内部随时间变化的行为或主观状态差异，并且这种关系不完全由任务时间进程或稳定个体差异所造成。

进一步地，如果不同模态确实提供相互补充的测量信息，则在共同样本和相同验证条件下，联合模型相对于相同基线条件下的单一传感模态模型应表现出稳定的增量信息。该预期通过按参与者分组的模型比较加以检验，以避免同一参与者的多次观测同时进入训练与验证而高估跨个体泛化能力。
