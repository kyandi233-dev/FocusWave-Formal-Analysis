# 3 研究目标与研究问题

本研究旨在构建面向持续注意动态变化的多模态测评框架。研究以游戏化持续性注意反应任务（SART）为统一任务情境，同步记录行为、思维探针、近红外眼部视频、毫米波雷达和 RGB 视频，分别考察任务时间变化、单模态效标关系以及传感特征相对于近期行为的增量预测价值。

## 3.1 研究问题

1. 游戏化 SART 中的反应速度、反应稳定性、Go 遗漏、No-Go 误按和辨别力如何随任务进程变化？这些行为指标与 Q1 注意内容和 Q2 警觉程度呈现怎样的关系？

2. 近红外瞳孔、毫米波心肺相关微动与身体运动、RGB 可见运动和眼睑活动分别与行为表现及思维探针呈现怎样的关系？其中哪些关系主要体现为参与者间差异，哪些体现为参与者内波动？

3. 在相同探针时间窗和留一参与者验证条件下，加入 NIR、毫米波和 RGB 特征后，Q1 和 Q2 的预测表现是否优于近期行为基准？不同传感模态的边际贡献有何差异？

## 3.2 研究假设与分析预期

随着任务持续，反应稳定性预计下降；任务脱离或较低警觉状态预计伴随更大的反应时变异，并可能伴随较差的辨别表现。Go 遗漏与 No-Go 误按分别分析，不预设二者具有相同的时间变化方向。

瞳孔、心率、呼吸和身体运动受视觉输入、任务时间、运动和个体差异等因素影响，因此不对所有传感特征设定统一方向。分析考察这些特征与行为及思维探针的关系，并在适用模型中区分参与者间差异与参与者内波动。

预期部分传感组合能够提高 Q1 或 Q2 的预测表现，增量大小可能因模态和评价指标而异。外层验证以参与者为独立单位。
