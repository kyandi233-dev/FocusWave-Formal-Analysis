# 3 研究目标与研究问题

综上，已有研究已经从行为表现、主观体验、生理活动和外显行为等层面描述持续注意，并为毫米波连续感知人体微动和部分生命体征提供了技术基础。然而，将这些观测进一步用于持续注意测评仍存在若干关键问题。其一，既有毫米波研究主要集中于生命体征提取或动作识别，其特征与标准化持续注意行为及思维探针之间的效标关系仍缺乏系统检验；其二，持续注意具有明显的时间动态，同一指标的参与者间稳定差异与参与者内短时波动可能具有不同含义；其三，不同传感模态具有各自的非特异性、测量误差与缺失模式，单一模态出现效标关联并不必然意味着该模态能够提高对独立参与者注意状态的预测。因此，多模态持续注意测量需要在统一任务、明确时间单位和一致统计框架下，分别建立单模态效标证据与多模态增量证据。

基于上述问题，本研究旨在构建一套面向持续注意动态变化的多模态测评框架。该框架以游戏化持续性注意反应任务（SART）提供统一任务情境，以行为表现和思维探针分别表征可观察的任务表现与可报告的主观状态，并同步获得近红外眼部、毫米波雷达和 RGB 视频信息。研究首先考察行为表现及主观状态随任务进程的变化；随后分别评价近红外瞳孔、毫米波心肺相关微动与身体运动、RGB 可见行为特征的数据质量、时间变化及其与行为和思维探针的效标关系，并在适用分析中区分参与者间差异和参与者内波动；最后在共同探针前时间窗上，以近期行为构成预测基准，检验加入不同传感模态后对主观注意状态是否产生稳定的增量预测信息。

## 3.1 研究问题

围绕上述目标，研究提出三个相互衔接的问题。

1. 游戏化 SART 中的反应速度、反应稳定性、Go 遗漏、No-Go 误按和辨别力等行为指标，如何从区块、Block 内时间进程、错误事件和探针前窗口等尺度描述持续注意表现？这些行为变化与思维探针记录的注意内容和警觉程度呈现怎样的对应关系？

2. 在考虑任务时间进程、重复测量结构以及各模态特有影响因素后，近红外瞳孔动态、毫米波心肺相关微动与身体运动、RGB 可见运动与眼睑活动分别与行为表现和思维探针呈现怎样的关系？对于能够进行层级分解的连续指标，这些关系主要体现为稳定的参与者间差异，还是同一参与者相对于自身平均水平的动态变化？

3. 在相同探针时间窗和参与者独立验证条件下，以近期行为特征构成预测基准后，加入 NIR、毫米波和 RGB 中一个或多个传感模态，是否能够提高对 Q1 注意内容和 Q2 警觉程度的预测表现？不同传感模态在已有信息基础上的边际贡献主要表现为互补、重复还是有限增量？

## 3.2 研究假设与分析预期

基于持续注意和思维探针研究，对行为与主观状态之间的关系提出方向性预期：随着任务持续，反应速度本身未必持续改变，但反应稳定性可能下降；相较于任务专注和较高警觉状态，任务脱离或较低警觉状态预计伴随更大的反应时变异，并可能伴随较差的辨别表现。由于 Go 遗漏与 No-Go 误按具有不同的任务要求和形成过程，两类错误分别检验，不预设其必然沿同一方向变化。

对于连续生理和外显行为信号，既有研究显示瞳孔、心率、呼吸和身体运动与注意状态之间的关系会受到视觉输入、任务时间、运动、个体特征和状态类型调节，因此不对每一项传感特征预设统一的升高或降低方向。相应地，预期至少部分近红外、毫米波或 RGB 特征在考虑相关影响因素后，与行为表现或思维探针存在可重复的效标关系；对于具有重复测量结构的指标，同时检验参与者间稳定差异与参与者内状态波动是否表现出不同方向或大小。

多模态分析检验的是传感信息相对于近期行为基准的增量价值，而不是重新定义单模态效度。若不同传感模态确实包含行为基准未能覆盖的稳定状态信息，则在相同参与者、相同探针观测和相同留一参与者交叉验证划分下，加入相应传感特征后至少部分性能指标应优于行为基准；若不同模态提供的信息主要重复或测量噪声较大，则增量可能较小或只出现在部分结局、模型与评价指标中。所有增量比较均以参与者为独立验证单位，以避免同一参与者同时进入训练与测试造成的性能高估。
