## 一、报告总叙事调整

当前报告最有竞争力的主线应从“多传感器 + AI”调整为“心理测量证据链 + AI 自动感知 + 严格泛化验证”。

推荐总链条：

持续注意构念 → 游戏化 SART 行为 → 思维探针 Q1 / Q2 → NIR / mmWave / RGB 自动感知 → 可解释候选指标 → 重复测量统计与构念效度 → 行为基线上的多模态增量 → 独立参与者泛化。

原因：测验赛道关注的不是只把分类性能做高，而是解释“为什么系统输出有资格被理解为持续注意相关测量”。因此 AI 方法必须放在测量链中，而不是成为独立炫技模块。

## 二、第 2 章文献综述：补强测量学逻辑

### 2.1 保留持续注意的多层表现

需要明确：持续注意不是单一可直接观察变量，可在行为、主观体验、生理活动和外显运动上表现。不同模态不是同一个指标的重复复制，而是不同观测方法。

### 2.2 强化构念效度 / 聚合 / 区分逻辑

在 2.5 中清楚说明：

- 构念效度不是“某个相关显著”就完成；
- 理论上相关的不同方法应出现一定聚合；
- 注意内容、警觉、体动、光照和稳定个体生理差异需要区分；
- 多模态价值要由测量质量、效标关系和增量信息共同支持。

### 2.3 不提前承诺传感器一定优于行为

文献综述和研究目标都不写“多模态必然更准确”。改为：检验传感模态能否提供行为之外的稳定补充信息，以及不同模态是否对应不同状态维度。

## 三、第 3 章研究问题：建议保持四层问题

1. 行为和主观状态是否随任务时间发生变化？
2. NIR、mmWave、RGB 候选指标是否具备足够测量质量，并与行为 / 主观效标呈理论可解释关系？
3. 这些关系是稳定参与者差异，还是同一个人的短时状态变化？
4. 在新参与者上，传感模态相对于近期行为基线是否提供稳定增量？

后续若完成 ICC / 构念效度矩阵，可增加“哪些指标表现出稳定个体差异与状态波动的不同组成”，但未运行前不在研究结果中预写结论。

## 四、第 4.3 预实验：升级为“测验设计形成证据”，不是单纯流程试跑

现有第二阶段三个相同 B Block 有明确方法价值：

- 证明相同条件下也能出现任务时间动态；
- 一个短 Block 不足以稳定观察缓慢变化；
- 三个长 Block 增加负担，而第三 Block 的新增信息相对有限；
- 因此正式采用两个长 Block 是基于预实验的测验长度优化，而不是拍脑袋决定。

后续若完成补分析，正文可增加极少量“B1→B2 方向与正式实验一致”的形成性复现描述；完整 B1→B2→B3 统计继续放附录 B，不与正式 116 场合并。

## 五、第 4.5 方法：AI 方法需要更清晰但不堆网络结构

### 5.1 NIR 自动感知链

正文应清楚解释：

NIR 视频 → YOLO26n 定位眼部 ROI → RITnet 对背景 / 巩膜 / 虹膜 / 瞳孔逐像素分割 → 瞳孔几何拟合 → Dgeom / Phard 等指标。

术语第一次出现时给中文解释：

- object detection：目标检测，回答“目标在哪里”；
- semantic segmentation：语义分割，回答“每个像素属于哪一类”；
- geometric fitting：几何拟合，把像素区域转成可比较的连续几何量。

重点说明 AI 的职责是自动获取测量特征，不是直接输出心理真值。

### 5.2 RGB 自动感知链

正文应区分：

- BlazePose：预训练人体姿态关键点模型；
- MediaPipe Face Mesh：预训练面部 / 眼部关键点模型；
- EAR（eye aspect ratio，眼睛纵横比）：由关键点几何关系描述眼睑开合；
- blink candidate：基于 EAR 时序、双眼一致性和持续时间等规则形成候选事件；
- motion energy / exposure：传统图像变化与亮度统计，不包装成深度学习。

“预训练视觉模型”解释为：模型已经在外部大量图像上学习通用人体 / 面部结构，本项目利用其特征提取能力，而不是使用本项目 61 名参与者视频从零训练。

### 5.3 毫米波

明确为数字信号处理与估计链，不写成“深度学习雷达”。区分 HR / BR / motion / quality，并继续保留当前生理效度等级。

### 5.4 融合模型

正文对 L2 正则化多项 Logistic 回归只解释到科学需要的程度：

- 多项 Logistic 用于四分类；
- L2 正则化限制过大的系数，减少多特征条件下过拟合；
- 正则化强度只在训练参与者内选择；
- Random Forest 作为非线性补充模型，用于检查复杂组合信息，不取代可解释主模型。

实现细节继续放附录 A。

## 六、第 5.2 行为：强调“时间动态”，而不是简单总分

### 6.1 SDT

方法中保留 d′ / c / β、最低机会数和 loglinear 校正的科学解释；结果只报告需要的指标与数值。

不要写“4 次全对就等于真实 100% 能力”。有限窗口的 0 / 1 比例需要校正后再做 Z 变换。

### 6.2 错误事件轨迹

保留 Go omission 前 RT 延长和错误后回落等局部时间信息。它的价值是说明错误前存在行为轨迹，不应直接写成“证明走神”。No-Go commission 与 omission 的不同轨迹支持两类错误分开分析。

### 6.3 B1 / B2 与 cycle

正文要让读者清楚：

- B1 vs B2 = 较大时间尺度；
- cycle = Block 内较细时间尺度；
- 两者一致支持的主要变化是 RT 变异增大，而不是所有行为指标一起恶化。

## 七、重复被试与 GEE：正文必须让评委看出已正确处理

建议在 4.1 / 4.5 用一句简洁但明确的方法陈述：

“同一参与者的重复实验记录构成参与者内重复测量；推断统计采用参与者聚类或参与者层级重抽样，预测模型按参与者划分训练与测试。”

解释重点：

- 116 个 session 不等于 116 个独立人；
- 2,000 多 probe 也不等于 2,000 多个独立样本；
- GEE 以 participant 为 cluster；
- B1/B2 bootstrap 按 participant 重抽样；
- LOSO 整个人留出，避免同人跨训练 / 测试。

若正式代码没有明确 working correlation structure，不在正文或附录补造。

## 八、95% CI 与效应大小：结果写作需避免“CI 不跨 0 = 效果很大”

正式结果继续报告 effect estimate + 95% CI，但讨论和答辩材料要区分：

- CI 是否跨 0：方向的不确定性；
- B / Δ / OR：效应大小；
- 实际意义：对测验和预测是否有足够价值。

例如 RT-CV 的 B1→B2 差值虽然数值约 0.029，但指标本身约 0.3，不能只凭“小数点后数值”判断效果微不足道，也不能因为 CI 全为正就称为大效应。

## 九、第 5.3–5.5 单模态结果：按证据等级写，不要求三模态同样“成功”

### 9.1 NIR

定位：中等成熟度的候选测量。

写法重点：

- 视觉刺激与质量控制；
- between-person 和 within-person 分开；
- 不把“参与者平均瞳孔较大的人行为不同”误写成“同一个人瞳孔瞬时变大就更专注”。

### 9.2 RGB

定位：眨眼候选统计关联较集中，但上游事件效度未完成。

写法重点：

- 坚持“blink candidate”；
- 将 motion / exposure / pose 的功能分别说清；
- 不把曝光或有效帧比例写成心理特征。

### 9.3 mmWave

定位：支持性 / 探索性心肺估计 + motion / quality。

写法重点：

- BR 可作为后续候选；
- HR 当前误差与系统偏差明确；
- HRV 未过逐搏验证，不进入正式解释。

## 十、第 5.6 多模态：需要重新组织“为什么选这些特征”

当前 M0–M7 正式结果不回改，但报告表达应把输入分成三层：

### 10.1 核心构念候选

- 行为：RT-CV、omission、commission、d′、必要的 RT；
- NIR：Dgeom；
- mmWave：respiration，HR 作为探索性；
- RGB：blink candidate rate。

### 10.2 外显行为 / 辅助状态

- overall motion；
- pose / direction candidates。

### 10.3 质量 / 混杂

- exposure；
- valid-frame coverage；
- mmWave confidence / timestamp coverage；
- NIR quality。

理由：如果所有变量在表里平铺，会让人误以为“亮度变化、有效帧率、姿态方向都被当成注意构念”。分层后可明确哪些变量用于心理解释，哪些只是帮助模型判断输入质量或排除混杂。

## 十一、多模态补分析：theory-guided compact feature set

现有 full feature M0–M7 继续保留为正式基线。

建议新增敏感性分析：

- full feature set；
- theory-guided compact set。

两者必须使用相同：

- 61 人共同 cohort / 实际可用共同样本；
- LOSO folds；
- 训练折内插补 / 标准化 / 筛选；
- Logistic / Random Forest 评价框架；
- AUC、balanced accuracy、macro-F1、log loss；
- participant-level bootstrap CI。

若 compact set 性能相近：可作为“模型不依赖大量弱解释特征”的证据。

若性能下降：只能说明辅助 / QC 特征对预测有帮助，不能自动把它们提升为注意心理指标。

## 十二、心理测量补强：优先级

### P1：重复测量稳定性 / ICC

优先行为 RT-CV、d′、commission、omission；NIR pupil 和 RGB blink 是否进入取决于重复有效 session 和质量覆盖。

ICC 目的：分解稳定个体差异与 session 内 / session 间变化，不是证明“注意应该恒定”。

正文未完成前只写“计划补充”，不写结果。

### P1：聚合 / 区分效度矩阵

将行为、Q1、Q2、NIR、RGB、mmWave 的关系汇总为一张证据矩阵，标记：

- 方向一致；
- only-within；
- only-between；
- 不明确；
- 探索性；
- 上游测量未验证。

该图 / 表优先进入讨论或附录，必要时在第 7 章作为“测量效度框架”创新展示。

### P2：预实验复现

- 预实验 B1→B2 与正式 B1→B2 做方向一致性比较；
- 预实验 B3 用于测验长度边际信息；
- 不把预实验并入正式 N。

### 暂不优先

- 常模；
- 诊断切点；
- 为形成统一总分而强行做因子分析 / SEM / IRT；
- 为“更 AI”而增加端到端深度网络。

## 十三、第 6 章讨论：建议采用“证据分层”而不是逐模态报喜

建议讨论顺序：

1. 行为时间动态最稳定；
2. Q1 / Q2 说明注意内容与警觉需要区分；
3. NIR / RGB / mmWave 各自提供不同层次候选信息；
4. participant-within / between 说明“谁本来不同”和“同一个人此刻变化”不能混在一起；
5. 多模态增量小且模型依赖，说明无感传感目前是补充而非替代；
6. 上游测量验证不足是限制，而不是靠统计显著性绕过；
7. 后续重点是测量效度和简洁可解释模型，不是单纯提高模型复杂度。

## 十四、第 7 章特色创新：AI 与心理测量结合的正确落点

建议创新点从“用了哪些算法”提升到以下层面：

- AI / 视觉模型把原始视频转成无感可重复测量特征；
- 心理统计把自动感知结果与持续注意构念建立效度关系；
- 多模态按测量质量—效标关联—共同队列增量逐层验证；
- 重复参与者通过 participant-level clustering / LOSO 正确处理；
- 形成性预实验用于任务参数和测验时长优化；
- 结果允许阴性和边界结论，不以传感器数量或模型复杂度定义“智能”。
