# 2.3 心肺活动与身体微动

持续注意的波动伴随自主神经活动变化。心率（heart rate, HR）描述单位时间内的心搏次数，心率变异性（heart rate variability, HRV）描述相邻心搏间期随时间的变化。二者同时受到自主神经调节、呼吸、姿势、应激和个体差异影响。Hansen 等（2003）在持续注意与工作记忆任务中发现，较高的静息迷走神经调节水平与更好的认知表现相关，支持心脏自主神经活动与注意控制之间的联系。

任务中的心脏活动与注意状态关系并不固定。Smallwood 等（2004）在 SART 中结合思维探针、行为、心率和皮肤电反应，发现任务投入与任务无关思维对应不同的行为和心理生理模式。Corcoran 等（2025）进一步发现，心智游移与较高 HRV 相关，而大脑空白表现出更明显的心率降低；较低心率还与较低警觉、较慢反应及较小瞳孔相关。HR 与 HRV 因而可能对应不同的任务脱离和唤醒过程。

心率效应还会受到个体特征和分析条件调节。Sorella 等（2026）比较有经验冥想者与无冥想经验对照者在 SART 中的任务专注和心智游移片段，发现两组在心智游移时均表现出反应时和眨眼增加，但显著心率下降只出现在冥想者中。既有研究对心智游移时心率升高或降低的结果并不一致，样本、时间窗口和状态分类均可能影响效应方向。

呼吸活动也与注意调节有关。Melnychuk 等（2018）从蓝斑核（locus coeruleus, LC）的共同调节作用出发，报告呼吸相位、蓝斑核相关活动与注意表现之间的同步证据。呼吸频率和周期同时受到说话、姿势、情绪、运动和个体生理差异影响，因此需要结合任务情境和时间窗口分析。

身体微动同样具有明显的情境依赖。Carriere 等（2013）发现，更高的自发心智游移和不注意倾向能够独立预测更高的自报告小动作倾向。Farley 等（2013）在 40 分钟视频讲座中发现，宏观小动作随任务时间增加而增多，同时主观注意下降；将任务时间纳入模型后，小动作与注意评分之间的直接关系不再显著，提示任务持续时间可能同时影响身体运动与注意表现。

在非接触生命体征测量中，身体运动还会改变胸壁位移和雷达回波，影响心率和呼吸估计。因此，毫米波分析需分别保留心率、呼吸和运动特征，并同时评价运动条件下的测量质量。IBI（interbeat interval，心搏间期）和 HRV 的解释还依赖逐搏时序精度及外部参考验证。
