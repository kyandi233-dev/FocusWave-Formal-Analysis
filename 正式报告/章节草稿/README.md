第 4 章继续使用“参与者与研究结构 → 共同任务范式 → 预实验形成正式方案 → 正式程序与采集 → 数据处理与统计”的原报告逻辑。2026-08-30 的整章复核进一步压缩了跨节重复：4.2 首次定义“任务区块（Block）”并只保留共同 SART 规则；4.3 将预实验结果压缩为支持设计决策的关键方向和少量代表数字；4.4 集中呈现正式实验结构、探针、伪随机规则、实验流程和多模态采集，并新增“表 4-1 正式实验设备与采集参数”；4.5 则集中说明各模态算法、分析变量和统计推断。

4.5 的技术颗粒度按“正文保留科学解释、附录承载实现参数”组织。正文保留 YOLO26n、RITnet、Motion Energy、EAR、VMD、主要生理频段、行为阈值、探针窗口和留一参与者交叉验证等会影响测量或统计解释的内容；网络训练规模、ROI 与模型输入尺寸、滤波器阶数、VMD 参数和内部候选窗口等复现性实现细节集中到 [`../附录草稿/A-分析算法与关键实现参数.md`](../附录草稿/A-分析算法与关键实现参数.md)。毫米波实现参数在最终报告冻结前仍需按照权威生产代码再次核对。

4.3 删除的详细预实验统计没有丢失。两阶段预实验的完整方向性结果和第二阶段主要描述统计、检验结果、错误前轨迹及跨 Block 一致性集中记录在 [`../附录草稿/B-两阶段预实验补充结果.md`](../附录草稿/B-两阶段预实验补充结果.md)，正文仅保留能够解释正式方案形成的必要证据。

正式研究总体样本口径按完整实验资料书写：第一阶段预实验 11 名参与者，第二阶段预实验 17 名参与者完成 20 次实验，正式实验 63 名参与者完成 119 次实验。当前正式行为 science-v3 配置中的 116 个场次、61 个参与者组属于当前分析队列，配置明确注明其不是正式研究总体样本。结果章节必须区分“正式研究总体样本”“当前分析队列”“单模态可用样本”和“具体统计模型实际样本”，不得相互替代。

第 5 章已建立结果结构和证据边界。结果顺序为：5.1 分析样本与各模态有效观测 → 5.2 行为表现与思维探针 → 5.3 近红外瞳孔 → 5.4 毫米波胸部微动 → 5.5 RGB 可见行为 → 5.6 多模态增量与互补信息。正式结果采用论文式写法：先报告必要的描述统计，再说明具体统计方法、观察单位、效应估计及 95% 置信区间，最后给出一句限于数据本身的结果概括；心理机制、跨模态用途和替代解释留到讨论。
