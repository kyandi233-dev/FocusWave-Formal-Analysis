4.5 继续保留 `0827报告v1.docx` 原有的五部分分析结构，但已依据最新正式分析方案重新修订。行为部分以 Go 遗漏率和 No-Go 误按率作为不同结局，并将 Go 遗漏进一步简洁区分为无时序歧义遗漏率和时序歧义遗漏率；探针以前 30 s 为主窗口，10 s 和 20 s 用于时间尺度敏感性分析。NIR 已由旧稿的瞳孔—虹膜比例改为 pupil-only 直接瞳孔几何，并分别使用实验过程中稳定的典型瞳孔水平、事件前短时水平和条件式静息参考来回答不同问题。RGB 正式范围已收缩为整体运动与画面亮度变化、必要的姿态确认和方向性运动候选，以及眨眼候选事件，不再把 AU、情绪、rPPG、PERCLOS 或复杂 RGB 独立预测作为正式主线。毫米波方法从设备已经输出的复数距离域信号开始，分别分析呼吸相关变化、心搏相关变化和身体运动，并使用真实逐帧时间与任务事件对齐；IBI/HRV 只有在逐搏和外部参考验证满足要求后才进行正式生理解释。

跨模态分析现在按共同样本上的增量与互补信息组织。以任务进程和近期行为作为基准，在相同参与者、相同探针窗口和相同外层测试划分上比较加入毫米波、NIR、RGB 后的模型变化；主要验证采用留一参与者交叉验证。可解释的特征级融合是主要比较层，复杂 AI 融合作为次级分析，只有在相同参与者独立验证中形成稳定额外收益时才进入主结果。

正式研究总体样本口径按完整实验资料书写：第一阶段预实验 11 名参与者，第二阶段预实验 17 名参与者完成 20 次实验，正式实验 63 名参与者完成 119 次实验。当前已经整理进入部分分析的数据子集不替代正式实验总体样本；结果章节按各项分析实际使用的参与者数、实验记录数和有效观测数报告。

第 5 章当前已完成结果结构与证据边界的修订，但尚未填入未经真实正式运行确认的统计结果。结果顺序为：5.1 分析样本与各模态有效观测 → 5.2 行为表现与思维探针 → 5.3 近红外瞳孔 → 5.4 毫米波胸部微动 → 5.5 RGB 可见行为 → 5.6 多模态增量与互补信息。每一模态先报告实际分析分母和有效观测，再报告任务时间变化及其与行为/探针的关系；跨模态比较只使用共同样本。

目前 Behavior+NIR+RGB 已有阶段性共同探针级建模准备证据，但该证据不包含毫米波，也没有产生正式融合模型结果。类似的阶段性分析子集、代码测试、单场 smoke、自动化测试或“已经满足建模前提”等状态均不能替代最终科学结果。第 5 章的详细证据准入与图表映射见 `分析设计/1.7-第5章结果结构与证据准入映射.md`，最新来源和方法边界见 `分析设计/1.8-正式分析最新权威来源与报告口径_20260830.md`。
