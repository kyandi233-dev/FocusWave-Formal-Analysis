**正文篇幅采用“完整但不过载”的原则。** “不要写太短”只意味着不能把一个结果小节压成几句结论或提纲，不意味着把完整分析管线、全部模型参数、所有样本审计和次要结果都搬进正文。每个章节正文保留回答该研究问题所需的描述统计、核心方法、主要效应及必要的关键非显著结果；完整模型表、次要参数、敏感性分析、逐 lag/逐窗口细节、QC 和补充图优先进入附录。后续 NIR、毫米波、RGB 和多模态章节同样执行这一分工，避免在“过短”和“过长”之间来回摆动。

图表也采用同一原则：正文优先使用能够同时回答一个科学问题的多面板组合图，而不是为每个指标分别放图。若多个结果可组成统一叙事，可优先做 2×2 或 2×3 多面板图；完整单图和次要指标图进入附录。不同面板应统一字体、字号、误差线、图例和面板字母，避免直接拼接视觉风格不一致的图片。

当前正式实验样本统一按 **61 名参与者、116 个实验场次** 书写。场次是采集与任务时间轴单位；同一参与者的重复实验记录按重复测量处理。各单模态和具体统计模型在此基础上根据实际数据可用性报告相应的参与者数、场次数以及试次、时间窗或探针数。不得再沿用旧稿中的 63 人/119 场口径。

第 5 章已建立结果结构和证据边界。结果顺序为：5.1 分析样本与各模态有效观测 → 5.2 行为表现与思维探针 → 5.3 近红外瞳孔 → 5.4 毫米波胸部微动 → 5.5 RGB 可见行为 → 5.6 多模态增量与互补信息。正式结果采用论文式写法：先报告必要的描述统计，再说明具体统计方法、观察单位、效应估计及 95% 置信区间，最后给出一句限于数据本身的结果概括；心理机制、跨模态用途和替代解释留到讨论。
