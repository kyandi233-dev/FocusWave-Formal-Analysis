# 行为结果组合图放置逻辑说明

## 一、基本原则

第 5.2 节的图不按“文件数量”堆叠，而按正文论点组合。主文图应回答三个问题：任务进程是否变化、错误是否具有时序特征、思维探针是否对应行为表现。因此，主文优先使用已经生成的三张组合图；单指标的完整图谱可作为附录或答辩备查，不宜全部塞进正文。

图内不放中文大标题，正文和图注承担解释功能。组合图保留 A/B/C/D 面板标识，便于在正文中逐点引用。PNG 用于 Word 快速插图，SVG 作为后续可编辑矢量稿。

## 二、主文推荐放置

### 1. 5.2.1 总体行为表现与任务进程

推荐主图：`behavior_task_progression__combined.png` / `behavior_task_progression__combined.svg`

建议图号：图 5-2，总体行为变异与任务进程

版式：两列横排，即 A/B 两个面板并列。

面板来源：

- A 面板来自 `behavior_go_correct_rt_cv__block_pair.png` / `behavior_go_correct_rt_cv__block_pair.svg`
- B 面板来自 `behavior_go_correct_rt_cv__cycle_trend.png` / `behavior_go_correct_rt_cv__cycle_trend.svg`

放置位置：表 5-2 之后，B1/B2 参与者聚类自助法结果和 Block × cycle GEE 结果之前或之后均可。若正文先给表 5-2，再解释 RT-CV 是任务进程中最稳定的行为变化指标，则图 5-2 放在这段解释之后最顺。

使用逻辑：A 面板展示同一场次在 B1 与 B2 的配对变化，B 面板展示两个 block 内随 cycle 推进的过程。两者合在一起，可以把“后半程 RT-CV 更高”和“这种差异不是单一均值表格能表达的时间过程”同时呈现。

图注必须交代：细线为场次级配对轨迹，粗线或点为场次汇总均值，误差线为图中对应的标准误或置信区间口径；场次不等同于完全独立自然人。

## 三、不建议进入主文的大拼图

四张横排只适合横版页面、答辩幻灯片或附录。若在 A4/Word 正文单栏中横排四张，坐标轴、类别标签和误差线会被压得过小，读者必须放大才能辨认，不适合作为正式报告主图。

如果一定要做“四张横着放”的汇总图，建议只用于一个指标的内部备查图，命名为“单指标四联图”。每张四联图可按以下顺序组织：

1. `*_session_distribution.png` / `*_session_distribution.svg`
2. `*_block_pair.png` / `*_block_pair.svg`
3. `*_cycle_trend.png` / `*_cycle_trend.svg`
4. `*_probe_q2_ordinal.png` / `*_probe_q2_ordinal.svg`

这个结构适合快速检查某一个指标的分布、B1/B2 配对变化、任务进程和主观警觉关系。但它不适合主文，因为它按“同一指标的所有视角”组织，而不是按“结果段落需要证明的论点”组织。
