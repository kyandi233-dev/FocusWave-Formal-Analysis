# 附录 B 两阶段预实验补充结果（草稿）

本附录保存用于正式方案形成的预实验补充统计。第 4.3 节只保留与设计决策直接相关的方向性结果和少量代表数字，较完整的预实验行为结果集中记录于此。预实验用于形成正式实验方案，其统计结果不与正式实验结果合并解释。

## B.1 第一阶段预实验

第一阶段采用 6 个 Block，顺序为 A-B-C-C-B-A，A、B、C 三种条件的 No-Go 比例分别为 22.2%、11.1% 和 6.25%。行为整合分析包含 8 份完整记录。

形成性分析的主要结论为：三种 No-Go 比例没有形成稳定的单调难度梯度；任务后段的误按、遗漏和反应时波动整体高于前段，辨别力呈下降趋势，而平均反应速度呈加快趋势；同一 B 条件在前后位置出现时也可观察到相似的时间进程差异。固定 18 试次循环同时存在位置规律逐渐变得可预测的可能，因此条件差异与任务时间、序列可预测性难以完全分离。

思维探针还表现出频率和作答范围不完全一致的问题，部分记录出现超出预设范围或长期固定作答的现象。上述证据共同支持第二阶段采用统一 B 条件、延长 Block、使用伪随机序列并标准化双问题探针。

第一阶段的完整逐参与者统计、条件比较和问卷整合以原《行为整合分析-全被试》报告为证据来源；最终附录排版时可从该报告提取需要展示的表格和图形，而不在正文重复全部分析。

## B.2 第二阶段预实验

第二阶段由 17 名参与者完成 20 次实验，其中 1 份记录几乎没有有效 Go 反应，主要行为分析使用其余 19 份记录。每次实验包含 3 个相同的 B 条件 Block，每个 Block 432 个试次、48 个 No-Go 和 10 次双问题思维探针。

三个 Block 的主要行为描述如下：

| 指标 | Block 1 | Block 2 | Block 3 |
|---|---:|---:|---:|
| No-Go 误按率 | 0.359 | 0.331 | 0.361 |
| Go 遗漏率 | 0.029 | 0.053 | 0.048 |
| d′ | 2.746 | 2.482 | 2.452 |
| 正确 Go 反应时中位数（ms） | 315.5 | 312.9 | 299.4 |
| 反应时变异系数 | 0.369 | 0.456 | 0.485 |

Go 遗漏率的 Block 差异达到统计学显著，Friedman 检验 `p = .003`，其中 Block 3 与 Block 1 的 Holm 校正比较 `p = .007`。反应时变异系数同样表现出 Block 差异，Friedman 检验 `p = .018`，相应配对比较的 Holm 校正 `p = .021`。No-Go 误按率没有出现显著的 Block 主效应。

错误前轨迹分析显示，随后发生 No-Go 误按的事件在前 1～2 个正确 Go 试次中反应更快，差异约为 45 ms 和 24 ms，相应 Holm 校正检验均小于 `.002`。这一结果与 Block 尺度的慢性变化并不等价，而是提示抑制失败前可能存在更短时间尺度的反应加速。

思维探针中，注意内容第一问的“完全专注于分类任务”约占 63.2%；警觉程度第二问的较高两个等级合计约占 71.2%。这些分布用于判断各类别的实际覆盖，不单独作为主观状态测量效度的证据。

Block 1 与 Block 3 的个体排序具有较高一致性：Spearman 相关在 No-Go 误按率、Go 遗漏率、d′、反应标准 c、正确 Go 反应时中位数和反应时变异系数上分别约为 `.849`、`.896`、`.917`、`.548`、`.772` 和 `.853`。这说明参与者之间存在相对稳定的个体差异，同时组水平仍出现明显的任务时间变化。

第二阶段结果共同支持正式实验保留统一 B 条件、长 Block、伪随机刺激序列和双问题探针，并将三个连续长 Block 缩减为两个，以保留早期—后期比较的同时控制持续任务负担。
