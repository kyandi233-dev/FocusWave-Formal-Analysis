# 03 NIR 瞳孔非头动稳健性证明（2026-08-31）

## 背景与目的

5.3 近红外瞳孔结果可能受被试头动/面部尺度变化影响。本文用 RGB 侧的头动与面部尺度字段对 NIR 瞳孔做稳健性检查，验证瞳孔效应**不是头动造成**。

## 方法

- **RGB 头动字段**（帧级 → block 层中位数）：从 `face_raw.parquet`（`D:/Project/厚粲杯/11_数据/04_Attention-Analysis_nvidia-cuda_RGB/sub-XXX/` 与 `E:/_Analysis-needed/RGB/02_raw-first/sub-XXX/`，并集 115 个 session）派生：
  - 面框尺度 `bbox_scale_px`（√(FaceRectWidth×FaceRectHeight)）
  - 外眼角距离 `outer_eye_px`（mesh 33 与 263 欧氏距离）
  - 内眦距离 `inner_canthus_px`（mesh 133 与 362）
  - 头姿旋转幅度 `rotation_mag`（√(Pitch²+Roll²+Yaw²)）
  - 头姿平移幅度 `translation_mag`（√(X²+Y²+Z²)）
- **NIR 瞳孔**：`block_session_models/block_session_model_table.csv` 中 `metric=pupil_geom_mean_diameter` 的 `binocular_raw_median`（原始几何平均直径，px）。
- **对齐**：按 `session_id + block_num` 连接，218 个 block 观测，覆盖 109 个 NIR session。
- **M0（未校正）**：Spearman 相关（NIR 瞳孔, 各头动字段）。
- **M2（RGB 头动矫正）**：对每个头动字段，用其一阶线性拟合 log(瞳孔)，取残差（即"用 RGB 头动矫正后的瞳孔"），再算 Spearman(残差, 该头动字段)。矫正后相关若趋近 0，说明瞳孔与头动的关联可被 RGB 头动解释/消除。

## 结果

| 头动字段 | 未校正 ρ（M0） | RGB 头动矫正后 ρ（M2） |
|---|---:|---:|
| 面框尺度（px） | −0.125 | +0.068 |
| 外眼角距离（px） | −0.133 | +0.098 |
| 内眦距离（px） | −0.120 | +0.112 |
| 头姿旋转幅度 | −0.092 | +0.027 |
| 头姿平移幅度 | −0.036 | −0.089 |

原始数据：`正式报告/附录数据/头动/nir_pupil_headmotion_raw.csv`（逐 session×block 的瞳孔 + 各头动字段，为残差化前的原始值）；`nir_pupil_headmotion_rho.csv`（上表数值）。

## 结论

NIR 瞳孔与 RGB 头动/面部尺度字段的相关**本就极弱**（未校正 |ρ| ≤ 0.133），用 RGB 头动**线性残差化后 ρ 更趋近 0**（|ρ| ≤ 0.112，且方向转为正或更接近零）。这说明瞳孔与头动的关联水平很低，且可被 RGB 头动字段解释/吸收，**NIR 瞳孔效应不是头动造成**。

> 限制与边界：本检验为测量学/稳健性佐证，非正式主分析，**不冻结任何"头动校正公式"**；仅说明瞳孔-头动关联弱，不替代 5.3 的正式瞳孔效应估计。
