# 3 研究目标与总体方案

基于前述理论与技术依据，本章进一步明确 FocusWave 面向持续注意测评系统构建的研究目标、研究问题与总体方案。

## 3.1 研究目标

本研究的总体目标是构建并评价一套低干扰、非接触的多模态持续注意测评系统，在统一任务情境下连接任务表现、即时主观状态与连续非接触观测，并评价这些信息对新参与者状态测评的实际价值。研究同时区分科学信息与设备来源，使系统评价既回答“哪些信息有价值”，也回答“现实硬件配置能够支持哪些测评”。

## 3.2 研究问题

围绕上述目标，本研究提出三个相互衔接的研究问题。

**研究问题一：如何通过规范化实验设计建立持续注意的任务内测量参照，为后续多模态测评提供统一、可解释的任务表现与即时主观状态信息？**

**研究问题二：如何利用非接触多模态信息刻画并预测持续注意相关状态，不同信息在已有行为表现之外是否还能提供额外的测评价值？**

**研究问题三：所构建的多模态持续注意测评系统能否适用于模型训练中未出现的新参与者，并在不同现实设备配置下保持实际可用性？**

三个问题依次对应实验参照、多源信息价值和系统适用性。行为表现、即时主观报告和整场回顾承担不同测量角色；眼部、动作和心肺信息的价值既通过解释性关系评价，也通过跨参与者预测检验；设备组合则用于评价这些科学信息在现实硬件条件下的可获得性。

## 3.3 总体研究方案

本研究按照“实验测量建立—非接触多模态测评—系统可用性评价”三个阶段推进。三个阶段服务于同一系统目标，并以前一阶段形成的测量基础作为后一阶段的前提。

| 研究阶段 | 核心任务 | 主要输出 |
|---|---|---|
| 实验测量建立 | 建立持续注意任务、即时主观报告和整场回顾组成的实验参照体系 | 任务表现、即时主观状态和场次层背景信息 |
| 非接触多模态测评 | 将多设备记录形成行为、眼部、动作和心肺信息，并建立状态测评模型 | 各类信息的测量与解释依据、状态预测及行为基础上的额外价值 |
| 系统可用性评价 | 检验模型对新参与者的适用性，并比较不同现实设备配置 | 新参与者测评表现、有效数据覆盖及设备组合适用范围 |

解释性统计、监督学习和设备组合比较属于回答上述研究问题的分析手段。具体实验程序、设备与同步方式、指标形成、统计模型和跨参与者验证方法在第 4 章说明；相应结果在第 5 章按研究问题组织。
