# 3 研究目标与总体方案

本研究的最终目标是构建并评价一套低干扰、非接触的多模态持续注意测评系统。围绕这一目标，研究需要依次解决三个层面的问题：首先建立规范、可重复的持续注意实验测量方案，为后续系统开发提供统一的任务与状态参照；随后利用近红外、RGB（红绿蓝三通道）可见光和毫米波等非接触设备获取多源信息，建立持续注意测评模型；最后检验所构建系统在新参与者和不同现实设备配置下是否仍具有实际可用性。

## 3.1 研究目标

第一，建立持续注意的实验测量方案。持续注意具有明显的时间动态，单一行为指标或单次主观报告都难以完整描述其变化。本研究采用持续性注意反应任务（Sustained Attention to Response Task，SART）获得连续任务行为，并在任务过程中设置思维探针获取即时主观状态，事后问卷补充整场任务体验与参与者背景。通过统一任务结构、刺激与反应规则、探针设置和时间组织，形成后续多模态测评所依赖的任务内参照。

第二，建立非接触多模态持续注意测评。正式任务过程中同步采集近红外眼部视频、RGB 可见光视频和毫米波信号，并从中形成眼部、动作和具有测量支持的心肺信息，与任务行为共同进入分析。单模态分析用于判断各类信息的测量质量及其与任务内参照之间的关系；监督学习进一步评价这些信息对注意状态的预测能力，并检验在已有行为信息的基础上，非行为信息是否仍能提供额外预测价值。

第三，评价多模态测评系统的实际可用性。系统不仅需要在当前数据中形成可解释的测量关系，还需要面对模型训练中未出现的新参与者保持有效，并能够说明不同设备配置能够提供哪些科学信息、覆盖多少有效数据以及相应测评表现。由此将实验测量、模型建立和系统应用连接为完整的研究链。

## 3.2 研究问题

围绕上述目标，本研究提出三个相互衔接的研究问题。

**研究问题一：如何通过规范化实验设计建立持续注意的测量参照，为后续多模态测评提供统一、可解释的任务与状态信息？**

该问题对应实验测量基础。研究通过 SART、思维探针和事后问卷，从任务行为、即时主观状态和整场回顾三个时间层面描述持续注意。行为指标与主观信息之间的关系、任务时间变化以及重复观测结构用于说明这一实验参照能够提供什么信息及其解释边界。这里的目标是建立后续系统训练和评价所依赖的统一参照，而不是把某一个行为指标或某一道探针题目视为持续注意本身。

**研究问题二：如何利用非接触多模态信息实现持续注意测评，不同信息在已有行为表现之外是否还能提供额外的测评价值？**

该问题对应系统的模型建立。近红外和 RGB 视频提供眼部信息，RGB 视频同时提供身体动作信息，毫米波在测量支持允许的范围内提供心肺相关信息。各类信息首先经过测量质量和可估计性检查，再与任务内参照建立关系；随后通过监督学习评价行为、眼部、动作和心肺信息的预测能力，并比较加入非行为信息后是否改善已有行为基础上的预测表现，以及各类信息在完整组合中的条件预测价值。

**研究问题三：所构建的多模态持续注意测评系统能否适用于模型训练中未出现的新参与者，并在不同现实设备配置下保持实际可用性？**

该问题对应系统应用与适用范围。监督学习按照参与者划分训练与测试数据，使测试参与者的数据不参与模型拟合，以检验系统对新参与者的测评能力；同时结合近红外摄像头、RGB 摄像头和毫米波雷达的真实设备依赖，比较不同设备配置能够获得的科学信息、有效覆盖和测评表现。系统的应用价值由新参与者上的表现、现实设备条件下的信息获取能力以及测量解释边界共同决定。

## 3.3 总体研究方案

本研究按照“实验测量建立—非接触多模态测评—系统可用性评价”三阶段推进。三个阶段共同服务于最终的持续注意测评系统，其中后续阶段以前一阶段形成的测量基础为前提。

| 研究阶段 | 核心任务 | 主要证据 |
|---|---|---|
| 实验测量建立 | 建立统一的持续注意任务与主观状态参照 | SART 行为、思维探针、事后问卷、任务时间变化及其相互关系 |
| 非接触多模态测评 | 从多设备信号形成科学指标，并建立状态预测模型 | 测量质量与覆盖、单类信息关系与预测、行为基础上的增量预测、完整信息组合中的条件预测价值 |
| 系统可用性评价 | 判断系统是否能用于新参与者，并评价现实设备组合 | 参与者互斥验证、参与者等权性能、场次内状态区分、设备配置的覆盖与测评表现 |

第一阶段形成实验参照。SART 提供连续任务表现，思维探针提供时间明确的即时主观状态信息，事后问卷提供整场回顾和背景信息。不同信息不被强行合并为单一“注意真值”，而是在各自测量含义下共同构成系统开发的参照体系。

第二阶段形成多模态测评模型。正式任务中的行为事件、近红外视频、RGB 视频和毫米波信号首先对应到共同任务时间轴，再形成行为、眼部、动作和心肺四类科学信息。解释性分析用于确认各类指标的测量意义及其与任务内参照的关系；监督学习则用于评价这些信息能否支持持续注意状态测评，并检验非行为信息在行为基础上的额外价值。具体的预测目标、时间窗口、特征与模型定义在第 4 章方法部分说明。

第三阶段评价系统可用性。模型评价重点检验对训练中未见参与者的适用性，同时把科学信息类别与设备来源分开：前者回答模型利用了什么信息，后者回答现实中需要哪些硬件才能获得这些信息。通过新参与者评价、有效覆盖和设备组合比较，判断系统在当前研究条件下能够支持怎样的实际使用范围。

总体上，本研究不是把若干单模态分析并列堆叠，而是围绕一个连续目标推进：先建立可重复的持续注意实验测量参照，再利用非接触多模态信息建立测评模型，最后检验模型和设备组合能否支持面向新参与者的实际测评。
