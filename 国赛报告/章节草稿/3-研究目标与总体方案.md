# 3 研究目标与总体方案

持续注意具有明显的时间动态。同一参与者在持续任务中的注意内容、困倦程度、行为表现、生理活动和身体动作均可能随任务进程发生变化，不同参与者之间也存在稳定的个体差异。第 2 章表明，持续注意难以由单一指标完整表征，不同观测分别反映任务执行、主观体验、眼部动态、外显动作和自主生理活动。因此，本研究在统一任务时间轴下组织多源信息，以持续性注意反应任务（Sustained Attention to Response Task，SART）和思维探针建立任务内参照，并同步采集近红外眼部视频、RGB（红绿蓝三通道）可见光视频和毫米波信号，形成低干扰、非接触的多源观测体系。

## 3.1 研究目标

本研究旨在构建并评价一套面向持续注意动态变化的多模态测评方案。研究首先考察持续任务中行为、眼部、动作和心肺信息如何随任务进程和主观注意状态变化，明确不同观测与持续注意变化之间的关系；在此基础上，进一步检验这些信息能否用于识别专注状态，以及眼部、动作和心肺信息在已有近期行为信息后是否仍能提供额外识别价值；最后评价这种识别能力在模型训练中未出现的新参与者上是否仍然成立，并结合不同设备配置考察系统的实际可用性。

研究在同一任务时间轴上组织四类科学信息。行为信息反映参与者在 SART 中的实际任务执行；眼部信息包括瞳孔动态和眨眼；动作信息反映头部与身体的可见外显活动；心肺信息由具有充分测量支持的毫米波估计心率和估计呼吸率等指标表征。思维探针提供探针附近注意内容和困倦—清醒程度的即时主观报告，事后问卷补充整场任务体验和参与者背景。即时主观报告用于描述任务过程中主观状态的变化，并在后续识别分析中提供状态参照；事后问卷用于整场回顾和背景解释。

## 3.2 研究问题

围绕上述目标，本研究提出三个相互递进的研究问题。

**研究问题一：持续注意状态变化时，行为、眼部、动作和心肺信息呈现怎样的变化特征，它们与任务进程和主观状态之间存在怎样的关系？**

该问题首先建立各类观测与持续注意变化之间的解释性联系。研究考察行为表现、瞳孔与眨眼、身体动作以及具有测量支持的心肺指标在任务过程中的变化，并分析这些变化与即时主观状态、困倦—清醒程度和事后回顾之间的关系。测量质量、数据覆盖和指标可估计性作为这些关系分析成立的基础单独报告。

**研究问题二：能否利用行为和多源传感信息识别专注状态，眼部、动作和心肺信息在已有近期行为信息后是否还能提供额外的识别价值？**

该问题从解释性关系进一步进入状态识别。研究首先评价行为及各类传感信息自身对专注状态的识别能力，再以近期行为信息作为共同参照，比较加入眼部、动作和具备测量支持的心肺信息后识别性能是否改善；在完整信息组合中，进一步考察各类信息和具体指标在其他信息已经存在时是否仍具有条件预测价值。

**研究问题三：上述专注状态识别能力能否适用于模型训练中未出现的新参与者，并在现实设备配置下形成具有实际可用性的测评系统？**

该问题关注系统是否具有超出当前样本的使用价值。监督学习按照参与者划分训练与测试数据，同一参与者的全部实验场次和思维探针始终位于训练侧或测试侧，以检验在没有使用该参与者数据拟合模型的情况下，系统是否仍能有效识别其专注状态。进一步结合近红外摄像头、RGB 摄像头和毫米波雷达的真实依赖关系，评价不同设备配置能够提供哪些科学信息、覆盖多少有效数据以及相应识别表现，从而综合判断系统的实际可用性。

## 3.3 总体研究方案

总体研究方案由“任务与主观参照—同步采集—指标形成—解释性分析与状态识别—系统评价”五个连续环节构成。三个研究问题是科学目标，五个环节是完成这些目标的数据与分析流程。前几个环节为后续问题提供共同的数据基础，因此二者不是机械的一一对应关系，而是逐步形成“理解状态变化—识别专注状态—检验系统可用性”的证据链。

| 总体环节 | 主要作用 | 主要对应研究问题 |
|---|---|---|
| 任务与主观参照 | 通过 SART 和思维探针获得连续任务表现与即时主观状态信息 | 为三个研究问题提供共同参照 |
| 同步采集 | 在共同任务时间轴上获得近红外、RGB 和毫米波信息 | 为三个研究问题提供原始观测基础 |
| 指标形成 | 形成行为、眼部、动作和心肺指标，并记录测量质量、覆盖和可估计性 | 为研究问题一建立可解释观测，并确定研究问题二、三可进入的信息 |
| 解释性分析与状态识别 | 先分析各类指标与任务进程和主观状态的关系，再评价专注状态识别及行为基础上的增量信息 | 直接回答研究问题一和研究问题二 |
| 系统评价 | 在新参与者上评价识别能力，并结合真实设备依赖比较不同硬件配置 | 直接回答研究问题三 |

第一，SART 提供连续任务行为，思维探针采集即时注意内容和困倦—清醒程度，事后问卷记录整场任务体验及背景信息。思维探针提供时间明确的即时状态参照，事后问卷用于整场回顾和背景解释。

第二，正式任务过程中同步采集近红外眼部视频、RGB 可见光视频和毫米波信号，并与行为事件和思维探针对应到统一任务时间轴。近红外视频主要用于形成瞳孔测量，RGB 视频提供眨眼及头部和身体动作信息，毫米波记录胸部微动并形成经过质量评价的心肺估计指标。

第三，各来源经过时间对应和质量检查后形成行为、眼部、动作和心肺四类分析指标。分析既保留实验场次和任务区块等较长时间尺度，也围绕思维探针建立探针前时间窗口，以描述接近即时主观报告时的近期状态。测量质量、有效覆盖和指标可估计性在这一阶段独立记录，作为后续心理解释与预测分析的基础。

第四，解释性统计首先分析任务进程、即时主观状态和各类指标之间的关系，回答不同注意状态下各类观测怎样变化；随后使用监督学习评价行为和多源传感信息能否识别专注状态，并进一步检验非行为信息在近期行为之外是否提供额外预测价值。

第五，系统评价检验上述识别能力在模型训练中未出现的新参与者上是否仍然成立，并同时保留科学信息和设备依赖两个层面。科学信息层回答行为、眼部、动作和心肺各自提供什么信息；设备层回答近红外摄像头、RGB 摄像头和毫米波雷达在不同组合下能够支持哪些测量内容、数据覆盖和识别能力。两者共同用于评价系统在现实使用条件下的适用范围。
