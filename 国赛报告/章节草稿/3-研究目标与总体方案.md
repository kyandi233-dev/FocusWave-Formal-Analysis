# 3 研究目标与总体方案

第 2 章表明，持续注意的测量存在三个彼此关联的缺口：单一行为或主观指标不足以完整描述动态状态，连续非接触信号虽然提供了更多观察通道但其心理意义与测量质量需要分别验证，多模态模型即使在现有样本中有效也不能自动说明其能够推广到新参与者。FocusWave 因此不把“增加传感器”作为研究目标本身，而是围绕任务内参照、额外信息价值和跨参与者适用性建立一条连续证据链。

## 3.1 研究目标

本研究旨在构建并评价一套低干扰、非接触的多模态持续注意测评系统。在统一的持续任务情境中，以任务行为和即时主观报告建立状态参照，同步获得眼部、身体动作和心肺相关信息，分析这些观测与任务进程及主观状态之间的关系，并进一步评价它们对模型训练中未见参与者的预测价值。

系统评价同时区分“科学信息”和“设备来源”。前者回答行为、眼部、动作和心肺信息分别提供什么；后者回答近红外视频、RGB（红绿蓝三通道）可见光视频和毫米波雷达等硬件组合能够支持哪些科学信息。这样的区分使多模态价值和硬件部署价值能够分别检验。

## 3.2 研究问题

围绕上述目标，本研究提出三个递进的研究问题。

**研究问题一：如何通过规范化持续任务、即时主观报告与任务进程分析，建立能够反映持续注意动态变化的任务内测量参照？**

这一问题首先回答“测量参照是什么”。研究分别保留任务行为、Q1 注意内容、Q2 困倦—清醒程度及整场回顾的时间尺度和解释角色，分析它们在任务过程中怎样变化、怎样对应，而不将其中任何一项预设为唯一真值。

**研究问题二：眼部、身体动作和心肺相关信息能否提供稳定的注意相关信息，并在已有近期行为表现基础上增加对 Q1 注意内容的预测价值？**

这一问题区分单模态科学解释与多模态预测。各类非接触信息先经过测量资格和单模态关系检验，再进入跨参与者预测；新增信息的价值通过与同一行为参照模型进行配对比较确定，而不是由单独相关显著或全模态模型性能直接推断。

**研究问题三：所形成的测评模型能否推广到模型训练中未出现的新参与者，不同设备组合又能够保留怎样的数据覆盖与测评能力？**

这一问题将统计泛化与实际系统配置连接起来。跨参与者验证用于检验对未见个体的预测，设备组合评价则依据正式科学指标的真实硬件依赖关系，比较不同配置能够获得的信息、有效数据范围和相应测评表现。

## 3.3 总体研究方案

三个研究问题对应“建立参照—评价信息—检验推广”的连续研究路径，而不是相互独立的三组分析。

| 研究阶段 | 核心任务 | 主要输出 |
|---|---|---|
| 任务内测量参照 | 建立 SART、即时思维探针和整场回顾，并刻画任务进程与近期行为状态 | 任务表现、Q1/Q2 即时主观状态及场次层背景信息 |
| 非接触多模态信息评价 | 形成眼部、动作和取得测量资格的心肺指标，先检验单模态意义，再评价行为基础上的新增信息 | 各类信息的测量依据、解释性关系、单独预测能力与增量预测价值 |
| 跨参与者与系统配置评价 | 在参与者完全互斥的验证框架下评价预测，并按真实设备依赖比较硬件组合 | 新参与者预测表现、有效数据覆盖与不同设备组合的可用范围 |

第 4 章按照这条证据链说明样本结构、实验程序、设备同步、指标形成、解释性统计和跨参与者监督学习方法。第 5 章则按同一顺序呈现结果，使“测到了什么”“这些信息与状态怎样相关”“能否改善新参与者预测”三个层面的证据保持分离又能够相互衔接。
