# 3 研究目标与总体方案

持续注意具有明显的时间动态性，同一参与者在持续任务中的注意内容、困倦程度、行为表现、生理活动和身体动作均可能发生变化。第 2 章的理论与技术基础表明，持续注意难以由单一指标完整表征，不同观测通道分别反映任务执行、主观体验、眼部动态、外显动作和自主生理活动。因此，本研究在统一任务时间轴下组织多源信息，以持续性注意反应任务（Sustained Attention to Response Task，SART）和思维探针建立任务内参照，并结合近红外眼部视频、RGB（红绿蓝三通道）可见光视频和毫米波雷达形成低干扰、非接触的多源观测体系。

## 3.1 研究目标

本研究旨在构建并验证一套面向持续注意动态变化的多模态测评方案，使系统既能够描述持续任务过程中不同类型的注意相关变化，又能够检验这些信息能否推广到模型训练中未出现的参与者。

研究首先从测量层面建立行为、眼部、动作和心肺四类科学信息。行为信息反映参与者在 SART 中的实际任务执行；眼部信息包括瞳孔动态和眨眼；动作信息反映头部与身体的外显运动；心肺信息反映心率和呼吸率等自主生理活动。Q1 思维探针提供探针附近注意内容的即时主观报告，Q2 提供困倦—清醒程度，事后问卷补充整场任务体验和参与者背景。不同信息在同一任务时间轴上建立对应关系，从而支持对任务进程、探针附近状态以及参与者差异的分层分析。

在此基础上，研究进一步考察不同信息是否具有可推广的预测价值。分析分别评价各类科学信息自身包含的 Q1 预测信息，并检验眼部、动作和心肺信息在已有近期行为表现基础上是否还能改善预测。多类信息共同纳入后，再考察移除某一类信息所造成的性能变化，用于描述该类信息在其他信息同时存在时的条件预测价值。预测评价以模型训练中未出现的参与者为对象，使系统性能对应于现实中面对新使用者时的推广能力。

## 3.2 研究问题

围绕上述目标，本研究提出三个相互衔接的研究问题。

**研究问题一：持续注意相关变化能否在低干扰、非接触条件下得到稳定且可解释的观察？**

该问题关注测量与解释基础。研究分别考察行为、眼部、动作和心肺信息的有效观测范围及其随任务进程的变化，并分析这些指标与 Q1 注意内容、Q2 困倦—清醒程度及事后主观回顾之间的关系。这里关注的是不同观测通道能否形成具有明确测量含义的注意相关信息，而不预设任何单一指标能够完整代表持续注意本身。

**研究问题二：不同类型的信息是否提供超出近期行为表现的补充预测信息？**

该问题关注多源信息的互补性。研究首先评价行为、眼部、动作和心肺信息各自对 Q1 的跨参与者预测能力，再以近期行为信息作为共同参照，检验加入眼部、动作或心肺信息后预测表现是否改善。进一步在完整信息组合中考察移除某一类信息或具体指标后的性能变化，以区分单独预测能力、相对于行为的增量预测价值和多信息共同存在时的条件预测价值。

**研究问题三：上述测量与预测关系能否推广到模型训练中未出现的参与者，并形成可解释的测评系统？**

该问题关注跨个体推广和系统应用。监督学习按照参与者划分训练与测试数据，同一参与者的全部实验场次和思维探针始终位于训练侧或测试侧。模型只使用相应思维探针出现之前已经获得的信息进行预测，并在参与者层面汇总评价结果。除科学信息类别外，研究还从实际设备组合出发考察不同硬件配置能够获得的信息范围及其系统表现，使科学解释与现实部署保持对应。

## 3.3 总体研究方案

本研究总体方案由“任务与主观参照—同步采集—科学信息形成—解释性分析与跨参与者预测—系统输出”五个环节构成。

第一，SART 提供连续任务行为，思维探针在任务过程中采集 Q1 注意内容和 Q2 困倦—清醒程度，事后问卷记录整场任务体验及背景信息。三类主观与行为信息分别对应不同时间尺度，其中思维探针提供时间明确的即时状态参照，事后问卷用于整场回顾和背景解释。

第二，正式任务过程中同步采集近红外眼部视频、RGB 可见光视频和毫米波信号，并与行为事件和思维探针共同对应到统一任务时间轴。近红外视频主要提供瞳孔测量，RGB 视频提供眨眼以及头部和身体动作信息，毫米波雷达记录胸部微动并用于形成具有充分测量支持的心肺信息。

第三，各来源经过时间对应和质量检查后形成行为、眼部、动作和心肺四类科学信息。分析既保留实验场次和任务区块等较长时间尺度，也围绕思维探针建立探针前时间窗口，以描述接近即时主观报告时的近期状态。

第四，解释性统计和跨参与者预测从两个层面评价这些信息。解释性统计用于分析任务进程、主观状态和各类指标之间的关系；跨参与者预测用于检验这些信息是否能够对训练中未出现参与者的 Q1 报告形成稳定预测。多模态比较按照“单类信息预测—行为基础上的增量—完整组合中的条件预测价值”逐层展开。

第五，系统输出同时保留科学信息和设备配置两个层面。科学信息层回答行为、眼部、动作和心肺分别提供了什么信息，以及这些信息能否形成互补；设备层回答近红外摄像头、RGB 摄像头和毫米波雷达在不同组合下能够支持哪些测量内容。二者分开呈现，使系统性能、心理生理解释和实际硬件需求能够形成清晰对应。
