# 3 研究目标与总体方案

持续注意具有明显的时间动态，同一参与者在持续任务中的注意内容、困倦程度、行为表现、生理活动和身体动作均可能发生变化。第 2 章表明，持续注意难以由单一指标完整表征，不同观测分别反映任务执行、主观体验、眼部动态、外显动作和自主生理活动。因此，本研究在统一任务时间轴下组织多源信息，以持续性注意反应任务（Sustained Attention to Response Task，SART）和思维探针建立任务内参照，并同步采集近红外眼部视频、RGB（红绿蓝三通道）可见光视频和毫米波信号，形成低干扰、非接触的多源观测体系。

## 3.1 研究目标

本研究旨在构建并评价一套面向持续注意动态变化的多模态测评方案，考察不同观测能否形成具有明确测量含义的注意相关信息，以及这些信息能否推广到模型训练中未出现的参与者。

研究在同一任务时间轴上组织四类科学信息。行为信息反映参与者在 SART 中的实际任务执行；眼部信息包括瞳孔动态和眨眼；动作信息反映头部与身体的可见外显运动；心肺信息由具有充分测量支持的毫米波估计心率和估计呼吸率等指标表征。Q1 思维探针提供探针附近注意内容的即时主观报告，Q2 提供困倦—清醒程度，事后问卷补充整场任务体验和参与者背景。不同时间尺度的信息共同用于描述任务进程、探针附近状态和参与者差异。

在此基础上，研究进一步检验不同信息的跨参与者预测价值。分析先考察各类科学信息自身包含的 Q1 预测信息，再以近期行为表现为共同参照，检验眼部、动作和心肺信息是否提供额外预测信息；在完整信息组合中，再通过移除某类信息或具体指标评价其条件预测价值。预测评价面向模型训练中未出现的参与者，使模型性能对应于跨个体推广问题。

## 3.2 研究问题

围绕上述目标，本研究提出三个相互衔接的研究问题。

**研究问题一：行为、眼部、动作和心肺信息能否形成稳定、可解释的持续注意相关观测？**

该问题关注测量与解释基础。研究考察各类信息的实际可用范围、随任务进程的变化，以及它们与 Q1 注意内容、Q2 困倦—清醒程度和事后主观回顾之间的关系。该层首先明确不同观测实际测到了什么，以及这些观测在何种条件下能够支持心理或生理解释。

**研究问题二：不同类型的信息是否提供超出近期行为表现的额外 Q1 预测信息？**

该问题关注多源信息的预测互补性。研究分别评价行为、眼部、动作和心肺信息对 Q1 的跨参与者预测能力，再以近期行为信息作为共同参照，检验加入非行为信息后预测表现是否改善；进一步在完整信息组合中考察各类信息和具体指标的条件预测价值。

**研究问题三：这些关系能否推广到模型训练中未出现的参与者，并支持可解释的系统评价？**

该问题关注跨个体推广。监督学习按照参与者划分训练与测试数据，同一参与者的全部实验场次和思维探针始终位于训练侧或测试侧；模型只使用相应探针出现之前已经获得的信息进行预测。除科学信息类别外，研究还从实际设备依赖出发评价不同硬件组合能够获得哪些信息，使科学解释与现实采集需求保持对应。

## 3.3 总体研究方案

总体研究方案由“任务与主观参照—同步采集—指标形成—解释性分析与跨参与者预测—系统评价”五个环节构成。

第一，SART 提供连续任务行为，思维探针采集 Q1 注意内容和 Q2 困倦—清醒程度，事后问卷记录整场任务体验及背景信息。三者对应不同时间尺度，其中思维探针提供时间明确的即时状态参照，事后问卷用于整场回顾和背景解释。

第二，正式任务过程中同步采集近红外眼部视频、RGB 可见光视频和毫米波信号，并与行为事件和思维探针对应到统一任务时间轴。近红外视频主要用于形成瞳孔测量，RGB 视频提供眨眼及头部和身体动作信息，毫米波记录胸部微动并用于形成经过质量评价的心肺估计指标。

第三，各来源经过时间对应和质量检查后形成行为、眼部、动作和心肺四类分析指标。分析既保留实验场次和任务区块等较长时间尺度，也围绕思维探针建立探针前时间窗口，以描述接近即时主观报告时的近期状态。

第四，解释性统计用于分析任务进程、主观状态和各类指标之间的关系；跨参与者监督学习则检验这些信息能否对训练中未出现参与者的 Q1 报告形成稳定预测，并进一步评价行为基础上的增量信息及完整组合中的条件预测价值。

第五，系统评价同时保留科学信息和设备依赖两个层面。科学信息层回答行为、眼部、动作和心肺各自提供什么信息；设备层回答近红外摄像头、RGB 摄像头和毫米波雷达在不同组合下能够支持哪些测量内容。两者分开呈现，避免把设备来源直接等同于心理或生理信息类别。
