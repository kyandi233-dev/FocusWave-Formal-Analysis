# 3 研究目标与总体方案

持续注意具有明显的时间动态，同一参与者在持续任务中的注意内容、困倦程度、行为表现、生理活动和身体动作均可能发生变化。第 2 章表明，持续注意难以由单一指标完整表征，不同观测分别反映任务执行、主观体验、眼部动态、外显动作和自主生理活动。因此，本研究在统一任务时间轴下组织多源信息，以持续性注意反应任务（Sustained Attention to Response Task，SART）和思维探针建立任务内参照，并同步采集近红外眼部视频、RGB（红绿蓝三通道）可见光视频和毫米波信号，形成低干扰、非接触的多源观测体系。

## 3.1 研究目标

本研究旨在构建并评价一套面向持续注意动态变化的多模态测评方案。研究首先考察任务行为以及眼部、动作和心肺信息，能否区分思维探针中参与者报告的任务聚焦状态与其他注意内容，并明确这些观测与持续注意相关变化之间的关系；随后检验在已经获得近期行为表现的条件下，非行为信息是否还能提供额外的专注状态识别信息；最后评价这种识别能力能否适用于模型训练中未出现的新参与者，并结合不同设备配置考察系统的实际可用性。

研究在同一任务时间轴上组织四类科学信息。行为信息反映参与者在 SART 中的实际任务执行；眼部信息包括瞳孔动态和眨眼；动作信息反映头部与身体的可见外显活动；心肺信息由具有充分测量支持的毫米波估计心率和估计呼吸率等指标表征。Q1 思维探针提供探针附近注意内容的即时主观报告，其中任务聚焦报告作为首轮专注状态识别的参照；Q2 提供困倦—清醒程度，事后问卷补充整场任务体验和参与者背景。Q2 和事后问卷用于解释状态差异及个体背景，不作为首轮逐探针 Q1 识别的输入。

研究中的“专注状态识别”指利用探针出现前合法获得的信息，区分 Q1 中报告的任务聚焦状态与其他注意内容。该识别结果反映对参与者即时主观报告的预测能力，不等同于直接测得不可观测的“真实注意状态”。

## 3.2 研究问题

围绕上述目标，本研究提出三个相互衔接的研究问题。

**研究问题一：行为、眼部、动作和心肺信息能否区分 Q1 所报告的任务聚焦状态与其他注意内容，并呈现可解释的状态差异？**

该问题首先回答“能否识别专注”。研究考察不同观测在任务进程中的变化，以及它们与 Q1 注意内容、Q2 困倦—清醒程度和事后主观回顾之间的关系；在此基础上，评价各类信息自身对任务聚焦状态的识别能力。测量质量、数据覆盖和指标可估计性作为这些分析成立的前提单独报告，不把它们与专注状态识别性能混为同一问题。

**研究问题二：在已经掌握近期行为表现后，眼部、动作和心肺信息是否还能提高对任务聚焦状态的识别？**

该问题关注多源信息是否带来额外价值。研究以近期行为信息作为共同参照，分别比较加入眼部、动作和具备测量支持的心肺信息后，对 Q1 任务聚焦状态的概率预测是否改善；在完整信息组合中，再考察各类信息和具体指标在其他信息已经存在时是否仍具有条件预测价值。

**研究问题三：这种专注状态识别能力能否适用于模型训练中未出现的新参与者，并在现实设备配置下形成具有实际可用性的测评系统？**

该问题同时关注跨参与者可用性和系统实现。监督学习按照参与者划分训练与测试数据，同一参与者的全部实验场次和思维探针始终位于训练侧或测试侧，以检验在没有使用该参与者数据拟合模型的情况下，系统仍能否区分其任务聚焦状态。进一步结合近红外摄像头、RGB 摄像头和毫米波雷达的真实依赖关系，评价不同设备配置能够提供哪些科学信息、覆盖多少有效数据，以及相应识别性能，从而判断系统是否具有超出当前训练参与者和单一硬件配置的实际使用价值。

## 3.3 总体研究方案

总体研究方案由“任务与主观参照—同步采集—指标形成—解释性分析与专注状态识别—系统评价”五个连续环节构成。三个研究问题是需要回答的科学目标，五个环节是实现这些目标的数据与分析流程，因此二者并非逐项一一对应，而是在不同阶段共同形成证据链。

| 总体环节 | 主要作用 | 主要对应研究问题 |
|---|---|---|
| 任务与主观参照 | 通过 SART、Q1 和 Q2 建立任务执行与即时主观状态参照 | 为三个研究问题提供共同参照 |
| 同步采集 | 在共同任务时间轴上获得近红外、RGB 和毫米波信息 | 为三个研究问题提供原始观测基础 |
| 指标形成 | 形成行为、眼部、动作和心肺指标，并记录测量质量、覆盖和可估计性 | 主要支持研究问题一，并为研究问题二、三确定可用信息范围 |
| 解释性分析与专注状态识别 | 描述任务进程和主观状态关系，评价单类信息识别能力及行为基础上的增量信息 | 直接回答研究问题一和研究问题二，并产生研究问题三所需的预测模型 |
| 系统评价 | 在新参与者上评价识别能力，并结合真实设备依赖比较不同硬件配置 | 直接回答研究问题三 |

第一，SART 提供连续任务行为，思维探针采集 Q1 注意内容和 Q2 困倦—清醒程度，事后问卷记录整场任务体验及背景信息。思维探针提供时间明确的即时状态参照，事后问卷用于整场回顾和背景解释。

第二，正式任务过程中同步采集近红外眼部视频、RGB 可见光视频和毫米波信号，并与行为事件和思维探针对应到统一任务时间轴。近红外视频主要用于形成瞳孔测量，RGB 视频提供眨眼及头部和身体动作信息，毫米波记录胸部微动并形成经过质量评价的心肺估计指标。

第三，各来源经过时间对应和质量检查后形成行为、眼部、动作和心肺四类分析指标。分析既保留实验场次和任务区块等较长时间尺度，也围绕思维探针建立探针前时间窗口，以描述接近即时主观报告时的近期状态。测量质量、有效覆盖和指标可估计性在这一阶段独立记录，作为后续心理解释与预测分析的基础。

第四，解释性统计用于分析任务进程、主观状态和各类指标之间的关系；监督学习首先评价各类信息能否区分 Q1 所报告的任务聚焦状态，再检验非行为信息在近期行为之外是否提供额外预测价值。面向新参与者的评价使用参与者互斥的训练与测试划分，使测试参与者的数据不参与模型拟合。

第五，系统评价同时保留科学信息和设备依赖两个层面。科学信息层回答行为、眼部、动作和心肺各自提供什么识别信息；设备层回答近红外摄像头、RGB 摄像头和毫米波雷达在不同组合下能够支持哪些测量内容、数据覆盖和识别能力。两者分开呈现，使系统可用性既反映对新参与者的识别表现，也反映现实硬件配置下能够实际获得的信息范围。
