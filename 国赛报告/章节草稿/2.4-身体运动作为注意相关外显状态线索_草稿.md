# 2.4 身体动作作为注意相关外显状态线索

与瞳孔和眨眼相比，身体动作反映的是更宏观的外显状态。坐立不安、姿态维持、头部活动和上半身动作都会受到注意、困倦、身体不适、任务要求以及个体习惯影响，因此可见动作能够补充任务行为与眼部动态，却不能直接换算为“注意水平”。这一类信息的价值在于提供低干扰、连续的外显行为观察，并检验它是否包含任务行为尚未捕捉到的状态变化。

小动作或坐立不安（fidgeting）提供了较直接的注意相关证据。Carriere、Seli 和 Smilek（2013）发现，日常注意不集中与自发心智游移倾向能够预测自报告的小动作倾向。Seli 等（2014）进一步在持续任务中结合思维探针和客观身体活动，发现心智游移总体伴随更多身体活动和更大的反应时变异；当心智游移程度较轻时，行为波动已经出现，而身体活动并未同步明显增加。这个结果提示，任务表现与身体动作可能对应状态变化的不同阶段或不同侧面，身体动作并不是行为错误的简单替代。

任务持续时间也会改变动作模式。Farley、Risko 和 Kingstone（2013）在较长的课堂式视频学习任务中发现，随着观看时间延长，注意自评和材料保持下降，而小动作增加；即使控制注意自评，小动作与材料保持仍存在关系。办公情境中的久坐干预研究则显示，不同活动形式对注意、工作记忆和心理运动表现的影响并不一致（Tuckwell et al., 2022）。这些结果共同说明，“动作增加”可能与任务脱离、身体调节、疲劳或任务负担等多种过程相联系，其心理含义必须依赖具体情境判断。

姿态和头部活动提供了比整体动作量更具体的空间结构，但解释边界也更严格。Qian 等（2024）在持续性注意反应任务（Sustained Attention to Response Task，SART）和侧抑制任务（Flanker task）中发现，仰卧条件下心智游移更多，但执行控制指标没有出现同等变化；驾驶困倦研究也表明，头部点动和姿态特征能够携带警觉下降信息（He et al., 2016; Perrotte et al., 2024）。这些证据支持把姿态作为状态线索，却不能推出某一头部方向或画面位移具有跨任务固定含义。头部朝向首先反映身体和视觉定向，也不能直接等同于视线位置。

普通 RGB（红绿蓝三通道）可见光视频使这类外显状态能够在不增加穿戴负担的情况下连续记录。Bosch 和 D’Mello（2021）从视频中提取上半身动作、头部姿态和面部特征，用于预测思维探针报告的心智游移，并在实验室与课堂数据中获得高于机会水平的识别表现。学习投入自动测量领域也广泛使用姿态、头部和其他非言语视觉线索（Xu et al., 2026），但学习投入本身包含行为、情绪和认知多个维度，并不等同于持续注意（Fredricks et al., 2004）。因此，对持续注意研究而言，更稳妥的路径是先把整体动作强度与姿态变化作为可测量的外显特征，再通过任务内关系和跨参与者预测评价其实际信息价值。

身体动作扩大了连续观测的行为层面，但仍主要描述外显表现。持续任务中的警觉、心理负荷和任务投入还会伴随自主神经活动改变，其中心率与呼吸能够提供与眼部、动作不同的生理视角。下一节因此转向心肺活动，并进一步区分“这些生理活动具有何种心理学意义”和“非接触设备能否可靠测到它们”两个问题。
