# 5.7 多模态增量、互补与条件预测价值

> 当前状态：**等待 Behavior、Ocular、Movement 正式特征冻结及参与者互斥真实运行；Cardiopulmonary 仅在毫米波心肺测量资格通过后加入。**  
> 本节只报告在相同参与者、相同探针和相同外层测试划分上形成的配对比较，不把“完整模型性能较高”直接解释为每个模态均有独立贡献。

本节进一步回答多模态是否真正增加测评价值。分析分三个层级：首先检验非行为模态在已有 Behavior（行为）信息后是否提供额外预测信息；随后下钻到具体特征；最后在四类科学模态均具备正式资格时，用完整模型和删一模态/删一特征比较描述条件预测价值。

## 5.7.1 行为条件增量：Behavior + modality

以正式 Behavior-only 模型为共同参照，分别比较：

- Behavior 与 Behavior + Ocular（眼部）；
- Behavior 与 Behavior + Movement（动作）；
- Behavior 与 Behavior + Cardiopulmonary（心肺；待测量资格通过）。

每一项比较使用 comparison-specific analysis set（比较特异分析集合），由比较双方实际需要的正式特征并集决定，因此两个模型必须在相同参与者和相同探针上形成折外预测。无关设备或无关模态的缺失不缩小该项比较的共同样本。

主要增量指标使用配对的 participant-macro log loss（参与者宏平均对数损失）差异，可统一定义为：

`Δlog loss = log loss(Behavior) − log loss(Behavior + modality)`

正值表示加入该模态后概率预测改善，负值表示预测变差。95% 置信区间以参与者为重抽样单位进行配对 bootstrap（自助重采样），正式次数和随机种子以当前冻结配置为准。

结果解释限定在预测信息层。如果某一模态单独具有预测能力，但加入 Behavior 后改善很小，可说明其 Q1 相关预测信息与近期行为存在较多重叠；如果单独表现和行为条件增量均稳定，则支持其在已有行为信息之外还包含补充预测信息。上述模式均不作因果解释。

## 5.7.2 具体特征的 standalone 与行为条件增量

在模态整体结果之外，对每个最终冻结的具体科学特征 x 分别报告：

- `x -> Q1`：单独使用该特征时的跨参与者预测信息；
- `B -> B+x`：在正式 Behavior reference（行为参照特征集）B 已存在时，加入该特征后的配对性能变化。

这一层用于回答模态整体结果究竟主要由哪些具体心理、生理或行为变化支撑。瞳孔水平、瞳孔波动、瞳孔趋势、眨眼频率、身体运动以及通过资格的 HR（心率）和 BR（呼吸率）等变量均应按最终 feature registry（特征登记表）逐一解释，而不由设备来源替代。

正式结果以折外预测性能和参与者层面不确定性为主要证据。标准化回归系数如报告，仅用于辅助描述模型在不同训练样本中使用某变量的方向与稳定性，不称为“贡献率”“权重百分比”或心理构念组成比例。

## 5.7.3 完整多模态组合

在 Behavior、Ocular、Movement 和 Cardiopulmonary 四类科学模态的正式变量均具备资格后，构造：

`Full = Behavior + Ocular + Movement + Cardiopulmonary`。

完整模型用于回答在所有正式科学信息同时存在时，对训练阶段未见参与者 Q1 的总体预测表现。该结果本身只说明完整信息组合的总体能力，不能单独证明其中每个模态均提供独立或必要的信息。

如果 Cardiopulmonary 在本轮未通过测量资格，则本节不强行构造名义上的“四模态 Full”。当期完整模型应只由实际获得正式资格的科学模态构成，并在正文中明确其组成。

## 5.7.4 删一模态的条件预测价值

对于进入当期 Full 的每个科学模态 m，比较：

`Full − m` 与 `Full`。

这一 leave-one-modality-out（删一模态）比较回答：在其他正式科学信息已经存在时，加入该模态后是否仍改善跨参与者预测。正式表述统一为 conditional predictive value（条件预测价值）。

如果移除某模态后性能几乎不变，只能说明在当前特征集合、当前样本和当前模型条件下，该模态没有显示稳定的额外条件预测价值；这不等价于该模态不包含真实信息，因为其他模态可能已经提供高度冗余的信息。相反，如果移除后性能稳定下降，则支持该模态在当前完整组合中仍包含其他正式信息未完全覆盖的预测信息。

## 5.7.5 删一特征的条件预测价值

具体特征层进一步比较：

`F − x` 与 `F`，

其中 F 表示当期全部正式特征组成的 Full model（全特征模型），x 为单个正式特征。该比较用于描述在其他正式特征已经存在时，x 是否仍有条件预测价值。

特征级删一分析和模态级删一分析具有不同解释单位：前者定位具体变量，后者评估整类科学信息。二者均需要相同参与者和探针上的配对折外预测，不能用不同样本模型的总体分数直接相减。

## 5.7.6 共享、补充与冗余信息的结果解释

单模态、行为条件增量和完整模型删一结果联合用于描述多模态之间的信息结构：

- 单模态表现说明该类信息本身是否包含可推广的 Q1 预测信息；
- Behavior → Behavior + modality 说明该模态在已有任务行为后是否还有增量预测价值；
- Full − modality → Full 说明该模态在其他正式信息存在时是否仍有条件预测价值。

当不同层级结果出现差异时，正文优先使用“共享信息”“补充信息”“冗余信息”或“当前条件下未显示稳定增量”等表述。只有在后续明确检验非加性交互并获得相应证据时，才使用更强的 synergy（协同增益）概念。

## 5.7.7 概率校准与参与者差异

在主要预测比较完成后，可使用正式折外概率报告 Brier score（布里尔分数）和 calibration plot（校准图），判断模型给出的概率是否与实际 Q1 报告频率相符。校准属于概率预测质量的补充证据，不改变主要的科学模态比较结构。

还可展示参与者层面的性能分布和增量分布，以判断总体平均改善是否由少数参与者驱动。该分析用于描述预测稳定性和个体差异，不重新定义主要总体评价。

## 5.7.8 与设备组合分析的分工

本节全部主要结论以科学模态和具体特征为单位。RGB、NIR 和 mmWave 的实际组合属于 device-package analysis（设备组合分析），回答部署某套硬件后能够现实地产生哪些正式特征及其预测能力如何变化。

例如 Ocular-only 可以依赖 NIR+RGB，而 RGB-only 设备包可能同时产生 Ocular 的眨眼和 Movement 的身体运动。因此设备包结果不与本节的科学模态结果混在同一主图。历史 M0–M7 如继续使用，仅作为设备组合或兼容编号，其正式报告位置放在后续系统/部署结果中。
