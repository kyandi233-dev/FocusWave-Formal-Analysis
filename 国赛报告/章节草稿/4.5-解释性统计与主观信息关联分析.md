# 4.5 解释性统计与主观信息关联分析

解释性统计用于回答行为、眼部、动作和心肺指标怎样随任务进程变化，以及这些观测与 Q1 注意内容、Q2 困倦—清醒程度之间存在怎样的关系。分析保留参与者、实验场次和更细观察单位之间的层级结构，同一参与者的重复场次和重复探针不按相互独立个体处理。进入推断分析的指标均遵循 4.4 所述质量控制与可估计性规则，并报告实际分析分母。

## 4.5.1 行为表现与任务进程

行为表现首先比较同一实验场次内两个正式 Block 的变化。每个场次形成第二个 Block 相对第一个 Block 的差值；对于重复参加的参与者，多个场次仍归属于同一参与者，并以参与者为重抽样单位进行聚类自助法估计总体变化及 95% 置信区间。

为描述 Block 内的任务持续效应，每个 Block 按任务进程划分为六个连续时间段。反应时水平、反应时波动、Go 遗漏率、No-Go 误按率和辨别力等指标采用广义估计方程（generalized estimating equations，GEE）分析 Block、时间段及二者交互作用，并以参与者作为重复观测聚类单位。

Go 遗漏和 No-Go 误按的局部时序过程分别分析。以错误试次为中心，比较错误前后相邻正确 Go 试次的反应时变化；反应时相对于参与者自身典型正确 Go 反应水平表示，以减少稳定个体反应速度差异对局部错误轨迹的影响。

## 4.5.2 思维探针与近期行为状态

以 4.4 定义的主要探针前窗口为近期状态分析单位。Q1 四类注意内容按名义类别处理，行为指标与 Q1 的关系采用参与者聚类稳健的多项逻辑回归，以 Q1=1 的任务聚焦状态为参照类别。连续行为指标在模型中标准化，因此回归系数表示预测指标每增加 1 个标准差时相对于参照类别的变化。

Q2 的四级困倦—清醒报告按有序等级处理，行为指标与 Q2 的关系采用以参与者为聚类单位的有序广义估计方程。Q1 和 Q2 模型均报告效应估计、标准误、95% 置信区间，以及实际参与者数、实验场次数和探针数；样本不足、类别不足、模型未收敛或参数不可估计均记录为不可估计，而不以空结果代替成功模型。

## 4.5.3 可见动作与眨眼的解释性分析

RGB 可见光视频的主要解释性指标为整体可见运动水平和眨眼频率，姿态方向及曝光变化用于补充分析或质量检查。任务进程分析采用与行为时间结构一致的 Block × 时间段广义估计方程，连续指标以参与者为聚类单位处理重复观测。

在探针层面，Q1 四分类采用参与者聚类稳健的多项逻辑回归，Q2 四级报告采用有序广义估计方程。模型中的连续 RGB 指标先标准化，并报告效应估计、标准误和 95% 置信区间。除与 Q1/Q2 的关系外，可见运动和眨眼还与同期行为指标进行窗口级单预测变量 GEE 对照，用于描述外显动作、眼睑活动与近期任务表现之间的对应关系。曝光变化等成像条件指标只用于检查潜在测量混杂，不作为注意相关结果变量解释。

## 4.5.4 眼部与心肺指标的重复测量关系

瞳孔和毫米波心肺指标只有在完成 4.4 所述测量质量与可估计性检查后才进入心理学推断。对实际进入分析的连续指标，Q1/Q2 关联模型沿用与其他探针层连续指标一致的重复测量处理，并同时区分总体个体差异与同一参与者内部的状态变化。

人内—人间分解通过参与者自身平均水平区分个体内偏离与参与者间平均差异。该分解用于解释性重复测量分析，不进入零个体校准的跨参与者监督学习，因此测试参与者的完整序列统计不会用于构造其预测特征。

## 4.5.5 事后问卷与稳健性分析

事后问卷主要用于场次层或参与者层的描述性对应与背景解释，包括整场走神回顾、困倦与疲劳变化、任务策略、睡眠及其他背景信息。问卷与 Q1/Q2、行为及传感指标的对应保持其原有时间尺度，不将整场问卷回答复制到每个探针窗口，也不把问卷作为即时状态的真值验证。重复参加者的多份问卷按照各自实验场次保留。

时间窗口敏感性分析沿用 4.4 中预先定义的主要窗口与较短窗口。瞳孔备选测量表示、RGB 成像条件以及毫米波运动干扰均在各自测量层进行稳定性检查，不依据正式 Q1 结果或跨参与者测试性能反向选择处理方案。正文以效应估计、95% 置信区间和实际分析分母为主要统计信息；补充指标和测量敏感性结果集中于表格或附录。
