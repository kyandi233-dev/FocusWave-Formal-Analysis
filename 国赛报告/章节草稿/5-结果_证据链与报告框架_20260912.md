# 5 结果：证据链与报告框架

> 日期：2026-09-12  
> 状态：章节结构工作稿  
> 依据：当前 `分析设计/1.16` 系列、`国赛报告/0-总结构与研究叙事_20260912.md` 与第 4 章方法框架。

## 1. 本章总逻辑

第 5 章按“数据与测量基础 → 单模态心理学证据 → 新参与者预测 → 多模态增量与条件预测价值 → 设备组合与系统输出”组织。科学结果统一按 Behavior（行为）、Ocular（眼部）、Movement（动作）和 Cardiopulmonary（心肺）组织；RGB、NIR（近红外）和 mmWave（毫米波）仅作为设备来源和部署层概念。

每项结果分别报告实际参与者数、场次数、试次/窗口/探针数、效应或性能估计、95% 置信区间及必要的质量信息。代码测试、接口验证、少量场次运行和阶段性共同样本不作为正式科学结果。

## 2. 推荐结构

### 5.1 分析样本、数据覆盖与测量资格

报告正式实验总体，以及 Behavior、Ocular、Movement、Cardiopulmonary 的实际可分析分母；同时报告 NIR、RGB、毫米波的覆盖、同步和主要不可用原因。心肺信息须先通过独立测量资格验证后再进入后续结果。

### 5.2 行为表现、主观状态与任务时间进程

报告反应时水平、波动和趋势，Go 遗漏率、No-Go 误按率及必要的信号检测论指标；报告 B1/B2 和 Block 内时间变化；报告 Q1/Q2 分布及探针前 30 s 近期行为关系。Q1 与 Q2 均按主观报告解释，不作为客观注意真值。

### 5.3 Ocular（眼部）：瞳孔与眨眼

先报告有效观测与质量，再报告瞳孔水平、波动、趋势以及眨眼频率的任务时间变化，最后报告它们与行为、Q1/Q2 的关系。瞳孔最终表示在真实测量审计完成后冻结；如 RGB 眨眼用于 NIR 瞳孔清洗，应同时报告清洗后的有效时间支持。

### 5.4 Movement（动作）：头部与身体运动

先报告有效视频覆盖、整体运动和成像质量，再报告任务进程中的运动变化以及与行为、Q1/Q2 的关系。方向性姿态只作辅助解释，不将无量纲方向指标解释为真实身体位移。

### 5.5 Cardiopulmonary（心肺）：心率与呼吸率

先报告毫米波 HR（心率）和 BR（呼吸率）的测量资格、有效覆盖和运动敏感性，再报告通过资格的指标随任务变化以及与行为、Q1/Q2 的关系。IBI（心搏间期）和 HRV（心率变异性）只有在逐搏与外部参考验证通过后进入正式结果。

### 5.6 各科学模态对新参与者 Q1 的预测能力

分别报告 Behavior-only、Ocular-only、Movement-only 和通过资格后的 Cardiopulmonary-only。主要性能为 participant-macro log loss（参与者宏平均对数损失），AUROC（受试者工作特征曲线下面积）作为主要补充，同时给出 95% 置信区间和必要的辅助指标。

Ocular-only 表示只使用眼部科学信息；即使正式瞳孔表示依赖 NIR+RGB 清洗，也仍属于 Ocular 科学模态。单模态整体表现不能推出其中每个具体特征都重要。

### 5.7 多模态增量、互补与条件预测价值

首先报告 Behavior vs Behavior+Ocular、Behavior vs Behavior+Movement、Behavior vs Behavior+Cardiopulmonary，回答传感信息在已有近期行为后是否仍提供额外预测信息。每项比较使用双方实际所需特征并集形成相同参与者、相同探针的比较集合。

随后报告具体特征的 `x -> Q1` 与 `B -> B+x`；在四类正式科学模态均具备资格后构造 Full = Behavior + Ocular + Movement + Cardiopulmonary；再以 `Full-modality` vs `Full` 和 `F-x -> F` 评估模态或特征在其他正式信息存在时的条件预测价值。该层统一使用“条件预测价值”，不表述为“不可替代信息”或“贡献百分比”。

正式 OOF（折外）概率产生后，可补充 Brier score（布里尔分数）、calibration plot（校准图）和逐参与者性能分布，用于概率质量与稳定性诊断。

### 5.8 设备组合与系统级输出

RGB、NIR、mmWave 在此作为 device-package（设备组合）组织。历史 M0–M7 如继续保留，只作为工程兼容编号。设备包只能包含其现实中能够生成的正式特征；需要 NIR+RGB 才能生成的正式 pupil（瞳孔）不能放入 NIR-only 设备包。

本节只在真实系统结果足够成熟时独立成节，否则并入 5.7 或讨论。未实际实现的实时界面和部署能力不提前写入结果。

## 3. 研究问题对应

| 研究问题 | 主要结果证据 |
|---|---|
| RQ1：持续注意动态变化能否被可靠观察和刻画 | 5.1–5.5：覆盖、测量资格、任务变化、行为与 Q1/Q2 关系 |
| RQ2：不同模态是否提供互补信息 | 5.6 单模态预测 + 5.7 行为条件增量与条件预测价值 |

## 4. 固定证据层级

同一模态或特征按“测量资格 → 心理学关联 → 单独预测效用 → 行为条件增量 → 完整组合中的条件预测价值 → 设备部署价值”依次解释。前一层不能自动推出后一层；尤其不能用显著关联替代增量预测证据，也不能用 Full 模型整体表现证明每个模态均有独立贡献。
