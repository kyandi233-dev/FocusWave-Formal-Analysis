**排序指标（AUROC）与主指标回答不同问题，必须分开陈述。** 参与者宏平均 AUROC 只在具有两类标签的参与者上平均（行为与动作各 49 人，眼部与仅传感组合各 48 人）：行为 **0.7060** [0.6656, 0.7447]；眼部 **0.5683** [0.5080, 0.6257] 与仅传感信息组合 **0.5560** [0.5003, 0.6081] 的**区间下限也高于 0.5**，构成**有限的排序区分证据**（仅传感组合下限 0.5003 极贴近 0.5）；动作 **0.4569** [0.4008, 0.5079] 与补充比较中的心肺 **0.4691** [0.4159, 0.5240] 区间包含 0.5。

### 1.3 毫米波心肺信息的补充比较

毫米波估计心率与估计呼吸率在冻结注册表中**没有正式预测资格**，因此不属于 §1.0 的正式主比较。为了让报告能够回答"心肺信息能预测多少"，本次建立了**明确隔离的补充比较通道**。

**为什么不能直接进入正式注册表**：`modality_model_eligible` 是进入模型的唯一路径，而它同时是一次预测资格请求；`time_legality.py` 对任何资格请求、状态又不是 `verified_pre_probe_only` 的特征**严格失败关闭**；特征被省略的资格字段默认值为 `True`，因此"什么都不写"也会被读作资格请求。毫米波持有 `physiology_qualification = LIMITED_SUPPORTING_ONLY` 与 `time_legality_status = blocked_upstream_contract_mismatch`，要获得该状态需满足 `分析设计/1.15.9` §3 的四项前置。

**补充通道的性质**（运行 manifest 内逐条记录）：

- `prediction_eligibility_claimed = false`、`device_package_eligibility_claimed = false`
- `preregistration = post_hoc_declared_after_primary_results_observed`（在主结果之后声明）
- 不修改冻结注册表、不改变正式主比较的任何数字
- 每个补充模型复用**冻结的** `behavior_reference` / `full` 作为基线，在同一批行上重新拟合

## 2. 正式模型的科学问题

1. 单独使用 Behavior、Ocular、Movement，以及通过测量资格后的 Cardiopulmonary，能否预测训练中未出现参与者的 Q1；
2. 在 Behavior 已知的情况下加入某类传感信息，是否仍能提供额外预测信息；
3. 在完整组合中移除某一类信息，性能是否稳定下降；
4. 具体指标层的贡献是否与信息类别层结论一致；
5. 不同现实设备组合能够得到哪些科学信息，以及这些设备组合的系统级性能如何。

## 4. 数据划分与泄漏控制

正式结果必须使用参与者互斥的外层验证：测试参与者不能出现在训练或内部模型选择中。内部模型选择继续按参与者分组，所有标准化、插补和参数选择只能使用当前训练数据。
