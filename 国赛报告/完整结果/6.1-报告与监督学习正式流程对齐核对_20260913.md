# 报告与监督学习正式流程对齐核对

本文件用于记录国赛报告第 3–5 章与当前监督学习正式方法、实际实现之间的对应关系。它属于内部结果与方法核对材料，不作为报告正文，也不代表已经产生任何模型性能结果。

## 1. 当前一致的部分

报告与当前正式监督学习流程已经一致的核心内容包括：

- 首轮预测目标为 Q1“任务聚焦”与其余三类注意内容的二分类；
- 预测单位为单次思维探针，输入限定为探针出现前合法获得的信息；
- 外层采用参与者互斥的留一参与者交叉验证，重复参加形成的全部场次随参与者共同进入训练侧或测试侧；
- 内层采用参与者分组交叉验证，预处理和模型参数选择限制在训练参与者内部；
- 行为、眼部、动作、心肺按科学信息类别组织，近红外、RGB 和毫米波按设备依赖组织；
- 具体科学指标在监督学习前完成测量资格、时间合法性和表示冻结；
- 直接模型比较使用由两种模型实际所需指标决定的共同分析集合，并在相同参与者、相同探针和相同外层划分上重新训练和评价；
- 结构性设备缺失和测量失败不通过普通数值插补转化为有效观测；
- 正式结果必须来自折外预测，解释性关联不承担监督学习特征筛选作用。

## 2. 当前实现已经显式支持的比较

当前 `Attention-Analysis` 分支 `codex/1.16.10-modality-device-separation`、PR #68 的正式比较计划已经显式支持：

1. Behavior、Ocular、Movement、Cardiopulmonary 的科学信息类别独立模型，其中 Cardiopulmonary 仅在取得正式预测资格后可用；
2. Behavior 与 Behavior + Ocular / Movement / Cardiopulmonary 的行为条件增量比较；
3. 具体科学指标的单指标模型、行为条件增量和完整组合删一指标比较；
4. 完整科学信息组合的逐类删一比较；
5. 按真实硬件依赖形成的设备组合分析。

当前实现仍未运行正式模型性能。P5 三类信息接口通过只证明行为、眼部和动作在身份、时间边界和缺失语义上能够进入同一正式流程，不构成预测结果。

## 3. 发现的报告—实现缺口：仅传感信息联合模型

国赛报告第 3 章已经明确提出：除行为基础上的传感信息增量外，还需要独立评价**不包含任务行为的传感信息组合**，以回答减少专门任务行为依赖时能够保留多少注意内容预测能力。第 4.6 节已经沿用这一研究目标。

当前 PR #68 的比较计划包含单类信息模型、行为条件增量、完整组合删一和设备组合，但尚未显式生成一个按**科学信息类别**定义的“仅传感信息联合模型”。设备组合模型不能直接替代这一比较，因为设备组合回答硬件配置问题，而仅传感信息模型回答科学信息在不使用任务行为时的联合预测问题。

因此，在正式监督学习运行前需要把这一模型作为预先定义的科学比较补入正式比较计划。其输入应由当时已经取得正式预测资格的非行为科学信息组成：当前至少考虑 Ocular + Movement；Cardiopulmonary 只有在取得正式预测资格后才能加入。该模型需要使用与其他正式模型相同的参与者互斥验证、训练折内预处理、实际数据覆盖记录和折外评价规则。

这一补充属于**正式运行前的方法—实现对齐任务**，不能在模型结果生成后根据性能再决定是否加入。

## 4. 仍需在正式运行前完成的事项

- 完成 Behavior 反应速度水平主要表示的最终冻结；
- 物化统一的正式科学特征登记；
- 将仅传感信息联合模型加入预先定义的科学比较计划；
- 保持 Cardiopulmonary 在正式测量资格和时间合法性通过前不进入正式预测；
- 在正式大规模运行前完成相应的小规模跨参与者验证和输出合同核对；
- 正式运行后再填写第 5.6–5.8 节的性能、增量和设备组合结果。

## 5. 当前停止线

截至本次核对：

- P5 行为 + 眼部 + 动作接口核验：已通过；
- 正式统一特征登记：尚未最终物化；
- 正式跨参与者模型：尚未运行；
- 多模态增量性能：尚无结果；
- 仅传感信息联合模型：报告已要求，当前实现计划仍需补入；
- 第 5.6–5.8 节：继续保持无性能结论状态。
