## 2. 未来正式模型的科学问题

正式监督学习需要依次回答：

1. 单独使用 Behavior、Ocular、Movement，以及通过测量资格后的 Cardiopulmonary，能否预测训练中未出现参与者的 Q1；
2. 在 Behavior 已知的情况下加入某类传感信息，是否仍能提供额外预测信息；
3. 在完整组合中移除某一类信息，性能是否稳定下降；
4. 具体指标层的贡献是否与信息类别层结论一致；
5. 不同现实设备组合能够得到哪些科学信息，以及这些设备组合的系统级性能如何。

当前首轮监督学习目标为 Q1=1 与 Q1=2/3/4 的二分类。四分类 Q1 和脱离 SART 的直接连续部署属于后续验证问题，不与首轮结果混写。

## 4. 数据划分与泄漏控制

正式结果必须使用参与者互斥的外层验证：测试参与者不能出现在训练或内部模型选择中。内部模型选择继续按参与者分组，所有标准化、插补和参数选择只能使用当前训练数据。

测试参与者的完整场次、未来时点统计或整场个人均值不得反向用于构造测试窗口特征。解释性分析中的人内中心化结果不能直接移植为零个体校准预测特征。

## 5. 每个正式模型运行必须输出的表

### 5.1 模型与样本清单

至少保存：

| 文件/表 | 必须包含 |
|---|---|
| analysis-set manifest | 模型所需科学信息、设备依赖、纳入参与者/场次/探针、缺失原因 |
| outer-fold manifest | 每个 LOSO fold 的测试参与者、训练参与者、测试探针数 |
| feature manifest | 每个模型实际进入的冻结 feature id、表示、单位、时间范围 |
| preprocessing manifest | fold 内标准化/插补规则和是否实际触发 |
| model manifest | 模型族、超参数、内部选择规则、随机种子/确定性设置 |

### 5.2 逐探针预测

必须保留每个测试探针：

- participant id / session / block / probe key；
- 真实 Q1 二分类标签；
- 预测概率；
- 外层 fold；
- 当前模型/比较 ID；
- 是否进入该直接比较的共同样本。

逐探针表可能较大，可以 local-only，但必须在本总账登记绝对路径和 SHA/manifest。

### 5.3 总体性能表

至少报告：

- participant-macro log loss（参与者宏平均对数损失，主要指标）；
- AUROC；
- Brier score；
- 校准结果；
- 95% CI；
- 实际参与者数、场次数、探针数和类别分布。

### 5.4 场次内状态区分

报告可估计场次内 AUROC，并明确：

- 可估场次数；
- 单一类别而不可估的场次数；
- 该指标只表示同一场次离散探针之间的状态区分，不等于连续实时追踪。

## 6. 必须做成成对比较的结果

### 6.1 Behavior 条件增量

每一项直接比较使用**同一参与者、同一探针、同一外层测试划分**：

- Behavior vs Behavior + Ocular；
- Behavior vs Behavior + Movement；
- Behavior vs Behavior + Cardiopulmonary（仅在心肺测量资格通过后）。

输出至少包括：

- paired Δ log loss；
- 95% CI；
- paired Δ AUROC；
- 95% CI；
- 比较实际分母。

### 6.2 完整组合删一比较

完整组合形成后，至少比较：

- full vs drop Behavior；
- full vs drop Ocular；
- full vs drop Movement；
- full vs drop Cardiopulmonary（取得资格后）。

只有实际配对性能支持时才使用“额外信息”“条件预测价值”等表述；一般性能增量不自动等于统计交互或“协同效应”。
