# 国赛报告

本目录是 2026-09-12 起重新组织的国赛报告工作区，与历史 `正式报告/` 同级维护。

## 定位

- `正式报告/`：保留此前版本、历史统计结果、旧章节草稿、附录和写作规范，作为来源与版本对照，不再直接覆盖成新版报告。
- `国赛报告/`：按照当前 1.16 方法体系和最新真实分析结果重新构思、撰写和修改国赛正文。
- `分析设计/`：保存正式研究决策、变量定义、统计与监督学习规则。报告中的方法性陈述必须与当前正式决策一致。
- 各代码仓库：决定当前实际实现、数据结构和真实运行结果。涉及当前分析逻辑、变量或数值时，必须先核对对应代码、配置和结果，不能从旧报告直接搬运。

## 强制写作参照

虽然新版正文单独放在 `国赛报告/`，但此前 `正式报告/` 中已经核验过的写作规范、官方模板约束和图表规范继续作为强制参照。每次新增、重写或润色国赛正文前，至少读取：

1. `正式报告/0-正式报告写作与统计结果呈现规范.md`：学术语体、方法/结果/讨论边界、统计结果书写、样本口径、图表与两遍审查规则；
2. `正式报告/1-官方模板与评分标准约束.md`：题目、摘要、关键词、章节顺序、篇幅、三级标题、字体字号、三线表、统计符号和 APA 7 等硬约束；
3. `正式报告/2-章节融合工作要求.md`：章节信息归属、正文与附录分工、避免工程语言、防御性语言和章节导航、图表组织原则；
4. `正式报告/科研绘图/README.md` 及相关 Figure Specification：方法图、实验图和统计结果图的分工与输出要求。

上述文件中的**写作、版式、统计呈现、图表、隐私和证据核验规则继续继承**。其中与“旧报告必须存放在 `正式报告/`”“旧章节结构原则上不重构”等位置或版本治理相关的要求，已被本轮用户明确的新工作区和重新构思要求覆盖；新版国赛报告以本目录为正文工作区，并允许围绕“无感多模态注意力测评系统”的研究目的重新组织章节。

核心写作风格保持：正文采用心理学论文/科研竞赛报告语体，研究对象和心理意义优先，方法名称与统计量准确，结论克制；不写聊天式解释、代码治理过程、虚空辩护、连续否定式说明或章节导航。正文追求高信息密度和完整性，不因“精炼”而删掉必要的样本、方法、效应估计、不确定性和关键非显著结果。

## 当前工作方式

报告工作按“先梳理研究目的、构念和证据结构，再写章节”的方式推进。旧稿只作为素材来源，不作为新版结构模板。

每个章节区分三类内容：

1. 已由当前代码与正式结果支持，可直接写入正文；
2. 方法已经冻结，但真实结果尚未完成，可先写方法、暂留结果位置；
3. 仍在测量验证或方法审计中的内容，只记录为待定，不写成正式发现。

当前代码实现、测试、真实运行和问题修复主要在 `Attention-Analysis` 等代码仓库的专门工作分支处理；本目录主要负责研究叙事、心理学表述、章节结构、图表组织和最终文字。若写作过程中发现方法或代码问题，应返回分析设计/代码任务处理，修复并验证后再回写报告。
