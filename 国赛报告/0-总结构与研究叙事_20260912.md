# 国赛报告总结构与研究叙事

## 1. 研究目标

本研究旨在构建并评价一套面向持续注意动态变化的低干扰多模态测评方案。持续注意难以由单一指标直接、连续观察，而学习、工作和持续监控等情境又要求尽量减少额外操作和穿戴负担，因此系统以任务行为和思维探针建立任务内参照，并结合非接触的眼部、动作和心肺观测，对持续任务中的状态变化进行多层描述与识别。

报告围绕低干扰、多源信息和系统整合三个特征组织。低干扰强调传感测量尽量减少额外穿戴和主动操作；多源信息强调行为、主观报告、眼部动态、身体动作和自主生理活动分别提供不同观察角度；系统整合则把实验范式、同步采集、指标形成、解释性统计、跨参与者识别和测评输出连接为完整研究链。

## 2. 测量对象与可观察信息

本研究关注持续注意在任务过程中的动态变化。同一参与者在不同时间可能出现任务聚焦、任务脱离、内部思维和困倦—清醒程度的变化，不同参与者的平均行为、生理水平和动作习惯也存在差异。因此，各类可观察信息承担不同角色。

| 信息来源 | 主要含义 |
|---|---|
| SART 行为 | 反映实际任务执行，包括反应速度、稳定性、Go 遗漏和 No-Go 误按等 |
| Q1 思维探针 | 提供探针时点之前注意内容的即时主观报告，其中任务聚焦报告作为首轮专注状态识别参照 |
| Q2 困倦—清醒报告 | 描述探针附近的主观困倦—清醒程度 |
| 事后问卷 | 提供整场任务体验、走神与疲劳回顾以及个体背景信息 |
| 瞳孔与眨眼 | 提供瞳孔动态和眼睑行为信息 |
| 身体动作 | 提供头部和身体外显活动信息 |
| 毫米波估计心率与呼吸率 | 在测量支持允许的范围内提供心肺相关自主生理信息 |

这些信息可以一致，也可以出现分离，因此任何单一来源都不被视为持续注意本身。研究首先考察各类观测与任务进程和主观状态之间的关系，并评价它们能否区分 Q1 所报告的任务聚焦状态；随后检验非行为信息是否在近期行为之外提供额外识别信息；最后检验这种识别能力能否适用于模型训练中未出现的新参与者，并结合不同设备配置评价系统实际可用性。

## 3. 研究问题

### 研究问题一：行为、眼部、动作和心肺信息能否区分 Q1 所报告的任务聚焦状态与其他注意内容，并呈现可解释的状态差异？

研究考察不同观测在任务进程中的变化及其与 Q1、Q2 和事后回顾之间的关系，并进一步评价各类信息自身对任务聚焦状态的识别能力。测量质量、数据覆盖和指标可估计性作为这些分析的基础单独报告。

### 研究问题二：在已经掌握近期行为表现后，眼部、动作和心肺信息是否还能提高对任务聚焦状态的识别？

研究以近期行为信息作为共同参照，比较加入其他科学信息后对 Q1 任务聚焦状态的概率预测是否改善，并在完整信息组合中评价各类信息的条件预测价值。

### 研究问题三：这种专注状态识别能力能否适用于模型训练中未出现的新参与者，并在现实设备配置下形成具有实际可用性的测评系统？

监督学习采用参与者互斥验证，使测试参与者的全部场次和思维探针均不参与模型训练；设备组合评价则说明不同硬件配置能够获得哪些正式科学信息、覆盖多少有效数据以及相应识别性能。系统可用性同时考虑新参与者识别能力和现实设备条件下的信息获取能力。

## 4. 方法逻辑

持续性注意反应任务（Sustained Attention to Response Task，SART）提供连续行为记录，思维探针提供时间明确的注意内容和困倦—清醒报告，事后问卷提供整场回顾和背景信息。近红外眼部视频用于形成瞳孔信息，RGB（红绿蓝三通道）可见光视频用于获得眨眼和身体动作信息，毫米波雷达记录胸部微动并形成心率和呼吸率估计。

各来源首先通过共同任务时间轴建立对应关系，再形成行为、眼部、动作和心肺四类科学信息。总体流程依次完成任务与主观参照、同步采集、指标形成、解释性分析与专注状态识别，以及系统评价。三个研究问题是需要回答的科学目标，五个环节是实现这些目标的数据与分析流程，二者通过同一证据链相互对应，而不是逐项一一配对。

## 5. 报告结构

### 1 引言

从持续注意的重要性、动态性和测量困难出发，引出低干扰、多源连续观测的研究需求以及 FocusWave 的总体方案。

### 2 理论与技术基础

依次讨论持续注意构念与测量、SART 行为与思维探针、眼部动态、身体动作、心肺自主生理及毫米波非接触感知，并说明多模态测量与参与者独立验证的理论和方法依据。

### 3 研究目标与总体方案

明确研究目标和三个研究问题，并以总体框架呈现“任务与主观参照—多设备同步采集—分析指标形成—解释性分析与专注状态识别—系统评价”的关系。

### 4 系统实现与研究方法

依次说明参与者与样本结构、SART 与主观测量、设备布置与同步、行为/眼部/动作/心肺指标形成、解释性统计以及跨参与者监督学习。

### 5 结果

按照“各类信息能否识别任务聚焦状态—非行为信息是否提供行为之外的额外识别价值—这种识别能力能否用于新参与者—不同设备配置下系统表现如何”的主线组织，同时先报告各类测量的质量、覆盖和可估计范围。没有正式结果支持的分析不写成结果结论。

### 6 分析与讨论

结合理论和外部文献讨论各类观测反映的心理生理过程、多源信息之间可能的共享与补充关系、新参与者适用范围、系统适用边界和研究限制。

### 7 特色与创新

创新点围绕低干扰持续注意测量、多源信息共同时间轴、从专注状态识别到行为条件增量和新参与者可用性的分层证据，以及测量—识别—解释一体化的系统框架展开。
