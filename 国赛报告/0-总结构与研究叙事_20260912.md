# 国赛报告总结构与研究叙事

> 日期：2026-09-12  
> 状态：结构工作稿，随真实结果冻结逐步修订  
> 依据：当前 1.16 方法体系、心理学报告变量约定与监督学习评价框架

## 1. 整篇报告的核心论证

本报告围绕“持续注意如何被行为、主观报告和多种非侵入式测量共同刻画”展开。SART 行为表现反映任务执行，思维探针提供注意内容和困倦/清醒程度的即时自我报告，瞳孔、眨眼、身体运动以及经验证后的心率和呼吸率提供不同层面的生理与行为观察。各类信息可能一致，也可能分离，因此不预设任何单一指标等同于完整的注意状态。

报告的重点不是证明“传感器越多越好”，而是依次回答三个层次的问题：第一，注意相关行为和生理/动作指标本身如何随任务过程及主观报告变化；第二，这些信息能否推广到训练中未见的新参与者，用于预测 Q1 注意内容自我报告；第三，在已经知道近期行为表现后，传感测量是否仍提供稳定的额外信息。当前首轮监督学习以 Q1=1 与 Q1=2/3/4 的二分类为主，四分类作为更细粒度的扩展；Q2 保留为解释性变量，不作为首轮监督学习目标或 Q1 输入。

整体论证链可以概括为：

**持续注意随时间波动 → 行为与即时主观体验形成任务内参照 → 眼部、身体运动和心肺活动提供并行测量 → 单模态分析检验这些测量与任务过程及主观报告的关系 → 参与者独立预测检验信息能否推广 → 行为条件下的增量比较检验传感测量是否提供额外信息。**

## 2. 建议的研究问题

### RQ1 行为表现与主观注意体验如何随任务过程变化？

关注正确反应时水平、反应时波动、反应时变化趋势、Go 遗漏率和 No-Go 误按率，以及这些指标与 Q1 注意内容、Q2 困倦/清醒程度之间的关系。该问题首先建立整个研究的行为和主观体验坐标系。

### RQ2 不同非侵入式测量是否与注意相关行为和主观体验呈现稳定关系？

眼部层面关注瞳孔水平、瞳孔波动、瞳孔线性变化、瞳孔曲线变化和眨眼频率；可见行为层面关注身体运动；毫米波在独立验证完成后主要关注心率和呼吸率。该问题回答各类测量本身能够提供什么信息，而不把某一模态预设为注意状态的替代真值。

### RQ3 各类信息能否预测训练中未见参与者的 Q1 注意内容自我报告？

分别考察行为、眼部信息、可见身体运动及后续毫米波信息单独使用时的跨参与者预测能力。这里检验的是信息的可推广性，而不是同一样本内的相关程度。

### RQ4 传感测量在已有行为信息后是否仍提供额外预测信息？

以近期行为表现为共同参照，分别比较加入瞳孔、眨眼/身体运动及后续心率和呼吸率后，对新参与者 Q1 预测是否改善。具体变量同时考察其单独预测信息、加入行为后的增量，以及在完整正式变量集合中的不可替代信息。

Q1 四分类作为 RQ3/RQ4 的细粒度扩展，不单独构成新的主研究问题。

## 4. 方法章建议结构

### 4.1 参与者与研究结构

说明正式实验样本、重复实验结构、预实验与正式实验之间的关系。正式实验总体以当前治理队列为准；具体单模态分析再报告实际可用参与者、场次和观测数。

### 4.2 SART 与思维探针任务

介绍 Go/No-Go 任务、Block、试次时序、探针安排、Q1 注意内容和 Q2 困倦/清醒程度。这里完成行为与主观变量的概念定义。

### 4.3 两阶段预实验与正式方案形成

只保留能够解释正式实验为何采用当前任务结构、参数和采集安排的关键证据。预实验不写成第二套结果章。

### 4.4 正式实验与多模态采集

按“眼部—可见行为—心肺活动”的测量目的组织设备和同步方式，而不是按硬件参数堆叠。设备型号、采样率等集中在表格中。

### 4.5 数据处理与统计分析

按科学变量组织：行为指标；瞳孔与眨眼；可见身体运动；毫米波心率与呼吸率；单模态关联分析；跨参与者监督学习与多模态增量。工程字段、内部接口和代码治理不进入正文。

## 5. 结果章建议结构

### 5.1 分析样本与数据可用性

只交代理解后续结果所必需的样本与可用性，不把质量检查写成主要科学结果。

### 5.2 行为表现与主观注意体验

先给总体行为水平和任务时间变化，再报告 Q1/Q2 与近期行为的关系。行为本身是研究结果，不仅是后续预测的“基准输入”。

### 5.3 眼部动态：瞳孔与眨眼

将瞳孔和眨眼按共同的眼部动态问题组织，而不按 NIR/RGB 两种设备机械拆章。建议顺序为：数据可用性与基本分布 → 任务时间变化 → 与 Q1/Q2 及行为的关系。瞳孔最终主表示和时间参数等待当前真实测量审计冻结。

### 5.4 可见身体运动

集中报告身体运动水平随任务进程及 Q1/Q2 的变化。曝光变化和姿态方向主要承担成像条件检查或补充解释，不与主要心理变量并列铺陈。

### 5.5 心率与呼吸率

待毫米波独立验证完成后写入。正文重点放在经验证可解释的心率与呼吸率及其与任务、Q1/Q2、行为之间的关系，不为了设备完整性提前扩展未验证指标。

### 5.6 跨参与者预测与多模态增量

按以下顺序写：

1. 行为信息单独预测 Q1；
2. 眼部、身体运动以及后续心率/呼吸率的单模态预测；
3. 各传感信息在行为基础上的额外预测价值；
4. 具体变量的独立与不可替代信息；
5. 完整多模态组合；
6. Q1 四分类扩展。

该节把“单独有信息”和“行为之外还有信息”分开呈现。正文主图优先使用参与者等权的对数损失及其置信区间，AUROC 等指标作为补充。

## 6. 讨论章建议结构

### 6.1 行为表现、主观体验与任务时间

解释持续任务过程中反应稳定性、错误和主观体验的共同变化及可能的分离。

### 6.2 眼部、身体运动与心肺活动反映了什么

结合文献讨论瞳孔、眨眼、身体运动、心率和呼吸率分别可能对应的唤醒、任务投入、运动状态和自主生理变化，同时保持对替代解释的克制。

### 6.3 从相关到可推广预测

讨论为什么同一样本内有关联不等于能够预测新参与者，以及本研究采用参与者独立验证所回答的实际问题。

### 6.4 多模态的额外价值与边界

围绕“传感信息是否超出行为”解释结果。即使某模态单独预测较好，如果加入行为后没有明显改善，也应解释为信息重叠，而不是简单判断该模态“无效”。

### 6.5 局限与后续研究

重点讨论 Q1 属于即时自我报告而非客观真值、类别不均衡、30 s 时间窗口与离散探针的限制、部分测量的质量与设备依赖，以及样本规模对跨参与者泛化估计的约束。
