# 国赛报告总结构与研究叙事

## 1. 研究目标

本研究旨在构建并验证一套面向持续注意动态变化的无感多模态注意力测评系统。持续注意难以由单一指标直接、连续观察，而学习、工作和持续监控等情境又需要尽量减少额外操作和穿戴负担，因此系统以任务行为和思维探针建立任务内参照，并结合非接触的眼部、动作和心肺观测，对持续任务中的状态变化进行多层描述与预测。

报告围绕三个核心特征组织：低干扰、多源信息和系统整合。低干扰强调传感测量尽量减少额外穿戴和主动操作；多源信息强调行为、主观报告、眼部动态、身体运动和自主生理活动分别反映持续任务中的不同表现；系统整合则把实验范式、同步采集、变量形成、统计分析、跨参与者预测和测评输出连接为一条完整链路。

## 2. 测量对象与可观察信息

本研究关注持续注意在任务过程中的动态变化。同一参与者在不同时间可能出现任务投入、任务脱离、内部思维和警觉程度的变化，不同参与者的平均行为、生理水平和动作习惯也存在差异。因此，各类可观察信息承担不同角色。

| 信息来源 | 主要含义 |
|---|---|
| SART 行为 | 反映实际任务执行，包括反应速度、稳定性、Go 遗漏和 No-Go 误按等 |
| Q1 思维探针 | 提供探针时点之前注意内容的即时主观报告 |
| Q2 困倦—清醒报告 | 描述探针附近的主观警觉程度 |
| 事后问卷 | 提供整场任务体验、走神与疲劳回顾以及个体背景信息 |
| 瞳孔与眨眼 | 提供眼部心理生理和眼睑行为动态 |
| 身体运动 | 提供头部和身体外显活动信息 |
| 心率与呼吸率 | 提供自主心肺活动信息 |

这些信息可以一致，也可以出现分离，因此任何单一来源都不被视为持续注意本身。研究先考察各类观测与任务进程、行为表现和主观报告之间的关系，再通过参与者独立预测评价其跨个体信息价值。

## 3. 研究问题

### 研究问题一：持续注意的动态变化能否在低负担、非接触条件下得到稳定且可解释的观察？

研究考察行为、眼部、身体运动和心肺信息是否能够形成具有足够测量质量的连续指标，并与任务进程、Q1 注意内容、Q2 困倦—清醒程度及事后回顾建立合理关系。

### 研究问题二：不同类型的信息是否提供互补预测价值？

研究分别评价行为、眼部、动作和心肺信息对 Q1 的单独预测能力，并进一步比较在已有近期行为表现后加入其他信息是否改善预测。完整多模态组合中的删一类信息分析用于描述各类信息在其他观测同时存在时的条件预测价值。

### 研究问题三：上述测量与预测关系能否推广到模型训练中未出现的参与者，并形成可解释的测评系统？

系统采用参与者互斥验证，使测试参与者的全部场次和思维探针均不参与模型训练。最终输出同时说明预测性能、不同科学信息类别的作用以及实际设备组合对信息覆盖的影响。

## 4. 方法逻辑

持续性注意反应任务（Sustained Attention to Response Task，SART）提供连续行为记录，思维探针提供时间明确的注意内容和困倦—清醒报告，事后问卷提供整场回顾和背景信息。近红外眼部视频用于形成瞳孔信息，RGB 可见光视频用于获得眨眼和身体运动信息，毫米波雷达用于记录胸部微动并估计心率和呼吸率。

各来源首先通过共同任务时间轴建立对应关系，再形成行为、眼部、动作和心肺四类科学信息。解释性统计考察任务进程、主观状态和不同观测之间的关系；跨参与者预测分别评价单类信息、行为基础上的增量信息以及完整组合中的条件预测价值。科学信息类别与硬件设备分开解释，同一设备可以产生多类科学信息，同一科学指标也可能依赖多种设备共同完成测量和质量处理。

## 5. 报告结构

### 1 引言

从持续注意的重要性、动态性和测量困难出发，引出低干扰、多源连续观测的研究需求以及 FocusWave 的总体方案。

### 2 理论与技术基础

依次讨论持续注意构念与测量、SART 行为与思维探针、眼部动态、身体运动、心肺自主生理及毫米波非接触感知，并说明多模态测量与参与者独立验证的理论和方法依据。

### 3 研究目标与总体方案

明确系统总目标和三个研究问题，并以总体框架图呈现“任务与主观参照—多设备同步采集—科学变量形成—解释性分析与跨参与者预测—测评输出”的关系。

### 4 系统实现与研究方法

依次说明参与者与样本结构、SART 与主观测量、设备布置与同步、行为/眼部/动作/心肺变量形成、解释性统计以及跨参与者监督学习。

### 5 结果

依次报告分析样本与测量基础、行为和主观状态、眼部、动作、心肺、各科学信息类别的跨参与者预测，以及多模态增量和条件预测价值。硬件组合的实际系统意义单独呈现。

### 6 分析与讨论

结合理论和外部文献讨论各类观测反映的心理生理过程、多模态之间的共享与补充信息、跨参与者推广范围、系统的适用边界和研究限制。

### 7 特色与创新

创新点围绕低干扰持续注意测量、多源信息共同时间轴、从测量关系到跨参与者增量预测的分层证据，以及测量—预测—解释一体化的系统框架展开。
