# F05 眼部动态与持续注意状态：Figure Specification

## 1. 图的基本信息

- **Figure ID**：F05
- **暂定标题**：眼部动态与持续注意状态的多路径关系
- **正文位置**：第 2 章，2.3“眼部动态与持续注意状态”
- **图的类型**：理论关系示意图
- **一句话沟通目标**：持续注意相关状态会通过连续瞳孔动态和离散眨眼行为两个不同眼部通道表现出来，同时二者都受到任务情境和生理条件影响。

## 2. 科学内容边界

### 必须出现的事实

1. 中央对象是“持续注意相关内部状态”，不画成单一注意分数。
2. 内部状态至少包括：`唤醒`、`任务投入/认知努力`、`疲劳/困倦`、`注意内容变化`。
3. 从内部状态分出两条并行眼部路径：
   - `瞳孔：连续心理生理动态`
   - `眨眼：离散眼睑行为`
4. 瞳孔输出层展示：`水平`、`波动`、`时间轨迹`。
5. 眨眼输出层展示：`频率`，并以次要标签注明 `持续时间 / 间隔（条件性指标）`。
6. 外部条件独立放在上方或侧边：`光照/视觉输入`、`视觉加工需求`、`任务持续时间`、`个体生理差异`。

### 不得暗示或夸大的内容

- 不画“瞳孔变大 = 注意更好”或“瞳孔变小 = 心智游移”。
- 不画“眨眼增多 = 注意下降”。
- 不把瞳孔直接连接为“LC-NE 水平”或“去甲肾上腺素浓度”。
- 不把眨眼画成多巴胺的直接量尺。
- 不把图画成确定因果模型；主箭头表示理论上存在的状态—表现联系。

### 与正文/表格的分工

图只呈现关系结构；不同研究中的具体效应方向、文献差异、混杂因素和证据强度由 2.3 正文解释。

## 3. 空间拓扑

推荐横向三层构图：

### 上层：任务与生理条件

四个小节点：

`光照/视觉输入` ｜ `视觉加工需求` ｜ `任务持续时间` ｜ `个体生理差异`

用较细线连接到瞳孔与眨眼两条路径，表示这些条件会影响眼部表现。

### 中层：持续注意相关内部状态

中央一个较大的圆角框：

**持续注意相关内部状态**

内部四个短标签：

- 唤醒
- 任务投入 / 认知努力
- 疲劳 / 困倦
- 注意内容变化

### 下层：两类眼部观测

左右并列：

**左：瞳孔｜连续心理生理动态**  
下方三个指标框：`水平`、`波动`、`时间轨迹`

**右：眨眼｜离散眼睑行为**  
下方主指标：`频率`  
辅助小字：`持续时间 / 间隔`

最下方共同汇聚到一句短标签：

`持续任务中的眼部动态观测`
