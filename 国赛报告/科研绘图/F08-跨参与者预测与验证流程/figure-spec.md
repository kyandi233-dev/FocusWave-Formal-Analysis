# F08 跨参与者预测与验证流程 — Figure Specification

## 1. 图的基本信息

- Figure ID：F08
- 暂定标题：跨参与者监督学习与验证流程
- 正文位置：第 4 章 4.6“跨参与者监督学习与多模态比较”
- 图的类型：分层验证流程图
- 一句话沟通目标：说明模型如何在完全未参与训练的参与者上预测 Q1 注意内容，并展示外层参与者互斥验证、训练数据内部模型选择、训练数据内预处理、参与者等权训练以及最终折外预测汇总的完整关系。

## 2. 全图总体逻辑

全图建议采用从左到右的 4 个阶段：

**参与者划分 → 训练数据内部选择 → 最终训练与新参与者预测 → 汇总所有折外结果**

图中核心视觉对象应始终是“参与者”，而不是随机拆分的探针或实验场次。每名参与者用一个人物图标表示，其名下可包含多个“场次”和“探针”小点，强调同一参与者的全部记录始终处于训练侧或测试侧中的同一侧。

## 3. Panel A：外层参与者互斥验证

左侧画一组参与者图标，例如 6–8 人用于示意。

其中：

- 多名参与者组成“训练参与者”；
- 1 名参与者单独作为“本轮测试参与者”。

测试参与者应使用明显不同的边框或底色，并在其下方同时画出多个实验场次/思维探针，表示该人的全部记录一起留出。

核心文字：

- `训练参与者`
- `本轮测试参与者`
- `同一参与者的全部场次与探针保持在同一侧`

不要在图中使用“随机 80/20 切分”一类表达，也不要把同一参与者的探针散落在训练和测试两侧。

## 4. Panel B：训练数据内部的模型选择

Panel B 只作用于训练参与者。

用 5 个简化折叠区块表示“按参与者分组的五折交叉验证”。每一折都应显示：

1. 一部分训练参与者用于拟合；
2. 另一部分训练参与者用于内部验证；
3. 缺失值处理、标准化和模型参数选择只根据当前内部训练数据完成。

可以在下方放一个统一框：

**训练数据内部完成**
- 缺失值处理
- 连续变量标准化
- 正则化强度选择

图中不要出现程序名称、配置键、字段名或具体参数数组。

### 参与者等权

在 Panel B 中加入一个小型“等权”视觉：每名训练参与者上方显示相同大小的总权重圆点；若某参与者有更多探针，则其单个探针图标更小或权重被分散，但该参与者总体权重与其他人相同。

旁边只写：

**每名参与者贡献相同总训练权重**

不需要在主图写公式。

## 5. Panel C：最终训练与测试参与者预测

训练数据内部完成选择后，用全部外层训练参与者重新拟合最终模型。

模型输入画成四个并列信息块：

- 行为
- 眼部
- 动作
- 心肺

这四块根据实际模型可以单独进入，也可以组合进入。不要画成四类信息在所有模型中必然同时存在。

中间统一使用一个框：

**L2 正则化逻辑回归**

模型右侧连接测试参与者的多个思维探针，每个探针得到：

**Q1“专注于分类任务”的预测概率**

可以用 0–1 概率条示意，但不填任何真实或虚构数值。

### 信息边界

测试参与者旁边增加一个小型边界框，写：

**预测某次探针时，仅使用该探针之前已经获得的信息**

下面用三个禁止符号或灰色图标表示不使用：

- 该参与者后续思维探针
- 未来视频或毫米波记录
- 该参与者完整实验记录形成的个人基线

这些内容用图形说明即可，不需要在正文图内展开方法争议。

Q2 和事后问卷不要画进预测输入。

## 6. Panel D：轮换测试与总体评价

Panel D 显示“测试参与者轮换”：

参与者 A → 测试一次
参与者 B → 测试一次
参与者 C → 测试一次
……

最终把所有参与者在其作为测试对象时得到的预测汇总到一个结果框中。

总体评价分成两层：

### 参与者内

先在每名参与者内部汇总其多个思维探针的预测损失和分类表现。

### 参与者间

再在参与者之间等权汇总。

主指标只需要突出：

- **参与者宏平均对数损失**
- **受试者工作特征曲线下面积（AUROC）**

辅助指标可缩小放在次级区域：

- 平衡准确率
- 宏平均 F1
- 敏感度
- 特异度
- 布里尔分数与概率校准

不要在图中展示任何当前尚未获得的数值。

## 7. 多模态比较在图中的呈现方式

为了避免把验证流程和模型比较画成两张互不相关的图，可以在 Panel C 下方增加一个横向“小比较带”，只展示三类科学问题：

1. **单独使用某类信息**
   - 行为
   - 眼部
   - 动作
   - 心肺

2. **在行为基础上增加传感信息**
   - 行为 + 眼部
   - 行为 + 动作
   - 行为 + 心肺

3. **完整组合中的条件信息**
   - 比较保留与移除某类信息后的模型

这三类比较全部复用上方相同的参与者互斥验证流程。不要把它们画成不同的数据切分方案。

如果版面过满，可以将这条比较带移到 F09 单独绘制；F08 主体仍以参与者独立验证为核心。

## 8. 推荐视觉层级

推荐横向 16:9，四个 Panel 从左到右排列。

- Panel A：人物图标最多，强调参与者级切分；
- Panel B：五折训练结构，背景应明显属于“训练区域”；
- Panel C：模型与预测，是视觉中心；
- Panel D：所有测试参与者结果汇总。

建议通过背景分区区分“训练侧”和“测试侧”，不要用过多交叉箭头。

行为、眼部、动作、心肺四类信息可沿用 F07 的同一视觉编码，以保持第 4 章方法图一致性。

## 9. 图内文字

主图建议只保留：

- 训练参与者
- 本轮测试参与者
- 参与者分组五折交叉验证
- 训练数据内预处理
- 参与者等权训练
- L2 正则化逻辑回归
- 行为 / 眼部 / 动作 / 心肺
- 探针前信息
- Q1 预测概率
- 轮换测试每名参与者
- 参与者内汇总
- 参与者间等权
- 对数损失
- AUROC

不要出现程序字段、模型编号、设备组合编号、内部工作状态或代码实现名称。

## 10. 建议图注

**图 X. FocusWave 跨参与者监督学习与参与者独立验证流程。** 每轮外层验证将一名参与者的全部实验场次和思维探针作为测试数据，其余参与者用于模型训练；训练数据内部再按照参与者分组进行五折交叉验证，以完成数据预处理和模型参数选择。最终模型使用外层训练参与者重新拟合，并仅依据测试参与者各思维探针出现前已经获得的行为和传感信息预测其 Q1 注意内容。每名参与者依次作为测试对象，最终先在参与者内部汇总多个思维探针的预测表现，再在参与者之间等权评价模型的跨个体推广能力。

## 11. QA

- [ ] 外层切分单位明确是参与者
- [ ] 同一参与者的多个场次和探针不跨训练/测试两侧
- [ ] 内部五折仍按参与者分组
- [ ] 缺失处理、标准化和参数选择只画在训练区域
- [ ] 每名训练参与者的总权重相同
- [ ] 测试参与者不用于重新估计个人基线
- [ ] 预测某次探针只使用该探针之前的信息
- [ ] Q2 和事后问卷不进入首轮 Q1 预测输入
- [ ] 四类科学信息与 F07 使用一致视觉编码
- [ ] 不展示虚构概率值、性能值或效应方向
- [ ] 评价顺序体现“参与者内汇总 → 参与者间等权”
- [ ] 图内无程序字段、内部方案代号和工程状态词
