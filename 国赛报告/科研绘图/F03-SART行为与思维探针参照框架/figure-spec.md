# F03 SART 行为与思维探针参照框架 — Figure Specification

## 1. 图的基本信息

- Figure ID：F03
- 暂定标题：SART 行为与思维探针构成任务内注意参照
- 正文位置：第 2.2 节“SART 行为表现与思维探针”
- 图的类型：理论—测量逻辑图
- 一句话沟通目标：只说明持续 SART、连续行为记录、离散 Q1/Q2 主观报告和连续传感记录如何在同一时间轴上形成互补观察，不展示任何模拟数据、信号波形或未经真实结果支持的效应方向。

## 2. 科学内容边界

必须表达：

1. SART 是持续 Go/No-Go 任务，高频 Go 建立连续反应背景，低频 No-Go 要求抑制按键；
2. SART 产生连续的逐试次行为记录，并可形成正确 Go 反应时、反应时波动、Go 遗漏、No-Go 误按和 d′ 等行为指标；
3. 思维探针只在离散时间点出现；
4. Q1 是四类无序注意内容：完全任务聚焦、任务相关干扰、任务无关思维、思维空白；
5. Q2 是四级有序困倦—清醒程度；
6. 眼部、可见行为和心肺等传感通道在任务期间连续记录；
7. probe onset（探针出现时点）提供时间锚点，探针前窗口用于把近期行为/传感记录与随后 Q1/Q2 报告对应；
8. 行为、Q1、Q2 和传感记录是不同观察来源，不画成相互等同，也不共同指向一个已经观测到的“真实注意状态”。

明确禁止：

- 任何人为生成的 RT、瞳孔、眨眼、身体运动、心率、呼吸等波形；
- 任意上升/下降趋势线、显著性符号、效应箭头或状态差异；
- 用曲线形态暗示某个模态在探针前发生了变化；
- Q1 四类从 1 到 4 单调变差；
- Q1=2/3/4 统一标为 mind wandering（心智游移）；
- Q2 画成客观 vigilance（警觉）真值；
- No-Go 误按等同走神、Go 遗漏等同困倦；
- 30 s 被画成领域规定的唯一标准窗口。

## 3. 推荐版式：共享时间轴的三层结构

整图使用一条从左向右的共享时间轴。所有内容由矩形、短标签、时间锚线和括号组成，不使用任何数据曲线。

### A 层：持续 SART 任务

用 8–12 个等高小矩形表示连续 trial stream（试次流）：

`Go` — `Go` — `Go` — `No-Go` — `Go` — `Go` — … — `Probe` — `Go` — …

其中：

- Go 框可标注 `非苹果 → 按键`；
- No-Go 框可标注 `苹果 → 抑制按键`；
- Probe 使用垂直锚线，不画成与 SART 并列的独立实验阶段；
- 本图不需要展示 250 ms / 900 ms 的单试次细节，该内容留给方法图 F04。

### B 层：任务内参照

该层分成两个互补部分。

**连续行为记录**

在整段任务时间轴下方放一个长条矩形，文字写：

`逐试次行为记录`

长条下方以并列标签列出：

`正确 Go RT` ｜ `RT 波动` ｜ `Go 遗漏` ｜ `No-Go 误按` ｜ `d′`

这些标签只表示后续可形成的行为指标，不画实际数值、折线或变化方向。

**离散主观报告**

在 Probe 垂直锚线右侧或上方放两个独立模块：

Q1 `注意内容（无序四类）`
- 完全任务聚焦
- 任务相关干扰
- 任务无关思维
- 思维空白

Q2 `困倦—清醒程度（有序四级）`
- 非常困倦
- 比较困倦
- 比较清醒
- 非常清醒

Q1 与 Q2 之间只表示“同一探针依次采集”，不画成上下游因果关系。

### C 层：连续传感记录与时间对应

在最下方放三个等长的水平条带，分别写：

- `眼部连续记录：瞳孔 / 眨眼`
- `可见行为连续记录：身体运动`
- `心肺连续记录：心率 / 呼吸率（按验证边界纳入）`

每个条带都只是一个纯色/空心矩形，表示“整个任务期间连续采集”，不画任何波形。

从 Probe 垂直锚线向左画一个矩形括号或浅色区间，统一跨过行为长条和三个传感条带，标注：

`探针前近端窗口`

窗口与 Probe 的关系只表达：

`近期连续记录` → `按时间窗口汇总` → `与随后 Q1 / Q2 对应`

这里的箭头只表示数据组织顺序，不表示心理因果关系。

## 4. 整图的逻辑关系

整图需要让读者一眼看到以下关系：

**持续任务**产生两类时间结构不同的参照：

- SART：持续产生逐试次行为记录；
- Probe：离散采样 Q1 注意内容与 Q2 困倦—清醒程度。

与此同时，传感器持续采集。Probe 出现时点只承担“时间锚”的角色，使其前方一段行为和传感记录能够与随后主观报告对应。

因此图中不设置一个位于中央的“注意状态”圆圈，也不画“行为/主观/传感 → 注意真值”的汇聚箭头。

## 5. 视觉语法

- 只使用矩形、细线、括号、标签和必要箭头；
- 箭头仅用于表示实验流程或数据对应方向，不表示因果；
- Q1 四类使用同级并列布局，不使用渐变、排序轴或严重度颜色；
- Q2 可以使用从困倦到清醒的有序排列，但不使用“差→好”的评价性色彩；
- Probe 垂直锚线贯穿行为和传感层，用来强调共同时间轴；
- 全图禁止波形、模拟散点、模拟柱形、置信区间、显著性星号等任何类似真实结果的视觉元素。

## 6. 建议图注

**图 3. SART 行为与思维探针构成任务内注意参照。** 持续性注意反应任务连续产生逐试次行为记录，可形成反应速度、反应稳定性、Go 遗漏、No-Go 误按和 d′ 等行为指标；间歇思维探针在离散时间点分别采样注意内容（Q1）和主观困倦—清醒程度（Q2）。眼部、可见行为和心肺等传感通道在任务过程中连续记录，探针出现时点用于确定近端探针前时间窗口，使同期行为与传感记录能够与随后主观报告进行对应。图仅表示测量结构与时间关系，不表示任何模态的真实信号形态或效应方向。
