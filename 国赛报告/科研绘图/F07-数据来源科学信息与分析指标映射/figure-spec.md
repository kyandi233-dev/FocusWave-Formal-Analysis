# F07 数据来源、科学信息与分析指标映射 — Figure Specification

## 1. 图的基本信息

- Figure ID：F07
- 暂定标题：多源数据如何形成持续注意相关科学信息
- 正文位置：第 4 章 4.3“多设备布置、同步采集与原始数据来源”与 4.4“科学变量形成、窗口化与质量控制”之间
- 图的类型：三层映射图
- 一句话沟通目标：说明任务记录、近红外摄像头、RGB 可见光摄像头和毫米波雷达分别提供什么原始观测，这些观测怎样形成行为、眼部、动作和心肺四类科学信息，并进一步形成报告中的分析指标；同时明确“设备来源”和“科学信息类别”并不是一一对应关系。

## 2. 核心结构

整图从左到右分为三列：

**数据来源 → 科学信息类别 → 分析指标**

左列进一步用视觉分区区分“任务记录”和“非接触传感设备”，避免把行为误画成某一种硬件模态。

### 左列：数据来源

1. **任务记录**
   - SART（持续性注意反应任务）逐试次记录
   - 思维探针 Q1/Q2
   - 任务阶段与时间信息

2. **近红外摄像头**
   - 眼部连续图像

3. **RGB（红绿蓝三通道）可见光摄像头**
   - 眼睑、头部和上半身连续视频

4. **毫米波雷达**
   - 胸壁微动连续信号

Q1、Q2 和事后问卷不画进四类科学信息的“传感指标”链条。Q1/Q2 可在图的上方以“即时主观参照”小框表示，事后问卷可作为右上角“整场回顾与背景信息”小框表示，二者都不与传感设备等同。

### 中列：四类科学信息

中列固定为四个同层级模块：

- **行为**
- **眼部**
- **动作**
- **心肺**

其中：

- 任务记录 → 行为；
- 近红外摄像头 → 眼部中的瞳孔信息；
- RGB 摄像头 → 眼部中的眨眼信息；
- RGB 摄像头 → 动作；
- 毫米波雷达 → 心肺。

不得画成“近红外=眼部、RGB=动作、毫米波=心肺”的简单一一对应，因为 RGB 同时提供眨眼和动作信息，眼部信息实际跨越近红外与 RGB 两种设备。

### 右列：分析指标

#### 行为

建议只列能够概括科学含义的指标名称：

- 反应时水平
- 反应时波动
- 反应时变化趋势
- Go（执行反应）遗漏
- No-Go（抑制反应）误按
- 辨别力与反应倾向

图中不出现程序字段名、变量名或内部方案代号。

#### 眼部

分为“瞳孔”和“眨眼”两个子组：

**瞳孔**
- 瞳孔大小
- 瞳孔波动
- 线性时间趋势
- 二次时间趋势

可在“瞳孔大小”下用小字注明两种测量表示：
- 几何平均直径
- 瞳孔占瞳孔—虹膜区域的面积比例

**眨眼**
- 事件数量与频率
- 持续时间
- 闭眼时间占比

#### 动作

- 整体可见运动强度
- 头部与身体姿态变化

方向性信息只表示相对变化，不在图中画成真实三维位移轨迹。

#### 心肺

- 毫米波估计心率
- 毫米波估计呼吸率

心搏间期和心率变异性不放入本图的主指标层，以免让图示超出目前能够稳定解释的测量范围。

## 3. 辅助依赖的画法

本图需要明确区分“形成科学指标的主路径”和“辅助质量处理”。

### 实线箭头

表示该数据来源直接形成某类科学信息，例如：

- 近红外摄像头 → 瞳孔
- RGB 摄像头 → 眨眼
- RGB 摄像头 → 动作
- 毫米波雷达 → 心肺

### 虚线箭头

只表示辅助处理关系，不表示新增科学信息类别。

当前必须保留的一条辅助关系：

- **RGB 眨眼识别 → 近红外瞳孔记录的眨眼伪迹识别与排除**

这条虚线应从 RGB 摄像头产生的“眨眼事件”指向“瞳孔数据质量处理”，而不是直接指向毫米波或其他设备。

毫米波记录中的较大身体运动用于判断胸部微动是否受运动干扰，可在毫米波模块内部用小型“运动干扰检查”标签表示，不单独连到“动作”科学信息模块，以免把质量检查信号误解释为正式动作指标。

## 4. 统一时间轴

图底部增加一条横跨所有数据来源的浅色底带：

**统一任务时间轴：试次 → 错误事件 → 任务进程 → 思维探针**

该底带表示所有连续观测都依据共同任务时间建立对应关系。不要为不同设备各画一套独立时间轴。

在右端可以用一个小型“探针前 30 s”框说明主要近期状态窗口，但不要重复 F04 中完整的 30/20/10 s 窗口结构。

## 5. 推荐版式

推荐横向 16:9 或接近双栏宽图。

视觉层级：

1. 左：四个数据来源卡片，其中任务记录与三种传感设备用不同的上位分区标题；
2. 中：四类科学信息，用同样大小的卡片纵向排列；
3. 右：各类指标以紧凑子卡片展开；
4. 上方：Q1/Q2“即时主观参照”和事后问卷“整场回顾与背景”；
5. 下方：统一任务时间轴。

数据来源卡片建议使用简化设备图标或现有设备照片裁切；中间科学信息层使用概念图标；右侧指标层以文字为主，不需要再加入大量装饰性图形。

## 7. 建议图注

**图 X. FocusWave 多源数据、科学信息与分析指标的对应关系。** 任务记录提供持续性注意反应任务中的行为表现及思维探针信息；近红外摄像头主要记录瞳孔动态，RGB 可见光摄像头同时提供眨眼和头部、身体动作信息，毫米波雷达通过胸壁微动估计心率和呼吸率。各来源数据依据统一任务时间轴与试次、任务进程和思维探针对应，并进一步组织为行为、眼部、动作和心肺四类科学信息。RGB 识别的眨眼事件还用于辅助排除近红外瞳孔记录中的眨眼伪迹。图中的连接表示测量和信息来源关系，不表示各指标之间的效应方向或预测贡献大小。
