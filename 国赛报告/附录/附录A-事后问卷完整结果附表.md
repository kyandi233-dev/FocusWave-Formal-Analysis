# 附录 A　事后问卷场次级有序模型完整结果

对应正文 **5.9 事后问卷与任务内报告的场次级一致性**。本附录给出完整系数表、结局分布与来源清单；正文只报告方向与置信区间。

| 项目 | 值 |

| 纳入场次 | **68**（北京正式实验中有有效事后问卷者） |

| 1 | 几乎没走神（不到 10%） | 23 |

| 3 | 相当一部分时间（30%–50%） | 9 |
| — | 大于 50% | 0 |

## A.3 模型与估计方法

- 模型族：**累积 logit 有序模型**（ordinal），结局为 A.2 的三级有序变量；
- 随机效应：**重复被试编号随机截距**，用于处理同一被试的多次场次；
- 连续预测变量按**场次级标准差**标准化，故优势比为"预测变量增加 1 个标准差时进入更高走神等级的优势比"；
- 三个模型在结果产生前冻结（确认性效度一致性、探索性行为、探索性毫米波）；
- 心率变异性**未进入**模型（独立心电留出验证尚不足以支撑确认性使用）；
- 反应时小于 150 ms 的预判按键不计入有效 Go 反应时中位数；遗漏率不作主要预测变量（预判策略会使其含义混杂）；
- 收敛：所有模型最大梯度 < 1.3e-6。

## A.5 解释边界

- 确认性结果显示**两类主观层级一致**：整场自评走神比例更高的场次，其任务内非专注探针比例也更高。置信区间很宽（2.15–318.49），只支持方向性结论，不能估计精确效应量；区间偏宽的主因是最高走神等级仅 9 个场次。
- 行为与毫米波两组**只可写作探索性信号**；No-Go 误按率在探索性校正后不再显著（*q* = .143），不能作为独立确认发现。
- 毫米波心率与呼吸率**未显示与整场走神等级的稳定关联**。这**不等于**毫米波无效，只表示在该层级、该效标、该样本量与该汇总尺度下未发现关联。
- 结论限定在**场次级自评效标**；不能用于把全场生理窗口统一标记为高走神，也不能替代任务内探针报告、测量资格或预测评价（后者见 5.2–5.8）。
