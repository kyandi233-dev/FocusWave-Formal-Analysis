## 2. 为什么必须是独立的只读后处理层

`src/attention_pipeline/supervised_learning/evaluation.py` 定义主指标 `participant_macro_multiclass_log_loss`（参与者宏平均多类对数损失）与 D10 固定折外参与者聚类自助（`n = 1000`、`seed = 20260830`、95%、不重训），并定义选择规则；`metrics_multiclass.py` 定义逐折类别先验无信息基线。**改动这两个文件即等于改动冻结契约。**

因此实现方式为新增只读后处理层，从**已归档**的 `probe_predictions.csv` 计算。

## 3. 指标定义与口径

### 3.1 聚合与区间

- **聚合**：参与者内 probe 等权 → 参与者间等权，与冻结评价层一致。
- **区间**：原样复用 `evaluation.fixed_oof_participant_bootstrap`——参与者聚类百分位自助，`n = 1000`、`seed = 20260830`、95%，**自助内不重训预测模型**。

### 3.2 多类布里尔分数

对 probe $i$ 与 $K = 4$ 个无序类别，

$$\text{BS}_i = \sum_{k=1}^{K}\left(\hat{p}_{ik} - \mathbb{1}\{y_i = k\}\right)^2 \in [0, 2].$$

参与者宏平均布里尔分数 = 先在该参与者的合法 probe 上取均值，再在参与者之间等权平均。与对数损失不同，**单类参与者仍可估**，不存在不可估问题。

同时报告：逐类布里尔分数（$(\hat{p}_{ik} - \mathbb{1}\{y_i = k\})^2$ 的同一聚合）与逐类先验参照。

### 3.3 无信息基线（与主指标**同一批** probe）

基线为预注册 §4.3 的**逐外层折类别先验常数预测器**，在**同一批** probe 上以**同一个**聚合口径评估，因此与模型构成合法配对比较。

先验从归档**重建**而非另取：四分类线沿用留一参与者外层划分，每名参与者恰好被留出一次，故外层折 $g$ 的训练侧 = 「所有外层折 $\ne g$ 的参与者」的全部合法 probe，这些行完整出现在归档里，重建是精确的，且**从不接触被留出的那一名参与者**。先验按冻结口径做加性下限截断（$10^{-12}$）并重新归一化。

**fail-closed 对账**：CLI 接受冻结汇总 `four_class_summary.csv`，把重建先验的无信息基线对数损失与该表的 `prior_baseline_participant_macro_multiclass_log_loss` 逐行比对（容差 $10^{-9}$）；**任何一行不一致即抛错并且不写出任何产物**。这样"重建正确"不是声称，而是每行都会打印的可核验事实。

派生指标：

- **配对布里尔差** = 先验布里尔 − 模型布里尔（正 = 模型优于无信息基线），带参与者簇区间；
- **布里尔技能分数**（Brier skill score）$= 1 - \text{BS}_{\text{model}} / \text{BS}_{\text{prior}}$。

### 3.4 判别力（仅用于守卫与描述）

折外合并的 one-vs-rest 宏平均 AUROC（area under the receiver operating characteristic curve，受试者工作特征曲线下面积）。本层**刻意直接复用冻结层 `metrics_multiclass._safe_macro_auroc`**，以保证与冻结汇总使用**同一个**宏平均定义（某类在样本内缺失时不计入宏平均、全部缺失才返回不可估）。区间由参与者簇自助得到（重抽样内允许某类缺失，按同一规则处理）。

**参与者级 AUROC 不报告**：`1.16.24` §4.2 已规定，60 名参与者中 11 名在 `AS.full` 内只出现单一类别；本层不产生任何参与者级 AUROC 数值，也不得为凑分母剔除参与者。

### 3.5 校准诊断（**事后操作化**）

**（a）顶端标签可靠性表。** 以每个 probe 的**最大概率**（置信度）为横轴、以「argmax 是否等于真实类别」为纵轴，按置信度的概率分位切分 10 个箱，逐箱报告探针数、平均置信度、观测正确率、差值，以及该箱的平均多类布里尔分数。另报**期望校准误差**（expected calibration error, ECE）$= \sum_b \frac{n_b}{N}\lvert \text{acc}_b - \overline{\text{conf}}_b \rvert$。置信度高度集中时实际生效箱数会少于请求箱数，**实际生效箱数随表报告**；ECE 依赖分箱，仅作描述性指标。

**（b）校准模型。** 拟合

$$\operatorname{logit}\big(\mathbb{1}\{\arg\max_k \hat{p}_{ik} = y_i\}\big) = \text{intercept} + \text{slope}\cdot\operatorname{logit}\big(\max_k \hat{p}_{ik}\big).$$

完美校准为斜率 1、截距 0。与二分类诊断层一致使用**准无惩罚**逻辑回归（`C = 1e6`；用超大 `C` 而非 `penalty=None`，以兼容本仓库支持的多个 scikit-learn 版本）。该小型诊断模型的区间来自在重抽样上**重新拟合它**；预测模型从不重拟合。每一行显式记录：

```text
prediction_model_retrained_in_bootstrap = False
calibration_model_refitted_in_bootstrap = True
used_for_model_or_c_selection           = False
used_for_feature_selection              = False
role                                    = supplementary_descriptive_diagnostic
```

**（c）校准总体偏差（calibration-in-the-large）。** 参与者内（平均置信度 − 正确率）→ 参与者间等权，带参与者簇区间。

**（d）可解读性守卫（沿用 `1.16.22` §4.2）。** 仅当折外合并宏平均 AUROC 的 95% 区间**排除 0.5** 时，才把校准斜率标为 `reportable`；否则标为 `not_reportable_low_discrimination`；校准模型自身不可估时标为 `not_estimable`。

## 4. 事后选择的自由度（如实登记）

以下四项**不是**事前预注册，而是本次实现时做出的操作化选择。逐条说明为何它们不可能把结论推向某个偏好方向。

| # | 事后选择 | 备选方案 | 为何不构成按结果调参 |
|---|---|---|---|
| 1 | 多类校准采用**顶端标签**（argmax 置信度）而非逐类 one-vs-rest 或向量缩放 | 逐类 one-vs-rest（4 组斜率）、Dirichlet/向量缩放校准 | 该选择在**看到任何四分类结果之前**即由二分类线 `1.16.22` §3 的 `logit(p̂)` 回归结构确定，与之一一对应；且不引入"类别数"这一自由度 |
| 2 | 可靠性分箱数固定为 10 | 5 / 20 / 等宽 / 等频 | 与二分类诊断层一致；实际生效箱数随表报告，读表者可自行判断分箱敏感性 |
| 3 | 守卫依赖折外合并 AUROC 区间而非参与者宏平均 AUROC | 参与者宏平均 AUROC 区间 | 参与者级 AUROC 在四分类下按预注册**不可报告**；折外合并 AUROC 是唯一可估的判别力指标 |
| 4 | 守卫规则本体 | 无守卫、或按斜率大小设阈值 | 规则**不依赖斜率估计本身**，只依赖判别力区间，因此无法被调成想要的斜率符号或大小 |

四项选择对**全部行统一适用**，不做个案豁免；**原始斜率、截距与区间在每一行都保留**，守卫只给出"是否可解读"的判定与理由文本，不隐藏任何数字。守卫的作用方向是**限制解释、使主张更弱**。

| 检查 | 内容 |

| C | 重新计算的主指标与冻结 `four_class_summary.csv` 逐行一致 |
| D | 逐 probe 计数闭合（诊断表 `n_probes` == 归档成功行数） |
| E | 参与者宏平均多类布里尔分数独立复算一致 |
| F | 逐折类别先验常数预测器的布里尔分数与对数损失独立复算一致 |
| G | 可靠性分箱对探针的计数闭合 |
| H | 期望校准误差可由分箱表还原 |
| I | 每个区间包住其点估计 |
| J | 治理标志（非选择性 / 不重训预测模型 / 不报告参与者级 AUROC） |
