# 1.16.9 单模态预测扩展与结果可视化框架

> 日期：2026-09-12  
> 状态：methodology_freeze_before_feature-finalization  
> 上游：1.16.1、1.16.4、1.16.8、**1.16.10**  
> 最新口径：科学模态按信息内容定义为 Behavior（行为）、Ocular（眼部）、Movement（动作）、Cardiopulmonary（心肺）；RGB、NIR（近红外）和 mmWave（毫米波）只称设备。若与旧表述冲突，以 `1.16.10-监督学习模态与设备定义修订及代码迁移计划_20260912.md` 为准。

## 1. 研究问题

监督学习需要分开回答三件事：某类科学信息单独能否预测训练中未见参与者的 Q1；在已有行为信息后，该模态是否仍增加预测信息；在完整正式信息已存在时，移除该模态是否使预测下降。设备组合属于工程部署问题，不能替代上述科学比较。

## 2. 首轮模态比较

各模态正式特征冻结后，首轮模型为：

- `Behavior -> Q1`；
- `Ocular -> Q1`：瞳孔与眨眼等眼部特征；
- `Movement -> Q1`：头动、体动等动作特征；
- `Cardiopulmonary -> Q1`：通过测量资格验证的 HR（心率）、BR（呼吸率），HRV（心率变异性）待资格通过后再加入。

这里的 `only` 只限制 predictor（预测变量）的科学模态，不限制硬件数量。例如正式 pupil（瞳孔）表示若由 NIR 主信号并使用 RGB 眨眼或头动信息清洗，仍属于 Ocular 模态，但其 `required_devices`（所需设备）可以是 NIR+RGB。

行为条件增量比较为：

- `Behavior` vs `Behavior + Ocular`；
- `Behavior` vs `Behavior + Movement`；
- `Behavior` vs `Behavior + Cardiopulmonary`。

四类模态正式特征均冻结后，可构造 `Full = Behavior + Ocular + Movement + Cardiopulmonary`，并比较 `Full-modality` vs `Full`，估计某模态在其他信息存在时的条件预测价值。

## 3. 与具体特征分析的关系

具体特征层继续保留：

- `x -> Q1`：单特征预测信息；
- `B -> B+x`：行为之后的单特征增量；
- `F-x -> F`：其他正式信息存在时的单特征条件预测价值。

模态整体表现不能推出该模态内每个特征都重要。`F-x -> F` 和 `Full-modality -> Full` 默认使用“条件预测价值”，不写成“不可替代信息”“贡献百分比”或心理构念组成比例。

## 4. 模态与设备分开

正式术语固定为：

- 科学模态：Behavior / Ocular / Movement / Cardiopulmonary；
- 设备：RGB / NIR / mmWave；
- 具体特征：RT、pupil、blink、head/body motion、HR、BR 等。

同一模态可以依赖多个设备，同一设备也可以产生多个模态的信息。例如 RGB 可同时产生 Ocular 中的 blink 和 Movement 中的头动/体动；NIR+RGB 可共同产生经过正式清洗的 pupil。

旧 M0–M7 仅保留为 device-package analysis（设备组合分析）或兼容编号，回答现实部署中某套硬件能产生哪些正式特征以及预测能力如何变化，不再称为科学模态比较。设备包只能包含其设备集合现实中能够生成的特征。

## 5. 方法与共同样本保持不变

本次重构不新增机器学习算法。二分类继续采用当前冻结的 L2 regularized logistic regression（L2 正则化逻辑回归）、外层 participant-disjoint LOSO（参与者互斥留一交叉验证）、内层 participant-grouped 交叉验证、训练折内预处理和参与者等权原则。

Task B 的 comparison-specific analysis set（比较特异分析集合）继续按待比较模型实际 `required_features`（所需特征）的并集构造，不按模态名或设备名直接求全局交集。某特征是否可用由真实来源、设备依赖、同步、QC（质量控制）、可估计性和预处理依赖决定。

## 6. 结果评价与可视化

主评价继续使用 participant-macro log loss（参与者宏平均对数损失），AUROC（受试者工作特征曲线下面积）为主要补充；balanced accuracy（平衡准确率）、macro-F1（宏平均 F1）、敏感度和特异度作为解释性指标。正式 OOF（折外）概率产生后，可追加 Brier score（布里尔分数）和 calibration plot（校准图）作为概率校准诊断，该补充不改变模态比较结构。

主报告建议分层展示：

1. 图 A：Behavior、Ocular、Movement、Cardiopulmonary 的单独预测表现；
2. 图 B：Behavior 加入 Ocular / Movement / Cardiopulmonary 后的增量；
3. 图 C 或补充材料：`Full-modality` vs `Full` 的删一模态结果；
4. 设备包结果单列工程/部署图表，不与科学模态结果混在同一主图。

## 7. 报告顺序

监督学习结果建议按以下顺序组织：

1. 各科学模态对新参与者 Q1 的单独预测能力；
2. 非行为模态在 Behavior 之后的增量预测价值；
3. 具体变量的单独、行为条件增量和完整模型中的条件预测价值；
4. 完整多模态及删一模态结果；
5. 设备组合的现实部署意义。

## 8. 实施时点

代码实现按 1.16.10 迁移合同进行：先拆开 `modality` 与 `required_devices`，再生成模态级模型计划和设备包计划。Behavior、眼部、动作和心肺的具体正式变量仍由各自上游 feature freeze（特征冻结）决定；本次定义重构本身不授权正式性能发布。
