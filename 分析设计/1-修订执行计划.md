## 二、已经核验的当前事实

### 2.1 重复被试不是附加敏感性，而是基础数据结构

- 场次是采集与时间轴单位，参与者是统计推断、自助重采样、交叉验证和身份隔离单位。
- 观测结构至少是：试次/窗口/探针嵌套于场次，场次嵌套于重复参与者。
- 同一参与者的所有场次必须进入同一训练/验证折；不能把场次当独立被试。
- 既有中央仓库已有重复参与者标识字段 `repeat_participant_id`、按参与者聚类的广义估计方程（GEE）、分组交叉验证、按参与者自助重采样和重复场次敏感性框架。这些可以复用工程结构，但需用当前 44 个场次的样本集重新核验身份表和科学口径。

### 2.2 当前 NIR 不是旧的 320×160 路线

- 当前正式生产器是 `fullclass-final` 瞳孔几何与质量链；RITnet 输入为 640×400，分析值只来自原图有效像素，不包括填充区。
- 正式表保留瞳孔椭圆、直径、面积、中心、硬/软分割比例、时间质量控制和不确定性；正式输出不再包含虹膜椭圆、瞳孔—虹膜比值（PIR）或其他虹膜归一化比值。
- 031 的眼部指标表为 173 列，包含额外几何验证字段；032、033 及历史 YOLO 主输出为 106 列。031 已冻结使用拓扑规则版本的主瞳孔几何；基础版、旧版和 EllSeg 版只保留一次紧凑对比，不再重新举行算法选择。
- 旧计划所记“27 个完成场次”是 2026-08-29 早期来源预检快照，已不再代表当前生产资产。2026-08-30 本机 `D:\_AttentionData\Beijing-NIR\amd-directml` 已能识别当前队列的 44 个唯一 NIR 场次级标识。下一步不是继续等待上游推理，而是为每场冻结唯一来源清单，并用最终便携分支重新物化分阶段分析表、模型和图表。
- pupil 可以进入正式候选分析，但是否进入最终报告取决于测量证据、质量覆盖、混淆控制、重复结构稳健性和科学解释，而不是预先一律贴“探索性”标签。
- PIR 旧脚本与历史结果保留；当前正式生产器没有 PIR。只有找到明确、可追溯且通过必要验证的虹膜几何来源后，PIR 才能作为候选对照重算；不能用当前虹膜类别比例偷换虹膜椭圆。

### 2.3 毫米波已有骨架，但生理状态要分层

- 既有代码覆盖相位/波形、通道与距离 bin、HR、RR/BR、信号质量、运动标记和部分 IBI/HRV 候选。
- 当前标准管线已有 30 秒主窗口、10/60 秒敏感性窗口、行为基线与毫米波增量、被试内稳健标准分、按参与者分组的折和可合并输出契约。
- “可计算”“工程 QC 通过”“外部参考验证通过”“能用于行为关联”“可进入正式报告”是五个不同层级。
- HR 目前有发展性参考证据但尚未达到强生理验证门槛；RR/BR 缺少匹配的外部呼吸参考；心搏间期（IBI）和心率变异性（HRV）不进入当前核心结论，但代码、输出和受阻原因必须保留。
- 毫米波不在本机迁移范围内；由连接完整毫米波数据和正式环境的另一台电脑运行。当前正式下游主线只维护毫米波标准结果接入、5 场结构性缺失、统一键和跨模态合并契约；报告措辞根据证据层级决定，不以“当前受阻”为由删除分析过程。

### 2.4 RGB 排在 NIR 和毫米波之后

- RGB 当前的算法与派生指标尚未全部冻结。优先内容是主脸覆盖、眼睑开合度、眨眼率/持续时间/间隔；头动、姿态、全局体动、面部动作单元（AU）和情绪概率分别作为外显行为、质量控制或候选特征处理。远程光电容积描记已退出当前分析路线，不再分配运行、验证或报告篇幅。
- 已有 RGB 运动门控可以作为毫米波运动伪影的辅助标记，但尚未成为正式 HR/RR 过滤器。原始毫米波结果必须保留，联合门控只生成并行敏感性结果。

### 2.5 既有 12 个行为特征不是完整结局体系

`focuswave-central` 当前探针前窗口工程特征为：试次数 `trial_count`、RT 均值 `rt_mean`、RT 中位数 `rt_median`、RT 标准差 `rt_sd`、RT 中位数绝对偏差 `rt_mad`、RT 变异系数 `rt_cv`、RT 斜率 `rt_slope`、准确率 `accuracy`、错误数/率 `error_count/error_rate` 和遗漏数/率 `omission_count/omission_rate`。这套特征适合探针前窗口建模，但不包含 d′、c、β，也不能替代机会数充足的区块/场次信号检测指标。

预实验阶段一与阶段二已经提供 No-Go 错误按键、Go 遗漏、d′、c、β、RT 变异系数、稳健趋势、错误前轨迹、探针前窗口、B1/B2 和图表模板。它们可以复用方法和代码结构，但预实验样本与正式 BB 设计不同，不能搬用数值结果。

## 三、总体分析逻辑

总体顺序不是“先跑每个模态所有指标，再找显著结果”，而是：

1. 冻结样本集、重复身份、来源、时间轴和版本；
2. 在任何模态效应之前识别设计因素、个体差异、重复场次、时间进程和质量因素；刺激亮度、对比度、大小和前一刺激只在 NIR 瞳孔模块中作为核心前置混淆审计；
3. 验证行为/探针如何共同定义注意状态或注意水平；
4. 按行为 → NIR → 毫米波 → RGB 的顺序建立每个模态从原始观测到二级指标的证据链；
5. 先检查覆盖、可靠性、冗余和组内/组间结构，再选择进入复杂模型的有限指标；
6. 完成单模态内部关系和行为关联；
7. 在共同样本、共同折和共同基线上做跨模态增量与有限交互；
8. 用多重准入标准选择正式报告内容；
9. 过程结果、失败结果和正式报告分区保存。

2. 检查 B1/B2、区块内时间、试次/周期/No-Go 固定位置、探针前窗口、场次顺序、重复参加/练习和设备/站点。
3. 检查参与者间差异、参与者内场次差异和场次内时间变化。
4. 将各模态有效覆盖、有效时长、最大缺口、算法未返回、质量拒绝、插值和人为排除分轨。
5. NIR 专属前置审计：引入当前与上一刺激的中央兴趣区亮度、对比度、可见面积/刺激大小和刺激身份；整屏指标只作敏感性替代。

说明：亮度调整图属于 NIR 正式效应之前的前置验证，不再排到结果末尾。

### 阶段 2：注意状态/注意水平与行为指标候选验证

目标：决定后续模型到底预测什么，而不是预先认定某一个“专注分数”。

候选层次：

1. 试次原始事实：Go/No-Go、正确、No-Go 错误按键、Go 遗漏、正确 Go RT、试次时间与位置。
   - Go 遗漏同时保留程序原始记分和互斥错误类型：有效 Go 反应、真正无反应、刺激前提前反应、超出合法反应窗、无法分类。分类必须基于原始按键、刺激前按键、反应时间和合法反应窗字段，并输出各类分母、分子和无法判断原因。
2. 跨尺度 RT 特征：在探针前窗口、区块和场次分别计算 RT 水平、离散程度、变异系数和稳健斜率，比较局部状态、阶段趋势与整体稳定性。
3. 信号检测指标：击中/虚警口径、极端比例的对数线性校正、d′、准则指标 c 和 β。它们可在任何机会数足够的聚合尺度计算；短窗口若 No-Go 分母不足则不强算。
4. 反应稳定性补充：中位数绝对偏差、四分位距、错误前轨迹，必要时使用指数高斯分布的 τ 长尾参数；低试次数聚合单位不强算分布参数。
5. 主观状态：Q1 原始类别和理论允许的合并方案；Q2 有序警觉度。
6. 时间过程：B1/B2、任务累积时间和重复场次顺序，不把这些设计因素简单合成注意分数。
7. 综合构念：只有在覆盖、可靠性、方向一致性和测量模型支持时才建立组合分数或潜在变量分数；否则保留“表现效率、稳定性、主观走神、警觉度”的多维主结局。

筛选标准：内容效度、分母/覆盖、重测或内部稳定性、天花板/地板、参与者内敏感性、参与者间区分、冗余、与 Q1/Q2 的收敛/区分效度、可解释性、预实验与文献一致性、后续可合并性。统计显著性不是首轮筛选器。详见 [1.1-指标与结局候选验证方案](1.1-指标与结局候选验证方案.md)。

输出：指标字典、候选结局卡、相关/冗余与可靠性结果、主结局与次级结局决策记录。

停止点：若证据不支持单一注意分数，则明确采用多维端点，不强行选“赢家”。

4. 使用按参与者聚类的 GEE 或层级模型处理试次/窗口；区块/场次指标使用重复测量模型或按参与者聚类的自助重采样。

小任务：

3. 质量门包括来源状态、有效图像内容、填充区、边界接触、破碎度、连通域、拟合质量、不确定性和时间缺口；“算法返回结果”与“质量验收通过”分开。
4. 候选原始指标包括等效直径 `pupil_equiv_diameter`、几何平均直径 `pupil_geom_mean_diameter`、椭圆/轮廓面积、短/长轴、硬分割瞳孔比例 `hard_pupil_fraction` 和软分割瞳孔比例 `soft_pupil_fraction`；中心移动主要作为尺度/运动质量控制，不直接解释为注意。
5. 派生层比较原始量、场次×眼稳健中心化差值、参与者/场次内稳健标准分和事件前局部基线差值；不预先决定哪一条一定最好，也不把场次中心化参考值误写成静息生理基线。
6. 二级指标按可用采样和窗口计算：中位数/分位数、四分位距/中位数绝对偏差、稳健时间斜率、峰谷幅度、一阶差分稳健幅度、扩张/收缩速度、事件响应幅度与恢复；频率指标只有在时间戳和缺口审计通过后才进入候选。
7. 在任何行为关联前先估计当前/上一刺激亮度、对比度、大小、试次类型、时间、左/右眼、质量和尺度候选的关系。
8. 用同一下游分析接口比较候选瞳孔指标。PIR 若未来恢复，必须作为有独立来源和状态标签的候选轨道，而不是覆盖瞳孔结果。
9. 先分析 NIR 内部关系与组内/组间分解，再连接已冻结的行为主/次结局。

输出：统一的眼—帧表、试次/探针/窗口表、候选指标比较、亮度调整结果、过程质量控制图、正式候选图和可合并数据包。

### 阶段 5：毫米波正式电脑分析与标准结果接入

目标：由另一台正式毫米波分析电脑运行可加载场次并形成标准结果包；本机只维护接入、缺失和合并契约，不搬迁毫米波原始数据或重复运行生产器。

小任务：

1. 把历史绝对路径迁移为本机私有配置；核验实际原始来源、解释器、通道、采样率、事件标记和参考数据可用性。
2. 对少量场次运行信号链快速测试：同相/正交（IQ）数据、距离单元、相位、呼吸/心动候选、HR/RR、质量控制和输出字段结构。
3. 修复只影响工程正确性的错误；任何改变窗口、特征、标签、折或模型家族的科学变更必须升管线版本并留下决策记录。
4. 对该电脑实际可加载场次正式运行，保存连续/窗口级 HR、RR/BR、质量、拒绝原因、运动、覆盖和来源，不只保存汇总图；当前 44 场队列必须明确保留 39 场可加载和 5 场结构性缺失的清单。
5. HR、RR 分别计算水平、变异、稳健 slope、有效窗口比例和相对静息/被试内标准化；IBI/HRV 候选继续输出到过程区，但不越过未通过的 beat/RSP gate。
6. 与行为主/次结局做考虑参与者聚类的关联和增量分析；区分“行为预测价值”与“生理测量准确性”。
7. RGB 运动门控延后到 RGB 有可用时间序列后做并行消融：仅雷达、加 RGB 标记、联合门控；不删除或改写原始结果。
8. 产出 `focuswave_canonical_v2` 或经批准的新版本包：生产器输出、聚合表、可合并表、阶段清单和运行清单。后续约 72 个场次使用相同列序和科学签名；最终合并后重新拟合，不平均两批曲线下面积（AUC）或 p 值。

### 阶段 6：RGB 指标冻结与分析

目标：在前两种生理模态稳定后，避免被大量 RGB 字段牵着走。

小任务：

1. 冻结主脸选择、多人/离屏/遮挡、人脸尺度、时间缺口和有效观测分钟数。
2. 优先验证眼睑开合度与眨眼事件，产出每分钟眨眼率、持续时间、间隔和群发事件；没有事件标注验证前不使用基于闭眼时长百分比的强结论。
3. 将俯仰/左右转头/侧倾角、速度、显著变化、姿态点可见度、全局体动和体动群发分为外显行为与质量控制。
4. 面部动作单元（AU）/情绪概率按预先定义的特征族、降维或正则化模型进入次级层，不逐项筛 p 值。
5. 先做 RGB 内部关系、覆盖/冗余/重测，再与行为端点连接。
6. 将运动门控输出提供给毫米波阶段做保留式敏感性分析。

### 阶段 7：单模态关系与跨模态融合

目标：回答每种模态提供了什么增量信息，以及多模态是否互补；不宣称某模态天然代表“专注”或“唤醒”。

因变量必须先写清楚，不再统称为“专注度”：

1. 试次层因变量：Go 正确 RT、Go 遗漏是否发生、No-Go 错误按键是否发生。
2. 探针前窗口因变量：经覆盖和可靠性验证的 RT 水平、RT 变异系数、RT 斜率或其他局部行为指标，以及 Q1 原始类别和 Q2 有序警觉度。
3. 区块/场次因变量：d′、c、β、No-Go 错误按键率、Go 遗漏率，以及在区块/场次重算的 RT 水平、离散程度、变异系数和时间斜率。

传感器指标是预测变量块。只有在模态内部质量/混淆分析中，瞳孔、HR/RR 或 RGB 指标才会作为因变量，用来检查它们是否被亮度、时间、运动或质量所驱动；这不是“预测注意”模型。

统一要求：

- 使用同一重复参与者映射、共同探针/窗口定义和共同外层分组折。
- 连续特征分解为参与者间均值与参与者内偏离；场次层偏离在数据支持时再加入。
- 解释性推断与预测性能分轨；模型选择不由最终测试结果驱动。
- 同一共同样本上的配对比较与各模态全可用样本的覆盖同时报告。
- 不强制所有因变量进入所有复杂模型。候选验证后，每个尺度冻结一个主结局和少量互补结局；若无单一胜出指标，则保留多维结局面板。

模型阶梯：

1. 设计基线：重复场次、场次顺序、区块、任务时间、设备/站点和质量覆盖。NIR 模型在此层额外加刺激亮度等视觉协变量；毫米波/RGB 不默认加。
2. 行为上下文基线：在预测当前试次或探针状态时，加入只使用当前时点之前信息生成的行为历史特征。
3. 单模态：分别加入筛选后的 NIR、毫米波或 RGB 特征，比较它们对同一因变量的增量信息。
4. 两两融合：只运行有理论依据和足够共同样本的组合。
5. 全模态：纳入全部通过门槛的模态，采用质量感知的后期融合或统一正则化特征模型。

模型选择：

- 层级关联优先使用线性/广义线性混合模型（LMM/GLMM）或按参与者聚类的广义估计方程（GEE）；Q2 用有序模型，Q1 依据验证后的口径使用多项或分层二分类。
- 广义加性混合模型（GAMM）仅在时间过程确有非线性、样本与诊断支持时用于预先声明的敏感性分析。
- 正则化线性/逻辑/有序模型作为主预测基准；直方图梯度提升树或随机森林作为次级非线性基准，不替代解释模型。
- 交互只保留少量理论驱动项，例如 NIR 人内偏离×Q2、毫米波×任务时间、NIR×毫米波；先报告主效应与覆盖，不从交互直接推断因果心理机制。

输出：统一合并审计、分组折分配、模型输入字典、预测/校准/覆盖/拒绝预测结果、解释性系数与不确定性、失败与不可估计模型表、可合并融合数据包。

图表要求见 [1.3-图表与分析问题台账](1.3-图表与分析问题台账.md)。

### 阶段 8：报告准入与完整过程分流

目标：不唯显著性，也不把所有跑出的图塞进报告。

每项结果按以下维度评分并留理由：

1. 是否回答核心研究问题或保证叙事逻辑完整；
2. 测量与时间对齐是否可信；
3. 样本覆盖和重复被试处理是否合格；
4. 效应大小、方向、不确定性和敏感性是否可解释；
5. 文献/理论对应是否清楚；
6. 是否有重要的意外发现或反例价值；
7. 是否可复现、可与后续约 72 个场次合并；
8. 图表是否能独立表达结论；
9. 是否存在结果选择、泄漏或多重比较风险；
10. 是否适合比赛报告篇幅。

结果状态统一使用中文：报告核心、报告支持、仅过程、仅验证、不可评估、当前受阻和未来工作。数据文件中若需保留英文状态码以兼容旧程序，字段字典必须给出中文映射。状态变化只新增决策记录，不删除旧产物。

工程兴趣区、分割遮罩、椭圆、失败例、诊断频谱和质量阈值选择默认进入“仅过程”，不进入正式报告；如果某个测量验证结果本身成为研究核心，再由证据台账明确升级。

## 五、代码、数据与本工作目录如何分工

- `Attention-Analysis@codex/formal-analysis-v2-portable`：Behavior、NIR、RGB 标准结果接入和跨模态融合的唯一正式下游主线；`analysis/multimodal-integration` 仅作为历史来源基线保留。

- 本工作目录：资产导航、方法、指标字典、结果解释、图表台账、运行证据和新报告版本。

同步 Git 时只提交代码、配置模板、测试、字段结构、聚合安全结果和文档；不提交原始视频、身份表或行级敏感数据。任何推送或合并请求之前单独征得确认。

## 八、本计划完成判据

- 每个阶段都有可运行入口、测试、字段结构、运行清单、路径导航和状态台账。
