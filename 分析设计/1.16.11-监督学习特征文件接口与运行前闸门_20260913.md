> 日期：2026-09-13

> 上位方法：`1.16.1`、`1.16.10`  
> 实现分支：`kyandi233-dev/Attention-Analysis@codex/1.16.10-modality-device-separation`，Draft PR #68  
> 实现接口文档：`docs/supervised_learning/1.16.10-feature-and-file-interface.md`

## 1. 当前阶段

监督学习总体结构已经进入“接口先冻结、真实特征后回填”的阶段。当前不再为每个模态另建一套训练逻辑；Behavior、Ocular、Movement、Cardiopulmonary 最终都通过同一 feature registry（特征登记表）、Task B comparison-specific analysis set（比较特异分析集合）和 Task A nested LOSO（嵌套留一参与者交叉验证）进入模型。

现在允许继续单模态真实分析和测量表示冻结，但正式监督学习仍未放行。真实 predictor、时间合法性证据、NIR #40/#41 接线、真实 schema smoke 和 mini-LOSO 仍是正式运行前闸门。

## 2. 冻结数据流

```text
单模态正式 producer
→ Task B probe-level quality / computability audit
→ probe_feature_status.csv
→ frozen feature registry + comparison spec
→ analysis_sets.csv / analysis_set_summary.csv
→ materialize one analysis_set_id × membership_type
→ Task A wide probe table
→ outer participant-disjoint LOSO + inner grouped 5-fold
→ OOF archive / paired comparison / manifest
```

单模态 producer 决定测量表示、清洗、QC 与数学可估性；Task B 决定某个具体模型比较的 probe 资格；Task A 只在已经冻结的 predictor 和比较特异样本上训练与评价。

## 3. 标准 probe 身份接口

标准 probe key 固定为：

- `session_id`
- `block_id`
- `probe_index_in_block`
- 统计身份另带 `participant_group_id`

主窗口为 `pre_30s`。Behavior 是 Q1/Q2 与 probe 元数据的权威来源；其他 producer 只能对齐和核验，不能重新定义标签。

## 4. Feature registry 最小合同

每个真实 feature 至少登记：

- `feature_id`
- `scientific_feature_id`
- `columns`
- `role`
- `modality`
- `feature_type`（需要时）
- `raw_source`
- `source_namespace`
- `required_devices`
- `preprocessing_dependencies`
- `temporal_anchor`
- `temporal_scope`
- `time_legality_status`
- `time_legality_evidence`
- standalone / Behavior+x / modality / Full / leave-one-out 资格
- device package 资格

科学模态、producer source namespace 和设备依赖必须分别登记；不得相互反推。

## 5. 时间合法性运行闸门

任何 feature 只要进入正式预测模型或 device package，必须同时满足：

```text
temporal_anchor = probe_time_ms
temporal_scope = pre_probe_only
time_legality_status = verified_pre_probe_only
time_legality_evidence != blank
```

`pending_upstream_freeze`、`blocked_future_information`、`blocked_temporal_scope_unknown` 只允许保留为候选/阻塞状态，全部正式预测资格必须为 false。

Q1-blind 表示冻结不能单独证明无泄漏。必须实际审计 producer 是否使用 probe 后帧、未来 probe、whole-session statistics（整场统计量）、完整测试参与者序列、非因果滤波/平滑或其他未来信息。

训练折内插补、标准化、列处理和超参数选择仍按 `1.16.1` 管理，与 producer-side time legality（生产侧时间合法性）是两个独立闸门。

## 6. Task B 文件接口

quality audit 固定产生：

- `formal_probe_identity.csv`
- `modality_probe_status.csv`
- `probe_feature_status.csv`
- `feature_coverage.csv`
- `modality_availability.csv`

其中 `probe_feature_status.csv` 的历史字段 `modality` 当前只表示 producer/source namespace（来源命名空间），不能解释为 Behavior/Ocular/Movement/Cardiopulmonary 科学模态。科学模态由 registry 与 `required_feature_records` 显式提供。

comparison-specific analysis set 固定产生：

- `analysis_sets.csv`
- `analysis_set_summary.csv`

每个比较有自己的 `analysis_set_id`；共同样本由所比较模型实际需要的 predictor union（预测变量并集）决定。

## 7. Task A 输入接口

每次只物化：

`一个 analysis_set_id × 一个 membership_type`

membership 允许：

- `included_complete`
- `included_missing_aware`

Task A 宽表至少包含标准 probe key、`participant_group_id`、`probe_event_id`、`q1_nominal_4class`、`analysis_set_id`、`membership_type`、`comparison_models`、`required_features`、`required_feature_records`、`required_outcomes` 和当前比较需要的全部 predictor columns。

Q2 可以作为报告/解释元数据保留，但不进入首轮 Q1 predictor。

## 8. Task A 输出接口

正式 run 至少归档：

- `probe_predictions.csv`
- `fold_audits.json`
- `failures.csv`
- `participant_log_loss.csv`
- `model_evaluation.csv`
- `participant_bootstrap.json`
- `paired_participant_increments.csv`
- `paired_model_increments.csv`
- `paired_fold_estimability.csv`
- `paired_increment_bootstrap.json`
- `probe_trajectory.csv`
- `session_discrimination.csv`
- `paired_comparison_provenance.json`
- `run_manifest.json`

跨 analysis set 的 raw increment 不得直接排行；直接增量解释要求两侧来自同一 comparison-specific analysis set。

## 9. 当前真实特征尚未回填的项目

以下内容仍待单模态结果，不在本文件提前决定：

1. Behavior RT level 使用 mean 还是 median；
2. pupil 的最终 signal、cleaning track、buffer、bin、level/variability/dynamics 表示；
3. pupil 是否依赖 RGB 及具体依赖；
4. RGB blink/movement producer 的真实 QC 放行；
5. HR/BR 的正式生理测量资格；
6. 每个真实 feature 的 time-legality evidence（时间合法性证据）。

这些决定完成后，只回填真实 registry 与 producer 接线；Task B / Task A 总体文件接口不再因具体特征选择重构。

## 10. 正式监督学习放行条件

至少同时满足：

1. Behavior / Ocular / Movement 首轮真实 feature freeze 完成；Cardiopulmonary 仅在资格通过后加入；
2. 所有正式 predictor 通过 time-legality fail-closed；
3. 真实 feature registry 完成并通过 validator；
4. NIR #40/#41 完成最终接线；
5. producer → Task B → materialize 真实 schema smoke 通过；
6. mini-LOSO 验证 outer LOSO、inner grouped CV、OOF archive、failure/provenance 输出完整；
7. 之后才允许 governed cohort 正式二分类监督学习。

在这些条件完成之前，不发布正式 Q1 预测性能。
