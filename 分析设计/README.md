# 分析设计

本模块是方法总入口。先处理 cohort、重复被试、设计因素、视觉亮度和数据质量等潜在混淆，再验证“专注状态/专注水平”的候选定义，然后依次开展行为、NIR、毫米波、RGB、单模态关联和跨模态融合。复杂分析不是所有候选指标的机械全排列，而是经过测量、覆盖、可靠性、冗余和科学解释筛选后的分层分析。

当前文件按本目录内的阅读顺序编号：[1-修订执行计划](1-修订执行计划.md)、[1.1-指标与结局候选验证方案](1.1-指标与结局候选验证方案.md)、[1.2-文献证据矩阵](1.2-文献证据矩阵.md)和 [1.3-图表与分析问题台账](1.3-图表与分析问题台账.md)。
