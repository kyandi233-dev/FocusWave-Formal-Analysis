# 分析设计

本模块是正式分析的方法总入口。先处理 cohort、重复被试、设计因素、视觉亮度和数据质量等潜在混淆，再验证“专注状态/专注水平”的候选定义，然后依次开展行为、NIR、毫米波、RGB、单模态关联和跨模态融合。复杂分析不是所有候选指标的机械全排列，而是经过测量、覆盖、可靠性、冗余和科学解释筛选后的分层分析。

当前文件按本目录内的阅读顺序编号：[1-修订执行计划](1-修订执行计划.md)、[1.1-指标与结局候选验证方案](1.1-指标与结局候选验证方案.md)、[1.2-文献证据矩阵](1.2-文献证据矩阵.md)、[1.3-图表与分析问题台账](1.3-图表与分析问题台账.md)和 [1.4-正式报告证据映射](1.4-正式报告证据映射.md)。

## 正式报告入口

本目录负责“分析怎么做、哪些证据可以进入报告”，但不保存正式报告正文。正式报告逐章融合稿统一维护在 [`正式报告/章节草稿`](../正式报告/章节草稿/README.md)，写作要求见 [`正式报告/2-章节融合工作要求`](../正式报告/2-章节融合工作要求.md)。后续当行为、NIR、毫米波、RGB 或跨模态分析形成新的冻结证据时，在本分析设计模块的 [1.4-正式报告证据映射](1.4-正式报告证据映射.md) 中更新证据与报告章节的对应关系，正文仍只在 `正式报告/` 中维护。
