# 分析设计

本模块是正式分析的方法总入口。先处理样本结构、重复参与者、设计因素、视觉亮度和数据质量等潜在混淆，再验证持续注意相关候选指标，随后依次开展行为、NIR、毫米波、RGB、单模态关联和跨模态增量分析。复杂分析不是所有候选指标的机械全排列，而是依据测量含义、覆盖程度、冗余和科学解释进行分层组织。

当前文件按本目录内的阅读顺序编号：[1-修订执行计划](1-修订执行计划.md)、[1.1-指标与结局候选验证方案](1.1-指标与结局候选验证方案.md)、[1.2-文献证据矩阵](1.2-文献证据矩阵.md)、[1.3-图表与分析问题台账](1.3-图表与分析问题台账.md)、[1.4-正式报告证据映射](1.4-正式报告证据映射.md)、[1.5-第3章研究问题与分析映射](1.5-第3章研究问题与分析映射.md)、[1.6-第4章方法事实与来源映射](1.6-第4章方法事实与来源映射.md)、[1.7-第5章结果结构与证据准入映射](1.7-第5章结果结构与证据准入映射.md)和 [1.8-正式分析最新权威来源与报告口径](1.8-正式分析最新权威来源与报告口径_20260830.md)。

## 正式报告入口

本目录负责“分析怎么做、哪些证据可以进入报告”，但不保存正式报告正文。正式报告逐章融合稿统一维护在 [`正式报告/章节草稿`](../正式报告/章节草稿/README.md)，写作要求见 [`正式报告/2-章节融合工作要求`](../正式报告/2-章节融合工作要求.md)。

`1.4` 维护章节与证据来源的总体对应关系，`1.5` 把第 3 章研究问题映射到后续统计，`1.6` 固定第 4 章研究结构、实验程序、设备与方法来源，`1.7` 固定第 5 章结果顺序、最低必报分母、图表和证据准入条件，`1.8` 则记录当前两个自有仓库的职责、外部只读毫米波/多模态来源，以及 Behavior、NIR、RGB、毫米波和多模态方法的最新报告口径。

正式报告与本项目分析说明只写入 `kyandi233-dev/FocusWave-Formal-Analysis` 和 `kyandi233-dev/Attention-Analysis`。外部 `greenboo26/focuswave-multimodal-attention-analysis` 仅作为毫米波与多模态方法证据来源，不作为本项目报告或治理文件的写入位置。
