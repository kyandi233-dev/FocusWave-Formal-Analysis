# 分析设计

本模块是正式分析的方法总入口。先处理 cohort、重复被试、设计因素、视觉亮度和数据质量等潜在混淆，再验证“专注状态/专注水平”的候选定义，然后依次开展行为、NIR、毫米波、RGB、单模态关联和跨模态融合。复杂分析不是所有候选指标的机械全排列，而是经过测量、覆盖、可靠性、冗余和科学解释筛选后的分层分析。

当前文件按本目录内的阅读顺序编号：[1-修订执行计划](1-修订执行计划.md)、[1.1-指标与结局候选验证方案](1.1-指标与结局候选验证方案.md)、[1.2-文献证据矩阵](1.2-文献证据矩阵.md)、[1.3-图表与分析问题台账](1.3-图表与分析问题台账.md)、[1.4-正式报告证据映射](1.4-正式报告证据映射.md)、[1.5-第3章研究问题与分析映射](1.5-第3章研究问题与分析映射.md)和 [1.6-第4章方法事实与来源映射](1.6-第4章方法事实与来源映射.md)。

## 正式报告入口

本目录负责“分析怎么做、哪些证据可以进入报告”，但不保存正式报告正文。正式报告逐章融合稿统一维护在 [`正式报告/章节草稿`](../正式报告/章节草稿/README.md)，写作要求见 [`正式报告/2-章节融合工作要求`](../正式报告/2-章节融合工作要求.md)。`1.4` 维护章节与证据来源的总体对应关系，`1.5` 把第 3 章研究问题映射到后续统计，`1.6` 则固定第 4 章当前使用的身份、最终 BB 实验程序、设备与方法来源，并记录尚未裁决的硬件参数冲突。正文仍只在 `正式报告/` 中维护。
