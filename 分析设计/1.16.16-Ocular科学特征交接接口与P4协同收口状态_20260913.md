## 1. 为什么本轮还需要补 Ocular handoff

`1.16.14` 已经冻结：

- RGB blink buffer（眨眼缓冲）：`pre200_post200`；
- fixed bin（固定时间箱）：`2 s × 15 bins`；
- cleaning track（清洗轨道）角色：`nir_qc_only` 与 `rgb_plus_nir_qc + pre200_post200` 均保留；

- variability（波动）收窄为 SD / MAD；

## 3. 当前进入 handoff 的 Ocular 候选

### 3.1 pupil

只保留 G1 已收窄的两条正式信号：

- `pupil_geom_mean_diameter`；
- `seg_pupil_fraction_within_pupil_iris_hard`。

soft `R_seg`（软分割比例）继续只属于 sensitivity（敏感性），不进入正式 handoff 候选。

每条信号只物化两条已冻结角色的 cleaning track：

- `nir_qc_only`，`required_devices=[nir]`；
- `rgb_plus_nir_qc + pre200_post200`，`required_devices=[nir,rgb]`。

时间箱固定为 2 s，不重新开放 1/5 s 全排列。

每条 signal × track 只保留当前窄候选：

- level mean；
- level median；
- variability SD；
- variability MAD；
- linear slope；
- quadratic curvature。

其中 slope / curvature 的 handoff 明确写为 `pending_temporal_span_freeze`，不会把尚未读取的本地 `g1_temporal_support_freeze_grid.csv` 假装成已完成的参数冻结。

### 3.2 blink

若提供现有 RGB `rgb_probe_pre30s_strict_features.csv`，builder 同时把 `blink_event_rate_per_min` 物化为 Ocular 独立科学维度：

- `scientific_modality = ocular`；
- `source_namespace = rgb`；
- `required_devices = [rgb]`；
- 缺失 RGB source 保持 missing，不补为 zero blink。

因此 RGB 仍是设备/来源，blink 的科学语义仍是 Ocular。

## 4. 与 P4 Movement 的协同

P4 已在 Movement builder 中增加 `ocular_cross_artifact_audit.csv`：在相同 probe（思维探针）身份上，用 participant-clustered Gaussian GEE（参与者聚类高斯广义估计方程）检查 geometry / hard `R_seg` 对 body motion（身体动作）、pose（姿态）、radial proximity proxy（径向接近代理）和 exposure change（曝光变化）的敏感性。

Ocular builder 可以接收该表并保留为 `ocular_movement_artifact_sensitivity.csv`，但该证据严格标记为 measurement-artifact sensitivity（测量伪迹敏感性）：

- 不使用 Q1/Q2；
- 不依据显著性选择 geometry / hard `R_seg`；
- 不把 radial proxy 解释为真实物理位移；
- 当前没有冻结的独立 physical face-scale（真实物理面部尺度）字段，因此不人为构造该变量。

## 5. 与后续监督学习接口的边界

Behavior、Movement、Ocular 三个 handoff 现在共享同一字段合同。Ocular builder 还会物化 `ocular_probe_features_wide.csv`，把 long-form（长表）G1 candidates 转成 probe-level（探针级）明确 predictor columns（预测变量列），使研究者最终冻结后能够无歧义写入后续 feature registry。

本轮硬约束继续为：

- `registry_ready = false`；
- `researcher_freeze_required = true`；
- `final_feature_registry_mutated = false`；
- `supervised_model_run = false`；
- `multimodal_model_run = false`；
- Q1/Q2 significance（显著性）和 supervised outer-test performance（监督学习外层测试表现）不是 freeze criterion（冻结标准）。
