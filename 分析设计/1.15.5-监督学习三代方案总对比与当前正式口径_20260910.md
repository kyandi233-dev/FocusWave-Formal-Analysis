## 1. 三个版本分别指什么

本文只比较三条容易混淆的路线。

- **A｜旧版已实现/已分析路线**：以 `1.10` 和当前 `Attention-Analysis/codex/formal-analysis-v2-portable` 多模态融合代码为代表。它已经形成代码和历史结果，但当前已发现若干样本、特征和验证实现问题。
- **B｜2026-09-09 修订计划**：以 `1.13/1.14` 为代表。该阶段曾计划先由行为 + Q1/Q2 形成共同状态，再让传感器识别该状态；同时提出连续传感信号从单一水平汇总扩展为 level（水平）+ variability（波动）+ trend（趋势）。共同状态目标后来被 `1.15` 的 Q1 监督学习主线取代，但动态特征扩展方向继续保留。
- **C｜当前修正后的正式计划**：以 `1.15/1.15.2/1.15.3/1.15.4/1.15.6` 为准。首轮主任务为 Q1=1 对 2/3/4 的零个体校准新参与者监督预测；保留动态特征扩展，并增加模态原生质量控制、训练前科学候选预筛、训练内经验筛选、嵌套验证、NIR 新参与者信息边界和完整过程留档。

`1.15` 本身是 B 到 C 之间的路线切换记录，因此不再单独列为第四代。

## 3. 当前正式特征逻辑

当前计划是“训练前科学预筛 + 训练数据内经验筛选”两级过程。

### 3.1 第一级：训练前预冻结科学候选库

这一层只回答“什么信息在科学上有资格成为候选”。

- 连续信号优先覆盖 level（水平）、variability（波动）和 trend（趋势）三个信息维度；
- 同一维度不机械堆叠大量操作化相近的统计量；
- mean 与 median 可作为水平家族候选，最终主方案只需代表项；
- SD 必须进入波动家族初始候选，MAD/IQR 可作稳健替代，不要求三者同时进入主模型；
- 趋势只有在真实时间序列和时间支持足够时计算；
- 峰谷差、相邻变化、变化率、扩张/收缩速度等细动态量无预先额外科学问题时不进入首轮默认主输入；
- QC/技术质量字段与科学预测特征分轨；
- 不因扩大特征空间重新引入尚未验证的 HRV、LF/HF 等指标；
- 30 秒是主窗口，10/20 秒是敏感性窗口。

### 3.2 第二级：每个外层训练集内部决定实际特征

只要保留/删除判断依赖本研究样本实际分布，就不能先看全体正式数据后固定。包括：

- 特征可计算覆盖率及缺失原因；
- 零/近零方差、有效值过少；
- 地板/天花板分布；
- 经验冗余；
- 同一候选家族中需要依据实际数据决定的代表项。

80% 仅作为重点覆盖审计参考线，不再自动决定纳入/排除。若某项选择需要根据预测性能判断，则继续下沉到每个内层训练/验证折。

不采用逐特征 p 值筛选，也不根据全数据 Q1 相关性或外层测试 AUC 选择特征。

## 4. 当前训练与测试流程

以某一外层折为例：

`全部参与者 -> 留出 1 名外层测试参与者 -> 其余参与者构成外层训练集 -> 在外层训练数据中完成样本依赖的特征质量复核 -> 如需根据预测性能比较少量候选方案/超参数，则在外层训练集内部做 participant-group 内层交叉验证，并在每个内层训练折重新拟合数据驱动预处理和选择 -> 选定方案 -> 在完整外层训练集重新拟合同一套处理和最终模型 -> 只使用训练所得规则处理外层测试参与者 -> 保存其每个 probe 的预测概率与完整身份键 -> 换下一名参与者重复。`

其中 NIR 零校准主预测不再需要测试参与者自己的完整序列均值。真正的人内/人际分解若保留，应进入解释性重复测量分析，或另建有合法个人基线的 calibrated prediction（个体校准预测）。

## 5. 当前必须留下的过程证据

新版至少需要保留以下可审计对象：

1. `analysis_set`：每次比较实际纳入哪些参与者、场次和 probe，以及各模态真实可用状态；
2. 模态源/时间对齐/QC 与缺失原因表；
3. 科学候选库与字段资格表；
4. 每个外层训练折的覆盖、稳定性、分布、冗余和实际入选特征；
5. 每个内层候选方案与超参数选择结果；
6. 每折插补、标准化及其他预处理参数；
7. 逐 probe 外层留出预测：真实 Q1、二分类标签、预测概率、预测类别、外层折、组合、`analysis_set_id`、特征集标识；
8. 逐折和汇总性能、M0–M7 配对增量、参与者级不确定性；
9. run manifest：代码 commit、配置、输入版本、失败记录及输出路径。

## 6. 历史结果的定位

旧版代码和旧结果不删除，也不因新版计划形成而重命名为当前正式结果。它们用于记录方法演变和在严格相同条件下进行历史对照。旧性能数值不能与新版不同样本、不同标签或不同特征筛选流程的结果直接做差解释为特征扩展收益。

## 7. 当前一句话口径

**当前正式路线 = Q1 二分类零校准新参与者预测 + 30 秒主窗口 + 连续传感信号“水平/波动/趋势”紧凑科学候选 + 不使用跨模态统一 80% 硬门 + 指标特异的可估计/稳定性审计 + 训练数据内经验筛选与嵌套验证 + 行为 raw Go omission 首轮简化表示 + M0–M7 公平增量比较 + 完整逐窗口与训练过程留档。**

其中 `1.13/1.14` 的“共同状态作为首轮预测目标”已经被后续 Q1 监督学习路线取代；`1.15.2/1.15.5` 的早期 80% 硬门和 omission 拆分主输入也已由 `1.15.6` 与本次同步修订替代。
