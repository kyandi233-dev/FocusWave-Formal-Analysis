RT level（反应时水平）仍只有一个科学维度，但 `go_correct_rt_mean_ms` 与 `go_correct_rt_median_ms` 的最终表示尚未研究者冻结。报告绘图代码不得自行根据 Q1/Q2 结果、显著性或视觉效果二选一；在冻结完成前，主图中的 RT level 必须 fail closed（失败关闭）或明确显示为“表示待冻结”，不能把 mean 与 median 当成两个独立科学维度重复展示。

`dprime_loglinear` 继续作为 signal detection（信号检测）正式伴随指标，可服务科学解释，但不因进入报告而升级为首轮 Behavior reference 的独立主特征。

RT mean/median 一致性、mean−median 分布、RT-CV 分布、RT slope 分布和覆盖率均进入资格/QC附录。

## 4. Movement 当前裁决

第一轮正式主科学指标保持 `body_motion_energy_median`。Q1/Q2 个别无效应也属于正式结果，不因置信区间跨 0 删除。

正文规划两张主图：

- `M-M1`：B1/B2 六阶段的身体动作**模型调整后轨迹**与 95% CI。当前 `movement_block_pair_task_progression` 的阶段轨迹是描述性阶段均值，`movement_task_progression_coefficients` 才承载正式 participant-clustered GEE（参与者聚类广义估计方程）推断。因此目标轨迹必须由**完全相同的冻结 GEE**派生 predicted values（预测值）和 95% CI；不得用当前均值±SE 冒充模型预测。
- `M-M2`：Q1 与 Q2 的身体动作关系双面板图。`movement_q1_models.csv` 与 `movement_q2_models.csv` 已足以确定性重绘，不需要模型重跑。

姿态横向/纵向方向及径向代理继续留在 sensitivity（敏感性）附录；曝光和来源覆盖进入 QC。`movement_behavior_relationships` 中主身体动作指标与近期行为的正式模型结果调整为 `formal_companion` 报告角色并放附录；“放附录”不等于“敏感性分析”。姿态/径向与行为的结果仍保持 sensitivity。

## 6. 哪些图需要模型派生

本轮把“重画”和“重新派生模型展示量”严格分开。

| 图 | 是否需要重新调用冻结模型 | 原因 |
|---|---:|---|
| B-M1 / B-M2 / B-M3 | 否 | 正式效应表已有估计与 95% CI，可确定性重组 |
| M-M1 | **是** | 目标为 GEE 调整后六阶段轨迹；现有系数表/描述均值不能提供完整预测 CI |
| M-M2 | 否 | Q1/Q2 正式效应表足够 |
| O-M1 | **是** | 目标为五维 GEE 调整后轨迹；需要同一冻结模型的预测协方差 |
| O-M2 / O-M3 / O-M4 | 否 | 现有表已有 within-person 正式估计、OR/CI 或原生效应/CI |
| between-person 附录 | 否 | 直接由同一正式表的 `ocular_between_z` 重组 |

因此第一轮不批准为了“画得更直观”而普遍重跑 adjusted probability（调整后概率）或 marginal effects（边际效应）。后续若报告确实需要概率展示，再单独追加裁决。

## 7. 中文语义与绘图规范

正文图不得出现 `go_correct_rt_cv`、`body_motion_energy_median`、`ocular_within_z`、`contrast_category` 等程序字段。`Attention-Analysis/configs/reporting/scientific_label_dictionary.csv` 作为报告语义映射合同，必须使用实际冻结代码字段，不使用 `pose_direction`、`pupil_level` 等无法直接追溯真实结果列的泛化占位符。

现有 reporting 分支共享 `publication_style.py` 仍主要满足 Times New Roman（英文）及通用 serif 回退，不能单独保证中文标签字形。后续正式绘图代码必须增加可验证的 CJK（中日韩文字）字体解析/失败关闭策略，同时保留拉丁文字的出版字体规则、无内部标题、无图例边框、300 dpi PNG + SVG 以及完整中文图注。不得共享字体文件本身。
