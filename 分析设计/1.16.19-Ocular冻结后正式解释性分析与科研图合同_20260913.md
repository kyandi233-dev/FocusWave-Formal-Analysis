# 1.16.19 Ocular 冻结后正式解释性分析与科研图合同

日期：2026-09-13

## 1. 本文件的作用

P3 已经冻结第一轮 Ocular（眼部）科学表示，P5 已经完成 Behavior + Ocular + Movement 三模态接口 smoke（接口冒烟测试）。当前剩余任务是把冻结后的眼部特征形成正式解释性科学结果、科研图件和结果资产。本文只冻结这一层的方法，不重开 P3，不改变 P5，也不进入监督学习。

当前正式治理总体继续是 61 个 participant groups（参与者组）、116 sessions（实验场次）、2,320 probes（思维探针）。NIR（近红外）正式可用 109 场；`sub-086`～`sub-091`、`sub-099` 的 140 个 probe 为已接受的结构性 NIR 缺失。其 canonical identity（规范身份）保留，NIR predictor（预测变量）保持 missing（缺失），不得补零、插补或使用旧 schema 补值。

## 2. 第一轮正式 Ocular 特征保持不变

正式解释性主分析只使用 P3 已冻结的五个第一轮特征：

1. pupil level（瞳孔水平）：hard `R_seg = pupil / (pupil + iris)` 的 `level_mean`；
2. pupil variability（瞳孔波动）：hard `R_seg` 的 `variability_mad`；
3. temporal dynamics（时间动态）：`linear_slope_per_sec`；
4. temporal dynamics（时间动态）：`quadratic_curvature_per_sec2`；
5. blink（眨眼）：`blink_event_rate_per_min`。

P3 已冻结的 RGB blink + NIR QC（RGB 眨眼 + 近红外质量控制）、前后 200 ms blink buffer（眨眼缓冲）、probe 前 30 s、2 s × 15 fixed bins（固定时间箱）、不插值、dynamic term（动态项）要求 early + late support（前后段支持）且首末有效时间点相隔至少 20 s，均不在本轮调整。

geometry（几何表示）、level median（水平中位数）、variability SD（波动标准差）、NIR-only（仅近红外清洗）等继续只属于 sensitivity（敏感性）、qualification（测量资格）、QC（质量控制）或 device alternative（设备替代）层，不因本轮 Q1、Q2 或 Behavior 显著性而升级为第一轮主特征。

## 3. 数据单位与重复测量结构

解释性分析单位为 probe。数据结构为：

`probe ∈ session ∈ participant`

同一 participant 可能参加多个 session，因此 session 不能被当作彼此独立的参与者。探针级正式模型以 participant 为最高重复测量 cluster（聚类单位）；来自同一 participant 的不同 session 均处于同一 cluster 内。所有正式表同时报告 participant、session、probe 的实际分母。

Behavior 与 Ocular 必须使用 canonical probe key（规范探针键）一对一连接：

- `participant_group_id`
- `session_id`
- `block_id`
- `probe_index_in_block`

正式运行要求 Ocular 与 Behavior 的治理探针宇宙完全一致；有限值可用范围则按各特征实际缺失分别进入模型。模型采用 complete-case per model（逐模型完整观测），不得补零或插补。

## 4. Task progression（任务进程）

### 4.1 科学问题

判断五个冻结 Ocular 特征是否随同一实验场次内的任务进程系统变化，以及第二个 Block（区块）的变化斜率是否与第一个 Block 不同。

### 4.2 进程变量

每个正式 Block 有 10 个 probe。block 内进程固定为：

`progression_centered = (probe_index_in_block - 1) / 9 - 0.5`

因此第一个 probe 为 -0.5，最后一个 probe 为 +0.5；系数表示跨完整 block 进程的变化尺度。

### 4.3 正式模型

对每一个冻结 Ocular 特征分别拟合：

`Ocular feature ~ Block + progression + Block × progression`

正式实现使用 Gaussian GEE（高斯广义估计方程），exchangeable working correlation（可交换工作相关结构），以 `participant_group_id` 聚类。该聚类层覆盖同一参与者不同场次与同一场次多个 probe 的依赖，不把重复场次当作独立样本。

正式结果至少报告：

- Block 2 相对 Block 1 的平均水平差；
- Block 1 的 block 内 progression 斜率；
- Block × progression 交互，即 Block 2 相对 Block 1 的斜率差；
- estimate（估计值）、SE（标准误）、95% CI（95% 置信区间）、原始 p 和本结果族内 BH-FDR（Benjamini–Hochberg 假发现率）校正 q 值；
- participant/session/probe 实际分母。

## 5. Q1：四分类注意内容

### 5.1 模型方向

Q1 是要解释的四分类主观状态，Ocular 是解释变量。模型方向固定为：

`Q1 ~ Ocular + Block + progression`

不采用“按 Q1 显著性挑眼部指标”的逆向筛选逻辑。

### 5.2 Reference category（参照类别）

Q1=1 固定为 reference category（参照类别），其余 Q1=2、3、4 分别与 Q1=1 比较。

### 5.3 Within-person / between-person decomposition（人内 / 人际拆分）

每个 Ocular 特征按 participant 分解为：

- between-person component（人际成分）：该参与者所有有限 probe 的个人均值；
- within-person component（人内成分）：当前 probe 值减去该参与者个人均值。

两部分在同一个模型中同时进入，并分别标准化为 fitted sample（当前拟合样本）内 1 SD（一个标准差）尺度。该处理用于区分“某个人总体较高”与“同一个人此时比自己的通常水平更高”两类关系。该人内中心化只用于解释性分析，不能直接转成未来零校准预测特征。

### 5.4 正式模型

使用 multinomial logit（多项逻辑回归），Q1=1 为参照；协方差使用 participant-cluster robust covariance（参与者聚类稳健协方差）。Block 和 progression 作为预先规定的任务进程控制项进入。

每个冻结 Ocular 特征单独拟合，不把五个高度相关但科学含义不同的 Ocular 特征强行同时放进一个大模型。主结果报告各 Q1 对比的人内与人际系数、95% CI、odds ratio（优势比）、原始 p 与 Q1 结果族内 BH-FDR q 值。

## 6. Q2：有序主观状态

Q2 为 ordered outcome（有序结果变量），正式分析不得把 Q2 任意当作连续变量做普通线性回归。

正式模型使用 cumulative-logit OrderedModel（累积 logit 有序模型），同样包含 Ocular 人内与人际成分、Block 和 progression，并对 participant 使用 cluster-robust covariance（聚类稳健协方差）。正系数表示更高 Ocular 成分与进入更高 Q2 等级的累计优势变化方向相关；实际心理方向仍按 Q2 当前正式编码解释。

Q2 各眼部特征分别拟合，输出 estimate、SE、95% CI、odds ratio、原始 p 和 Q2 结果族内 BH-FDR q 值。Q2 显著性不得用于重新选择 Ocular 特征。

## 7. Ocular × recent Behavior（眼部 × 近期行为）

### 7.1 主分析的 Behavior 指标

本轮只进入当前已经冻结、且不依赖 RT level mean/median 研究者选择的四类近期 Behavior 指标：

- `go_correct_rt_cv`：正确 Go RT CV（反应时变异系数）；
- `go_correct_rt_theilsen_slope_ms_per_s`：正确 Go RT Theil–Sen slope（Theil–Sen 反应时斜率）；
- `raw_go_omission_rate`：原始 Go omission rate（遗漏率）；
- `commission_rate`：No-Go commission rate（误按率）。

`go_correct_rt_mean_ms` 与 `go_correct_rt_median_ms` 当前仍属于 Behavior 研究者冻结待决，因此本轮不得自行选择其中一个进入 Ocular 主关系分析。`dprime_loglinear`、RT SD/MAD/IQR 等保持 sensitivity（敏感性）角色，不与主关系结果混写。

### 7.2 模型方向与拆分

正式关系模型固定为：

`recent Behavior ~ Ocular within + Ocular between + Block + progression`

这里用于描述关联，不作因果解释。每个 Ocular 特征与每个 Behavior 主指标单独拟合，避免把相互相关的行为指标和全部 Ocular 特征放进单个难以解释的大模型。

连续 Behavior 指标使用 participant-clustered Gaussian GEE（参与者聚类高斯广义估计方程）。Go omission 和 No-Go commission 使用显式 numerator/denominator（分子/分母）的 binomial GEE（二项广义估计方程），两类错误保持分开，不合并为总准确率，也不把 rate（比率）随意当作普通连续变量。

## 8. Multiplicity（多重比较）与结果解释

四个科学结果族分别为：

1. task progression；
2. Q1；
3. Q2；
4. Ocular × recent Behavior。

每个结果族内部输出 Benjamini–Hochberg FDR（假发现率）校正 q 值，同时保留原始 p、效应方向、效应大小和 95% CI。FDR 只用于结果不确定性的透明报告，不用于重新筛选或替换 P3 已冻结特征。

由于五个 Ocular 特征具有预先冻结的不同科学维度，主分析采用 one-feature-per-model（每次一个眼部特征）的共同合同；不使用显著性逐步回归，也不以联合大模型中的“独立显著性”重新定义科学特征。
