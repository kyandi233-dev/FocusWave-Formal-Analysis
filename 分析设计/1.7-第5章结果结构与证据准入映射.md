# 第 5 章结果结构与证据准入映射

> 用途：固定正式报告第 5 章的结果顺序、各小节回答的研究问题、需要的分析分母、主要统计输出和当前证据状态。本文属于内部分析设计，不复制正式结果正文。

## 1. 结果章总原则

第 5 章不按“先把所有能算出的指标都列出来”组织，而按研究问题和证据链组织：先说明谁进入了哪一项分析，再报告行为/探针作为任务内认知参照的结果，随后依次报告 NIR、毫米波、RGB 的测量覆盖与效标关系，最后在共同样本上比较单模态和多模态的增量价值。

结果章只报告已经由正式分析产物支持的数值和模型状态。代码提交、CI、单场 smoke、工程覆盖审计、阶段性 44 场整理进度等不能单独升级为科学结果。正式实验总体仍为 63 名参与者、119 次实验；每项分析必须另外报告其实际参与者数、实验记录数以及与该分析单位相匹配的试次/窗口数。

结果描述优先报告效应估计、95% 置信区间、样本覆盖和模型可估计状态。显著性检验作为补充，不以 p 值决定某个预设终点是否被展示。失败或不可估计的预设模型保留状态和原因，不能通过空表或静默删除形成选择性报告。

## 3. 5.1 样本流的固定写法

结果章样本流必须同时区分三个计数轴：参与者、实验记录和更细分析单位。正式总体的 63 名参与者/119 次实验是研究样本口径，不等于每一模态都存在完整信号。最终 5.1 应从该总体向下报告行为、NIR、毫米波、RGB 以及共同样本分别进入多少参与者和实验记录；如果某分析只使用满足特定质量条件的 trial 或 window，还需给出有效观测数或覆盖率。

当前 44 session / 38 participant groups / 6 repeat groups 属于当前整理分析子集；毫米波 39 个可加载 session / 33 group 属于当前输入审计。两者都可以指导正式生产和流程图设计，但不能预填成最终结果章分母。最终正文只使用由对应正式产物及 manifest 再次确认的数字。

## 4. 行为结果的压缩规则

行为指标较多，但正文不能把 RT 均值、中位数、SD、MAD、IQR、CV、slope、omission、commission、d′、c、β 在所有尺度全部平铺。结果优先顺序如下：

1. 先报告数据分布和核心任务进程：典型 RT 水平、RT 稳定性、Go omission、No-Go commission、d′；
2. c 与 β 用于补充说明反应标准/倾向，不与 d′重复解释；
3. RT 离散指标若高度冗余，正文选一个或两个具有不同统计含义的代表，完整矩阵进入表格/附录；
4. Theil–Sen slope 主要回答窗口内/时间段内趋势，不替代 RT 水平或变异；
5. Q1/Q2 先报告观测分布与参与者覆盖，再进入模型，避免稀疏类别的模型结果脱离样本结构。

Go omission 的正式三终点为 raw、clean 和 timing-ambiguous。它们是有确定包含关系的预设结果，而不是三个独立错误机制；必须同步报告共享 Go 分母和 `raw = clean + timing-ambiguous` 恒等关系。更细 prestimulus/carry-over 分类只在支持结果或质量诊断中出现。

## 5. NIR 结果的固定边界

正式 NIR 结果使用 pupil-only 直接瞳孔几何，不再恢复 PIR。结果首先回答“有多少眼部观测形成有效瞳孔几何”，再回答“视觉条件与任务时间怎样影响瞳孔”，最后回答“瞳孔与行为/探针有什么关系”。

RITnet 接口成功、YOLO bbox 存在、topology 方法标签存在均不能单独写成瞳孔测量准确率。有效测量需要结合 source、pupil geometry、valid analysis domain、segmentation uncertainty 和 temporal continuity。历史 iris 类别仍可参与 topology 连接和 segmentation QC，但不被解释为已经验证的虹膜外边界。

视觉调整必须体现时间方向。trial onset 前的瞳孔窗口不得使用随后才出现的 current-stimulus 视觉属性作为解释变量；严格发生在此前的 previous-stimulus 属性才可用于该类窗口。静息 baseline 的结果只有在 baseline_start→baseline_stop 的眼部可观测性规则事先冻结并实际满足后进入正文。

## 6. 毫米波结果的固定边界

结果顺序固定为：实际数据可用性和质量 → HR/RR/身体运动各自的任务时间变化 → 与行为/探针的效标关系。这样可以避免把“能够从雷达信号计算某个数值”直接写成“已经获得注意测量结果”。

HR、RR/BR、身体运动必须分开。身体运动既可能是行为状态信息，也可能影响心肺相关微动估计，因此至少有原始模型与运动敏感性/调整结果。IBI/HRV 只有逐搏质量与相应验证满足方法章条件时才进入正式结果；若未满足，应直接在结果或支持表中说明不可用于正式推断，而不是消失。

## 7. RGB 结果的固定边界

RGB 先报告主脸和眼部的可观测范围。blink rate、duration、interval 只有事件识别经过验证后进入正式结果；PERCLOS 需要稳定的闭眼事件定义和持续时间识别。head pose、pose、global motion 的主要价值是描述外显行为并为毫米波运动敏感性提供并行信息；AU、emotion、valence/arousal 只能作为预定义特征族的补充结果，不能逐字段筛选显著性。

## 8. 跨模态结果的固定比较条件

多模态增量只能在共同样本、共同因变量和共同基础协变量下比较。禁止用不同样本上的单模态模型性能直接声称某个模态更优，也禁止因为加入某个模态后样本减少而忽略样本变化。

预测评价必须保持参与者互斥；同一参与者的重复实验不能跨训练和测试。预处理、标准化、特征筛选和调参发生在训练参与者内。模型阶梯为：设计基线 → 行为上下文基线 → 单模态 → 理论支持的两两组合 → 全多模态。比较时同步报告 common-cohort coverage、性能与不确定性；如果更复杂模型没有稳定增益，结果按无稳定增量报告。
