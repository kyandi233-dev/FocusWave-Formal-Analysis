## 1. 当前边界

Behavior（行为）已经可以作为科学模态独立完成正式单模态结果整理，并生成与后续 feature registry（特征登记表）一致的候选交接表。该层不自动修改正式 registry，也不依据 Q1/Q2 显著性或监督学习 outer-test（外层测试）表现冻结特征。

首轮 Behavior reference 的方法角色保持：

- RT level（反应时水平）：`go_correct_rt_mean_ms` 与 `go_correct_rt_median_ms` 二选一，**仍需研究者冻结**；
- RT variability（反应时波动）：`go_correct_rt_cv` 为主表示；`rt_cv_min_n=2` 只表示样本标准差的数学最低要求，不是经验覆盖阈值；
- RT trend（反应时趋势）：`go_correct_rt_theilsen_slope_ms_per_s`；
- Go omission（Go 遗漏）：`raw_go_omission_rate`；
- No-Go commission（No-Go 误按）：`commission_rate`；
- `dprime_loglinear`、SD/MAD/IQR、clean/timing-ambiguous omission 等保留为描述、QC（质量控制）或 sensitivity（敏感性），不与对应主表示同时进入首轮 Behavior reference。

因此当前 Behavior 唯一尚待研究者完成的首轮表示选择是 RT level mean vs median。

## 2. RT-CV 运行合同

当前正式 Behavior runner 不再保留历史 `n>=20` fallback。配置必须显式满足 `rt_cv_min_n=2`；若当前正式配置漂移到其他值，运行应 fail closed（失败关闭）。2–19 个有效正确 Go RT 的窗口不会因经验样本量门槛被删除，只要样本标准差数学上可计算即可保留 CV；实际覆盖与低 n 结构进入 QC/资格审计。

## 3. 当前绘图合同

默认正式绘图从“指标 × 尺度 × 图型”的排列组合改为 question-driven（问题驱动）allowlist（允许列表）。历史穷举图代码可以用于复现旧输出，但不再由当前正式 runner 或 redraw（重绘）入口默认调用。

首轮 Behavior 科学输出最多生成以下 8 个问题型图件，实际缺少对应结果表时允许少于 8 张：

1. RT mean vs median 配对散点 + identity line（恒等线）；
2. RT mean − median 的 ECDF（经验累积分布）；
3. RT CV 的 ECDF；
4. RT Theil–Sen slope 的 ECDF；
5. 紧凑候选集合的 Q1 标准化系数图与 95% CI（置信区间）；
6. 紧凑候选集合的 Q2 标准化系数图与 95% CI；
7. CV / raw omission / commission 的 participant-cluster（参与者聚类）B1–B2 效应图；
8. registry-ready（可交接登记）候选的覆盖率 QC 图。

这里的 Q1/Q2 图用于正式单模态科学解释，不能作为“显著才保留”的特征筛选器。Q1/Q2 模型直接复用 producer 已经按参与者聚类得到的估计量和区间，不重新把 probe（探针）当独立样本估 CI。B1–B2 图使用参与者优先聚合后的 cluster bootstrap（聚类 bootstrap）结果。

所有当前图继续遵守学术图规范：Times New Roman（含配置回退字体）、图内英文、无内部标题、图例无边框、主推断优先报告效应量和 95% CI；中文完整图注保存在 `figure_manifest.csv`，不以显著性星号替代区间估计。

## 4. 文件层级

大型 Behavior producer 表继续保存在既有 `Behavior/formal_v3/`，不为科学报告层复制第二份大表。当前科学输出统一进入：

```text
FormalScience/
└─ Behavior/
   ├─ tables/
   │  ├─ behavior_feature_handoff.csv
   │  └─ behavior_feature_coverage.csv
   ├─ figures/
   │  ├─ main/
   │  ├─ qualification/
   │  ├─ qc/
   │  └─ sensitivity/
   └─ manifests/
      ├─ figure_manifest.csv
      ├─ producer_source_pointers.csv
      └─ science_output_manifest.json
```

`producer_source_pointers.csv` 只保存源表路径与存在状态；大型 trial/probe/session 中间表仍由 producer 目录负责。正式 full run 写 `FormalScience/Behavior`；subset/smoke 只能写自己的局部 `science_output/Behavior`，不得覆盖权威科学输出。

## 5. Behavior feature handoff

`behavior_feature_handoff.csv` 至少保存：scientific feature id、candidate representation id、predictor column、scientific modality、source namespace、required devices、preprocessing dependencies、measurement QC status、estimability rule/status、coverage summary、redundancy relation、temporal anchor/scope、time-legality status/evidence、report role、registry-ready 和 researcher-freeze-required。

Behavior 的共同时间合法性冻结为：`temporal_anchor=probe_time_ms`、`temporal_scope=pre_probe_only`、`time_legality_status=verified_pre_probe_only`。证据来自当前 `build_probe_windows`：只接受同一 session/block 中 `trial_num < anchor_trial` 且 `absolute_onset_time < probe_time` 的记录；主窗口为 `[probe_time-30s, probe_time)`，锚定试次排除且不跨 Block。

Behavior 本身不依赖传感硬件，因此 `required_devices=[]`，`source_namespace=behavior`，科学模态为 `behavior`。

## 6. 与后续工作的关系

本文件完成的是 Behavior 单模态科学输出和交接接口，不宣布 RT mean 或 median 的最终冻结结果，也不启动多模态监督学习。后续先完成 Ocular（眼部）与 Movement（动作）的同层科学输出和候选交接；三条模态均准备完成后，再由研究者基于单模态测量与科学结果冻结具体特征，随后才允许物化真实 feature registry 并进入多模态分析。
