## 一、总体判断：当前项目不是“统计方法不可信”，而是需要把测量证据链讲得更清楚

当前结果的核心价值不是“所有传感器都能稳定预测注意”，而是已经形成了一套相对完整的数字心理测量证据链：

1. 以 SART 行为作为任务表现参照；
2. 以 Q1 注意内容和 Q2 警觉程度作为任务内主观参照；
3. 分别评价 NIR、毫米波和 RGB 的测量质量与候选指标；
4. 处理重复参与者和任务内重复观测；
5. 在共同时间窗和共同参与者条件下检验单模态关联；
6. 以近期行为为 M0 基准检验传感模态增量；
7. 用参与者独立 LOSO 评价对新参与者的泛化，而不是随机拆 probe 造成泄漏。

因此，后续改进重点不是“为了好看再找更多显著结果”，而是：

- 明确每个指标为什么进入分析；
- 区分稳定个体差异与同一个人的短时状态变化；
- 区分核心构念候选、辅助行为特征和质量/混杂变量；
- 将现有分散证据组织成心理测量学意义上的聚合、区分、增量和泛化证据；
- 对仍未完成测量验证的模态保持证据等级边界。

## 二、信号检测论结果的解释与正文改进

### 2.1 d′ 不能只用原始正确率替代

SART 中至少要同时考虑：

- Go 条件下是否按键：命中 / 遗漏；
- No-Go 条件下是否误按：虚报 / 正确抑制。

d′ 的作用是把“应该按时能不能按”和“不应该按时能不能忍住”同时纳入，避免把“总是按键”误解成高辨别能力。

### 2.2 Hautus / loglinear 校正的解释固定

在短窗口中，若观测到命中率恰好为 1 或虚报率恰好为 0，直接做 Z 变换会产生正负无穷。当前解释采用常见 loglinear 思路：

- 校正命中率 = (命中数 + 0.5) / (Go 机会数 + 1)
- 校正虚报率 = (虚报数 + 0.5) / (No-Go 机会数 + 1)

例如 4 个 Go 全命中、2 个 No-Go 均未误按：

- 原始 H = 1，F = 0；
- 校正后 H = 4.5 / 5 = 0.90；
- 校正后 F = 0.5 / 3 ≈ 0.167；
- 再进行 Z 变换并计算 d′。

这不是伪造半次错误，而是有限样本下避免把 0% / 100% 直接当成真实总体概率极限。

### 2.3 最小机会数规则的报告方式

当前窗口分析要求至少具备最低 Go / No-Go 机会数后才计算 SDT 指标。此阈值属于项目分析规则，不应在正文写成普适心理统计定律。正文只需说明：为避免极少事件造成不稳定比例，仅在机会数满足预设条件的窗口中估计 d′、c、β；详细门槛与校正规则进入方法附录。

## 三、错误事件分析与时间过程：为什么需要保留

当前行为结果不应只报告整段平均分，因为持续注意的核心是时间波动。

错误事件分析把某次 Go omission 或 No-Go commission 设为事件 0，再观察其前后正确 Go RT。这样可以区分：

- 整体任务做久后的缓慢变化；
- 一次具体错误发生前几秒的局部轨迹。

参与者内中心化 RT 的意义是：不直接比较天然反应较快和较慢的人，而比较“这个 trial 相对这个人自己的通常水平偏了多少”。这能更接近状态变化，而不是稳定个体速度差异。

正式结果中 Go omission 前出现逐步 RT 延长，而 No-Go commission 前后平均 RT 偏移较小。报告应保留这一差异，因为它支持“遗漏与误按不是同一种行为过程”，但不能把 RT 延长直接写成“已经证明走神”。心理机制只能在讨论中谨慎提出。

## 四、重复参与者：已有处理是合理的，但报告需要更直观说明

### 4.1 当前已经做了什么

正式数据包含重复参与者，因此 session 不是独立被试。当前处理包括：

- B1/B2：每场先形成差值；同一参与者多个 session 的差值先在参与者内汇总，再按参与者做 bootstrap；
- GEE：以参与者为 cluster，处理同一个人多个窗口 / trial / session 的相关性；
- 多模态预测：按参与者划分训练和测试；LOSO 中一名参与者的全部记录只能出现在同一测试折，不能同人跨训练/测试。

因此后续正文可准确表述为：重复参加形成参与者内重复测量，推断统计采用参与者聚类或参与者层级重抽样，预测评价按参与者隔离。

### 4.2 GEE 的解释边界

GEE 的作用不是“把重复被试删掉”，而是承认同一个人贡献的多条观测彼此相关，避免把 2,000 多个 probe 当成 2,000 多个独立个体。

正文需要保留：模型类型、参与者聚类、B / SE / 95% CI / n 等核心统计量。更底层的 working correlation structure、link / family 若当前正式 runner 或配置没有明确证据，不补造；如后续要完善方法附录，应先从正式代码与配置核验。

## 五、95% CI 的解释：不跨 0 只回答“方向是否稳定”，不回答“效应是否大”

后续报告与答辩必须明确区分：

- 统计确定性：主要看估计值的不确定范围，如 95% CI 是否跨 0；
- 效应大小：看 B、均值差、OR 等在实际尺度上的大小；
- 实际意义：看这个变化对任务、心理构念和预测性能是否有实质价值。

例如 B1→B2 的 RT-CV 差值约 0.029，95% CI 为正，说明方向较稳定；但不能仅因 CI 不跨 0 就称为“大效应”。应结合 RT-CV 本身约 0.3 的量级和相对变化解释为中小幅、较稳定的反应稳定性下降。

对于有序 Logistic / GEE 的标准化预测变量，原始 B 在 log-odds 尺度，不能直接与 RT-CV 均值差比较。必要时可在讨论或答辩材料中将 B 转换为 odds ratio 以便解释，但正式报告是否呈 OR 必须与当前写作规范和正式结果表一致。

## 六、当前结果可信度分层

### 6.1 较高可信度：行为时间过程

支持理由：

- 重复参与者已按 participant level 处理；
- B1/B2 与 Block 内 cycle 指向一致；
- 主要结果不是所有指标一起变差，而是 RT 变异 / RT-CV 更稳定地上升，符合数据实际。

报告措辞：任务持续过程中主要行为变化表现为反应稳定性下降，而不是笼统写“所有表现全面恶化”。

### 6.2 中高可信度：行为与 Q1 / Q2 的任务内效标关系

Q2 较低警觉与更多 commission、真 omission、更高 RT-CV、更低 d′方向一致。可作为任务内效标关联证据，但 Q1/Q2 仍是主观报告，不是脑状态金标准。

### 6.3 中等：NIR 瞳孔

存在部分行为 / 主观关联，且已经做视觉刺激和质量控制；但部分结果主要体现参与者间平均差异，不等于同一个人某时刻瞳孔变大就代表注意变好或变差。

改进重点：明确 within-person 与 between-person 解释，不使用“瞳孔越大 = 越专注”这种单方向总括。

### 6.4 中等但受上游效度限制：RGB 眨眼候选

统计关系较密集，但算法事件仍未经过独立人工事件标注效度验证。报告继续使用“眨眼候选事件”，不能直接提升为经过验证的真实眨眼指标。

### 6.5 探索性：毫米波 HR / BR

心率存在误差和系统性偏差，呼吸相对更稳定，但当前仍属于支持性 / 探索性测量。HRV 在逐搏门未通过前不进入正式解释。

### 6.6 多模态预测：验证设计可信，但增量本身较弱

LOSO 和参与者分组能够避免明显身份泄漏，因此“当前没有稳定、普遍的多模态优势”本身是可信结论。不能把少量某指标 CI 不跨 0 扩写成“完整多模态显著优于行为”。

## 七、心理测量学证据：已有与待补的边界

### 7.1 已有证据

当前已经具备：

- 任务行为效标；
- Q1 / Q2 主观效标；
- 时间进程证据；
- 参与者内 / 间分解；
- 跨模态关联；
- 行为基线上的增量效度；
- 参与者独立预测泛化。

因此不应说“项目没有做心理测量效度”。更准确的表述是：已经形成较现代的数字心理测量效度框架，但还未完成标准化测验开发的全部证据链。

### 7.2 优先补：重复测量稳定性 / ICC

目的不是证明“注意很稳定”，而是回答每个指标的总差异中，有多少来自稳定的人际差异，有多少来自同一个人的状态波动。

候选优先级：

1. 行为：RT-CV、d′、commission、omission；
2. NIR：有足够重复有效 session 时再考虑 participant-level pupil；
3. RGB：有足够事件质量与重复有效 session 时再考虑 blink candidate rate。

建议输出：ICC 点估计 + 95% CI + 每名参与者有效重复 session 数分布。

重要边界：

- 不把高 ICC 自动解释为“更好的状态指标”；
- 状态测量本来需要保留个体内变化；
- 若某指标 ICC 很高，可能更多反映稳定个体特征；若 ICC 很低，也可能来自真实状态波动、测量误差或两者共同作用，需要结合质量证据解释。

执行前先核验重复 session 时间间隔、有效样本量和 ICC 模型类型，不能机械套公式。

### 7.3 优先补：聚合效度证据矩阵

目标：把当前散落在行为、Q1、Q2、NIR、毫米波、RGB 各章节的关系组织成一个构念效度网络。

建议矩阵维度：

- 行为稳定性：RT-CV / RT-SD；
- 行为错误：omission / commission；
- 辨别：d′；
- 注意内容：Q1；
- 警觉：Q2；
- NIR pupil；
- RGB blink / motion；
- mmWave respiration / HR / motion。

每格标记：

- 方向一致；
- 仅参与者内；
- 仅参与者间；
- 95% CI 含 0 / 证据不明确；
- 探索性；
- 上游测量未验证。

用途：让评委看到“不同方法在理论上应一致的地方是否一致”，而不是面对几十个散乱相关系数。

### 7.4 优先补：区分效度叙事

核心问题：系统测到的是持续注意，还是只是疲劳、一般唤醒、光照、体动或稳定个体生理差异？

现有可利用基础：

- Q1 = 注意内容，Q2 = 警觉程度，两个结局本身可形成区分；
- NIR 已控制视觉亮度、对比度、刺激大小等；
- RGB 已将 motion 与 exposure 分开；
- mmWave 将 motion / quality 单独保留并做高运动敏感性。

报告改进方向：强调“注意内容”和“警觉”不是同一个标签，不把所有传感变化都统一命名为专注度。

### 7.5 暂不优先：常模、诊断阈值、复杂潜变量模型

61 人不足以建立代表性常模或诊断阈值。除非明确要开发统一 FocusWave 总分，否则不为比赛形式感强行加入因子分析 / SEM / IRT。若未来建立统一总分，再讨论潜变量结构与量表化。

## 八、AI 与心理测量结合：需要重点讲，但不能写成“用了深度学习所以智能”

### 8.1 NIR：深度学习负责自动视觉感知

完整链条应在报告方法中讲清：

NIR 视频 → YOLO26n 眼部目标检测 → RITnet 四分类语义分割 → 背景 / 巩膜 / 虹膜 / 瞳孔 → 几何拟合 → Dgeom 等瞳孔指标。

解释：

- 目标检测负责回答“眼睛在哪里”；
- 语义分割负责回答“每个像素属于哪类组织”；
- 几何拟合把像素区域转成可解释的连续测量指标。

AI 在这里解决的是“从原始图像自动提取测量对象”，不是直接输出注意真值。

### 8.2 RGB：预训练视觉模型 + 几何 / 时序规则

建议表述：

- BlazePose：从图像提取人体姿态关键点；
- MediaPipe Face Mesh：提取面部 / 眼部关键点；
- EAR：由眼部关键点计算眼睛纵横比，反映开合；
- blink candidate：由 EAR 时序、双眼一致性、持续时间等规则识别候选事件；
- motion energy / exposure：传统图像差分和图像统计，不包装成深度学习。

“预训练视觉模型”指模型已在外部大量图像上学会人体 / 面部结构，本项目直接利用其表征能力，不是用当前 61 名参与者视频从零训练。

### 8.3 毫米波：主要是信号处理，不应包装成深度学习

毫米波主线是 Range-domain 复信号、滤波、VMD、频域 / 时域估计、质量与运动控制等数字信号处理。后续如果没有正式深度学习模型进入该链，不在报告中用“深度学习雷达”描述。

### 8.4 融合：主模型不是深度学习

当前主要融合模型是 L2 正则化多项 Logistic 回归，Random Forest 为非线性补充。

解释固定：

- 多项 Logistic：处理 Q1 / Q2 四分类预测；
- L2 正则化：惩罚过大的模型系数，降低小样本 / 多特征条件下的过拟合风险；
- Random Forest：多棵决策树集成，可补充非线性和复杂特征组合信息，但解释性较弱。

项目 AI 总叙事建议固定为：

原始传感数据 → AI / 信号处理自动感知 → 可解释行为 / 生理候选特征 → 心理统计检验效度 → 参与者独立机器学习检验预测增量。

这比“端到端黑盒预测专注”更符合测验赛道。

## 九、第二阶段三 Block 预实验：有分析价值，但绝不并入正式 cohort

第二阶段三个 B Block 的前两阶段与正式方案主体高度接近，第三 Block 是额外时长。已有形成性结果已显示 RT-CV 和 Go omission 随 Block 进程变化。

### 9.1 决策：作为形成性复现 / 测验长度优化证据

不把预实验 19 份有效记录与正式 116 场合并推断。原因：

- 预实验用于形成方案，正式实验用于确认；
- 直接合并会模糊确认性与形成性证据边界；
- 第三 Block 的存在意味着测验结构并不完全相同。

### 9.2 可补分析 A：B1→B2 方向复现

分别在：

- 第二阶段预实验 B1 vs B2；
- 正式实验 B1 vs B2；

估计同一组核心行为指标的方向和 CI。目标不是把小样本预实验当作额外显著性来源，而是检验核心时间效应是否在两个独立阶段方向一致。

### 9.3 可补分析 B：B1→B2→B3 的边际信息

问题：第三 Block 是否继续增加有意义的状态区分，还是主要增加疲劳与参与负担？

优先指标：RT-CV、RT-SD、Go omission、No-Go commission、d′；必要时保留事件轨迹，不机械扩展所有次要指标。

如果 B3 只带来有限新增信息，可作为正式采用 2 Block 的“测验长度优化”依据：一个 Block 太短不利于观察缓慢变化，三个 Block 负担增加且边际信息有限，最终保留两个长 Block。

## 十、多模态正式输入：总体有理由，但当前需要从“特征堆积”改为“理论分层”

### 10.1 当前问题不是“指标全选错”，而是三类变量混在同一层

建议把正式输入重新标注为：

#### A. 核心构念候选特征

直接与持续注意 / 警觉理论相关：

- 行为：RT-CV、omission、commission、d′、必要的 RT 水平；
- NIR：Dgeom；
- mmWave：respiration，HR 当前保留探索性；
- RGB：blink candidate rate。

#### B. 外显行为 / 辅助状态特征

- overall motion；
- pose / direction candidates。

这些可能包含状态信息，但不直接等于注意指标。

#### C. 质量与混杂控制特征

- RGB exposure / valid-frame coverage；
- mmWave confidence / timestamp coverage / motion quality；
- NIR segmentation / geometry / coverage quality。

这些主要负责测量可靠性和混杂解释，不应在报告图中与核心心理候选特征等权呈现。

### 10.2 正式特征进入模型的理由门

一个变量进入“理论精简主模型 / 敏感性模型”至少满足一项：

1. 有明确理论依据；
2. 单模态效标分析有有意义的关联；
3. 是必要质量 / 混杂控制变量。

仅仅因为 producer 能算出来，不足以成为正式核心预测特征。

### 10.3 当前 M0–M7 不回改，新增 theory-guided sensitivity

现有 M0–M7 作为当前正式结果冻结，不删除变量、不重写历史结果。

新增一条补充分析：

- full feature set：保持当前正式输入；
- theory-guided compact set：仅保留理论核心候选 + 必要质量控制；
- 使用相同共同 cohort、相同 LOSO folds、相同 preprocessing-in-train、相同评价指标；
- 比较 AUC、balanced accuracy、macro-F1、log loss，以及 participant-level bootstrap CI。

若精简模型性能相近或更稳定，可支持“主要信息来自有限可解释指标，而非大量弱解释特征”；若明显下降，则说明辅助 / QC 特征确实提供预测信息，但仍需区分“预测贡献”和“心理构念意义”。

## 十一、报告赛道定位：结果“够看”的正确理由

项目不应把竞争力建立在“模型准确率最高”上，而应建立在：

- 标准化持续注意任务；
- 思维探针与行为共同形成认知参照；
- 无感视觉 / 雷达自动感知；
- 重复测量统计；
- 参与者内 / 间区分；
- 严格参与者独立泛化；
- 测量质量—效标关联—增量验证的证据链；
- 对阴性结果和上游验证不足保持明确边界。

当前多模态增量较小并不等于项目失败。更有价值的结论是：在严格的新参与者验证下，传感器提供的是有限、结局依赖的补充信息，当前不能替代行为测量。这种结论比随机拆分得到高 AUC 更符合心理测量可信度要求。

### 14.3 问卷在测量链中的角色分层

问卷不应被当成“新的专注真值标签”，也不直接替代 Q1 / Q2。其主要角色分为四类：

#### A. 外部效标 / 收敛效度候选

优先条目方向：

- 整体走神时间占比；
- 走神自我觉察；
- 整体主观专注；
- 维持专注是否吃力、何时开始吃力；
- 平时可持续专注时间。

这些变量用于检验：一个人在事后总体上报告“更容易走神 / 更难持续专注”时，是否同时表现出更高 RT-CV、更多 omission / commission、更低 d′、更多 Q1 任务脱离类别等理论一致关系。

#### B. 警觉 / 疲劳维度与区分效度

优先条目方向：

- 明显疲惫 / 维持不住；
- 困倦变化；
- 最难集中发生在哪个任务阶段。

这些变量优先与 Q2 警觉、time-on-task、后期 cycle、blink candidate 等关联。目的不是把困倦等同专注下降，而是检验“注意内容”和“警觉 / 疲劳”是否由不同指标反映。

如果某个传感器只与困倦 / Q2 有关系、与走神 / Q1 不一致，应优先解释为警觉或疲劳相关候选，而不能笼统命名为“专注指标”。

#### C. 背景 / 混杂与敏感性变量

优先包括：

- 前一晚睡眠时长；
- 咖啡因摄入；
- 其他会明显影响警觉或生理信号的背景信息。

这些主要用于描述样本、协变量检查或敏感性分析，不与核心持续注意指标等权呈现，也不因一次显著相关就提升为核心模型特征。

#### D. 测验形成与可接受性 / 策略证据

包括：

- 任务策略；
- 是否感到 No-Go / 苹果存在规律；
- 探针是否造成打断；
- 整体体验与理解反馈。

这类信息主要用于解释任务可接受性、策略形成和测验设计边界。例如若相当一部分参与者形成了固定序列预期，需要在 time-on-task / cycle 解释中考虑固定预设约束序列可能带来的位置 / 学习效应，而不是把所有后期变化都单一归因于注意衰退。

### 14.4 正式优先分析顺序

优先恢复并核验 `questionnaire_analysis_v1`，禁止未经核对就从两份 Excel 重新造一套不兼容的新口径。

最短执行顺序：

1. 读取 `questionnaire_analysis_v1` 的 manifest / schema / existing tables / runner 或生成逻辑；
2. 建立问卷记录 → subject → repeat_participant_id → session 的正式身份映射表；
3. 明确正式 cohort、重复 participant、一人多场、未匹配 / 结构性缺失；
4. 先做 questionnaire ↔ behavior / probe 的桥接；
5. 再做 questionnaire ↔ NIR / RGB / mmWave 的支持性桥接；
6. 将结果汇总进统一 validity/reliability evidence matrix；
7. 最后再决定哪些结果进入第 5 章正文、哪些放附录或 discussion supporting evidence。

核心桥接优先级：

- 走神自评 ↔ Q1 + RT-CV + omission + commission + d′；
- 困倦 / 疲劳 ↔ Q2 + RT-CV + time-on-task + blink candidate；
- 自评专注 / 可持续专注时间 ↔ participant-level 行为稳定性与总体 probe 分布；
- 睡眠 / 咖啡因 ↔ Q2、行为以及必要的生理 / 眨眼敏感性；
- 规律感 / 策略 ↔ commission、No-Go 位置 / cycle / Block 时间趋势的解释性检查。

### 14.5 统计与解释边界

问卷多为事后、自编或任务特异条目，不是经过标准化常模和独立心理测量验证的成熟量表，因此：

- 不称“标准化量表”；
- 不把单个条目当作真实持续注意金标准；
- 不使用问卷去反向定义或训练 Q1 / Q2 标签；
- 主要作为外部效标、收敛证据、区分效度、背景混杂和形成性证据；
- participant-level 问卷不能复制到多个 session 后伪装成独立观测；若一名参与者多次填写，则采用与设计匹配的重复测量模型或先定义聚合规则；
- 任何问卷—行为 / 传感关系都需报告 n、分析单位、效应量、95% CI 和必要的多重比较控制，不用单独 p<.05 作为“验证成功”的标准；
- 若题目只在部分版本存在，则明确版本分母，不跨版本强行合并；
- 问卷与 Q1 / Q2 的一致不等于构念已被完全证明，只是效度证据网络中的一条来源。

### 14.6 对正式报告结构的落地

完成分析后，报告应把问卷从当前较边缘的“预实验反馈”位置扩展为一条正式但有边界的测量学证据来源：

- 第 4 章方法：说明事后问卷的用途、条目维度、对应时点、重复 participant / session 处理与分析角色；
- 第 5 章结果：增加简洁的 questionnaire–behavior / probe 外部效标结果，并只呈现预先定义且解释清楚的核心条目；
- 第 6 章讨论：利用走神 vs 困倦的差异支持“注意内容”和“警觉并非同一维度”的区分效度叙事；
- 第 7 章创新：把 FocusWave 定位为“行为 + 任务内探针 + 事后总体自评 + 连续无感传感”的多层证据框架，而不是只靠单一生理信号输出专注分数。

正式总链条建议更新为：

持续注意构念 → SART 行为表现 + 任务内 Q1/Q2 → 事后问卷外部效标 / 收敛与区分证据 → NIR / RGB / mmWave 连续候选过程指标 → participant-level 重复测量与效度检验 → 行为基线上的多模态增量 → 新参与者泛化。
