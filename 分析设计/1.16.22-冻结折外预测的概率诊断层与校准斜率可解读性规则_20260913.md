该三层指标的**范围**属事前预注册，见 `分析设计/1.16.9-单模态预测扩展与结果可视化框架_20260912.md` §6：

因此本层不是看到性能之后才决定加入的评价维度，而属于 1.16.9 已授权的补充诊断。**但它不参与选择**：主指标与 C/候选搜索仍由冻结的 `evaluation.py` 单独决定。

## 2. 为什么必须是独立的只读后处理层

`src/attention_pipeline/supervised_learning/evaluation.py` 定义了主指标 `participant_macro_log_loss`（参与者宏平均对数损失）、D10 固定折外参与者聚类自助（`n = 1000`、`seed = 20260830`、95%、不重训）以及选择规则。**改动该文件即等于改动冻结契约**。

因此实现方式为新增只读后处理层，从**已归档**的 `probe_predictions.csv` 计算：

| 文件 | 性质 |
|---|---|
| `src/attention_pipeline/supervised_learning/probability_diagnostics.py` | 新增模块 |
| `scripts/build_probability_diagnostics.py` | 新增 CLI |
| `tests/test_probability_diagnostics.py` | 新增 14 项契约测试 |

`evaluation.py`、冻结特征登记表、冻结比较集生产者与 LOSO runner **逐字节未改**（见 §7 第 J 项）。

## 3. 指标定义与口径

- **聚合**：参与者内 probe 等权 → 参与者间等权，与冻结评价层一致（D2/D3）。
- **区间**：原样复用 `evaluation.fixed_oof_participant_bootstrap`——参与者聚类百分位自助，`n = 1000`、`seed = 20260830`、95%，**自助内不重训预测模型**。
- **AUROC**：仅当某参与者的探针**同时包含两个类别**时可估。单类参与者**排除出分母并单独计数**（`n_participants_auroc_single_class`），**不做任何插补**。
- **Brier**：参与者内均值 → 参与者间等权，对单类参与者仍可估。
- **校准**：概率分位分箱的观测/预期频率表（`calibration_bins.csv`）+ 校准模型
  `logit(p(y=1)) = intercept + slope * logit(p_hat)`。完美校准为斜率 1、截距 0。
  该**小型诊断模型**的区间来自在重抽样上重新拟合它；预测模型从不重拟合。每一行显式记录：

  ```text
  prediction_model_retrained_in_bootstrap = False
  calibration_model_refitted_in_bootstrap = True
  used_for_model_or_c_selection           = False
  used_for_feature_selection              = False
  role                                    = supplementary_descriptive_diagnostic
  ```

## 4. 事后补入的两条机器可查守卫

以下两条**不是**事前预注册，而是在初次运行看到真实数字之后发现的真实陷阱。如实登记于此，并说明为何它们不可能把结论推向某个偏好方向。

### 4.1 run 身份必须进入分组键

探索性 smoke 运行 `smoke_go_omission__aware` 写出的 `analysis_set_id` 与 `model_id`
**与正式 `AS.standalone__behavior.go_omission.raw.v1` 完全相同**。仅按
`(model_id, analysis_set_id, membership_type)` 分组会把一个探索性 smoke 预测集静默合并进正式行，所有计数都会错误但外观完全合理。

处理：`run_id` 纳入分组身份；CLI 默认 `--run-glob '*__included_missing_aware'`，排除 smoke 目录；并加两项回归测试。

### 4.2 校准斜率在低判别力下不可解读

在准无惩罚（`C = 1e6`）的 `logit(p_hat)` 逻辑回归下，**接近随机的评分**会产生数值巨大、符号不稳定的斜率。本次实际观测：冻结的仅传感与单特征模型给出 **−0.2 至 −43.9**，自助区间宽度最高 **72**。把这类数字读作"模型概率严重反向"超出数据可支持的范围；它们反映的是未惩罚拟合在近乎无判别力评分上的数值不稳定。

处理：新增 `calibration_slope_reporting` 字段，规则为——**仅当 participant-macro AUROC 的 95% 区间排除 0.5 时，才把校准斜率标记为可解读**（`reportable`），否则标记为 `not_reportable_low_discrimination`。附加 `calibration_n_valid_replicates`，记录有多少次重抽样产生了有限拟合。

**该规则为何不构成按结果调参**：

1. 规则**不依赖斜率估计本身**，只依赖 AUROC 区间，因此无法被调成想要的斜率符号或大小；
2. 规则对全部 43 行**统一适用**，不做个案豁免；
3. 规则的作用方向是**限制解释、使主张更弱**，不可能制造出有利的实质结论；
4. **原始斜率与区间在每一行都保留**，守卫不隐藏任何数字，只给出"是否可解读"的判定与理由文本。
