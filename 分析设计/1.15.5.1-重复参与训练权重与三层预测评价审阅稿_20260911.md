# FocusWave 重复参与训练权重与三层预测评价审阅稿

> 日期：2026-09-11  
> 状态：**方法实现审阅稿**。用于研究负责人审阅重复参与者的训练权重、probe/participant/session 三层预测评价及其代码实现合同。  
> 权威关系：本文件不替代 `1.15.5-监督学习三代方案总对比与当前正式口径_20260910.md`。研究负责人审阅通过后，最终冻结结论回填 `1.15.5`；本文件保留详细依据与实现说明。  
> 代码事实基准：`Attention-Analysis` 的 `codex/1.15.7-task-a-supervised-core`。当前外层为 participant-disjoint LOSO（参与者互斥的留一参与者验证），训练拟合与内层 log loss 仍是逐 probe 等权。

## 1. 本轮需要解决的实际问题

FocusWave 的监督学习预测对象始终是 probe（探针）时点的注意状态。实验中每个 session（场次）固定 20 个 probe，但同一 participant（参与者）可以参加多场，因此数据结构为：

`probe ⊂ session ⊂ participant`

重复参与带来两类影响。第一类是训练/测试身份泄漏：同一人的不同场次若被拆到训练和测试两侧，模型可能通过已经见过该人而高估对“新参与者”的推广能力。当前 A 分支已经按 `participant_group_id` 整体留出，同一人的全部场次始终同侧，这一点正确且不得回退。

第二类是**相对权重**。当前逻辑回归直接把每个 probe 当作一行等权训练，因此参加 3 场、约 60 个 probe 的参与者，对拟合的总影响约为参加 1 场、约 20 个 probe 的参与者的 3 倍。这个问题不会造成身份泄漏，但会使模型训练目标偏向重复参与者。

## 2. 主训练：所有 probe 都保留，不做每人只抽一个 probe

拟议主口径采用 participant-equal training（参与者等权训练）。它不删除 probe，也不把一个参与者压缩成一个训练样本。

若参与者 `i` 在当前训练折中有 `n_i` 个合法 probe，则其每个 probe 的基础权重为：

`w_ij = 1 / n_i`

因此：

`sum_j w_ij = 1`

例如 A 有 60 个 probe，B 有 20 个 probe：A 的 60 个 probe 全部进入训练，每个基础权重约 `1/60`；B 的 20 个 probe 也全部进入训练，每个约 `1/20`。A 内部 60 个不同状态时点的信息没有丢失，只是 A 不再因为参加更多场而获得 3 倍总训练权重。

权重必须在**每一个内层训练折**以及**每一个完整外层训练集**内部重新计算，不能在全数据上预先计算后再切折。实现时可以把基础权重统一乘以一个常数，使当前训练折内平均样本权重为 1；这不改变参与者之间的相对权重，同时减少对 L2 regularization（L2 正则化）参数 `C` 数值尺度的额外影响。

session 不作为独立训练个体额外再给一票。session 字段继续保留用于对齐、质量诊断、跨场稳定性和人内状态分析。

## 3. participant 等权必须贯穿完整训练链

若主科学目标定义为“随机一个此前未见参与者上的状态预测”，仅在最终 `LogisticRegression.fit(..., sample_weight=...)` 加权并不充分。以下数据依赖步骤需要使用一致的参与者等权原则：

1. **训练折内缺失插补**：插补所使用的训练分布估计不能重新由多场参与者按 probe 数主导；具体加权中位数算法需在代码实现前写清并测试。
2. **训练折内标准化**：中心和尺度估计采用与参与者等权一致的加权均值/加权标准差。
3. **逻辑回归拟合**：使用训练折内重新计算的 participant-equal `sample_weight`。
4. **内层模型和超参数选择**：验证时先对每个 validation participant 的 probe log loss（对数损失）求平均，再对 validation participant 等权平均。不能训练采用 participant 等权、选择模型时又回到 probe 等权。
5. **外层完整训练重拟合**：用该外层训练集中实际存在的参与者和合法 probe 重新计算权重，再拟合并预测 held-out participant（留出参与者）。

当前逐 probe 等权训练可预先保留为 sensitivity analysis（敏感性分析），用于检查结果是否强依赖训练权重；不得依据 outer-test（外层测试）结果在两种训练方案中挑表现更好者作为主方案。

## 4. 同一套折外预测产生三种不同评价

三种评价不需要训练三套不同目标模型。主模型仍然逐 probe 输出 `P(Q1=1)`，同一份合法 out-of-fold prediction archive（折外预测档案）可以从不同统计层级汇总。

| 评价 | 主要统计单位 | 回答的问题 | 建议角色 |
|---|---|---|---|
| probe 等权 | probe | 随机抽一个实际观测时刻，当前状态预测得怎么样 | 补充总体性能 |
| participant 等权 | participant | 随机来一个完全没见过的新参与者，模型在其状态观测上平均表现怎样 | **主总体性能** |
| session 内 AUROC | 同一 participant 的同一 session | 固定同一个人和同一次实验，他的状态变化能否被模型正确区分 | **人内动态专门证据** |

### 4.1 Probe 等权：时刻级识别能力

对所有合法 probe 的损失直接平均：

`L_probe = mean_ij loss(y_ij, p_ij)`

心理学含义：从研究产生的所有有效测量时刻中随机抽一个时刻，模型判断当时注意状态的总体能力。参加更多场或保留更多有效 probe 的参与者会贡献更多时刻，因此不作为跨参与者推广的唯一主指标。

### 4.2 Participant 等权：新参与者零校准推广能力

先在每个参与者内部平均其所有合法 probe 的损失：

`L_i = mean_j loss(y_ij, p_ij)`

再让参与者等权：

`L_participant = mean_i L_i`

心理学含义：随机来一个此前从未参与模型训练的新参与者，在不做个人校准的情况下，模型在其多个注意状态时点上平均能够预测多好。一个人参加 1 场还是多场，不改变其在最终总体推断中的参与者权重。

M0（例如 Behavior，行为模型）与 M1（例如 Behavior + NIR，行为加近红外模型）在完全相同的 `analysis_set_id` 和 probe 成员上进行参与者内配对：

`Delta_i = L_i(M0) - L_i(M1)`

`Delta_i > 0` 表示加入该传感器后，该参与者上的平均对数损失下降，即传感器提供了正的增量预测价值。主增量证据对 `Delta_i` 做参与者等权汇总。

### 4.3 Session 内 AUROC：同一个人的状态变化追踪能力

AUROC（area under the receiver operating characteristic curve，受试者工作特征曲线下面积）在本项目中用于衡量**同一场实验内部两类状态的排序区分能力**。可以用一个直观概率解释：

> 在同一个 session 内，随机抽一个真实 `Q1=1` probe 和一个真实 `Q1!=1` probe，模型把前者的 `P(Q1=1)` 排得更高的概率有多大。

因此：

- `AUROC = 0.5`：大致相当于随机排序，没有稳定区分能力；
- `AUROC > 0.5`：专注类 probe 通常得到更高的专注概率；
- 越接近 `1`：场内两类状态的排序区分越稳定。

它不要求先选一个固定分类阈值，因此适合回答“模型概率是否随着个人状态变化而有正确方向的变化”。但 AUROC 主要反映**区分/排序**，不直接等于概率校准质量，因此不能替代 log loss。

## 5. 为什么必须先在 session 内算 AUROC

如果同一参与者参加多场，直接把这个人的所有 session 混在一起计算一个 AUROC，可能把跨场差异错误解释成人内状态变化。例如第一场整体更专注、传感器整体水平也较高，第二场整体更不专注、传感器整体水平较低；跨场混合后可以得到很高 AUROC，但模型可能主要识别的是“第一场 vs 第二场”。

为了让心理学解释严格对应“同一个人在同一次实验中的注意状态变化”，拟议算法为：

1. 对 participant `i` 的每个 session `s` 单独计算 `AUC_is`；
2. 只有该 session 同时存在至少一个 `Q1=1` 和至少一个 `Q1!=1` probe 时，AUROC 才可计算；
3. 如果某场只有单一类别，记 `AUC_is = NA`，并标记 `not_estimable_single_class`，不能填成 0.5；
4. 对 participant `i` 的全部可估 session 等权平均：`AUC_i = mean_s(AUC_is)`；
5. 对至少有一个可估 session 的 participant 等权平均：`AUC_within = mean_i(AUC_i)`；
6. 同时报告“可估 session 数 / 总 session 数”和“至少一个 session 可估的 participant 数 / 总 participant 数”。

心理学解释为：

> 对一个此前完全没有被模型见过的人，在同一次实验场次内，当他的注意状态从一类变化到另一类时，模型给出的状态概率能否产生与真实状态一致的相对变化。

这项证据最直接支持“FocusWave 能否追踪个人注意状态的动态变化”。participant 等权 log loss 仍回答“这个新参与者总体预测得好不好”，二者不能互相替代。

## 6. 重复参与还提供跨 session 稳定性诊断

保留每个 `L_is`（参与者 i、第 s 场的平均损失）和 `AUC_is` 后，可以额外检查同一个人的模型性能是否跨场稳定。该诊断可区分：

- 某个参与者在所有场次都难预测；
- 同一个参与者只有某一场突然失效；
- 某一场可能存在设备、对齐或状态构成异常。

跨 session 稳定性诊断不作为第四个主总体指标，但建议保留输出，尤其适合多模态质量追溯。

## 7. 不确定性和 M0/M1 比较

participant 等权主性能以及 M0/M1 的 `Delta_i` 使用 participant-cluster bootstrap（参与者簇自助法）描述参与者抽样不确定性。现有 `science` 配置已经给出 `participant_cluster_bootstrap_replicates: 1000` 和 seed `20260830`，本轮不重新决定次数和种子。

需要在报告中明确：如果 bootstrap 只对已经生成的折外预测按 participant 重采样，它描述的是**参与者抽样层面的不确定性**，并不包含每次 bootstrap 都重新训练模型所产生的完整算法变异。

对于 session 内 AUROC，同样以 participant 为最终推断层级；单类 session 不可估计，不允许静默记作 0.5。若一个 participant 没有任何可估 session，则不进入 `AUC_within` 的数值平均，但必须继续出现在分母和不可估计原因审计中。

## 8. 当前代码需要怎么改

当前 A 分支的正确部分继续保留：participant-disjoint LOSO、内层按 participant 分组、训练与外层测试身份隔离、完整逐 probe 折外预测。

拟议新增/修改：

- `supervised_learning/models.py`：participant-equal `sample_weight`；内层评价改为 validation participant 等权的 log loss；
- `supervised_learning/preprocessing.py`：训练折内参与者等权的插补和标准化实现及审计；
- `supervised_learning/runner.py`：每个内/外训练折重新计算参与者权重，保存权重审计元数据；
- 新建独立 evaluation/reporting 模块：从通过标签和全集校验的预测档案计算 probe 等权、participant 等权、session 内 AUROC、M0/M1 `Delta_i` 与 participant-cluster bootstrap；
- 保留 session-level 和 participant-level 中间表，禁止只输出一个最终总数字。

`prediction_folds: 5` 的角色需要在代码实现前再核清。当前正式外层已经是 LOSO，不能仅因为配置存在 `prediction_folds: 5` 就自动增加第二套外层 5 折评价。

## 9. 建议验收测试

| 测试 | 输入 | 必须满足 |
|---|---|---|
| 重复参与训练权重 | A 60 probes、B 20 probes | 80 个 probe 全部保留；A、B 的训练总权重相等 |
| LOSO 身份隔离 | 同一参与者有多 session | 全部 session 始终同侧 |
| 内层评分 | 验证参与者 probe 数不同 | 先人内平均 loss，再参与者等权 |
| probe vs participant 汇总 | 人工可手算预测 | 两套结果分别正确，不混用分母 |
| 单类 session | 某场只有 Q1=1 或只有 Q1!=1 | `AUC_is=NA/not_estimable_single_class`，不得为 0.5 |
| 多场人内 AUROC | 同一参与者两个可估 session | 先算两个 `AUC_is`，再得到 `AUC_i` |
| M0/M1 配对 | analysis set 或 probe 成员不一致 | 拒绝计算 `Delta_i` |
| bootstrap 可复现 | 固定预测档案、固定 seed | 点估计/区间在数值容差内可复现 |
| 防结果回流 | outer-test 指标用于选特征、调参或阈值 | fail closed（拒绝运行） |

## 10. 审阅后需要回填 `1.15.5` 的结论

若研究负责人确认本稿，`1.15.5` 应更新为：

1. 主训练目标采用 participant-equal training，所有合法 probe 保留；逐 probe 等权训练降为预先规定的训练权重敏感性分析；
2. participant 等权 log loss 为跨个体零校准推广的主总体性能；probe 等权 log loss 为时刻级补充；
3. session 内 AUROC 为人内注意状态动态追踪的专门评价；单类 session 显式不可估计；
4. M0/M1 主增量在相同 analysis set 上计算 participant-paired `Delta_i`；
5. participant-cluster bootstrap 使用现有 1000 次 / seed `20260830`；
6. `prediction_folds: 5` 在实现前单独核清其与现有 LOSO 的角色，不自行新增第二套外层评价。
