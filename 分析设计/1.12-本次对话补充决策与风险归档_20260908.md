## 一、持续注意构念与操作化：统一解释口径

### 1.1 不是“没有操作化”，而是当前报告需要把操作化链写得更明确

持续注意是潜在心理构念，不能直接观察。当前项目已经通过以下层级完成操作化：

1. **任务行为层**：RT、RT-CV、Go omission、No-Go commission、d′ 等，用于描述持续注意任务表现；
2. **任务内主观层**：Q1 注意内容、Q2 警觉程度，用于描述离散时点的主观状态；
3. **连续候选过程层**：NIR pupil、RGB blink/motion/pose、mmWave HR/BR/motion 等，用于提供连续过程信息；
4. **多模态模型层**：把同一探针前时间窗中的行为与传感特征拼接，检验其对 Q1/Q2 或相关行为结局的预测与增量。

因此后续正文不能写“传感器直接测得真实专注”，而应写成：

> 以标准化持续注意任务和思维探针建立认知参照，再检验连续传感指标是否与这些参照形成理论可解释、可重复、可区分且对新参与者可泛化的关系。

### 1.2 当前不是统一的“专注总分”

当前 M0–M7 属于多模态特征融合与增量预测，不是人工规定权重后形成 0–100 的专注总分。

模型关系应解释为：

- 行为 / NIR / RGB / mmWave 提供同一时间窗的不同观测；
- Logistic / RF 学习这些特征组合与 Q1/Q2 等结局之间的统计关系；
- M0 行为作为基准，M1–M7 检验传感信息是否提供行为之外的增量。

在没有潜变量结构、评分规则、可靠性、常模与阈值证据前，不建立“FocusWave 总专注分”。

### 2.2 正式问卷的角色分层

对当前正式事后问卷，优先分成四类：

1. **构念 / 收敛效度候选**：整体走神比例、走神觉察、疲惫/维持不住、困倦变化、自评专注、可持续专注时长；
2. **区分效度候选**：区分“走神/注意内容”与“困倦/警觉下降”，避免把所有传感变化统一称为专注；
3. **背景与混杂**：睡眠、咖啡因等，用于解释或敏感性分析；
4. **形成性/体验/策略**：任务策略、是否感觉刺激有规律、被打断感、任务理解等，用于解释范式行为与设计风险。

### 2.3 正式分析优先级

优先桥接：

- 问卷走神 ↔ Q1 分布 ↔ RT-CV / omission / commission / d′；
- 问卷困倦 ↔ Q2 ↔ RT-CV / blink candidate / 必要的生理候选；
- 自评专注 / 可持续专注时长 ↔ participant-level 行为稳定性；
- 睡眠 / 咖啡因 ↔ Q2 / 行为 / 生理变量，作为背景或敏感性分析。

必须先解决 participant / session / repeated-participant identity 对齐，再做统计；不能把两份 Excel 简单拼接后当作独立样本。

### 2.4 术语边界

这些问卷条目若不是成熟、标准化、经过独立验证的量表，不得称“标准化量表”或“金标准”。应称：

- 事后问卷；
- 外部主观效标；
- 收敛/区分证据来源；
- 形成性体验证据。

## 三、思维探针反应性：新增补充分析候选

### 3.1 当前正式主分析主要是 probe 前窗口

当前正式逻辑主要是：

`probe 前近期行为/生理状态 → Q1/Q2 报告`

这回答“被试报告的前一刻状态，是否能被前面的行为/传感信号支持”。

### 3.2 新问题：probe 本身会不会改变后续状态

思维探针可能中断任务、把注意重新拉回任务，产生 probe reactivity（探针反应性）。因此可新增事件锁定补充分析：

- 以 probe onset / 回答完成 / task resume 为事件锚点；
- 比较 probe 前窗口与 task resume 后窗口；
- 行为优先：RT、RT-CV、omission、commission；
- 传感器后接：pupil、blink、mmWave 等。

### 3.3 推荐事件定义

如果日志中存在精确事件时间，优先使用：

- probe onset；
- Q1 response；
- Q2 response；
- task resume。

后效应最好从 `task resume` 或回答完成后开始，因为 probe 作答期间包含阅读、决策和按键动作，本身不是正常 SART 状态。

### 3.4 immediate 与 later recovery 分开

建议至少区分：

- 第一批 1–2 个恢复 trial：可能主要反映重新进入任务的运动/切换效应；
- 后续 3–10 个 trial 或稳定秒级窗口：更适合讨论状态恢复。

### 3.5 统计与解释边界

- probe 嵌套于 session / participant，需 participant-clustered GEE 或 mixed model；
- 简单 pre/post 汇总可辅以 participant-level bootstrap；
- Q1 class 3/4 较少，Q2 可能更有统计功效；
- commission / d′ 在过短窗口内机会数不足，不应机械用 10 s 窗口；
- 没有 no-probe / randomized-probe control 时，不能把 post-probe 改善直接写成因果“探针恢复了注意”；
- 可能存在 regression to mean、trial composition、time-on-task 等替代解释。

该分析定位为 theory-motivated supplementary，不替代当前 probe 前主效标分析。

## 四、Block 内 6 cycle：解释、风险和敏感性分析

### 4.1 当前 cycle 的意义

当前每个正式 Block 被顺序划分为 6 个连续时间段，用于描述比单个错误事件更慢、又比 B1/B2 更细的 time-on-task 变化。

三个时间尺度应统一解释为：

- B1 vs B2：粗时间尺度；
- 6 cycle：Block 内中等时间尺度；
- error-locked / probe-locked：局部事件尺度。

### 4.2 为什么是 6

当前报告明确使用 6 段，但现有证据并没有证明“6”是心理学理论上的唯一最优切法。

可采用的保守解释：

> 6 段是时间分辨率与段内观测稳定性之间的分析折中。

每个 Block 432 trial，6 段对应每段约 72 trial 的量级；但具体各类 Go/No-Go 机会仍以实际正式序列为准，不能凭平均数断言每段完全相同。

不得写“6 cycle 已被理论验证为最优”。

### 4.3 新增 cycle 数敏感性

建议保留 6 cycle 为当前正式主分析，再增加：

- 4 bins；
- 6 bins；
- 8 bins。

使用同一 cohort、同一行为定义、同一重复测量处理，只检验核心 time-on-task 结论（优先 RT-CV / RT-SD 等）是否在合理切分下保持方向一致。

这不是为了找最显著 p 值，必须：

- 6 段保持主分析；
- 4/8 段明确标记 sensitivity；
- 全部合理备选一起报告；
- 不按结果最好看选择最终切分。

### 4.4 连续时间模型是后续更强替代，但不是当前必做

未来可考虑以 trial index / elapsed time 连续建模，或 GAM / rolling window，减少人为分箱；但比赛当前不应为追求复杂度替换已有、可解释的主分析，除非时间充足且实现契约清晰。

## 五、正式刺激序列：固定约束伪随机，而非每名参与者运行时重新随机

### 5.1 已核到的程序事实

对 `kyandi233-dev/FocusWave` 正式 tag `v3.1.3`（commit `321a22b56cd2865c39be5dea1c5402d32918762b`）的程序检查显示：

- 正式为两个 B Block；
- 程序直接读取预先生成的 `formal_B1.csv` / `formal_B2.csv`；
- 序列表预先写入 trial 顺序、stimulus、No-Go 标记、刺激大小等字段；
- `load_sequences()` 在运行时按 block_num 读取对应 CSV；
- 没有看到根据 participant ID 在每位参与者开始时重新生成序列的逻辑。

因此程序层面的准确说法是：

> 正式实验采用预先生成的约束伪随机序列；随机性发生在序列生成阶段，而不是每名参与者运行时重新随机。

### 5.2 报告措辞

可写：

> 水果以满足 No-Go 比例与分布等约束的预先生成伪随机序列呈现，两个正式 Block 使用独立序列。

不可写：

> 每名参与者均接受独立随机生成的刺激序列。

### 5.3 科学风险

如果所有正式参与者实际使用同一套 B1/B2 文件，则相同 cycle / trial position 对应相同刺激位置，因此：

- time-on-task position 与 sequence-position effect 理论上可能混杂；
- 某些固定位置若更难，可能被误读为时间效应的一部分。

两套 B1/B2 独立约束序列以及序列分布约束可以降低风险，但不能完全等价于 participant-level randomization。

### 5.4 必须再做“实际采集事实”核验

当前结论首先是“committed program behavior”。不能仅凭代码断言实验期间没有人工重新生成 CSV 或现场替换文件。

若正式 raw/current trial 数据可用，应进一步对实际 session 做 sequence fingerprint：

- 按 session 提取 stimulus_name / is_no_go / stimulus_size 序列；
- 对 B1/B2 分别计算 hash / exact-match；
- 检查不同 participant/session 是否完全一致；
- 若存在差异，追溯是否来自正式生成器、版本变化或现场文件替换。

只有这一步通过，才能把“所有正式参与者用了同一固定序列”提升为实际采集事实。

## 六、固定序列与问卷“感觉有规律”的联动风险

事后问卷中存在“是否感觉苹果/刺激有规律”“任务策略”等题目。若参与者报告识别到规律，这一信息可以用于解释固定约束序列是否被部分学习。

建议分析：

- 规律感/策略 ↔ commission；
- 规律感/策略 ↔ RT / RT-CV；
- 规律感/策略 ↔ B1/B2 或 cycle time-on-task；
- 必要时作为 sensitivity/分层解释，而不是直接作为主构念变量。

该分析优先用于范式有效性和 sequence predictability 风险，而不是为了制造新的“专注指标”。

## 七、当前“专注状态”测量关系：统一成四层证据网络

正式报告建议统一画成以下逻辑：

### 7.1 构念层

持续注意：长时间维持目标指向加工和对偶发/低频事件的反应准备。

### 7.2 认知参照层

- 行为：任务表现；
- Q1：注意内容；
- Q2：警觉程度；
- 事后问卷：全局/回顾性主观外部效标。

### 7.3 连续候选过程层

- NIR pupil；
- RGB blink / motion / pose；
- mmWave respiration / HR / motion；
- 各模态质量/QC。

### 7.4 验证层

依次问：

1. 与行为 / probe / questionnaire 是否有理论可解释的关系？
2. 是 within-person 状态变化还是 between-person 稳定差异？
3. 是否与疲劳、警觉、运动、光照等替代解释可以区分？
4. 是否在行为基准之外提供增量？
5. 是否在 participant-independent validation 中保持？

因此“持续注意”不是由所有变量简单加权相加，而是通过多来源证据网络逐层获得解释资格。
