## 1. 当前研究主线

FocusWave 当前监督学习与多模态分析已经从“重新设计方案”进入**协议收口、上游特征冻结、跨分支集成与真实数据验证**阶段。

首轮监督学习的科学问题固定为：对模型训练中完全未见的 participant（参与者），利用 probe（探针）之前合法获得的 Behavior（行为）与传感器信息，预测该 probe 的 Q1 注意内容自我报告。当前首轮标签为 `Q1=1` 对 `Q1=2/3/4`。Q1 不是“真实注意真值”；Q2 是探针时点主观困倦/清醒信息，首轮不作为 Q1 预测输入；事后问卷主要用于场次级回顾与背景解释。

监督学习的解释分两层：

- **具体特征层**：`x -> Q1`、`B -> B+x`、`F-x -> F`；
- **设备/信息包层**：M0–M7，回答增加某套采集设备及其全部合法信息后，Q1 预测是否改善。

其中 `B` 为待最终冻结的 Behavior reference（行为参照特征集），`F` 为全部正式可用科学特征组成的 Full model（全特征模型）。

## 5. 当前最重要的四个监督学习协议风险

这些问题属于**科研语义风险**，不能以 CI（持续集成）通过替代判断。

### 5.1 Task B `required_features` 与 Task A 实际模型必须一致

Task B 为某个 `analysis_set_id` 建立共同样本时使用的 `required_features`，必须等于该分析集合中待直接比较模型实际需要特征的并集。

例如比较 `B` 与 `B+x` 时：

`required_features = B ∪ {x}`。

不得因为无关特征 `y` 缺失而额外缩小共同样本。Task A 在消费 materialized input（物化输入）时必须显式核对 `required_features` 与 `comparison_models`/模型计划的一致性，不能只读取模型名称后忽略共同样本是怎样筛出的。

### 5.2 被研究特征在 fold 内被删掉时，该 fold 的增量不可解释

训练折内因全缺失、零方差等原因删除列本身可以是合法技术处理，但必须影响 scientific comparability（科学可比较性）。

如果某 outer fold（外层折）中的 `B+x` 实际把 `x` 删除，则这一折不再估计“加入 x 的增量”；同理，`F-x -> F` 中若 Full 侧实际未包含 `x`，该折不能解释为 `x` 的不可替代贡献为 0。

应将 fold audit（折级审计）中的 actual output columns（实际输出列）和 dropped columns（删除列）传入 paired comparison（成对比较）资格判断，并把此类折标为 `not_estimable_feature_absent` 或等价明确状态。

### 5.3 feature registry 的布尔字段必须严格解析

feature registry / YAML / JSON 中的资格字段不得使用 `bool("false") == True` 这类 Python 真值转换。所有 `eligible_for_standalone`、`eligible_for_behavior_increment`、`eligible_for_full`、设备依赖等布尔合同应使用与 membership（成员资格）相同的严格解析规则，并对非法字符串 fail closed（失败关闭）。

### 5.4 missing-aware 必须区分真正缺失与 malformed value（格式坏值）

`pd.to_numeric(..., errors="coerce")` 会同时把真正缺失和无法解析的坏字符串转成 `NaN`。Task B 不得把格式损坏、非法数值、上游 schema 错误静默归类成 `single_feature_missing` 后交给 Task A 插补。

missing-aware（缺失感知）只允许科学资格和测量机会均成立、且被明确认定为 residual single-feature missingness（残余单特征缺失）的值进入训练折内插补。malformed / parse failure（解析失败）应单独记录并排除。

## 6. 特征选择的当前正式逻辑

当前不采用“把 producer 所有变量放进模型，再看谁表现好”的全样本筛选。特征进入监督学习分三层：

1. **科学资格冻结**：依据测量含义、时间合法性、producer 可靠性、QC、设备依赖和研究问题，决定哪些具体特征有资格进入候选范围；不得根据 outer-test 结果决定。
2. **训练数据内部开发**：在预先限定的有限候选表示和超参数范围内，只使用 outer-train 内的 inner participant-grouped CV（内层参与者分组交叉验证）选择；插补、标准化和数据依赖列处理同样只在对应训练折拟合。
3. **fold 内技术可估计性**：已冻结科学特征在某训练折全缺失/零方差时可以无法估计，但该状态必须进入比较资格和最终分母，不能被解释为“该特征没有信息”。

因此，coverage（覆盖率）、全样本相关冗余、零/近零方差审计可以作为描述和质量检查，但不能在完整正式样本上自动决定科学特征去留。
