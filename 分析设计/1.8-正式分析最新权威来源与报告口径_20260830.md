## 3. 用户已确认的报告口径

### 3.1 行为遗漏名称

正式正文采用简洁名称：

- `Go 遗漏率`；
- `无时序歧义遗漏率`；
- `时序歧义遗漏率`。

第一次出现时说明后二者依据按键时序特征对 Go 遗漏进一步区分。不得把“无时序歧义遗漏”直接命名为“注意遗漏”。更细的抢按、跨试次延续、迟发反应等用于解释时序构成，不作为并列核心心理结局。

### 3.2 RGB 最终范围

正式报告按已经确定的轻量范围书写，而不是按历史大而全 RGB 管线书写。当前正式范围为：

1. 整体运动；
2. 曝光/亮度变化控制；
3. 必要的姿态确认和方向性运动候选；
4. 眨眼候选事件。

AU、情绪、rPPG、PERCLOS、完整头姿分析、复杂 RGB 独立预测退出当前正式报告主线。Pose 前后方向只是辅助方向候选，不解释为真实物理位移。Blink 在独立事件效度建立之前统一称为眨眼候选事件。

### 3.3 NIR 基线表述

正式报告不使用“session 中心化”“baseline contract”“fallback”等工程语言。分析逻辑写为：

- 以每次实验中稳定的典型瞳孔水平描述个体内相对变化；
- 事件相关分析以事件发生前的短时瞳孔水平作为参照；
- 任务开始前 3 min 静息阶段仅在眼部具有足够可观测数据时用于探索性比较。

主分析不依赖静息瞳孔基线，也不把闭眼或不可观测时间补值后解释为静息瞳孔水平。

### 3.4 毫米波来源和边界

毫米波分析方法以 greenboo 最新 `main` 为权威。正式数据不是 raw ADC：正式存储结果为 2T4R、8 通道、256 距离单元的复数距离域数据，Range FFT 已在上游完成，因此报告不再描述“下游首先进行 256 点距离 FFT”。

逐帧时间使用当前核验后的采集时间信息与任务事件对齐。旧 Python `time.time()` 形成的窗口与当前逐帧时间口径已证明不可互换，因此旧窗口统计不直接作为当前正式结果。

毫米波中的心率和呼吸频率首先按心搏相关、呼吸相关估计解释，并同时报告信号质量和身体运动影响。IBI/HRV 只有在逐搏识别及外部参考验证满足要求后才作为正式生理指标。

### 3.5 多模态方法

多模态科学问题不是比较不同样本上的单模态准确率，而是在相同参与者、相同探针窗口和相同测试划分下检验每种模态在任务背景和近期行为之外提供的增量信息。

当前方法设计包括：

- 以探针前共同时间窗作为主要跨模态比较单位；
- 外层验证按参与者完全独立，重复实验始终随同一参与者进入同一划分；
- 先采用可解释的特征级融合；
- 在完整共同样本上比较任务背景/行为基线、分别加入毫米波/NIR/RGB、三个双模态组合以及完整三模态组合共八种模型；
- 主要比较相同测试参与者上的性能增量，并进一步评价不同模态之间的信息重复和互补；
- 规则化逻辑回归作为主要可解释模型，Random Forest 作为预设非线性稳健性比较；
- 更复杂的 MLP、根据模态质量调整权重的融合模型或小型跨模态模型只作为次级预测分析，只有在相同参与者独立验证下获得稳定增益时才进入最终报告主结果。

`docs/results/2026-08-30_FORMAL_MODEL_READY_V1/` 已形成 Behavior+NIR+RGB 的共同探针级建模前提和留一参与者验证划分证据，但毫米波尚未进入这份共同特征集合，也没有在该证据包中训练正式融合模型。其中 1,295 个共同探针、65 次实验、46 名参与者属于阶段性已整理分析子集，不能替代正式实验总体 63 名参与者、119 次实验的研究样本口径。

## 4. 报告语体转换

内部分析文件可保留 `gate`、`contract`、`model-ready`、`not_estimable`、`fallback`、`runner` 等词，但正式正文只写其科学含义，例如数据是否满足分析质量要求、某种测量在多少观测中可获得、某项统计是否能够估计、某个参照是否真正来自静息阶段，以及模型是否在独立参与者上获得稳定增量。

正文不复述仓库、分支、SHA、代码测试、生产状态、放行状态或数据管线治理。正式方法只说明研究实际采用的测量、时间对齐、质量评价和统计逻辑。

## 5. 当前报告状态

依据上述来源已经完成对 `正式报告/章节草稿/4.5-数据处理与统计分析.md` 的重新修订：

- 行为部分采用 Go 遗漏率、无时序歧义遗漏率和时序歧义遗漏率的简洁命名；
- NIR 使用 pupil-only 直接几何，并以实验内典型水平、事件前短时水平和条件式静息参考分别承担不同分析作用；
- RGB 已收缩为 Motion/曝光、姿态确认/方向候选和 Blink 候选；
- 毫米波改为直接从设备已输出的复数距离域数据开始，不再重复距离 FFT，并按当前时间语义和体动敏感性设计书写；
- 多模态改为共同样本上的参与者独立增量比较，使用八种组合和留一参与者交叉验证，复杂 AI 融合作为次级分析。

第 5 章结构也已同步调整为：分析样本与有效观测 → 行为/探针 → NIR → 毫米波 → RGB → 多模态增量与互补信息。尚未获得真实正式结果的部分只保留结果位置和最低必报信息，不填入代码测试、单场试跑或阶段性数据整理数字作为科学结论。
