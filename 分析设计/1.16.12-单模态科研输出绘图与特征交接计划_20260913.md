# 1.16.12 单模态科研输出、绘图与特征交接计划

> 日期：2026-09-13  
> 状态：**active_implementation_contract / stop_before_multimodal_fit**  
> 上位方法：`1.16`、`1.16.2`～`1.16.11`  
> 适用代码：`kyandi233-dev/Attention-Analysis` 当前 1.16 集成与修缮线  
> 本文件补充并收紧 `1.3-图表与分析问题台账.md`：旧文件中“覆盖矩阵”继续用于检查证据是否齐全，但不得解释为机械生成“候选指标 × 分析尺度 × 分组 × 图型”的排列组合。

## 1. 本轮目标与停止点

本轮代码修缮只推进到以下状态：

1. Behavior（行为）、Ocular（眼部）、Movement（动作）三条科学模态均能完成当前正式单模态分析；
2. producer（特征生产端）、QC（质量控制）、正式科学结果和后续监督学习接口能够清楚区分；
3. 每条模态输出一个可审计的候选特征交接表，能无歧义回填 feature registry（特征登记表）；
4. 单模态结果、特征资格证据和图表可以单独开启结果分析分支继续审阅；
5. 到“需要研究者依据真实结果冻结具体正式特征/表示”时停止。

本轮**不**自动决定最终 RT level、最终 pupil 表示或其他尚待真实结果判定的表示；不启动真实多模态监督学习；不发布 Q1 正式预测性能。

## 2. Task A/B/C/D 的当前地位

`Task A / B / C / D` 是 1.15 并行开发时期的实施和责任追踪名称，不再表示四条当前执行分支，也不表示四个科学模态。

当前统一运行关系写为：

```text
single-modal producer（单模态生产端）
→ measurement/QC + scientific analysis（测量审计、质量控制与科学分析）
→ comparison-specific analysis-set interface（比较特异分析集合接口）
→ frozen feature registry（冻结特征登记表）
→ formal supervised learning（正式监督学习；本轮停止点之后）
```

历史 issue、PR、模块名和测试文件中可保留 A/B/C/D 以便追溯，但新的方法说明、运行说明和结果组织不再以 A/B/C/D 作为主叙事。

## 3. 文件与输出组织

### 3.1 两层结构

现有 Behavior / NIR / RGB / mmWave 路径继续作为 **producer / staging（生产端/中间产物）层**。这些目录保存原始衍生表、帧级/窗口级技术产物、同步、对齐和设备 QC，不因科学模态重命名而重复复制大量数据。

新增或重构的正式小型结果采用 **science output（科学结果）层**，按信息内容而不是设备组织：

```text
<formal_science_output_root>/
├─ Behavior/
│  ├─ tables/
│  ├─ figures/
│  │  ├─ main/
│  │  ├─ qualification/
│  │  ├─ qc/
│  │  └─ sensitivity/
│  └─ manifests/
├─ Ocular/
│  ├─ tables/
│  ├─ figures/{main,qualification,qc,sensitivity}/
│  └─ manifests/
├─ Movement/
│  ├─ tables/
│  ├─ figures/{main,qualification,qc,sensitivity}/
│  └─ manifests/
└─ Cardiopulmonary/              # 当前仅预留；资格未冻结
   └─ ...
```

监督学习继续使用独立 `supervised_learning_output_root/<run_id>/`，不与单模态科学结果混放。

### 3.2 命名规则

- 新的 canonical（权威）科学目录不再使用 `5.5`、`11_analysis_tables` 等报告章节号作为语义主键；章节号只可保留为历史兼容路径。
- producer/source namespace（来源命名空间）继续使用 `behavior / nir / rgb / mmwave`；科学模态使用 `behavior / ocular / movement / cardiopulmonary`，两者不得互相代替。
- 一个 science table 可以引用多个 producer。例如经 RGB blink 清洗后的 pupil 表属于 `Ocular/tables`，其 provenance（溯源）同时记录 NIR 与 RGB 依赖。
- 不把大型帧级文件复制到 science output。科学层保存 probe/session/participant 级正式小表、模型估计、图、manifest 和来源指针。

## 4. 图表准入原则

### 4.1 一张图必须对应一个明确问题

图表生成改为 **question-driven（问题驱动）**，不再由“发现一个候选列就给它画所有图”驱动。每张图必须在 manifest 中声明：

- `figure_id`
- `scientific_modality`
- `scientific_feature_id` / `feature_id`（适用时）
- `purpose = main_science / feature_qualification / qc / sensitivity`
- `scientific_question`
- 横纵变量及单位
- analysis unit（分析单位）
- participant/session/probe 数量
- repeated-measure handling（重复测量处理）
- inference status（推断/描述状态）
- source table 与代码提交
- 生成状态、未生成原因和文件路径

模态总图与具体特征图都可以存在，但必须承担不同功能。模态总图用于总结同一科学问题下多个已保留指标；具体特征图用于解释该指标自身的分布、稳定性、动态或效应。

### 4.2 图型按问题选择

默认图型按数据结构和科研问题选择，不固定为箱线图或条形图：

| 科学问题 | 优先图型 | 主要限制 |
|---|---|---|
| 连续变量真实分布、偏斜和零值 | ECDF（经验累积分布）/ density（密度）/ histogram+rug（直方图+短线） | 不用均值柱掩盖分布 |
| 同一参与者/场次的两条件或两表示比较 | paired dots / slopegraph（配对点/斜率图） | 连线只连接真实配对单位 |
| 两种连续表示的一致性/替代性 | scatter/hexbin + identity line；必要时 Bland–Altman（一致性差值图） | Bland–Altman 只用于有实际“一致性”问题的连续测量 |
| 随时间或 probe-relative time（探针相对时间）变化 | trajectory（轨迹）+ participant-cluster uncertainty（参与者簇不确定性） | 不用逐帧伪重复置信区间 |
| 模型估计、组间/状态差异 | coefficient / dot-whisker（系数点区间图） | 展示估计量与 95% CI，不用星号替代效应 |
| 覆盖/可计算性结构 | compact heatmap（紧凑热图）或排序点图 | 仅 QC/资格证据，不冒充科学效应 |
| 多个表示之间冗余 | correlation/scatter matrix（相关/散点矩阵）仅限少量已入围候选 | 禁止对几十个候选机械展开 |
| 分类计数本身就是问题 | bar（条形图）可用 | 仅在计数/比例是直接科学量时使用 |

boxplot（箱线图）保留为需要四分位结构时的工具，不作为连续变量默认图。bar chart（条形图）保留给计数/比例或非常明确的汇总，不用来替代连续分布或模型区间估计。

## 5. 三条单模态的最小图包

“最小图包”不是固定张数，而是允许生成图的科学问题集合。没有相应问题或数据不可估时不生成。

### 5.1 Behavior

正式/资格图优先覆盖：

1. RT level 表示资格：mean 与 median 的配对关系、差值/尾部影响；用于 Q1-blind（不看 Q1）的表示冻结；
2. RT variability：`go_correct_rt_cv` 的分布、可估性与必要的 B1/B2 配对；
3. RT trend：探针前窗口/任务时间上的趋势与正式 slope 估计；
4. Go omission 与 No-Go commission：真实比例/配对变化和模型估计区间；
5. 与 Q1/Q2 的正式单模态关系：优先 coefficient/dot-whisker，而不是每个分类再画箱线图；
6. coverage、错误亚型、d′/c/β、冗余等仅按 qualification/QC/sensitivity 需要出图。

### 5.2 Ocular

正式/资格图优先覆盖：

1. pupil signal 表示资格：geometry 与 hard segmentation ratio 的关系、稳定性和替代性；soft segmentation 仅 sensitivity；
2. cleaning track / blink buffer：用紧凑的 retention–stability（数据保留—稳定性）或审计图决定清洗方案，不把所有组合逐张画图；
3. pupil level：最终入围表示的分布/状态关系；
4. pupil variability：候选波动表示的稳定性与冗余；
5. pupil dynamics：固定 probe-relative bins 下的时间轨迹，及 slope/curvature 的估计区间；
6. blink：以 `blink_event_rate_per_min` 为第一轮科学维度；持续时间/IBI 等仅在科学问题需要时作为 sensitivity/qualification；
7. binocular source、有效 bin、buffer loss、RGB 可用性等进入 QC，不与主科学图混放。

不再默认生成旧 NIR 配置中的 200 ms、1/3/5/10/20/30/60 s 全窗口 × 全候选表示图包。

### 5.3 Movement

正式/资格图优先覆盖：

1. `body_motion_energy_median` 的真实分布、B1/B2 配对和任务时间动态；
2. body motion 与 Q1/Q2 的正式单模态模型估计区间；
3. exposure change 只作为混杂/QC，优先 scatter/hexbin 等关系图；
4. pose direction 仅保留少量 exploratory/sensitivity（探索/敏感性）图，不进入第一轮主图包，除非后续真实结果和方法学决定升级其地位。

## 6. 学术绘图规范

继续继承 `1.3` 和 `1.4`，并补充：

1. 推断图必须显示效应量/模型估计与 95% CI（95% 置信区间）；不以显著性星号作为主要信息。
2. 参与者有重复场次/探针时，置信区间和模型必须与实际层级结构一致；不能把所有 probe 当独立观测生成过窄误差条。
3. 图注必须报告实际 participant groups、sessions、probes 及分析集合；不同分析集合不能通过视觉并排暗示成同样本直接增量。
4. 连续变量保留真实单位；对数显示必须明确标记且不改变底层统计模型。
5. 正式图内部不放完整标题/“图 X”编号；完整中文题名、样本量、限制和统计说明进入外部 caption manifest（题注清单）。
6. 中文字体采用可检测的中文字体；数字/西文优先 Times New Roman；图例无边框；避免缺字和 Unicode 负号问题。
7. 配色需色盲友好，同时使用线型/点型等非颜色编码；灰度打印仍应能区分核心系列。
8. 不使用 3D 装饰、阴影装饰或无必要双纵轴。
9. 正式结果图优先同时保存 vector（矢量）版本（PDF/SVG，视当前后端支持）与高分辨率 PNG；QC 可只保留 PNG。代码实现前先核对当前公共 `save_figure` 能力。

## 7. 候选特征交接表

Behavior / Ocular / Movement 各自产出一个统一 schema 的候选交接表，至少包含：

- `scientific_feature_id`
- `candidate_representation_id`
- predictor column(s)
- `scientific_modality`
- `source_namespace`
- `required_devices`
- `preprocessing_dependencies`
- measurement/QC status
- mathematical estimability rule
- coverage summary
- redundancy/alternative-representation relation
- temporal anchor/scope/status/evidence
- report role
- `registry_ready`（仅表示接口和证据齐全，不等于已经被研究者选为正式特征）
- `researcher_freeze_required`

Q1/Q2 关联可以进入正式单模态科学结果，但不得作为“看到显著就自动选择监督学习特征”的准入器。

## 8. 实施顺序

| 阶段 | 内容 | 停止/放行条件 |
|---|---|---|
| P0 | 当前方法、分支、图表与路径盘点 | 已完成 |
| P1 | modality/device/time-legality 接口收口；历史 Task 命名降级 | runtime fail-closed、provenance 可审计、CI 通过 |
| P2 | Behavior 运行与图包/目录收口 | 可运行、候选交接表完整，不替研究者选 RT level |
| P3 | Ocular pupil+blink 运行与图包/目录收口 | G1 决策证据可直接支持表示选择，接口完整 |
| P4 | Movement 运行与图包/目录收口 | body motion 正式分析与 QC 分离，接口完整 |
| P5 | 三模态联合接口 smoke（仅 schema/身份/时间合法性，不跑真实性能） | 三模态候选都可回填 registry；**随后停止** |

P5 后由研究者另开结果分析分支，审查真实结果并冻结具体 feature。只有冻结完成后，才进入真实多模态监督学习阶段。
