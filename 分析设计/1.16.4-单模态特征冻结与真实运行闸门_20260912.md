## 1. 本阶段优先级

当前不再继续扩大监督学习算法或无依据增加输入列。优先顺序固定为：

`单模态测量/科学特征冻结`
→ `单模态正式结果与报告`
→ `真实 feature registry（特征登记表）`
→ `#40/#41 最终 NIR 接线`
→ `真实监督学习 smoke（冒烟测试）`
→ `正式二分类监督学习`
→ `Q1 四分类与模态单独预测扩展`。

这一顺序的目的，是先冻结“模型到底在吃什么”，再比较“这些信息能预测多少”。当前不采用 Elastic Net（弹性网络）作为额外筛选或敏感模型；现阶段继续使用紧凑、可解释、预先冻结的科学特征和 L2 regularized logistic regression（L2 正则化逻辑回归）。

## 2. 单模态分析在当前项目中的双重角色

单模态分析同时承担两个角色，但二者必须分开解释。

第一，单模态分析本身是正式科研结果：描述 Behavior（行为）、NIR（近红外）、RGB（可见光视频）和 mmWave（毫米波）测量的分布、质量、动态及其与 Q1/Q2 的关系。这些内容可以先进入报告，不必等待全部多模态监督学习完成。

第二，单模态分析提供 feature qualification and representation freeze（特征资格审查与表示冻结）依据：依据科学含义、测量定义、时间合法性、QC（质量控制）、数学冗余和测量稳定性，将 producer（特征生成程序）的大量输出压缩成少数正式 scientific features（科学特征）。

Q1/Q2 显著性、outer-test（外层测试）性能和全正式样本上的预测表现不得作为“是否进入监督学习”的主要筛选规则。单模态中与 Q1 不显著的特征不因此自动删除；若需要数据依赖的预测选择，只能发生在对应训练边界内。

## 3. Behavior 当前冻结边界

Behavior 主窗口继续为 probe（探针）前 30 s；10/20 s 仅作为窗口敏感性分析。当前代码可生成 RT（反应时）水平、波动、趋势、错误率与 SDT（signal detection theory，信号检测论）指标。

首轮正式监督学习的 omission（遗漏）处理冻结为：

- 主输入：`raw_go_omission_rate`；
- `clean_go_omission_rate`、`timing_ambiguous_go_omission_rate` 及更细 motor-timing（运动时序）拆分只保留为 descriptive/QC/sensitivity（描述/QC/敏感性）；
- `omission_rate` 仅作为 `raw_go_omission_rate` 的兼容别名，不作为第二个独立预测变量。

当前 Behavior reference `B` 仍需完成以下正式冻结：

| 科学维度 | 当前候选 | 当前方法学状态 |
|---|---|---|
| RT level（反应时水平） | `go_correct_rt_mean_ms` / `go_correct_rt_median_ms` | **待冻结一个主表示**；不得二者无理由同时进入 `B` |
| RT variability（反应时波动） | `go_correct_rt_cv`，备选 SD/MAD/IQR | **CV 为当前优先候选**；其余主要作为替代/敏感性表示 |
| RT trend（反应时趋势） | `go_correct_rt_theilsen_slope_ms_per_s` | 当前 producer 定义已明确，保留为独立动态候选 |
| omission（遗漏） | `raw_go_omission_rate` | **已冻结 raw-only 主输入** |
| error control（错误控制） | `commission_rate` / `dprime_loglinear` | 待判断是否两者同时保留；不能因同源而默认都入 `B` |
| response bias（反应偏向） | `criterion_c` / `beta` | 暂不作为首轮 `B` 默认成员；如需进入必须给出独立科学问题 |

全队列 coverage（覆盖率）、floor/ceiling（地板/天花板）、within/between（人内/人际）和相关冗余只用于描述审计，不作为全样本自动删除门槛。

## 4. NIR / pupil × blink 当前冻结边界

当前 #44 / 1.16.3 的第一阶段只做 measurement audit（测量审计），不运行 Q1/Q2 推断、M0–M7 或正式监督学习。

当前主测量候选保持：

- `pupil_geom_mean_diameter`：几何瞳孔测量；
- `R_seg,hard = pupil/(pupil+iris)`：硬分割归一化瞳孔比例；
- soft segmentation（软分割）只作 sensitivity（敏感性）候选；
- RGB blink event（RGB 眨眼事件）既是独立眨眼特征来源，也可作为 NIR 瞳孔伪迹清洗信息；
- probe 前 30 s 主窗口；不跨 Block/场次；正式统计不插值；
- 每条瞳孔信号审计 level（水平）、variability（波动）、linear slope（线性斜率）与 quadratic curvature（二次曲率）。

真实审计需要冻结的不是“哪个候选与 Q1 更显著”，而是：

1. primary pupil representation（主要瞳孔表示）或明确的双轨角色；
2. formal cleaning track（正式清洗轨道）；
3. blink buffer（眨眼缓冲）；
4. fixed bin width/count（固定时间箱宽度/数量）；
5. linear/quadratic trend 的最低时间支持；
6. `R_seg` 独立 QC；
7. 每个最终特征的显式 estimability status（可估计性状态）。

这些冻结后，#40 才能让 Task B 读取最终 NIR 状态；#41 才应把 Behavior-authoritative probe-key mapper（行为权威探针键映射器）接入最终 NIR schema（数据结构）。

## 5. 监督学习模态扩展：保留，但后置

当前设备层 M0–M7 主要回答“Behavior 已知后增加设备是否产生额外信息”。后续应补充 modality-only（单模态独立预测），以回答每种信息来源独立使用时包含多少 Q1 信息。

首轮最小扩展定义为：

- `Behavior -> Q1`
- `NIR -> Q1`
- `RGB -> Q1`
- `mmWave -> Q1`

以及已有核心增量比较：

- `Behavior -> Behavior + NIR`
- `Behavior -> Behavior + RGB`
- `Behavior -> Behavior + mmWave`

这些不是新的机器学习算法，而是同一监督学习核心使用不同冻结 information package（信息包）。`Full - modality -> Full` 暂不列为当前必做，避免在特征尚未冻结前继续扩大比较空间。

## 6. 二分类与四分类的关系

当前先完成并验证的主实现为 Q1 二分类：`Q1=1` 对 `Q1=2/3/4`。

Q1 四分类 `1/2/3/4` 保持正式后续路线，不能遗忘，也不能把 1–4 当作连续数值。四分类应复用同一套已经冻结的 scientific feature registry（科学特征登记表），但必须重新执行合法的参与者隔离训练与评价；不得利用全体参与者二分类结果先选“赢家特征”，再把同一批数据当作独立四分类验证。

## 7. 真实数据运行闸门

### G0：现在即可运行

**G0-A Behavior 正式重跑：可以立即开始。** 目的为刷新当前 116-session governed cohort（治理队列）的 Behavior 多尺度表、probe 30 s 表、候选描述审计和报告输入。该运行不等于最终 `B` 已冻结；mean/median、commission/d′ 等未决表示仍在方法层审查。

**G0-B NIR 1.16.3 小样本 measurement-audit smoke：可以立即开始。** 先选择 2–3 个确有 NIR 来源、Behavior probe 表且尽量覆盖 RGB blink 可用/不可用情况的真实 session。目标只检查真实路径、文件读取、Behavior probe 时间、RGB blink 来源、NIR–RGB 同步、输出 schema 和 failure table，不用 Q1/Q2 选参数。

### G1：G0-B 无 I/O / schema 阻塞后

运行当前 **109 个 current-compatible NIR source records** 的全量 measurement audit。availability（模态可用性）的总体分母仍按 116-session governed cohort 报告，109 不能替代总体队列分母。

### G2：NIR 审计解释完成并回写 Formal 后

冻结 Behavior `B`、NIR 最终表示、blink buffer、bin、清洗轨道、时间支持和 QC；形成真实 feature registry。随后完成 #40/#41 最终接线。

### G3：#40/#41 接线与纵向集成通过后

先用 2–3 个真实 session 做 `producer -> Task B -> materialize` 的 schema smoke；确认 analysis-set、required features/outcomes、missingness 与 estimability 状态均符合合同。

### G4：真实 schema smoke 通过后

使用足够 participant groups（参与者组）运行 mini-LOSO（小规模留一参与者法），验证 outer LOSO（外层留一参与者）、inner GroupKFold（内层参与者分组交叉验证）、OOF（折外）归档、失败表和 paired comparison（成对比较）资格。

### G5：mini-LOSO 通过后

进入正式 governed-cohort 二分类监督学习；之后再扩充 modality-only 和 Q1 四分类。正式性能只能从这一阶段及其后发布。

## 8. 当前执行原则

1. 当前主要时间投入放在单模态特征冻结与 NIR 真实审计，不继续扩展 Elastic Net、复杂潜变量或额外模型族。
2. 单模态结果可以先写报告；监督学习未完成不阻塞 Behavior/NIR/RGB/mmWave 的方法与单模态结果章节。
3. 每个科学特征最终必须登记 scientific meaning（科学含义）、predictor column（预测列）、producer 来源、QC/清洗依赖、required devices（所需设备）、standalone、Behavior increment、Full/M0–M7 资格和冻结依据。
4. 紧迫性不改变 Q1-blind measurement freeze（不看 Q1 的测量冻结）、participant-disjoint validation（参与者隔离验证）和 fail-closed（失败关闭）原则。
