FocusWave 当前已经从“搭建 A/B/C/D 并行监督学习任务”进入 **单模态科学输出收口与正式特征冻结之前** 的阶段。当前允许完成 Behavior（行为）、Ocular（眼部）和 Movement（动作）的单模态科研输出、质量控制、重复测量统计与 feature handoff（特征交接）；当前不允许自动物化最终 feature registry（特征登记表），也不允许启动真实多模态监督学习 fit（拟合）。

`Behavior / Ocular / Movement science output`

Q1/Q2 单模态关联属于正式科学结果，但 Q1/Q2 显著性、outer-test（外层测试）表现和全样本监督学习性能都不能作为特征冻结规则。

## 2. 当前正式队列与真实运行事实

当前 governed cohort（治理队列）为 **116 sessions（场次）、61 participant groups（参与者组）**，Behavior 权威 probe（思维探针）总数为 **2,320**。模态 availability（可用性）与 cohort membership（队列成员资格）继续分开记录。

### Behavior

当前 `FormalScience/Behavior/` 已有本地正式科学输出。正式 30 s probe 窗口覆盖 61 名参与者、116 场、2,320 probes。当前主要科学维度为 RT level（反应时水平）、RT variability（反应时波动）、RT trend（反应时趋势）、Go omission（Go 遗漏）和 No-Go commission（No-Go 抑制错误）。

Behavior producer 不重跑。最终统一特征冻结仍未发生；尤其 RT mean/median（均值/中位数）的正式表示仍保留研究者最终裁决边界。Q1/Q2 关系只能作为单模态科研结果，不能据此自动选特征。

### Ocular / NIR G1

G1 权威真实运行：`NIR_G1_20260912_fixed`，requested / processed / failed = **109 / 109 / 0**。唯一 RGB blink source unavailable（RGB 眨眼来源不可用）为 `sub-041`；该缺失保持 missing，不解释为 zero blink（零眨眼）。

已经冻结的技术参数：

- blink buffer（眨眼缓冲）：`pre200_post200`；
- fixed bin（固定时间箱）：`2 s × 15 bins`，probe 前 30 s；
- bin 内使用 median（中位数），空 bin 不插值；
- `nir_qc_only` 与 `rgb_plus_nir_qc + pre200_post200` 的 cleaning-track（清洗轨道）角色已明确。

仍需研究者最终冻结：

- geometry（几何瞳孔）与 hard `R_seg`（硬分割瞳孔/虹膜比例）的最终角色；
- variability（波动）中的 SD（标准差）与 MAD（中位数绝对偏差）角色；
- linear slope / quadratic curvature（线性斜率 / 二次曲率）的最低真实 temporal span（时间跨度）。

`probe_measurement_candidates.csv` 与 `probe_fixed_bin_trajectories.csv` 仍以本地权威大表为准，云盘缺失不构成重跑 G1 的理由。

### Movement / RGB 5.5

当前 RGB 5.5 真实运行已有 116 场治理骨架、115 场视频、2,320 个 strict pre-probe 30 s（严格探针前 30 秒）窗口，正式 runner（运行器）已完成。P4 不重跑视频 producer，而从既有结果中按科学含义组织 Movement。

第一轮科学角色：

- `body_motion_energy_median`：Movement 主候选；
- pose lateral / vertical（姿态横向 / 纵向）：辅助或 sensitivity（敏感性）；
- radial proximity proxy（径向接近代理）：QC / sensitivity，仅为无量纲代理，不解释为真实物理位移；
- blink（眨眼）：属于 Ocular，不属于 Movement；
- exposure / coverage（曝光 / 覆盖率）：device-support / QC，不作为第一轮 Movement 正式候选。

`FormalScience/Movement/` 与 P4 Ocular×Movement 伪迹敏感性审计代码已实现，但本地真实 materialization（物化）仍待用现有 RGB 5.5 大表与 G1 probe 大表完成。

## 4. 三个 feature handoff 的当前关系

Behavior、Movement、Ocular 的 science-output 层统一采用同一 handoff 语义，至少显式记录：

- scientific feature / candidate representation（科学特征 / 候选表示）；
- predictor column(s)（预测变量列）；
- scientific modality（科学模态）；
- source namespace（来源命名空间）；
- required devices（所需设备）；
- preprocessing dependencies（预处理依赖）；
- measurement/QC status（测量 / 质量控制状态）；
- estimability（可估计性）；
- coverage（覆盖率）；
- redundancy / alternative representation（冗余 / 替代表示关系）；
- temporal anchor / scope / legality（时间锚点 / 范围 / 合法性）；
- report role（报告角色）；
- `registry_ready` 与 `researcher_freeze_required`。

当前 P4 / Ocular 在研究者冻结之前强制维持 `registry_ready = false`，不得把 handoff 接口存在误解成 feature registry 已经冻结。
