## 1. 研究中的“注意”及解释边界

FocusWave 不把任何单一指标当作“真实注意状态”的完整真值。持续注意被视为不能被直接完整观测、并随时间变化的心理构念；实验中只能从不同角度观察它。

| 信息 | 当前含义 |
|---|---|
| Q1 | probe（探针）时点的注意内容自我报告 |
| Q2 | probe 时点的主观困倦/清醒程度，1 更困、4 更清醒 |
| Behavior（行为） | SART 中实际任务表现，如反应时、波动、遗漏、误按、d′ |
| Sensors（传感器） | 瞳孔、眨眼、心率、呼吸、身体运动等生理或动作表现 |

Q1、Q2、行为和传感器可以一致，也可以分离。任何一方都不能仅凭自身被称为“注意真值”。正式报告避免把 Q1 写成 `attention ground truth`（注意真值），也避免把 Q1 预测表现写成“真实注意识别准确率”。

---

## 2. 首轮监督学习目标

首轮监督学习固定回答：

> **面对模型训练中完全未见的新 participant（参与者），利用某个 probe 之前合法可获得的行为与传感信息，预测该 probe 上参与者会报告的 Q1 注意内容。**

模型估计的是：

`P(Q1 report | probe 前合法信息)`

而不是：

`P(true attention state | 信息)`。

当前固定：

1. 推广对象：未见 participant；
2. 预测单位：probe；
3. 首轮标签：`Q1=1` 对 `Q1=2/3/4`；
4. 总体评价：先在 participant 内汇总合法 probe，再在 participant 之间等权；
5. Q1 四分类保留为后续扩展，四类按无序类别处理，不能解释成 1→4 的连续注意水平。

---

## 3. Q2 与事后问卷

### 3.1 Q2

Q2 测量主观困倦/清醒程度，与 Q1 的注意内容不同。首轮不建立平行的 Q2 监督学习，也不把 Q2 作为预测 Q1 的输入。

Q2 可用于解释性关联分析，例如比较：

`特征 ~ Q1`

与

`特征 ~ Q1 + Q2`

若加入 Q2 后 Q1 关系仍稳定，可说明该关系不能完全由同时报告的困倦/清醒程度解释；若明显减弱，则表示两者存在共享变化。不能据此声称已经分离出“纯注意效应”。

### 3.2 事后问卷

事后问卷主要用于整场回顾和背景解释，包括走神大致比例、走神内容与觉察、最难集中阶段、疲惫、开始吃力时间、困倦变化、情绪、任务策略、主观专注能力、平时持续专注时长、前一日睡眠、咖啡因等。

问卷可以：

- 与整场 Q1/Q2 及预测分布做描述性对应；
- 解释即时 probe 与事后回顾不一致；
- 提供睡眠、咖啡因、情绪和策略等背景；
- 在 session（场次）或 participant 层面检查外部关系。

问卷不参与 Q1 标签生成，不作为第二套客观真值，也不用于“验证 Q1 的准确率”。当前代码仓库尚未冻结 questionnaire-derived table（问卷派生表）的机器可读字段 schema，因此 Task A 不应提前硬编码具体问卷字段。

## 4. 行为关联分析与监督学习分开回答

行为首先是任务表现本身，不是 Q1 的替代真值，也不只是机器学习基线。

RQ1 类解释性分析仍直接研究具体行为指标与 Q1/Q2 的关系，包括 RT 水平、RT 波动、RT 趋势、Go omission（Go 遗漏）、No-Go commission（No-Go 误按）、d′ 等。该层回答主观体验和任务表现怎样一致或分离，不能由全特征预测模型中的某个回归系数替代。

同一参与者内 probe 变化与参与者间稳定差异，需要在解释性重复测量分析中按各自方法处理；监督学习的跨参与者泛化性能不能替代这些关联问题。

---

## 5. 具体特征是监督学习的主要解释单位

科研解释的基本单位是最终冻结的具体科学特征，而不是把 producer（特征生成程序）全部输出直接塞入模型。

正式候选可以包括：RT 水平、RT 波动、RT 趋势、Go omission、No-Go commission、d′、瞳孔水平、瞳孔波动、瞳孔趋势、眨眼、RGB 身体运动、毫米波心率/呼吸率等，但必须先获得科学资格并进入 feature registry（特征登记表）。QC（质量控制）字段、置信度和近义统计量不能因“已有列”自动成为正式预测特征。

### 5.1 Standalone：`x -> Q1`

对每个正式特征 `x`，保留单特征模型：

`x -> Q1`

回答：只看这个指标，它与 Q1 报告之间有多少可推广预测信息？

### 5.2 Behavior-conditioned：`B -> B+x`

定义冻结的 Behavior reference（行为参照特征集）为 `B`。它只是参照信息包，不是注意真值。

对每个有资格的传感特征 `x` 比较：

`B -> B+x`

回答：在已经知道近期任务表现后，该传感指标是否还包含 Q1 相关的额外条件预测信息。

### 5.3 Full leave-one-feature-out：`F-x -> F`

定义全部正式可用科学特征组成的 Full model（全特征模型）为 `F`。对每个特征 `x` 比较：

`F-x -> F`

回答：在其他正式信息已经存在时，该特征是否仍提供不可替代信息。

Behavior 内部特征和传感特征在这一层对称。三类比较必须复用同一训练核心、同一外层验证原则和相同公平比较规则。

---

## 6. M0–M7：设备/信息包比较

M0–M7 保留，回答：

> **实际增加某套采集设备及其全部合法信息后，对 Q1 报告的预测是否改善？**

它与具体特征解释不同。即使 `Behavior + mmWave` 优于 Behavior，也不能仅据此判断是心率、呼吸率还是体动起作用；具体来源由第 5 节的特征级比较回答。

### 6.1 特征来源与设备依赖必须分开登记

每个正式特征至少记录：

- `feature_id` 与科学含义；
- 实际 predictor column（预测列）；
- 原始信号来源；
- 所需设备；
- 清洗/预处理依赖；
- standalone / `B+x` / Full / `F-x` 资格；
- 可进入哪些 M0–M7；
- 当前资格状态与版本。

若 NIR 瞳孔使用 RGB 眨眼识别辅助清洗，该表示的实际设备依赖是 NIR+RGB，不能用于声称 NIR-only（仅近红外）设备能力。NIR-only 组合必须使用现实中不依赖 RGB 即可生成的版本。

M0 的 Behavior 部分必须严格等于正式冻结的 `B`，不能额外混入非参照行为特征。

## 7. 验证结构与零个体校准

首轮监督学习固定采用：

`outer participant-disjoint LOSO -> inner participant-grouped GroupKFold(n_splits=5)`

规则：

- 同一 participant 的全部 session/probe 处于同一侧；
- outer-test participant 完全不参与训练分布估计；
- 每个 inner split 中，插补、标准化、数据依赖列处理、候选方案和超参数选择只使用 inner-train；
- inner development 完成后，在完整 outer-train 重新拟合预处理和最终模型，再预测 untouched outer-test；
- 旧独立 `prediction_folds: 5` 不再启动额外外层预测交叉验证。

零个体校准要求预测测试 probe 时，不使用该人的完整 session、未来 probe、未来 RGB/NIR 帧、全场均值、个人完整序列或其他间接未来信息。

## 8. D1：参与者等权训练

若训练折中 participant `i` 有 `n_i` 个合法 probe，则每个 probe 基础训练权重为：

`w_ij ∝ 1 / n_i`

一个 participant 的全部 probe 共同分配相同总训练权重。所有合法 probe 保留，不通过每人抽一个 probe 实现等权。

权重可统一缩放到训练折平均值为 1，以保持 L2 regularization（L2 正则化）参数 `C` 的数值尺度稳定。当前不自动叠加 `class_weight="balanced"`；participant→session→probe 三层等权不作为首轮主训练。

---

## 9. D8：参与者等权预处理

所有数据学习型预处理只在当前训练折估计。

### 9.1 残余单特征缺失

只有上游已判定为合法 residual single-feature missingness（残余单特征缺失）的值才允许训练折内插补。结构性模态缺失、QC 失败、不可估计状态、schema/解析错误均不得伪装成可插补缺失。

对特征 `k`，participant `i` 有 `m_ik` 个有效值时，这些值共同分配该 participant 一票：

`w_ijk^(k) ∝ 1 / m_ik`

使用 participant-equal weighted median（参与者等权加权中位数）。若累计权重恰好在两个相邻不同值之间达到 0.5，取两侧边界值平均。

### 9.2 标准化

插补后按 D1 权重估计训练折 weighted mean（加权均值）和 weighted population SD（加权总体标准差）：

`mu_w = sum(w_ij * x_ij) / sum(w_ij)`

`sigma_w = sqrt(sum(w_ij * (x_ij - mu_w)^2) / sum(w_ij))`

`z_ij = (x_ij - mu_w) / sigma_w`

验证和测试 participant 只应用冻结训练状态，不做个体化中心化。

`included_complete`（完整样本）运行中，模型声明的实际 predictor 若有缺失必须直接失败；不能再由 Task A 静默插补，否则完整样本分析会改变成 missing-aware（缺失感知）分析。

---

## 10. D9：内层参与者宏平均评分

候选 feature scheme（特征方案）与 `C` 的内层选择采用 participant-macro log loss（参与者宏平均对数损失）：

1. 保存每个 inner-validation participant 的逐 probe 概率损失；
2. participant 内先平均得到 `L_i`；
3. 再对完整 inner CV 中全部 validation participant 等权平均；
4. 选择 participant-macro loss 最低的候选；
5. 无法为完整验证 participant 集合生成合法预测的候选不合格，不能静默缩小验证集合。

不能以各 fold 的普通 pooled-probe log loss（合并探针对数损失）再简单平均替代该口径。

---

## 11. D2/D3：最终总体评价

若 `L_ij` 是 participant `i` 的 probe `j` 的概率损失：

`L_i = mean_j(L_ij)`

`L_overall = mean_i(L_i)`

正式总体因此先 participant 内 probe 等权，再 participant 间等权。预测对象始终是 probe；全体 probe 一锅平均只能作为描述/敏感性统计。

session-level performance（场次级性能）主要用于稳定性、设备/同步/QC 排查和场内区分，不设为与 participant-equal overall（参与者等权总体评价）并列的第二个主目标。

## 12. D4–D7：报告与时间结构

### D4：二分类与四分类的边界

二分类 `Q1=1` vs `Q1=2/3/4` 是首轮已实现任务。四分类保留独立心理学含义并按无序类别处理。不得根据正式 outer-test 表现事后决定哪个任务更“主要”。

### D5：probe-sampled trajectory（探针采样轨迹）

从合法 OOF prediction archive（折外预测档案）按真实 probe 时间/顺序生成：

- observed Q1 四分类序列；
- Q1 二分类；
- `P(Q1=1)`；
- predicted binary label；
- Q2（若上游提供）；
- 四分类模型未来实施后对应的类别概率/预测序列。

这些轨迹只代表离散 probe 时点，不自动等同 continuous attention monitoring（连续注意监测），也不能仅凭图形声称识别变化点、持续时间或响应时延。

### D6：问卷时间对应

Q1/Q2/OOF 概率可以与事后问卷中的最难集中阶段、开始吃力时间、困倦变化和整场走神比例等进行 participant/session 层面的探索性对应。问卷时间分辨率较粗且属于回顾性信息，因此该层为描述/探索，不作为 Q1 或模型预测的真值验证。

### D7：session 内区分

二分类 session 内 AUROC（受试者工作特征曲线下面积）只解释为 within-session state discrimination（场内状态区分能力），不是动态追踪。单类 session 记 `NA / not_estimable_single_class` 并报告可估分母。

HMM（隐马尔可夫模型）、状态转移、变化点、滞后关系等真正时间顺序敏感模型当前不属于首轮必做，若未来提出独立动态研究问题再另立合同。

## 13. D10：fixed-OOF participant-cluster bootstrap

采用 fixed-OOF participant-cluster bootstrap（固定折外参与者簇自助法）：

- 以已经完成的合法 OOF 预测为输入；
- participant 为有放回重采样单位；
- 每个抽中的 participant 携带全部合法 probe；
- 每次重新计算与正式总体相同的 participant-equal statistic（参与者等权统计量）；
- 不在 bootstrap replicate（自助重复）中重新训练；
- `n=1000`；
- seed `20260830`；
- 95% percentile CI（百分位置信区间）；
- 成对模型比较使用完全相同的 participant 重采样索引；
- 单类或不可估统计量记录 `NA` 并报告有效 replicate 分母。

该区间表达参与者抽样不确定性，不覆盖模型重新开发不确定性。

## 14. prediction archive 与公平直接比较

每个模型运行至少保存：

- participant/session/probe 稳定键；
- probe 时间/顺序；
- 原始 Q1 与派生标签；
- OOF 概率与预测类别；
- `outer_fold_group`；
- `analysis_set_id`；
- `membership_type`；
- `run_id`、`model_id`、`feature_set_id`；
- 实际使用特征列表、删除列及原因；
- 代码/配置版本；
- 模型失败及原因；
- 与 Behavior 权威 probe/Q1 表的完整性回联状态。

任何直接性能差或增量必须满足：

- 同一 `analysis_set_id`；
- 同一 `membership_type`；
- 同一 participant；
- 同一 probe 成员；
- 同一 outer fold；
- 同一训练、预处理与 inner selection 原则；
- 只改变预先指定的特征或设备信息包。

#42 / Draft PR #46 已建立权威 Q1 回联、期望 `analysis_set × model × outcome` 全集、空归档/整模型缺失拒绝、失败行与 `run_id / feature_set_id / membership_type` 等合同；最终仍需随 A/B 集成验收。

## 15. analysis set 与 `required_features` 的正式语义

Task B 为某个直接比较构造共同分析集合时，`required_features` 必须等于该比较中所有模型实际需要特征的并集。

例如：

`B` vs `B+x`

必须满足：

`required_features = B ∪ {x}`。

无关特征 `y` 不得因为缺失而额外缩小该比较的共同样本。#48 / Draft PR #49 已能把 `analysis_set_id + membership_type + probe_feature_status.value` 物化成 Task A 宽表，但 Task A 还必须显式核对 `required_features` 与实际 model plan（模型计划）的一致性，不能只读取 `comparison_models` 后忽略样本是按哪些特征筛出的。

## 16. fold 内实际特征与比较可估性

训练折内因全缺失、零方差等原因删除列可以是合法技术处理，但不能改变科学问题后继续按原比较解释。

若某 outer fold 中：

- `B+x` 的 `x` 实际被删除；或
- `F` 侧本应包含的 `x` 实际被删除，

则该 fold 不能被解释为“x 的增量为 0”或“x 没有不可替代信息”，而应记录为该 fold 对相应特征贡献 **不可估计**。

paired comparison（成对比较）必须读取 fold audit 中 actual output columns（实际输出列）与 dropped columns（删除列），确认被研究特征真正进入对应模型。建议明确输出 `not_estimable_feature_absent` 或等价状态，并报告有效比较折/participant 分母。

## 17. feature registry 与 missing-aware 的剩余协议要求

### 17.1 布尔字段严格解析

feature registry / YAML / JSON 中的资格字段必须严格解析。不得使用 `bool(raw_value)` 直接处理字符串，因为 Python 中 `bool("false") == True`。

standalone、`B+x`、Full、`F-x`、设备依赖等资格字段均应只接受明确允许的布尔表示，非法值 fail closed（失败关闭）。

### 17.2 真正缺失与 malformed value 分离

`pd.to_numeric(..., errors="coerce")` 会同时把真正缺失和无法解析的坏字符串变成 `NaN`。Task B 不得因此把 malformed value（格式坏值）、parse failure（解析失败）或 schema 错误标成 `single_feature_missing` 后允许插补。

missing-aware 只允许：测量机会存在、源/对齐/native QC（原生质量控制）/producer support（特征生成程序可估计性）均合法，且明确认定为 residual single-feature missingness 的值进入训练折内插补。

## 18. 特征选择的正式逻辑

当前不使用完整正式样本预测表现做 feature selection（特征选择），也不恢复统一 80% coverage（覆盖率）硬门或全样本相关冗余自动删除。

特征进入模型分三层：

1. **科学资格冻结**：依据测量含义、时间合法性、producer 可靠性、QC、设备依赖和研究问题决定候选；outer-test 不参与；
2. **训练数据内部开发**：在预先限定的有限候选表示和超参数范围内，只使用 outer-train 内的 inner participant-grouped CV 完成选择；
3. **fold 内技术可估计性**：已冻结科学特征在某训练折全缺失/零方差时可以无法估计，但该状态必须进入比较资格和报告分母，不能被解释为科学上“没有信息”。

coverage、缺失、零/近零方差和相关冗余可以作为描述性/质量审计，但不在完整正式样本上自动决定科学特征去留。

专用 Task A CI 已在后续实现中通过；仓库通用 CI 的既有 staged-NIR regression（分阶段近红外回归）红灯不能用来否定这组监督学习专用合同，同样也不能把专用 CI 通过当成正式科学结果已放行。

当前剩余高优先级不在“再造一套模型”，而在：

2. fold 内实际特征与 paired comparison 可估性；
3. feature registry 严格布尔解析；
4. missing-aware 真正缺失与 malformed value 分离；
5. Behavior `B`、NIR/RGB/mmWave 正式 feature registry 的上游科学冻结；
6. #41/#40 最终接线；
7. A+B+#41+#42+#48 纵向 integration test（集成测试）和少量真实数据 smoke test（冒烟测试）。

相关 PR 在这些门槛满足前继续保持 Draft，不运行正式性能发布。

## 20. 当前简明结论

FocusWave 首轮监督学习评价的是：**对一个完全未见的新参与者，probe 前的行为和传感信息能在多大程度上预测其随后报告的 Q1 注意内容。**

Q2 和事后问卷帮助解释不同观测之间的一致与分离。具体特征分析回答“哪些信息在起作用”，M0–M7 回答“增加哪些设备/信息包整体有价值”。当前模型训练框架已经基本形成，下一阶段的科学有效性主要取决于：上游特征是否冻结、共同样本是否严格对应实际比较、被研究特征是否真正进入各 fold、跨模块身份/状态协议是否一致，以及真实数据纵向验证是否通过。
