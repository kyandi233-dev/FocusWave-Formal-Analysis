## 1. 当前监督学习究竟回答什么

FocusWave 首轮监督学习的核心使用场景是：**面对一个模型训练中完全未见过的新 participant（参与者），利用某个 probe（探针）之前合法可获得的 Behavior（行为）及传感器信息，预测该 probe 对应的 Q1 注意状态。**

因此三个概念必须固定区分：

1. **推广对象**：未见 participant；
2. **预测单位**：probe；
3. **最终总体汇总**：先在 participant 内对合法 probe 汇总，再在 participant 之间等权。

模型不另外预测“这个 participant 是什么类别”，也不另外预测“这个 session（场次）是什么类别”。participant 与 session 是数据结构、验证结构和结果汇总层级；真正的监督学习输出始终是一行一个 probe 的预测概率和类别。

首轮二分类的逐 probe 输出为：

`P(Q1=1 | 当前 probe 前合法信息)`

四分类实施后则保存：

`P(Q1=1), P(Q1=2), P(Q1=3), P(Q1=4)`

---

## 2. Q1 构念边界保持不变

Q1 是四种**无序**的注意内容/注意状态类别，不是 1→4 的连续注意程度。当前派生二分类为：

`Q1=1` vs `Q1=2/3/4`

它回答“最直观的任务专注自我报告能否与其他注意内容区分”。这一二分类不意味着 2/3/4 是同一个心理状态，也不意味着四类存在单调高低关系。

Q2 属于不同构念，不因为 Q1 的监督学习而自动成为首轮 Q1 预测输入。

四分类不能画成 1→4 连续曲线；应使用四类概率、类别时间带、真实/预测类别离散序列、混淆矩阵等表示。

二分类与四分类回答不同层次的心理学问题。当前阶段**不强行冻结 primary（主要）/secondary（次要）地位**，也不要求为了代码实施先规定报告顺序；两条分析逻辑均保留。正式报告撰写时再根据研究问题组织和篇幅确认叙事主次，但不得根据正式 outer-test（外层测试）结果谁更好而反向决定谁“更重要”。

---

## 3. 外层与内层验证结构保持不变

当前首轮监督学习继续采用：

- 外层 participant-disjoint LOSO（参与者互斥留一参与者验证）；
- 同一 participant 的所有 session 和 probe 必须处于同一侧；
- 测试 participant 完全不参与训练分布估计；
- 内层使用按 participant 分组的交叉验证进行特征方案/超参数选择；
- 插补、标准化、数据依赖列处理、特征选择和超参数选择必须限制在相应训练数据内部；
- 完整外层训练集在选定方案后重新拟合，再预测 held-out participant 的每个 probe。

零个体校准（zero-individual-calibration）继续要求：预测某个测试 probe 时，不得使用该人的完整 session、未来 probe、未来 RGB/NIR 帧、全场均值、未来状态分布，或通过全场 QC/清洗间接泄漏的未来信息。

## 4. D1 已决策：首轮主训练采用参与者等权

首轮监督学习主训练采用 participant-equal training（参与者等权训练）。若当前训练折中 participant `i` 有 `n_i` 个合法 probe，则基础权重原则为：

`w_ij ∝ 1 / n_i`

即该 participant 的全部合法 probe 共同分配其总训练权重，不同 participant 的累计训练权重相同。

这项决定的心理学与统计含义是：项目希望模型对“随机未见参与者”具有稳定推广能力，不希望一个人仅因为参加更多场次、拥有更多 probe，就在模型拟合中自动拥有更高累计影响。

participant→session→probe hierarchical equal training（参与者→场次→探针层级等权训练）不作为首轮主训练。若某 participant 两个 session 经 QC 后分别剩 20 与 5 个合法 probe，层级等权会强制两场各占该人的 50%，从而显著放大低覆盖场次少数残留 probe 的单行权重。该方案可预注册为 sensitivity analysis（敏感性分析），但不与主方案根据正式结果竞争。

为稳定 L2 regularization（L2 正则化）参数 `C` 的数值尺度，训练折内可将样本权重统一缩放到平均权重为 1；具体归一化、预处理和内层评分实现仍分别归入 D8/D9。

不自动叠加 `class_weight="balanced"`。类别权重与 participant 权重对应不同目标，叠加会再次改变各 participant 的累计贡献。

## 5. D2/D3 已决策：最终结果以“新 participant 的 probe 预测”作为主科学对象

### 5.1 主结果的 estimand（目标量）

监督学习最终核心结果定义为：

> **随机遇到一个模型从未见过的新 participant，再随机遇到该 participant 的一个合法 probe 时点，模型对该 probe 的 Q1 状态预测得怎样；加入某一传感器后，这个 probe 级预测是否改善。**

因此总体性能采用：

1. participant 内所有合法 probe 等权汇总；
2. participant 之间等权汇总。

若 `L_ij` 是 participant `i` 的 probe `j` 的概率型损失，则：

`L_i = mean_j(L_ij)`

`L_overall = mean_i(L_i)`

这不是“participant 级预测任务”。预测对象仍然是 probe；participant 等权只规定不同未见参与者对总体统计量贡献相同。

### 5.2 为什么不能直接把全体 probe 一锅平均

若 participant A 有 60 个合法 probe，B 有 20 个，直接对 80 个 probe 等权会让 A 对总体结果贡献 75%。这种统计量更接近“从数据库所有合法 probe 中随机抽一个 probe”。

当前研究要强调对新 participant 的推广，因此正式总体结果应先在人内汇总，再让 participant 一人一票。

### 5.3 session 的正式地位

session-level performance（场次级性能）保留，但**不作为与 probe/participant 并列的主要预测目标，也不另设一个全局 session 等权的主总体 estimand**。

session 层主要承担：

- 稳定性诊断：识别某个 participant 是否只有特定场次表现异常；
- 设备、日期、佩戴、同步、数据质量等场次差异排查；
- within-session state discrimination（场内状态区分能力）等补充指标。

participant→session→probe 层级等权的评价可作为敏感性分析，用于检查主结论是否依赖 participant 内各 session 的合法 probe 数差异，但不改变主 estimand。

因此 D2/D3 不再被描述为“probe、session、participant 三层主结果之间选择哪一个”。三层信息可以保存，但主要科学结论只有一个统一方向：**未见 participant 上的 probe 级状态预测，并以 participant 等权方式汇总。**

## 6. Behavior-anchored incremental comparison 是多模态监督学习的核心证据结构

项目整体科学问题之一仍然是：某个传感器在已有 Behavior 信息基础上是否提供稳定额外信息。因此核心证据结构统一表述为 Behavior-anchored incremental comparison（行为锚定的增量比较），M0-M7 只是具体模型组合名称。

最基本的单模态增量比较包括：

`Behavior -> Behavior + NIR`

`Behavior -> Behavior + RGB`

`Behavior -> Behavior + mmWave`

多模态条件增量还可以比较，例如：

`Behavior + RGB + mmWave -> Behavior + NIR + RGB + mmWave`

前者回答“在已经知道行为以后，这个传感器是否提供额外信息”；后者回答“在行为与其他传感器已经存在时，该模态是否仍有独立额外信息”。

任何直接比较必须保持：

- 同一 `analysis_set_id`；
- 同一 participant；
- 同一 probe 成员；
- 同一外层 participant 划分；
- 同一训练、预处理和超参数选择原则；
- 同一 participant-equal 主训练合同；
- 只改变预先规定的模态特征增量。

因此每一个模态比较都必须在该比较自己的共同有效集合上重新形成 Behavior baseline（行为基线）。不能拿更大全行为样本的 Behavior 性能直接对比更小共同样本上的 `Behavior + sensor` 性能。

### 6.1 增量效应的正式解释

对 participant `i`，可先在每个合法 probe 上计算两个成对模型的损失差：

`delta_ij = Loss_baseline,ij - Loss_added,ij`

再得到 participant 内平均增量：

`Delta_i = mean_j(delta_ij)`

最后 participant 等权汇总：

`Delta_overall = mean_i(Delta_i)`

若 `Delta_overall > 0`，表示：

> 对一个随机未见 participant 的随机合法 probe，加入目标模态后，平均预测损失下降。

因此多模态的主要“增量价值”既不是预测一个完整 participant，也不是预测一个完整 session；它是在**未见 participant 条件下，对具体 probe 状态预测的增益**。

## 7. M0-M7 最终需要报告什么

每个正式模型组合至少保存并报告以下层次的信息。

| 结果 | 主要用途 |
|---|---|
| 完整逐 probe OOF 预测概率与类别 | 最基础的预测档案，支持所有后续评价 |
| 主概率型预测性能 | 回答新 participant 的随机 probe 预测得怎样 |
| participant 内 probe 汇总 + participant 等权总体结果 | 正式总体性能 |
| 行为锚定的成对增量 `Delta_i` 与总体 `Delta_overall` | 回答目标模态是否提供稳定额外信息 |
| participant 间增量分布 | 检查提升是否只来自少数 participant |
| participant-cluster bootstrap（参与者簇自助法）置信区间 | 表达参与者抽样不确定性；完整合同见 D10 |
| probe 概率轨迹 | 展示未见 participant 随实验进程的 probe-sampled state trajectory（探针采样状态轨迹） |
| session-level performance | 稳定性/QC/场次异常诊断 |
| within-session discrimination | 补充回答同一场内不同 Q1 状态的区分能力 |

报告中应明确区分：预测单位是 probe；推广边界由 LOSO 保证为未见 participant；总体推断通过 participant 等权完成。

## 8. probe-sampled state trajectory 与 session 内区分

只要一个完全未见 participant 的每个 probe 都有合法 OOF（out-of-fold，折外）预测，并按真实 probe 时间排序，就可以形成 probe-sampled state trajectory（探针采样状态轨迹）。

二分类可画：

`P(Q1=1 | probe_t)`

四分类可画：

`P(Q1=1), P(Q1=2), P(Q1=3), P(Q1=4)`

该轨迹表示离散 probe 时点的状态预测，不自动等同连续实时监测、转换点识别或响应时延估计。

对于二分类，session 内 AUROC（受试者工作特征曲线下面积）可作为 within-session state discrimination（场内状态区分能力）：固定同一个 participant、同一个 session，检验真实 `Q1=1` probe 是否倾向获得更高 `P(Q1=1)`。

AUROC 不使用 probe 时间顺序，因此不能直接称为动态追踪。单类 session 的 AUROC 必须记为 `NA / not_estimable_single_class`，并报告可估 session 与 participant 的分母。

其最终是否进入正文、补充材料或只用于诊断，可留到正式报告结构确认；它不承担主要总体预测效应。

## 9. participant-equal training 必须落实为完整训练合同

D1 已经确定，因此后续 Task A 代码不能只在 `LogisticRegression.fit()` 增加 `sample_weight`。至少需要统一：

1. 每个 inner training fold（内层训练折）重新计算 participant 权重；
2. 完整 outer training set（外层训练集）重新计算 participant 权重；
3. 插补与标准化如何遵守 participant-equal 原则；
4. 内层候选方案与 `C` 的选择指标如何对应 participant-equal estimand；
5. 最终完整外层重拟合使用同一合同；
6. 权重、列删除、插补、标准化和失败原因均可审计。

如果先算每个 inner fold 的 participant 平均 loss，再简单对 fold 等权平均，fold 大小差异仍可能破坏“所有 validation participant 等权”。因此 D9 应优先采用：收集整个 inner CV（内层交叉验证）中每个 validation participant 的 probe loss，先形成 participant-level loss，再对所有 validation participant 统一平均。

加权中位数、特征缺失后的权重重新归一化、标准化公式和 50% 平局规则仍属于 D8 的实现细节。

## 11. 各模态进入监督学习后的统一与差异

NIR（近红外）、RGB（可见光视频）和毫米波都遵守相同的监督学习合同：

- probe 前合法窗口；
- participant-disjoint LOSO；
- participant-equal training；
- 训练折内数据依赖预处理；
- 同 `analysis_set_id` 的公平直接比较；
- 完整逐 probe OOF 预测；
- participant 内 probe 汇总、participant 等权总体推断；
- Behavior-anchored incremental comparison。

统一的是**训练与比较合同**，不是具体特征字段。各模态 producer（特征生成器）仍应根据自身测量含义产生少量科学合理的候选特征。

Task C/D 等 producer/interface 不自行决定训练权重或最终评价口径；Task B 继续负责权威 probe/Q1 键、模态可用性与质量状态、`analysis_set_id`、共同成员和预测档案完整性。

## 12. 当前已经解决、不再反复开放的问题

1. Q1 是四个无序类别；二分类 `Q1=1` vs `Q1=2/3/4` 是派生任务。
2. Q2 不自动进入首轮 Q1 预测输入。
3. 外层继续 participant-disjoint LOSO；同一人的 session/probe 必须同侧。
4. 预测单位始终是 probe。
5. 首轮主训练采用 participant-equal training。
6. participant→session→probe 层级等权不作为主训练，只可作敏感性分析。
7. 最终主科学问题是：未见 participant 上具体 probe 的状态预测与模态增量。
8. 正式总体评价采用 participant 内合法 probe 等权，再 participant 之间等权。
9. session-level performance 保留为稳定性/质量诊断和补充区分分析，不作为并列主预测目标，不另设 global session-equal 主总体 estimand。
10. Behavior-anchored incremental comparison 是多模态监督学习核心证据结构，M0-M7 是具体模型组合。
11. 模态增量必须在相同 `analysis_set_id`、相同 participant/probe、相同外层划分和相同完整训练合同上成对比较。
12. probe-sampled state trajectory 来自逐 probe OOF 概率；session 内 AUROC 只直接支持场内状态区分。
13. 四分类不能按 1→4 连续注意水平解释。
14. 二分类与四分类均保留其独立研究含义；当前不强制指定报告主次。
15. 不允许根据正式 outer-test 表现反向选择权重、任务主次或评价口径。

## 13. 仍需明确的报告与实现问题

### D4：二分类与四分类的报告组织 —— 当前不要求提前冻结主次

二分类回答“任务专注 vs 其他注意内容”，四分类回答“四种原始注意内容之间的区分”。两者都保留，并遵守相同的参与者互斥验证、参与者等权训练、共同样本和逐 probe 预测原则。

当前阶段只需把两条逻辑、输出和解释边界梳理清楚，不要求为了实施代码先指定 primary/secondary。正式报告撰写时再根据研究问题与叙事结构确认正文主次、章节顺序和篇幅；该确认必须依据理论与研究问题，而不能根据正式结果谁更显著、谁预测更好来事后排序。

### D5：四分类正式指标集合

四分类的指标不必在本轮逻辑梳理中全部定死，但在正式四分类结果进入解释与报告前，应至少明确一个主要概率型指标，并规定必要的区分类和错误结构指标，避免看到结果后按表现挑选指标。同时考虑单 session 类别缺失导致的不可估问题。

### D6：session 内 AUROC 的报告位置

含义已固定为 within-session state discrimination（场内状态区分能力），不承担主要总体预测效应。是否进入正文、补充材料或仅作为诊断，可留到正式报告结构确认。

### D7：是否需要真正时间顺序敏感的动态分析

当前首轮报告若只声称 probe 时点状态预测和 probe-sampled trajectory，则现有 OOF 档案已足够，不需要额外增加 transition/lag（转换/滞后）模型。只有后续报告希望声称连续监测、转换点识别或响应时延时，才需要另立时间顺序敏感分析。

### D8：participant-equal preprocessing（参与者等权预处理）合同

需冻结 weighted median（加权中位数）规则、缺失后的权重归一化、weighted standardization（加权标准化）等具体算法，并保证仅使用当前训练折。

### D9：inner participant-equal scoring（内层参与者等权评分）

原则上应使每个 validation participant 在内层模型选择中等权。优先实现为：形成每个 validation participant 的 participant-level loss，再对全部 validation participant 等权平均；需冻结字段名、失败处理和测试合同。

### D10：bootstrap（自助法）完整合同

## 15. 当前简明结论

FocusWave 首轮监督学习的主问题已经可以清楚表述为：**对模型从未见过的新 participant，在一个具体 probe 时点，利用 probe 前合法信息预测 Q1；通过 participant-disjoint LOSO 保证新参与者泛化，通过 participant-equal training 防止重复参与者在训练中因 probe 更多而占更大累计权重，通过 participant 内 probe 等权、participant 间等权得到正式总体性能。**

多模态价值通过 Behavior-anchored incremental comparison 评价：在完全相同的参与者、probe、外层划分和训练合同下，比较 Behavior baseline 与加入目标传感器后的模型。增量的正式解释是：**对随机未见 participant 的随机合法 probe，加入该模态后预测损失平均改变多少。**

session 层继续保存，用于场次稳定性、QC/设备异常和场内状态区分；它不再与核心 probe 预测问题竞争主结果地位。二分类与四分类当前都保留，正式报告时再确认叙事主次。下一步应转向 participant-equal training 真正需要落到代码的 D8/D9。
