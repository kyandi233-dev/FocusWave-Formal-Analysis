# 1.16.7 RGB 可见行为科学特征冻结

> 日期：2026-09-12
> 状态：first_round_scientific_feature_freeze
> 上游：1.16.4、1.16.6
> Formal 权威分支：codex/code-fix-ledger

本文在已有 RGB 5.5 单模态结果和当前 `Attention-Analysis@codex/1.16-abcd-integration-review` producer 事实基础上，压缩首轮监督学习的 RGB scientific features（科学特征）。单模态结果继续完整保留；本文件只决定哪些 RGB 量进入首轮紧凑 feature registry（特征登记表）。

## 1. 当前代码事实与角色区分

当前 probe 前 30 s RGB 聚合预定义指标包括：`body_motion_energy_median`、`exposure_change_abs_median`、左右/上下 pose direction rate（姿态方向变化率）、`pose_radial_proximity_direction_score_median` 和 `blink_event_rate_per_min`。

其中当前代码已经明确：

- exposure change（曝光变化）与 motion energy 分轨，属于 exposure-control / QC 信息；
- radial proximity direction score 是无量纲方向一致性候选，明确不是物理距离或位移，并在配置中标为 auxiliary mmWave motion QC candidate；
- blink event rate 是当前预定义 probe 指标；
- RGB 5.5 单模态分析可以继续报告方向、运动、眨眼与 Q1/Q2/行为的关系，但这些既有关系不作为监督学习特征准入依据。

## 2. 首轮 RGB 科学特征压缩

首轮正式 RGB 预测输入暂冻结为两个互补科学维度：

1. **visible movement level（可见运动水平）**：`body_motion_energy_median`；
2. **blink event frequency（眨眼事件频率）**：`blink_event_rate_per_min`。

两者分别表征总体可见运动活动和眼部事件频率，科学含义不同，可同时进入 RGB-only、Behavior+RGB 与 Full 模型。

`body_motion_energy_median` 在报告和 feature registry 中应解释为“可见运动能量/活动水平”，避免把它过度命名为纯身体位移或物理运动量；其底层来源可能为 preserved producer 的 global motion energy，当前下游通过 temporal/motion validity 过滤形成 `body_motion_energy`。

## 3. 不进入首轮 Full 的 RGB 字段

### 3.1 `exposure_change_abs_median`

冻结为 QC / confound diagnostic（质量控制/混杂诊断），不作为首轮科学预测特征。理由是 producer 本身明确把 exposure change 与 body motion 分轨，曝光变化首先反映照明/成像条件，而不是一个待解释的注意行为构念。它可以用于检查 `body_motion_energy_median` 是否被光照变化污染，也可以做敏感性调整，但不能因为对 Q1 有预测力就升级为 scientific feature。

### 3.2 `pose_lateral_right_per_sec_median` 与 `pose_vertical_up_per_sec_median`

保留单模态正式结果与 exploratory/sensitivity（探索/敏感性）角色，首轮不进入 Full。当前指标是相机坐标下的 signed direction rate（有符号方向变化率）；30 s 中位数既可能因往返运动相互抵消，也依赖相机坐标方向。已有 5.5 关系可以作为可见姿态行为结果报告，但不足以把“向右/向上”本身预设成跨参与者稳定的注意构念。

若后续确实需要 pose 的第二个 RGB 科学维度，应另行定义对坐标方向更稳健、科学问题更明确的 posture/movement magnitude（姿态/运动幅度）指标，而不是在本轮临时增加。

### 3.3 `pose_radial_proximity_direction_score_median`

冻结为 QC / auxiliary（辅助）角色，不进入首轮科学预测集。当前 producer 明确把它定义为 `dimensionless_direction_agreement_score_not_physical_displacement`，主要用于运动方向确认/毫米波运动质量辅助，不宜解释成“靠近/远离屏幕的真实距离变化”或注意特征。

## 4. 与已有 RGB 5.5 单模态结果的关系

已有 RGB 5.5 结果继续作为正式单模态科学结果保留，包括姿态方向、眨眼候选、运动等与 Block/cycle/Q1/Q2/行为的关系。其作用是描述当前数据中可见行为怎样变化；监督学习的首轮 feature freeze 另按科学含义、测量语义和冗余控制完成。

因此，某方向特征在 5.5 中出现非零置信区间，不自动获得首轮 Full 准入；同理，运动能量单模态关联较弱也不因此自动删除，因为其科学维度与 blink 不同，且后续目标是评价其在 held-out participant（留出参与者）上的预测信息。

## 5. 首轮 RGB feature registry 目标

在不发现真实 producer 质量问题的前提下，RGB 首轮主科学特征为：

- `rgb_visible_movement_level` → predictor column `body_motion_energy_median`；required devices = RGB；
- `rgb_blink_event_frequency` → predictor column `blink_event_rate_per_min`；required devices = RGB。

两者均可登记 standalone `x -> Q1`、Behavior increment `B -> B+x`、RGB-only package、Behavior+RGB package 和 Full 资格。曝光与 pose 辅助字段只进入 QC/描述/敏感性登记，不进入首轮 Full。

最终接线前仍需读取真实 RGB 可用性/QC 输出，确认两项主特征没有系统性不可估问题；若发现 producer 质量退化，回到测量层处理，不以 Q1 结果补救。
