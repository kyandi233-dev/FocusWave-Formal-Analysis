# 1.10 多模态融合分析设计规格（2026-08-31）

> 状态：实现前置规格。实现代理必须先读本规格、`Attention-Analysis/AGENTS.md`、`docs/060-formal-analysis/001-正式多模态V2路径与分析契约.md`、`configs/formal_multimodal_v2.yaml`（fusion 段）和相关契约测试，实现与本规格一致。
> 报告对应：4.5.5 跨模态对齐与统计推断、5.6 多模态增量与互补信息。

## 1. 目标与范围

在共同样本上比较"任务背景/行为基准、三个单模态、三个双模态组合、完整三模态组合"共八种模型对思维探针结局（Q1 注意内容、Q2 警觉程度）的预测性能，评价各传感模态的增量信息与互补性。

本规格只授权：特征级可解释融合 + 规则化逻辑回归主模型 + Random Forest 非线性补充。小型 MLP 等复杂模型为可选第三阶段，不在主线阻塞范围内。

## 2. 共同样本规则（001 契约第 9 节）

严格执行：

```
governed cohort
-> modality availability masks
-> explicit common-available subset for that analysis
-> participant-disjoint validation (LOSO)
-> preprocessing inside training folds
-> report coverage + performance together
```

- 不把缺任何模态的场次从全项目删除；共同子集按"该分析所需的模态集合"逐分析定义。
- 主比较（八组合）使用四模态共同可用的探针观测子集；涉及较少模态的组合可在更大子集上报告敏感性，但**主结论只来自共同子集**。
- 历史阶段性共同样本数字不写入报告。

## 3. 输入特征表

分析单位：探针（probe），主窗口 `pre_30s`。融合键（probe 层）：

`(participant_group_id, session_id, block_id, probe_index_in_block, window_name)`

各模态 probe 级特征表（行 = 探针观测）：

| 模态 | 特征表 | 关键特征（主分析） |
|---|---|---|
| 行为基准 | 正式行为 probe 表（30 s 窗口） | 近期正确 Go RT 中位数/RT-CV、Go 遗漏率（真/预判）、No-Go 误按率、d′（机会数足够时） |
| NIR | NIR probe 特征（冻结端点） | 主指标 pupil_geom_mean_diameter、hard_pupil_fraction 的 within/between 两项；敏感性集 6 指标只进敏感性分析 |
| 毫米波 | 毫米波 probe 特征（身份桥后） | HR、BR、体动相关特征；HR/BR 使用当前核验版本（pre_30s 完整链） |
| RGB | `rgb_probe_pre30s_features.csv`（116 场口径，2320 行 × 30 列） | 运动能量、亮度变化、姿态方向候选、眨眼候选特征 |

- 身份以 `participant_group_id` 为 canonical 分组键；毫米波经 `mapping/mmwave_identity_bridge.csv` 映射（含 R029=R096 分裂标注，按既有标注处理）。
- Q1（4 类名义：完全专注/在任务上没想目标/走神/大脑空白）与 Q2（4 级有序警觉）标签必须与行为正式管线同一来源，不得在融合侧重新推导。
- 输入表只读；融合输出写独立目录，不覆盖任何单模态产物。

## 4. 八组合模型阶梯

| 编号 | 组合 | 特征块 |
|---|---|---|
| M0 | 任务背景/行为基准 | 行为特征 |
| M1 | +NIR | 行为 + NIR 主指标 |
| M2 | +毫米波 | 行为 + 毫米波 |
| M3 | +RGB | 行为 + RGB |
| M4 | NIR+毫米波 | 行为 + NIR + 毫米波 |
| M5 | NIR+RGB | 行为 + NIR + RGB |
| M6 | 毫米波+RGB | 行为 + 毫米波 + RGB |
| M7 | 完整三模态 | 行为 + NIR + 毫米波 + RGB |

所有组合使用同一结局、同一共同子集、同一 LOSO 外层划分与同一评估指标。

## 5. 结局与模型

- Q1（四分类名义）：规则化多项逻辑回归（multinomial logistic regression，L2），与行为正式模型的结局编码一致。
- Q2（四级有序）：规则化多项逻辑回归为主（sklearn 环境内有序累积链接需额外依赖且无规则化，故主分析不引入新依赖；有序信息利用作为敏感性记录，不改变主结论）。
- 补充：Random Forest（相同折内、相同预处理）。
- 可选第三阶段：小型 MLP，仅在主分析完成后评估，独立报告。

## 6. 验证：留一参与者交叉验证（LOSO）

- 外层折 = 参与者（`participant_group_id`），61 折（或共同子集内实际参与者数）。
- 每次将一名参与者的全部实验与探针观测作为测试数据，其余参与者用于训练。
- **标准化、缺失值处理、特征筛选、参数选择均只在训练折内拟合**，再应用到测试折；禁止任何跨折信息泄漏（含身份泄漏：同一参与者的观测不得同时出现在训练与测试）。
- 分类性能指标（共同报告 coverage）：ROC-AUC（Q1 多类别用 one-vs-rest 宏平均；Q2 同口径）、平衡准确率、宏平均 F1、Brier 分数或对数损失。
- 模型间比较：同一测试参与者集合上的配对性能差异及其不确定性（逐折配对，bootstrap 或折间配对 CI）；八组合相对 M0 的增量逐一报告。

## 7. 互补性与边际贡献

- 在八组合基础上，比较每种传感模态在已有信息基础上的性能变化，并考察两模态同时加入的联合增益（互补 vs 重复）。
- 三种传感模态在不同加入顺序下的平均边际贡献（Shapley 式平均，不做因果解释）。

## 10. 明确不做（本规格范围外）

- 不在共同子集之外合并解释不同模态样本。
- 不引入需要逐搏外部验证的 IBI/HRV 特征。
- 不把复杂模型结果伪装成主结果；解释与预测分开报告。
- 不修改任何单模态正式产物与已冻结端点。
