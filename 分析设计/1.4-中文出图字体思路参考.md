# 中文出图字体思路参考（2026-08-31）

> 供各模态出图参考，不规定具体字体名写死。毫米波统计图已按此思路出图且渲染正常（`output/06_正式实验/毫米波验证图_0831/` 四张可作视觉参照）。

## 乱码框的原因

matplotlib 默认字体为 DejaVu Sans，**不含中文字形**。不显式指定中文字体时，中文一律渲染为方框。与操作系统、matplotlib 版本无关，是字体回退问题。

## 可行思路（三个环节，缺一不可）

1. **检测后设置，不写死**：出图前遍历候选中文字体名，用 `font_manager` 查询系统实际安装情况，命中哪个就用哪个。这样同一脚本在装了不同字体库的机器上都能工作，不依赖某台机器的字体。候选顺序可按需求排优先级（如正文宋体优先、标题黑体次之）。

2. **西文回退**：中文字体本身带西文字形但排版一般，设置 sans-serif 列表时把中文字体放前、西文字体（Arial / Times New Roman）放后，matplotlib 3.7+ 按字形回退，中文用中文字体、数字与缩写用西文字体。

3. **负号与特殊字符**：matplotlib 默认用 Unicode 负号（U+2212），多数中文字体缺该字形，会变框。关闭 unicode 负号（改用 ASCII 连字符），轴标签里也避免手写 `−`，统一用 `-`。其他特殊字符（μ、℃ 等）同理，出图时留意 `Glyph missing` 警告即可定位。

## 避坑清单（实测踩过）

- 出图后检查 stderr 有没有 `Glyph XXXX missing from font ...` 警告，有就说明某个字符没字形，换 ASCII 等价字符或换字体；
- matplotlib 3.9+ 部分绘图 API 有变化（如 `boxplot` 的 `labels` 参数改为 `tick_labels`），升级版本后先跑通旧脚本；
- 字体名要精确匹配系统注册名（如 `SimSun`），大小写、空格错误会导致设置静默失效。

## 建议的落地方式

不要在每个出图脚本里复制同一段字体代码。在各自仓库维护一个公共的绘图样式模块（检测字体 + 设置 rcParams + 统一配色），出图脚本 import 调用；语言规则、语义颜色等全局规范继续由 `1.3-图表与分析问题台账.md` 统一管理。
