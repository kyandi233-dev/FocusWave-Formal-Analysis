# FocusWave 质量筛选与覆盖率规则

> 日期：2026-09-10  
> 状态：当前讲解与决策记录  
> 对应讲解提纲：`1.15.1-完整分析流程讲解提纲_20260910.md` 第 2、4、5、6 章。

## 1. 总体原则

质量筛选分为四层：数据与时间结构合法性、各模态自身的原生质量控制、候选特征质量、训练阶段的信息隔离。统一的 80% 规则只用于“候选特征可计算覆盖率”，不用于替代各模态自身的帧级、事件级或信号级质量标准。

## 2. 第 2 章：数据进入分析前的结构质量

### 2.1 正式队列与身份

参与者和场次必须来自正式 cohort；参与者推断与预测使用正式 `participant_group_id`，不得由 session 编号推断身份。模态缺失不得反向定义或缩小行为正式队列。

### 2.2 模态源存在

对 NIR（近红外）、RGB（可见光）和毫米波分别记录源是否真实存在、是否可读取。源缺失属于模态结构性缺失，不应填为 0，也不能等同于“测量值为 0”。

### 2.3 时间窗口合法性

正式主窗口为 probe 前 30 秒。窗口必须严格位于 probe 之前，不包含 probe 锚定试次，不跨 Block 或场次，不使用 probe 之后的未来信息。时间对齐失败的窗口不能作为有效模态观测。

## 3. 第 4 章：各模态自身的原生质量控制

统一原则是先由每个模态自己的测量规则判断原始观测是否有效，再计算 30 秒窗口特征。各模态不强行共享一个“帧有效率 80%”之类的统一阈值。

### 3.1 行为

当前正式规则包括：有效反应时下限为 100 ms；RT-CV（反应时变异系数）至少需要 20 个有效反应时；RT 斜率至少需要 5 个有效反应时；信号检测指标至少需要 4 个有效 Go 机会和 2 个有效 No-Go 机会。Go 遗漏与 No-Go 误按分开处理。

### 3.2 NIR（近红外）

主质量轨要求真实观测、RITnet 分割成功、瞳孔拟合几何为正的有限值，并排除仅由插值得到的观测。严格敏感性轨可进一步排除 ROI（感兴趣区域）裁切、边缘影响和时间异常。左右眼信息保留，双眼都有效时可取平均，否则使用有效单眼。

### 3.3 RGB（可见光）

继续使用当前姿态、眨眼、轨迹与有效帧规则。RGB 的质量标准用于判断帧或事件是否可靠，再据此形成窗口特征。

### 3.4 毫米波

逐 probe 保留是否观测、是否可加载、时间戳覆盖、HR（心率）内部可用窗口比例、HR 置信度、相位稳定性等质量字段。当前不额外人为冻结统一百分比阈值；现有毫米波科学合同仍决定哪些指标允许进入正式候选、哪些只能用于诊断或必须排除。

## 4. 第 5 章：统一候选特征筛选

### 4.1 第一关：定义合法性与数学重复

定义上完全相同的别名只保留一个。例如 `omission_rate` 与 `raw_go_omission_rate` 是兼容别名，不能作为两份独立特征。

存在确定代数关系的变量不能全部作为独立线性特征同时输入模型。当前遗漏分解为：

`总遗漏率 = 真遗漏率 + 时序模糊/预判遗漏率`

描述性分析中三项全部保留，用于报告总量与组成；监督学习中采用项目负责人已确认的方案：

`真遗漏率 + 时序模糊/预判遗漏率`

不再同时加入总遗漏率。这样保留全部独立信息，又避免完全共线。如果后续真实分布显示某一组成指标几乎没有变化，则在预先规定的质量复核中考虑退回“总遗漏率”这一更稳定表示，但不得根据外层测试性能选择表示方案。

### 4.2 第二关：单个特征可计算性

每个 probe 窗口只有在通过该模态原生 QC 且满足该特征自身的最低计算要求时，才记为该特征有效。无法计算时记为缺失，不得用 0 替代。

### 4.3 第三关：特征可计算覆盖率

统一定义：

`特征可计算覆盖率 = 通过该模态 QC 并成功计算该特征的 probe 数 / 该模态真实存在、可读取且正确对齐，因此有机会计算该特征的 probe 数`

主分析候选门槛冻结为：

`特征可计算覆盖率 >= 80%`

低于 80% 的特征不进入首轮主预测候选池，但保留覆盖率、缺失原因和科学价值记录，可进入补充或缺失数据分析。

另行报告两项描述性覆盖指标，不与 80% 门槛混用：

`模态可用率 = 有真实源并成功对齐的 probe 数 / 正式应有 probe 数`

`总体有效率 = 成功得到有效特征值的 probe 数 / 正式应有 probe 数`

### 4.4 第四关：信息量与分布

当前项目已有候选验证基线：至少 3 个不同有效值；零方差特征直接删除。比例指标若 95% 以上有效观测集中在 <=0.02 或 >=0.98，则标记严重地板效应或天花板效应并进入科学复核，不机械自动删除。

### 4.5 第五关：明显重复与经验冗余

对于测量含义相近的候选指标，以 `|Spearman rho| >= 0.90` 作为强经验冗余标记。该阈值用于提醒精简候选集，不作为跨所有不同科学含义变量的机械删除规则。

同一原始信号的均值和中位数若高度重合，应结合测量含义固定一个代表性水平指标，而不是长期把两者同时放入简单线性/逻辑回归。均值与中位数的选择不得依据外层测试集性能。

## 5. 第 6 章：筛选完成后进入监督学习

### 5.1 固定候选池

完成定义检查、可计算性、覆盖率、分布和冗余复核后，得到精简候选特征集。不同模态不要求特征数量完全相同；要求的是科学依据明确、候选集精简，并在相同样本、标签、参与者划分和模型选择条件下比较。

### 5.2 缺失值处理

通过 80% 覆盖率门槛的特征仍允许存在少量缺失。此类缺失在训练流程内处理；插补值、标准化参数和其他数据驱动预处理只能由训练数据估计，再应用于测试参与者。

整个模态结构性缺失与少量特征缺失分开处理。主要公平多模态比较优先使用共同有效分析集合；包含整模态缺失的样本另设明确缺失策略和敏感性分析，不应简单将整个模态全部用中位数填补后与完整模态样本等同解释。

### 5.3 参与者独立验证

外层验证按参与者完全隔离。同一参与者的所有 probe 必须全部位于训练侧或测试侧，测试参与者不能参与候选方案、插补、标准化、模型参数或其他数据驱动决策。

## 6. 当前质量筛选主链

`正式 probe 确定 -> 模态源与时间对齐检查 -> 各模态原生 QC -> 30 秒窗口特征计算 -> 特征可计算覆盖率 >=80% -> 信息量与分布检查 -> 定义重复/数学依赖处理 -> 同类经验冗余精简 -> 固定候选特征集 -> 训练内插补与标准化 -> 参与者独立预测`

## 7. 当前需要在代码层补齐的事项

1. 多模态分析统一输出模态可用率、特征可计算覆盖率和总体有效率，并保留缺失原因。
2. 将 80% 特征可计算覆盖率规则真正接入新版主候选特征流程，而不是只存在于部分行为/RGB 候选验证配置中。
3. 修正当前多模态内层参数选择之前已经基于完整外层训练集拟合预处理的调用顺序，使所有需要数据学习的预处理严格位于对应训练折内部。
4. 修正遗漏特征输入：描述性表保留总遗漏、真遗漏、时序模糊遗漏；监督学习主候选采用“真遗漏率 + 时序模糊/预判遗漏率”，不同时加入总遗漏率。
