# FocusWave 质量筛选与覆盖率规则

> 日期：2026-09-10  
> 状态：当前讲解与决策记录；已按 `1.15.6-覆盖阈值行为遗漏与训练前特征筛选纠偏_20260910.md` 修订  
> 对应讲解提纲：`1.15.1-完整分析流程讲解提纲_20260910.md` 第 2、4、5、6 章。

## 1. 总体原则

质量筛选分为四层：数据与时间结构合法性、各模态自身的原生质量控制、候选特征质量、训练阶段的信息隔离。当前不再使用跨模态统一的“80% 即纳入、低于 80% 即排除”硬门槛。特征可计算覆盖率仍必须完整报告，80% 可作为重点复核参考线，但每类指标是否具有足够数据支持，需要结合其测量定义、缺失来源和稳定性依据判断。

候选过程进一步区分两类决策：研究问题和测量含义能够预先确定的科学候选资格，应在预测模型之前冻结；需要根据本研究样本实际分布或预测表现决定的筛选，只能在相应训练数据内部完成。

## 2. 第 2 章：数据进入分析前的结构质量

### 2.1 正式队列与身份

参与者和场次必须来自正式 cohort；参与者推断与预测使用正式 `participant_group_id`，不得由 session 编号推断身份。模态缺失不得反向定义或缩小行为正式队列。

### 2.2 模态源存在

对 NIR（近红外）、RGB（可见光）和毫米波分别记录源是否真实存在、是否可读取。源缺失属于模态结构性缺失，不应填为 0，也不能等同于“测量值为 0”。

### 2.3 时间窗口合法性

正式主窗口为 probe 前 30 秒。窗口必须严格位于 probe 之前，不包含 probe 锚定试次，不跨 Block 或场次，不使用 probe 之后的未来信息。时间对齐失败的窗口不能作为有效模态观测。

## 3. 第 4 章：各模态自身的原生质量控制

统一原则是先由每个模态自己的测量规则判断原始观测是否有效，再计算 30 秒窗口特征。各模态不强行共享一个统一帧有效率、统一最小 n 或统一缺失比例阈值。

### 3.1 行为

当前代码事实为：有效正确 Go RT 的下限为 100 ms，当前没有 RT 上限；RT-CV（反应时变异系数）在现行 runner 中被 `rt_cv_min_n=20` 门控，RT 斜率被 `rt_slope_min_n=5` 门控；SD（标准差）、MAD（中位数绝对偏差）和 IQR（四分位距）并不存在 `n>=20` 的代码门槛。信号检测指标当前要求至少 4 个有效 Go 机会和 2 个有效 No-Go 机会。

其中 `rt_cv_min_n=20` 和 `rt_slope_min_n=5` 属于当前项目代码阈值，不再表述为领域统一标准。尤其 RT-CV 的 20-trial 规则需要完成测量稳定性审计后再决定是否保留或调整；不得根据“调整到多少能够让覆盖率超过某个百分比”反向选择门槛。

Go/No-Go 身份由正式实验序列决定。当前需要继续审计的是 Go 反应状态和 RT 可用性，而不是重新定义哪些 trial 属于 Go。程序原始 Go omission、有效 RT、刺激前/提前/跨试次边界按键等应在 trial-level（试次级）审计中保持可追溯，但不强制解释成多个互斥的心理机制类别。

### 3.2 NIR（近红外）

主质量轨要求真实观测、RITnet 分割成功、瞳孔拟合几何为正的有限值，并排除仅由插值得到的观测。严格敏感性轨可进一步排除 ROI（感兴趣区域）裁切、边缘影响和时间异常。左右眼信息保留，双眼都有效时可取平均，否则使用有效单眼。

连续 NIR 特征还必须区分“函数数学上能返回数值”和“30 秒窗口具有足够时间支持”。SD、波动量、斜率等可以具有不同最低时间支持要求；具体阈值需依据 producer 实际采样、缺失结构和测量稳定性审计冻结，不能机械复制 RT-CV 的 n=20，也不能把 2–3 个点可计算直接当作科学充分。

### 3.3 RGB（可见光）

继续使用当前姿态、眨眼、轨迹与有效帧规则。RGB 的质量标准用于判断帧或事件是否可靠，再据此形成窗口特征。

### 3.4 毫米波

逐 probe 保留是否观测、是否可加载、时间戳覆盖、HR（心率）内部可用窗口比例、HR 置信度、相位稳定性等质量字段。当前不额外人为冻结统一百分比阈值；现有毫米波科学合同仍决定哪些指标允许进入正式候选、哪些只能用于诊断或必须排除。

## 4. 第 5 章：统一候选特征筛选

### 4.1 第一关：训练前科学资格与定义重复

先根据研究问题、测量含义、代码定义和已知数学关系建立小型、结构化的科学候选库。这一步不使用 Q1 的 p 值、相关显著性、外层测试表现或外层测试参与者的数据分布。

定义上完全相同的别名只保留一个。例如 `omission_rate` 与 `raw_go_omission_rate` 是兼容别名，不能作为两份独立特征。存在确定代数关系的变量也不能全部作为简单线性/逻辑回归的独立输入。

当前 omission 分解为：

`raw Go omission = clean Go omission + timing-ambiguous Go omission`

描述性/QC 层继续保留三项及更细 timing flags，保证程序记分和时序歧义可以追溯。考虑到当前正式数据中 raw omission 本身较少、拆分后的 timing-ambiguous omission 更稀疏，首轮监督学习不再强制使用“clean + timing-ambiguous”两个组成变量。默认主候选改为 `raw_go_omission_rate`；clean 与 timing-ambiguous 作为描述/QC/敏感性候选。只有在训练数据内部确认两个组成指标具有足够非零发生率、有效变异与稳定性，并且拆分具有明确附加解释价值后，才允许把拆分方案作为预定义替代特征方案进入内层比较。

对于连续信号，训练前首先按科学信息维度精简。首轮每条主要连续信号原则上只要求覆盖 level（水平）、variability（波动）和 trend（趋势）：水平量的 mean/median 属于同一家族；波动量中 SD 必须进入初始候选家族，MAD/IQR 可作为稳健替代；趋势保留一个与 producer 实际实现一致的斜率。peak-to-trough（峰谷差）、相邻变化、单位时间变化率、扩张/收缩速度等更细动态量若没有预先明确的额外科学问题，不作为首轮主模型默认输入，可保留在探索/敏感性层。

### 4.2 第二关：单个窗口的特征可计算性与稳定性

每个 probe 窗口只有在通过该模态原生 QC 且满足该特征自身的数据支持要求时，才记为该特征有效。无法计算时记为缺失，不得用 0 替代。

不同指标的数据支持要求允许不同。最低 n、最低有效时间跨度或有效帧要求应来自方法依据、独立开发数据或预先规定的稳定性审计，而不是为了达到某个总体覆盖百分比而调整。

### 4.3 第三关：特征可计算覆盖率与缺失来源

统一定义：

`特征可计算覆盖率 = 通过该模态 QC 并成功计算该特征的 probe 数 / 该模态真实存在、可读取且正确对齐，因此有机会计算该特征的 probe 数`

当前不再把 `>=80%` 作为跨模态统一自动准入硬门。80% 保留为审计参考：当覆盖低于这一水平时，必须重点说明缺失来源和稳定性，但不得仅因低于 80% 自动删除，也不得仅因高于 80% 自动视为合格。

候选资格需要综合判断：该特征是否具有明确测量含义、单窗口估计是否可靠、缺失是否结构性、有效值是否有信息量、缺失处理是否合理，以及其在训练数据中的稳定性。若未来为某一具体指标类别建立了有证据的硬覆盖阈值，应单独记录该依据，不推广为所有模态通用标准。

另行报告：

`模态可用率 = 有真实源并成功对齐的 probe 数 / 正式应有 probe 数`

`总体有效率 = 成功得到有效特征值的 probe 数 / 正式应有 probe 数`

任何依赖本研究样本实际分布的覆盖判断，只能使用当前外层训练参与者；外层测试参与者不参与规则形成。

### 4.4 第四关：信息量与分布

至少记录有效值数量、唯一值数量和方差。零方差特征直接删除；近零方差、严重地板/天花板特征进入科学复核。既有“至少 3 个不同有效值”和“95% 以上比例值集中在 <=0.02 或 >=0.98”继续作为审计标记，不解释为跨所有指标的领域硬标准，也不机械自动删除。

对于 omission 等低发生率事件，重点报告非零窗口比例、参与者覆盖、参与者内/参与者间变异及不同窗口尺度稳定性。若一个拆分后的事件率在绝大多数 30 秒窗口恒为 0，则即使数学上可计算，也不应强制作为独立主预测变量。

### 4.5 第五关：明显重复与经验冗余

对于测量含义相近的候选指标，经验相关用于精简候选，但不能代替科学定义判断。既有 `|Spearman rho| >= 0.90` 可作为强经验冗余审计标记，不作为跨所有指标的领域统一删除定律。

同一原始信号的 mean 与 median、SD/MAD/IQR 等若需要根据本研究实际分布决定代表项，该判断只使用训练参与者。如果候选之间无法按测量原理直接冻结，且需要根据预测表现选择，则将少量预定义特征方案放入 inner cross-validation（内层交叉验证），而不是把所有候选同时塞入模型后再根据外层表现删选。

## 5. 第 6 章：筛选完成后进入监督学习

### 5.1 训练前候选库与每折实际特征集

监督学习之前先冻结科学候选库；进入外层参与者划分后，再由当前外层训练数据完成覆盖、方差、地板/天花板、经验冗余等样本依赖检查。若某项选择依赖预测表现，则进入内层训练/验证。

因此最终可能出现：同一个预冻结候选库在不同外层训练折中产生略有不同的实际特征集。这种差异需要记录，而不能先查看所有正式参与者后得到一个全局“赢家特征集”再声称外层测试完全独立。

### 5.2 缺失值处理

只有已经通过科学资格、单窗口可估计性和训练数据内经验复核的候选，才允许对残留的少量单特征缺失使用训练内插补。整个模态结构性缺失与少量特征缺失分开处理。主要公平多模态比较优先使用共同有效分析集合；包含整模态缺失的样本另设明确缺失策略和敏感性分析。

#### 5.2.1 中位数插补的正式适用边界

当前监督学习主线允许对已合格候选中的少量单特征缺失采用训练数据中位数插补，但必须满足：

1. 插补统计量只能由当前训练数据估计。外层测试参与者不得参与；进行内层交叉验证时，每一个内层训练折单独估计中位数并应用于相应内层验证参与者。
2. 中位数插补只处理“本来存在测量机会、但某个特征在少量 probe 上缺失”的情况。整个模态没有真实源、无法读取或无法正确对齐属于结构性模态缺失，不能用整模态中位数填满后当作完整多模态观测。
3. 插补值用于模型运行，不代表真实生理或行为测量值。
4. 本规则服务于参与者外预测。若后续目标为严格总体参数推断，单次中位数插补可能压缩方差并影响标准误或系数解释，需要另行评估缺失数据方法。
5. 插补不能替代质量控制或稳定性审查。覆盖明显不足、缺失结构异常或测量不稳定的特征，不因“可以插补”而自动获得主候选资格。

### 5.3 参与者独立验证

外层验证按参与者完全隔离。同一参与者的所有 probe 必须全部位于训练侧或测试侧。测试参与者不能参与候选方案、覆盖/分布筛选、插补、标准化、模型参数或其他数据驱动决策。

凡是需要根据预测性能比较的特征方案、算法或超参数，必须在 nested cross-validation（嵌套交叉验证）的内层完成；内层验证参与者同样不能参与相应预处理和筛选参数的拟合。

## 6. 当前质量筛选主链

`正式 probe 确定 -> 模态源与时间对齐 -> 模态原生 QC -> 训练前科学含义预筛 -> 小型结构化候选库 -> 单窗口特征可估计性/稳定性 -> 外层参与者划分 -> 外层训练数据内覆盖/方差/地板天花板/冗余复核 -> 必要时内层比较少量候选方案 -> 完整外层训练集重拟合 -> 外层留出参与者预测`

## 7. 当前需要在代码与审计层补齐的事项

1. 将现有 `candidate_validation.py` 和新版多模态监督学习中的 80% 从自动硬门改为覆盖审计/重点复核参考，并完整输出缺失原因。
2. 对 RT-CV `n>=20` 做测量稳定性审计；在完成前保留其重要科学候选身份，不把当前约 78% 的覆盖率解释为自动失败。明确 SD 不受 n>=20 规则约束。
3. 对 NIR 的 SD、MAD/IQR、斜率等建立各自的数据支持和稳定性审计；不统一套用 RT 的最低 n。
4. 行为监督学习默认使用 `raw_go_omission_rate` 作为 omission 主候选；clean/timing-ambiguous 作为描述/QC/敏感性候选，只有在训练数据内证明拆分稳定且有额外信息时才进入预定义替代方案。
5. 保持 Go 试次身份由正式实验序列定义，同时输出 trial-level 程序记分、RT 可用性和 timing QC 审计，避免把时序诊断标签解释成多个独立心理机制。
6. NIR 首轮主候选按水平 + 波动 + 趋势形成紧凑特征方案；更细动态 producer 输出默认留在探索/敏感性层，除非有明确科学依据升级。
7. 修正当前多模态内层参数选择之前已经基于完整外层训练集拟合预处理的调用顺序，使所有需要数据学习的预处理和选择严格位于对应训练折内部。

本文件与 `1.15.6` 共同构成当前质量筛选正式口径；如与本日更早版本的 `1.15.2/1.15.5` 有冲突，以 `1.15.6` 及本次修订后的本文件为准。
